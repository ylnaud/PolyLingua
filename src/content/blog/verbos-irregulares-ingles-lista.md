Los verbos irregulares del inglés son ese tema que todos odian y nadie puede
evitar. La buena noticia es que no son tantos como parecen, y la mayoría
sigue patrones que, una vez que los ves, hacen que memorizarlos sea mucho más
llevadero.

## Por qué existen los verbos irregulares

En inglés, los verbos regulares forman el pasado agregando **-ed** al final:
_work → worked_, _play → played_. Fácil. Pero un grupo de verbos muy
comunes no sigue esa regla: _go → went_ (no _goed_), _eat → ate_ (no
_eated_). ¿Por qué?

Porque son los verbos más viejos del idioma. Vienen del inglés antiguo
(anglo-sajón), que conjugaba distinto. Los verbos que se incorporaron después
(del francés, del latín) sí adoptaron la regla del **-ed**, pero los más
antiguos conservaron sus formas irregulares... precisamente porque se usan
tanto que nunca tuvieron tiempo de "regularizarse".

Conclusión práctica: **los verbos irregulares son los más frecuentes del
idioma**. No podés evitarlos, pero eso también significa que los vas a
escuchar y leer todo el tiempo, lo cual ayuda a fijarlos.

## Cómo están organizados: base, past simple, past participle

Cada verbo irregular tiene tres formas que tenés que conocer:

| Base form | Past simple | Past participle |
| --------- | ----------- | --------------- |
| go        | went        | gone            |
| eat       | ate         | eaten           |
| see       | saw         | seen            |

- **Base form:** la forma del diccionario. Se usa con
  [Simple Present](/es/en/a1/simple-present) (_I go_, _she goes_).
- **Past simple:** para acciones terminadas en el pasado
  (_I went yesterday_). Se usa con
  [Past Simple](/es/en/a2/past-simple).
- **Past participle:** para tiempos perfectos (_I have gone_) y la voz
  pasiva (_it was eaten_).

## El truco: agrupar por patrón

En vez de memorizar una lista de 100 verbos de corrido, agrupalos por cómo
cambian. La mayoría de los irregulares cae en uno de estos patrones:

### Patrón 1: Las tres formas son iguales (AAA)

Los más fáciles. La misma palabra para todo:

| Base | Past | Participle |
| ---- | ---- | ---------- |
| cut  | cut  | cut        |
| put  | put  | put        |
| let  | let  | let        |
| set  | set  | set        |
| shut | shut | shut       |
| cost | cost | cost       |
| hit  | hit  | hit        |
| hurt | hurt | hurt       |

**Truco:** si el verbo termina en **-t** o **-d** y es corto (una sílaba),
hay buenas chances de que sea AAA.

### Patrón 2: Past y participle iguales (ABB)

El pasado y el participio son iguales, pero distintos de la base:

| Base       | Past       | Participle |
| ---------- | ---------- | ---------- |
| buy        | bought     | bought     |
| bring      | brought    | brought    |
| think      | thought    | thought    |
| teach      | taught     | taught     |
| catch      | caught     | caught     |
| feel       | felt       | felt       |
| keep       | kept       | kept       |
| sleep      | slept      | slept      |
| leave      | left       | left       |
| mean       | meant      | meant      |
| build      | built      | built      |
| spend      | spent      | spent      |
| send       | sent       | sent       |
| lend       | lent       | lent       |
| lose       | lost       | lost       |
| find       | found      | found      |
| have       | had        | had        |
| make       | made       | made       |
| say        | said       | said       |
| tell       | told       | told       |
| sell       | sold       | sold       |
| sit        | sat        | sat        |
| win        | won        | won        |
| stand      | stood      | stood      |
| understand | understood | understood |

**Subpatrones dentro de ABB:**

- Los **"-ought/-aught"**: buy/bring/think → bought/brought/thought. Teach →
  taught. Catch → caught. Todos suenan parecido al final.
- Los **"-ept/-eft/-elt"**: keep → kept, leave → left, feel → felt, sleep →
  slept. La vocal cambia y el final se acorta.
- Los **"-ent/-ent"**: send → sent, spend → spent, lend → lent. La -d final
  se convierte en -t.
- Los **"-old/-old"**: tell → told, sell → sold. Se agrega una -o-.

### Patrón 3: El participio termina en -en (ABC con -en)

| Base   | Past   | Participle |
| ------ | ------ | ---------- |
| eat    | ate    | eaten      |
| give   | gave   | given      |
| take   | took   | taken      |
| see    | saw    | seen       |
| write  | wrote  | written    |
| drive  | drove  | driven     |
| speak  | spoke  | spoken     |
| break  | broke  | broken     |
| choose | chose  | chosen     |
| forget | forgot | forgotten  |
| fall   | fell   | fallen     |
| know   | knew   | known      |
| grow   | grew   | grown      |
| throw  | threw  | thrown     |
| show   | showed | shown      |
| hide   | hid    | hidden     |

**Truco:** muchos de estos siguen el patrón de cambio vocálico
**i → o/a → i/o**: drive → drove → driven, write → wrote → written,
ride → rode → ridden.

### Patrón 4: Cambio vocálico puro (ABC sin -en)

| Base   | Past   | Participle |
| ------ | ------ | ---------- |
| go     | went   | gone       |
| do     | did    | done       |
| come   | came   | come       |
| become | became | become     |
| run    | ran    | run        |
| begin  | began  | begun      |
| drink  | drank  | drunk      |
| sing   | sang   | sung       |
| swim   | swam   | swum       |
| ring   | rang   | rung       |

**Truco del "i-a-u":** begin → began → begun, drink → drank → drunk,
sing → sang → sung, swim → swam → swum, ring → rang → rung. La vocal
del medio cambia de **i → a → u**. Memorizá el patrón, no cada verbo.

### Los rebeldes que no siguen nada

Algunos simplemente hay que memorizarlos:

| Base | Past     | Participle |
| ---- | -------- | ---------- |
| be   | was/were | been       |
| go   | went     | gone       |

_Be_ y _go_ son los más irregulares del idioma. Pero como los usás en cada
frase, se memorizan solos con la práctica.

No intentes memorizar los 100+ de una vez. Empezá por los 20 que más vas a

3. **do** — did — done
4. **go** — went — gone

6. **make** — made — made

## Errores comunes que delatan a hispanohablantes

### 1. Agregar -ed a un irregular

> ❌ _I goed to the store._
> ✅ _I went to the store._

Este es el error más básico y el más común. Si dudás, es mejor usar la forma
irregular (aunque te equivoques de forma) que agregar **-ed**.

### 2. Confundir past simple con past participle

> ❌ _I have went to the store._ (went es past simple)
> ✅ _I have gone to the store._ (gone es past participle)

Con "have/has" siempre va el **past participle** (la tercera columna).

### 3. Regularizar verbos que ya son regulares

Algunos verbos "suenan" como que deberían ser irregulares pero no lo son:

- _work → worked_ (no _workt_)
- _play → played_ (no _plaied_)
- _want → wanted_ (no _wont_)

## Cómo practicar sin aburrirte

1. **Agrupá por patrón**, no por orden alfabético. Memorizar "buy-bought,
   bring-brought, think-thought" juntos es más eficiente que memorizar una
   lista aleatoria.

2. **Usá frases, no palabras sueltas.** En vez de repetir "eat-ate-eaten",
   pensá: _"Yesterday I ate pizza"_ y _"I have eaten too much"_. El contexto
   fija la memoria.

3. **Practicá con ejercicios interactivos.** Las lecciones de
   [Simple Present](/es/en/a1/simple-present) y
   [Past Simple](/es/en/a2/past-simple) en PolyLingua incluyen
   ejercicios de completar, emparejar y escribir que te obligan a usar las
   formas correctas en contexto.

4. **Repaso espaciado.** No repases todo cada día — repasá lo que te cuesta.
   El [sistema de repaso de PolyLingua](/es) marca automáticamente las
   palabras que fallás para que las practiques más.

## Preguntas frecuentes

**¿Cuántos verbos irregulares tiene el inglés?**
Alrededor de 200, pero en la práctica cotidiana usás unos 50-60. Los 20 de
la lista de arriba cubren la gran mayoría de las conversaciones.

**¿Hay alguna regla para saber si un verbo es irregular?**
No hay una regla infalible, pero los verbos de una sílaba que vienen del
inglés antiguo tienden a ser irregulares (go, run, eat, drink, see, know),
mientras que los verbos más largos y de origen latino/francés tienden a ser
regulares (decide, explain, organize).

**¿"Got" o "gotten"?**
En inglés americano, el past participle de _get_ es **gotten** (_I have
gotten better_). En inglés británico es **got** (_I have got better_). Ambos
son correctos — depende del acento que estés aprendiendo.

**¿Se puede decir "dreamed" o tiene que ser "dreamt"?**
Ambos son correctos. Algunos verbos tienen una forma regular e irregular
válidas: _dream → dreamed/dreamt_, _learn → learned/learnt_, _burn →
burned/burnt_. Las formas con **-t** son más comunes en inglés británico.

## En resumen

Los verbos irregulares del inglés no son un muro imposible — son un conjunto
finito de palabras muy comunes que siguen patrones reconocibles. Agrupá por
patrón (AAA, ABB, ABC), empezá por los 20 más frecuentes, practicá con
frases reales, y en unas semanas vas a usarlos sin pensar. Podés empezar
ahora mismo con las [lecciones de inglés A1](/es/en/a1) y
[A2](/es/en/a2) en PolyLingua.
