    text: 'Dove posso prendere il sette?'

anatomy:
  - '«Questo autobus va a...?» = bloque fijo para preguntar si un colectivo llega a un destino.'
  - '«Quanto tempo ci vuole?» = «¿Cuánto se tarda?» — expresión fija impersonal con «volerci».'
  - '«Scenda alla...» = imperativo de cortesía de «scendere». Se usa mucho para dar indicaciones.'

Practicá «Quanto tempo ci vuole?» — es una de las frases más útiles del italiano cotidiano. «Ci vuole» para singular, «ci vogliono» para plural.
