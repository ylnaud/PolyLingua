Tiervokabular ist eines der ersten Themen, das Kinder und Erwachsene gleichermaßen
lernen — und es bringt eine wichtige grammatische Falle mit sich: unregelmäßige
Pluralformen.

## Haustiere (pets)

| Englisch | Deutsch |
| -------- | -------- |
| dog      | Hund     |
| cat      | Katze    |
| bird     | Vogel    |
| fish     | Fisch    |

## Bauernhoftiere (farm animals)

| Englisch | Deutsch |
| -------- | -------- |
| cow      | Kuh      |
| horse    | Pferd    |
| pig      | Schwein  |
| sheep    | Schaf    |
| chicken  | Huhn     |

## Wildtiere (wild animals)

| Englisch | Deutsch  |
| -------- | --------- |
| lion     | Löwe      |
| bear     | Bär       |
| mouse    | Maus      |
| wolf     | Wolf      |

## Der Plural: normalerweise einfach, manchmal unregelmäßig

Die Standardregel ist simpel: hänge "-s" an.

```
cat  → cats
dog  → dogs
bird → birds
```

Aber ein paar häufige Tierwörter brechen diese Regel komplett:

```
mouse → mice   (nicht "mouses")
sheep → sheep  (bleibt unverändert)
fish  → fish   (bleibt meistens unverändert)
```

Diese Ausnahmen muss man einzeln auswendig lernen — es gibt kein Muster, das sie
vorhersagt.

## Ein Tier besitzen

```
I have a dog.
(Ich habe einen Hund.)

I have two cats.
(Ich habe zwei Katzen.)
```

## Der Trick zum Üben

Benenne beim nächsten Spaziergang oder Zoobesuch jedes Tier laut auf Englisch — inklusive
Plural, wenn du mehrere siehst. So verankerst du die unregelmäßigen Formen direkt im
Kontext statt als isolierte Liste.
