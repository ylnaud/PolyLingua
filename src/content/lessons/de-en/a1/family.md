Über die eigene Familie zu sprechen gehört zu den ersten natürlichen Gesprächen in jeder
Sprache. Im Englischen kommt noch ein Vorteil dazu: keine grammatischen Geschlechter, die
das Ganze komplizieren.

## Die Kernfamilie

| Englisch          | Deutsch               |
| ------------------ | ----------------------- |
| family              | Familie                 |
| father / mother     | Vater / Mutter           |
| parents             | Eltern                  |
| son / daughter      | Sohn / Tochter           |
| brother / sister    | Bruder / Schwester       |
| siblings            | Geschwister (Sammelwort) |

## Die erweiterte Familie

| Englisch                   | Deutsch                              |
| ---------------------------- | -------------------------------------- |
| grandmother / grandfather    | Großmutter / Großvater                 |
| grandparents                 | Großeltern (Sammelwort)                |
| aunt / uncle                 | Tante / Onkel                          |
| cousin                       | Cousin/Cousine (dasselbe Wort für beide) |

## Über die eigene Familie sprechen

```
I have two siblings: a brother and a sister.
(Ich habe zwei Geschwister: einen Bruder und eine Schwester.)

My mother's name is Ana.
(Meine Mutter heißt Ana.)

My brother is 20 years old.
(Mein Bruder ist 20 Jahre alt.)
```

## Ein Wort für beide Geschlechter

"cousin" (Cousin/Cousine) ist im Englischen dasselbe Wort für Mann und Frau — falls du
das Geschlecht wirklich klarstellen musst, fügst du "male cousin" oder "female cousin"
hinzu, auch wenn das im normalen Gespräch selten nötig ist.

## Der Trick zum Üben

Beschreibe deinen eigenen Stammbaum laut mit diesen Wörtern — das ist eine natürliche
Art, den Wortschatz zu festigen, während du über etwas sprichst, das du schon gut kennst.
