Über das eigene Zuhause zu sprechen ist eines der ersten Themen, das im Alltag ständig
vorkommt — von der Wohnungssuche bis zur Beschreibung des eigenen Zimmers. Der Schlüssel
dazu ist die Struktur "there is / there are".

## Die Zimmer

| Englisch     | Deutsch      |
| ------------- | ------------- |
| kitchen        | Küche          |
| living room    | Wohnzimmer     |
| bedroom        | Schlafzimmer   |
| bathroom       | Badezimmer     |
| garden         | Garten         |

## "there is" / "there are": das deutsche "es gibt", aber mit Zahl

Im Deutschen bleibt "es gibt" immer gleich, egal ob du von einem oder mehreren Dingen
sprichst. Im Englischen musst du zählen:

```
There is a table.        (Es gibt einen Tisch. — Singular)
There are two chairs.    (Es gibt zwei Stühle. — Plural)
```

Die Frageform stellt einfach "is"/"are" vor "there":

```
Is there a garden?       (Gibt es einen Garten?)
Are there two bathrooms? (Gibt es zwei Badezimmer?)
```

## Präpositionen des Ortes

| Englisch | Deutsch      | Beispiel                              |
| -------- | ------------- | -------------------------------------- |
| in       | in            | The keys are in the drawer.            |
| on       | auf           | The lamp is on the table.              |
| under    | unter         | The cat is under the bed.              |
| next to  | neben         | The sofa is next to the window.        |

## Ein Zimmer beschreiben

```
There is a big table in the kitchen.
(Es gibt einen großen Tisch in der Küche.)

There are two chairs next to the table.
(Es gibt zwei Stühle neben dem Tisch.)
```

## Der Trick zum Üben

Geh durch dein eigenes Zuhause und beschreibe laut jeden Raum mit "there is" / "there
are" — so verknüpfst du die Struktur direkt mit etwas, das du täglich vor Augen hast.
