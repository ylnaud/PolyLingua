Zahlen sind Überlebensvokabular: Preise, Uhrzeiten, Alter, Adressen. Hier ist die
komplette Grundlage von 0 bis 100 — inklusive der Fallen, die Deutschen typischerweise
passieren.

## Von 0 bis 20

| 0-10                               | 11-20                               |
| ----------------------------------- | ------------------------------------ |
| zero, one, two, three, four         | eleven, twelve, thirteen, fourteen   |
| five, six, seven, eight, nine, ten  | fifteen ... nineteen, twenty         |

Achtung: **eleven** und **twelve** sind unregelmäßig — sie folgen keinem Muster. Ab
**thirteen** beginnt das regelmäßige Muster [Grundzahl] + **-teen**.

## Die Zehnerzahlen (Achtung bei "forty"!)

| Zahl | Wort               |
| ---- | ------------------- |
| 20   | twenty               |
| 30   | thirty               |
| 40   | forty (ohne "u"!)    |
| 50   | fifty                |
| 60   | sixty                |
| 70   | seventy              |
| 80   | eighty               |
| 90   | ninety               |

## thirteen vs. thirty: die Betonungsfalle

Beide Wörter sehen fast identisch aus, aber die Betonung liegt an unterschiedlichen
Stellen:

```
thirTEEN  (13) — Betonung auf der zweiten Silbe
THIRty    (30) — Betonung auf der ersten Silbe
```

Das gilt für das gesamte Muster: fourteen/forty, fifteen/fifty, sixteen/sixty usw.
Muttersprachler verlassen sich beim Verstehen fast ausschließlich auf diese Betonung.

## Das Muster von 21 bis 99

```
[Zehner]-[Einer]

21 = twenty-one       47 = forty-seven       99 = ninety-nine
```

Die gleiche Reihenfolge wie im Deutschen (Zehner zuerst), aber ohne das "und" — dafür
mit einem Bindestrich zwischen den beiden Wörtern.

## Die großen Zahlen

```
100 = one hundred (oder einfach "a hundred")
1,000 = one thousand
```

Im Englischen wird bei großen Zahlen ein Komma statt eines Punktes als
Tausendertrennzeichen verwendet: 1,000 nicht 1.000.

## Der Trick zum Üben

Sprich Preise laut aus, sobald du eine englische Zahl siehst — in Apps, auf Kassenzetteln,
in Schaufenstern. Aktives Wiederholen prägt sich viel schneller ein als reines
Auswendiglernen der Liste.
