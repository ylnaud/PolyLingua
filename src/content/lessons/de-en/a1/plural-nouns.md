Die meisten Nomen im Englischen bilden ihren Plural auf einfache, vorhersehbare Weise — mit
ein paar Ausnahmen, die man extra lernen muss.

## Die allgemeine Regel: -s anhängen

```
cat → cats        book → books        table → tables
```

## Die orthografischen Ausnahmen (bleiben trotzdem regelmäßig)

| Endung             | Regel              | Beispiel                          |
| -------------------- | -------------------- | ------------------------------------ |
| -s, -x, -ch, -sh      | füge -es hinzu         | box → boxes, church → churches         |
| Konsonant + y          | y → ies                | city → cities, baby → babies           |
| Vokal + y              | nur -s hinzufügen       | boy → boys, day → days                 |
| -f / -fe               | manchmal f → ves        | leaf → leaves, life → lives            |

## Die Unregelmäßigen, die du auswendig lernen musst

| Singular | Plural   |
| -------- | -------- |
| child    | children |
| man      | men      |
| woman    | women    |
| foot     | feet     |
| tooth    | teeth    |
| mouse    | mice     |
| person   | people   |

## Die, die sich gar nicht ändern

Eine kleine Gruppe von Wörtern ist im Singular und Plural identisch:

```
one sheep, two sheep         one fish, two fish
```

## Der Trick zum Merken der Unregelmäßigen

Es ist eine kleine, geschlossene Gruppe (weniger als 10 gängige Wörter) — lerne sie
gemeinsam als kurze Liste, statt auf eine Regel zu warten, die sie erklärt. Der Rest des
englischen Wortschatzes folgt zuverlässig der -s-Regel.
