Einkaufen ist eine der ersten praktischen Situationen, in denen du dein Englisch im
Alltag brauchst. Hier lernst du die wichtigsten Fragen und Sätze dafür.

## Nach dem Preis fragen

```
How much does it cost?
(Wie viel kostet es?)

How much is this?
(Wie viel kostet das?)
```

## "How much" vs. "How many": zählbar oder nicht?

Diese beiden Fragewörter werden oft verwechselt, aber die Regel ist klar:

| Frageform  | Wann?                        | Beispiel                          |
| ----------- | ------------------------------ | ----------------------------------- |
| How much    | nicht zählbare Dinge            | How much money do you have?         |
| How many    | zählbare Dinge im Plural        | How many apples do you want?        |

Frag dich einfach: Kann ich es zählen (1, 2, 3...)? Wenn ja → How many. Wenn nein
(Geld, Wasser, Zeit) → How much.

## Nützliche Redewendungen beim Einkaufen

```
I'm looking for a jacket.
(Ich suche eine Jacke.)

Can I try this on?
(Kann ich das anprobieren?)

Do you have this in a different color/size?
(Haben Sie das in einer anderen Farbe/Größe?)

It's too expensive.
(Es ist zu teuer.)
```

## Größen und Farben

| Englisch | Deutsch  |
| -------- | --------- |
| size     | Größe     |
| color    | Farbe     |
| small    | klein     |
| medium   | mittel    |
| large    | groß      |

## Der Trick zum Üben

Formuliere beim nächsten Online-Einkauf oder Schaufensterbummel die Fragen laut auf
Englisch, bevor du sie im Kopf ins Deutsche übersetzt — so gewöhnst du dich daran,
direkt auf Englisch zu denken statt zu übersetzen.
