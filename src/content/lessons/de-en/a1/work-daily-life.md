Über die eigene Arbeit zu sprechen gehört zu den ersten praktischen Themen, die im Alltag
auf Englisch vorkommen. Ein paar feste Sätze reichen, um den eigenen Arbeitstag zu
beschreiben.

## Die Frage, die dir gestellt wird

```
What do you do?          (Was machst du beruflich?)
```

Beachte: Das Verb ist **"do"** (machen), nicht "work" — wörtlich "Was machst du?".

## Die Antworten folgen immer demselben Muster

```
I work in an office.        (Ich arbeite in einem Büro)
I work in a shop.           (Ich arbeite in einem Geschäft)
She works in a shop.        (Sie arbeitet in einem Geschäft)
```

Achte auf das "s" bei "she works" — genau wie beim Simple Present üblich.

## Die Arbeitszeit: from ... to ...

```
I work from nine to five.        (Ich arbeite von neun bis fünf)
I take a break at eleven.         (Ich mache um elf eine Pause)
I have a meeting at three.        (Ich habe um drei eine Besprechung)
```

## Wortschatz rund ums Büro

| Englisch      | Deutsch              |
| --------------- | ----------------------- |
| work            | die Arbeit                |
| the office      | das Büro                  |
| the boss        | der Chef                  |
| the meeting     | die Besprechung            |
| take a break    | eine Pause machen           |

## Ein kompletter Satz

```
I work in an office, from nine to five, and I take a break at eleven.
(Ich arbeite in einem Büro, von neun bis fünf, und mache um elf eine Pause)
```

## Der Trick zum Üben

Beschreibe deinen eigenen Arbeitstag in drei Sätzen: wo du arbeitest, deine Arbeitszeit und
wann du eine Pause machst. Verwende dabei immer dieselbe Struktur und ändere nur die
Angaben.
