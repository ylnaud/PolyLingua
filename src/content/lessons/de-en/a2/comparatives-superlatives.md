Dinge zu vergleichen ist ein grundlegendes Sprachwerkzeug, und das Englische wählt
zwischen zwei Wegen — abhängig von der Länge des Adjektivs. Das ist anders als im
Deutschen, wo fast jedes Adjektiv einfach "-er" bzw. "am -sten" bekommt (schnell →
schneller → am schnellsten) — im Englischen entscheidet die Silbenzahl, welcher Weg
gilt.

## Die Längenregel

| Adjektivtyp          | Komparativ  | Superlativ      | Beispiel                        |
| ---------------------- | ------------ | ----------------- | ---------------------------------- |
| Kurz (1 Silbe)         | -er          | the -est          | tall → taller → the tallest        |
| Endet auf -y           | -ier         | the -iest         | happy → happier → the happiest     |
| Lang (3+ Silben)       | more + Adj.  | the most + Adj.   | expensive → more expensive         |

## Vollständige Beispiele

```
This car is faster than that one.              (Komparativ)
This is the fastest car in the world.            (Superlativ)

This book is more interesting than that one.    (Komparativ)
This is the most interesting book I've read.     (Superlativ)
```

## Die wichtigsten unregelmäßigen Formen

| Grundform | Komparativ       | Superlativ             |
| ---------- | ----------------- | ------------------------- |
| good       | better             | the best                   |
| bad        | worse              | the worst                  |
| far        | farther/further    | the farthest/furthest      |

## Gleichheit ausdrücken

Um zu sagen, dass zwei Dinge gleich sind, benutze "as...as":

```
This book is as interesting as that one.
(Dieses Buch ist so interessant wie jenes)
```

## Der Trick für Adjektive mit 2 Silben

Manche zweisilbigen Adjektive (wie "happy", "easy") folgen der kurzen Regel (-ier);
andere (wie "modern", "famous") bevorzugen "more". Wenn du unsicher bist, ist "more +
Adjektiv" fast immer eine sichere und korrekte Wahl.
