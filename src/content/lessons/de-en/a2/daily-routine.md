Den eigenen Tagesablauf zu beschreiben ist eines der natürlichsten Gespräche im Simple
Present — die perfekte Gelegenheit, diesen Wortschatz zu üben.

## Die wichtigsten Routine-Verben

| Englisch                    | Deutsch                 |
| ---------------------------- | ------------------------ |
| wake up                      | aufwachen                |
| get up                       | aufstehen (aus dem Bett) |
| get dressed                  | sich anziehen            |
| have breakfast/lunch/dinner  | frühstücken/mittagessen/zu Abend essen |
| go to work/school             | zur Arbeit/Schule gehen  |
| go to bed                    | ins Bett gehen           |

## Häufigkeitsausdrücke

| Englisch  | Deutsch    |
| --------- | ---------- |
| always    | immer      |
| usually   | normalerweise |
| often     | oft        |
| sometimes | manchmal   |
| rarely    | selten     |
| never     | nie        |
| every day | jeden Tag  |

## Eine vollständige Routine aufbauen

```
I usually wake up at 7am. I get up and get dressed quickly.
I have breakfast at 7:30, and then I go to work.
I never skip breakfast — it's my favorite meal.
```

## Wo die Häufigkeitsausdrücke stehen

Häufigkeitswörter (always, usually, often, sometimes, never) stehen **vor** dem
Hauptverb, aber **nach** "to be":

```
I always have breakfast.        (vor dem Verb)
I am always tired in the morning. (nach "am")
```

## Der Trick zum Üben

Erzähl deine eigene Tagesroutine laut im Simple Present mit diesen Häufigkeitsausdrücken
— das ist eine der natürlichsten Arten, Wortschatz und Grammatik gleichzeitig zu
festigen.
