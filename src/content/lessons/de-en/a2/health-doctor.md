Beschreiben zu können, wie man sich fühlt, ist unverzichtbar, wenn man reist oder
einfach im englischsprachigen Umfeld krank wird. Hier ist der Grundwortschatz für den
Arztbesuch.

## Häufige Körperteile

| Englisch | Deutsch  |
| -------- | -------- |
| head     | Kopf     |
| throat   | Hals     |
| stomach  | Magen/Bauch |
| arm      | Arm      |
| leg      | Bein     |

## Grundlegende Symptome

| Englisch    | Deutsch       |
| ----------- | -------------- |
| headache    | Kopfschmerzen  |
| fever       | Fieber         |
| cough       | Husten         |
| sore throat | Halsschmerzen  |

## Sätze für den Arzt

```
I have a headache.
(Ich habe Kopfschmerzen)

My throat hurts.
(Mir tut der Hals weh)

I have a fever and a cough.
(Ich habe Fieber und Husten)
```

## Was der Arzt dir sagen kann

```
You should take this medicine.
(Du solltest diese Medizin nehmen)

You should rest and drink water.
(Du solltest dich ausruhen und Wasser trinken)
```

## "have" vs. "hurt": zwei Arten, Schmerz zu beschreiben

Du kannst "I have a headache" (ich habe Kopfschmerzen) oder "My head hurts" (mir tut
der Kopf weh) sagen — beides ist korrekt und sehr gebräuchlich:

```
I have a stomachache.  =  My stomach hurts.
(Ich habe Bauchschmerzen / Mir tut der Bauch weh)
```

## Der Trick zum Üben

Wenn du dich das nächste Mal schlecht fühlst (oder dir einfach ein Symptom vorstellst),
übe laut, es mit "I have a..." und "My... hurts" zu beschreiben — so festigst du beide
Strukturen gleichzeitig.
