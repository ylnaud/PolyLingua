Emma beendet die Woche und denkt über ihre Ausgaben nach: Sie spart für eine Reise, also
sind das die Geld-Sätze, die sie am häufigsten braucht.

## Die Frage, die man zuerst stellen sollte

```
Can I pay by card?           Kann ich mit Karte zahlen?
— Cash only, please.          Nur Bargeld, bitte.
```

Es lohnt sich, das **vorher** zu fragen, nicht erst nach der Bestellung.

## Geld abheben

```
I need to withdraw some cash.      Ich muss etwas Bargeld abheben.
Where's an ATM?                     Wo gibt es einen Geldautomaten?
I don't have any cash on me.        Ich habe kein Bargeld dabei.
```

"Cash" bedeutet Bargeld — nicht mit "Kasse" verwechseln ("box" ist die Kiste).

## Sparen und Ausgaben

```
I'm saving up for a trip.          Ich spare für eine Reise.
How much do I owe you?              Wie viel schulde ich dir?
```

## Ein vollständiger Satz

```
I need to withdraw some cash because I'm saving up for a trip.
(Ich muss etwas Bargeld abheben, weil ich für eine Reise spare)
```

## Der Trick zum Üben

Merk dir zuerst **"Can I pay by card?"** — den brauchst du am häufigsten, so wie Emma
vor jedem Einkauf. Danach kommt "I'm saving up for ...", das für jedes Sparziel passt.
