"There is/are" ist dein Werkzeug, um zu beschreiben, was existiert oder sich an einem
Ort befindet — und wird viel öfter gebraucht, als die wörtliche Übersetzung "dort
ist/sind" vermuten lässt. Auf Deutsch sagst du "es gibt", ohne über "dort" nachzudenken
— genau das leistet "there is/are" im Englischen.

## Die Grundformel

| Singular            | Plural                  |
| -------------------- | ------------------------ |
| There is a cat.      | There are two cats.      |
| There isn't a cat.   | There aren't any cats.   |
| Is there a cat?       | Are there any cats?      |

## some vs. any: die entscheidende Regel

| Kontext          | Wort  | Beispiel                 |
| ------------------ | ----- | -------------------------- |
| Bejahter Satz     | some  | There are some books.      |
| Verneinung        | any   | There aren't any books.    |
| Frage             | any   | Are there any books?       |

## Eine höfliche Ausnahme

Bei Fragen, die etwas anbieten (statt neutral nach Information zu fragen), wird "some"
sogar in der Frage verwendet:

```
Would you like some coffee?    (Möchtest du Kaffee? — das ist ein Angebot, keine neutrale Frage)
```

## Die vollständige Struktur in der Praxis

```
There is a park near my house.        (Es gibt einen Park in der Nähe meines Hauses)
There aren't any restaurants here.     (Es gibt hier keine Restaurants)
Are there any shops nearby?            (Gibt es Geschäfte in der Nähe?)
```

## Der Trick, um "there" nicht mit "their" zu verwechseln

"There is/are" (es gibt) hat nichts mit "their" (ihr/ihre) oder "they're" (sie
sind/befinden sich) zu tun — sie klingen gleich, werden aber unterschiedlich
geschrieben und bedeuten völlig verschiedene Dinge. Achte beim Schreiben besonders
darauf, da es im Deutschen keine vergleichbare Verwechslungsgefahr gibt.
