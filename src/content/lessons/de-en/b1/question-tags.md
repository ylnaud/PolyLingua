Im Deutschen hängst du einfach "oder?", "nicht wahr?" oder "gell?" an einen Satz und
fertig. Im Englischen ist das etwas komplizierter: Der **Question Tag** übernimmt genau
das Hilfsverb des Hauptsatzes und kehrt seine Polarität um.

## Die Grundregel: die Wippe

```
positiver Hauptsatz  →  negativer Tag
You are tired,        aren't you?

negativer Hauptsatz  →  positiver Tag
You aren't tired,     are you?
```

Der Tag besteht immer aus zwei Teilen: dem passenden **Hilfsverb** (be, do, have, oder
einem Modalverb wie can, will, should) und dem **Pronomen**, das zum Subjekt passt.

## Welches Hilfsverb nehme ich?

| Hauptsatz enthält     | Tag benutzt          | Beispiel                           |
| ---------------------- | --------------------- | ----------------------------------- |
| to be (is/are/was)     | to be                 | She is late, isn't she?             |
| Vollverb (kein Hilfsverb sichtbar) | do/does/did | He works here, doesn't he?  |
| Modalverb (can, will…) | dasselbe Modalverb    | They can swim, can't they?          |
| have (als Hilfsverb)   | have                  | You have finished, haven't you?     |

Steht im Hauptsatz kein sichtbares Hilfsverb (also ein einfaches Vollverb wie "like"
oder "work"), springt automatisch **do/does/did** ein – genau wie bei normalen Fragen
und Verneinungen.

## Drei Sonderfälle zum Auswendiglernen

**"I am"** bildet den Tag unregelmäßig:

```
I'm late, aren't I?      (nicht "amn't I")
```

**"Let's"** (ein Vorschlag) hat immer denselben festen Tag:

```
Let's have lunch, shall we?
```

**Imperative** (Aufforderungen) bekommen meist "will you?":

```
Close the door, will you?
```

## Vorsicht bei versteckten Verneinungen

Wörter wie "never", "no", "nothing" oder "hardly" machen einen Satz grammatikalisch
negativ, auch ohne "not". Der Tag ist dann trotzdem positiv:

```
She never calls, does she?
```

Die Betonung beim Sprechen verrät übrigens die Absicht: eine fallende Intonation
bedeutet, du bist dir sicher und erwartest Zustimmung; eine steigende Intonation
bedeutet, du fragst wirklich nach.
