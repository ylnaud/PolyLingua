"So" und "such" verstärken beide eine Aussage – auf Deutsch übersetzt du oft beide mit
"so". Im Englischen entscheidet aber ein einziges Kriterium darüber, welches Wort
richtig ist: **Steht ein Nomen dabei oder nicht?**

## so: nur mit Adjektiv oder Adverb, kein Nomen

```
so + Adjektiv:   The film was so boring.
so + Adverb:     She speaks so quickly.
```

Sobald ein Nomen ins Spiel kommt, funktioniert "so" allein nicht mehr:

```
❌ It was so a boring film.
❌ It was so boring film.
```

## such: braucht immer ein Nomen

```
such + Nomen (Plural):            They are such nice people.
such + a/an + Adjektiv + Nomen (Singular): It was such a boring film.
```

Bei einem zählbaren Nomen im Singular kommt der unbestimmte Artikel "a"/"an" **zwischen
such und dem Adjektiv**:

```
such a nice day       such an interesting book
```

## Die Konsequenz-Struktur: so...that / such...that

Beide Wörter bilden häufig eine Struktur mit "that", die eine Folge oder Konsequenz
ausdrückt:

```
so + Adjektiv + that:              It was so cold that we stayed home.
such + a + Adjektiv + Nomen + that: It was such a cold day that we stayed home.
```

Beide Sätze bedeuten dasselbe – der Unterschied liegt nur darin, ob ein Nomen (day)
Teil der Aussage ist.

## Die Eselsbrücke

Frag dich: "Ist da ein Nomen im Satz, das ich verstärken will?" Ja → such (plus
Artikel bei Singular). Nein, nur ein Adjektiv oder Adverb → so.

```
so tired            such a tiring day
so expensive         such expensive shoes
```
