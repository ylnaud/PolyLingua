Wörter wie "but", "so" und "and" reichen für die Alltagssprache, aber in formellen
Texten — Aufsätzen, Berichten, akademischen Arbeiten — brauchst du präzisere
Konnektoren. In dieser Lektion lernst du die wichtigsten fortgeschrittenen
Verbindungswörter des Englischen und wie man sie richtig einsetzt.

## Gegensatz ausdrücken: however, nevertheless, although, despite

Diese vier Wörter drücken alle einen Gegensatz aus, funktionieren aber grammatisch
unterschiedlich.

**however / nevertheless** — stehen am Satzanfang (oder nach einem Semikolon), gefolgt
von einem Komma, und verbinden zwei vollständige Sätze:

```
The report was well written. However, it lacked concrete data.
The plan was risky; nevertheless, they decided to go ahead.
```

**although / even though** — leiten einen vollständigen Nebensatz mit Subjekt und Verb
ein:

```
Although it was raining, we went for a walk.
```

**despite / in spite of** — folgt ein Nomen oder eine -ing-Form, NIE ein vollständiger
Satz mit konjugiertem Verb:

```
Despite the heavy rain, the match was not cancelled.
Despite losing the match, the team stayed positive.
```

```
❌ Despite it was raining, we went out.
✅ Despite the rain, we went out.
✅ Although it was raining, we went out.
```

## Ergänzung hinzufügen: moreover, furthermore, in addition

Diese Konnektoren fügen einen weiteren, oft stärkeren Punkt hinzu — typisch für
Argumentationstexte:

```
The hotel was expensive. Moreover, the service was poor.
The plan is unrealistic. Furthermore, it is far too costly.
In addition to being expensive, the flight was delayed.
```

## Konsequenz ausdrücken: consequently, as a result, therefore

Diese Wörter zeigen eine logische Folge:

```
The project was delayed. Consequently, the team decided to work overtime.
It rained heavily all week. As a result, the harvest was poor.
She missed the deadline. Therefore, her application was rejected.
```

## Kontrast zwischen zwei Fakten: whereas, while

"Whereas" und "while" vergleichen zwei gegensätzliche Fakten innerhalb eines Satzes,
ohne unbedingt einen "Widerspruch" auszudrücken — eher einen reinen Unterschied:

```
Northern Europe has cold winters, whereas southern Europe has mild ones.
Some students prefer online classes, while others prefer face-to-face teaching.
```

## Zusammenfassung: Konnektor nach Funktion wählen

| Funktion    | Konnektoren                        |
| ------------ | ------------------------------------ |
| Gegensatz (2 Sätze) | however, nevertheless, nonetheless |
| Gegensatz (1 Satz mit Verb) | although, even though        |
| Gegensatz (+ Nomen/-ing) | despite, in spite of            |
| Ergänzung    | moreover, furthermore, in addition   |
| Konsequenz   | consequently, as a result, therefore |
| Kontrast/Vergleich | whereas, while                  |

Der Schlüssel ist nicht nur die Bedeutung, sondern auch die **Grammatik**, die jeder
Konnektor verlangt — ein falsch angewendetes "despite" vor einem vollständigen Satz
ist einer der häufigsten Fehler fortgeschrittener Lernender.
