Bedingungssätze (Conditionals) verbinden eine Bedingung mit ihrer Konsequenz: "Wenn X
passiert, dann passiert Y." Im Englischen gibt es dafür feste Zeitform-Kombinationen,
die du nicht frei mischen darfst. In dieser Lektion lernst du die beiden wichtigsten
Typen für die Gegenwart und Zukunft: **First Conditional** und **Second Conditional**.

## First Conditional: reale Möglichkeit in der Zukunft

Das First Conditional beschreibt eine Bedingung, die **wirklich eintreten könnte** —
etwas Realistisches, keine Fantasie.

**Struktur:**

```
If + Simple Present, ... will + Infinitiv
If it rains, I will stay home.
```

Weitere Beispiele:

- If you study hard, you will pass the exam.
- If we leave now, we will catch the train.
- If she calls me, I will tell her the news.

**Wichtige Regel:** Nach "if" steht **niemals** "will" — auch wenn sich der Satz auf
die Zukunft bezieht. Das Simple Present übernimmt hier die Funktion der Bedingung:

```
❌ If it will rain, I will stay home.
✅ If it rains, I will stay home.
```

## Second Conditional: hypothetische Situationen

Das Second Conditional beschreibt etwas **Unwahrscheinliches, Unmögliches oder rein
Hypothetisches** in der Gegenwart oder Zukunft — eine Fantasie, keine reale Erwartung.

**Struktur:**

```
If + Simple Past, ... would + Infinitiv
If I had more money, I would buy a car.
```

Weitere Beispiele:

- If I won the lottery, I would travel the world.
- If she spoke English fluently, she would work abroad.
- If we lived in Berlin, we would visit museums every weekend.

**Achtung:** Das Simple Past im if-Satz bezieht sich hier NICHT auf die Vergangenheit —
es signalisiert nur, dass die Situation unwahrscheinlich oder hypothetisch ist.

## Die besondere Form "were"

Im formellen Second Conditional verwendet man für alle Personen (auch "I", "he", "she",
"it") die Form **were** statt "was":

```
If I were you, I would apologize.
If he were richer, he would buy a house.
```

Das ist besonders in der festen Redewendung "If I were you..." (An deiner Stelle...)
sehr gebräuchlich, um Ratschläge zu geben.

## First vs. Second Conditional: der Unterschied auf einen Blick

| Typ    | if-Satz      | Hauptsatz          | Bedeutung                          |
| ------ | ------------ | ------------------- | ----------------------------------- |
| First  | Simple Present | will + Infinitiv   | reale, mögliche Bedingung           |
| Second | Simple Past  | would + Infinitiv  | hypothetische, unwahrscheinliche Bedingung |

Vergleiche:

```
If it rains, I will stay home.        → Es könnte tatsächlich regnen.
If it rained every day, I would move. → Reine Fantasie, unwahrscheinlich.
```

## Häufiger Fehler: Zeitformen mischen

Die Zeitformen der beiden Typen dürfen niemals gemischt werden:

```
❌ If I study more, I would get better grades.
❌ If I studied more, I will get better grades.
✅ If I study more, I will get better grades.       (First)
✅ If I studied more, I would get better grades.    (Second)
```

Merke dir: Present + will gehören zusammen (First), Past + would gehören zusammen
(Second). Diese Kombination ist der Schlüssel, um beide Typen sicher zu unterscheiden.
