Du kennst bereits First, Second und Third Conditional — jeder mit einer festen
Zeitkombination. Aber in der echten Sprache passen nicht alle Situationen sauber in
eins dieser drei Muster. **Mixed Conditionals** kombinieren zwei verschiedene
Zeitbezüge in einem einzigen Satz.

## Muster 1: Vergangenheit → Gegenwart

Die häufigste Mixed-Conditional-Form beschreibt eine unerfüllte Bedingung in der
**Vergangenheit**, deren Konsequenz sich bis in die **Gegenwart** auswirkt:

```
If + Past Perfect, ... would + Infinitiv
If I had studied medicine, I would be a doctor now.
```

Weitere Beispiele:

```
If we had left earlier, we would be home by now.
If she had taken that job, she would be living in Berlin today.
If I had saved more money, I would not be worried now.
```

Erkennungszeichen: Wörter wie **now**, **today**, **at the moment** im Hauptsatz
signalisieren, dass die Konsequenz in der Gegenwart liegt, obwohl die Bedingung in
der Vergangenheit passiert (oder eben nicht passiert) ist.

## Muster 2: Gegenwart → Vergangenheit

Das umgekehrte Muster beschreibt eine dauerhafte Eigenschaft oder einen Zustand in
der **Gegenwart**, der eine Konsequenz in der **Vergangenheit** hatte:

```
If + Simple Past, ... would have + Past Participle
If she were more organized, she would have finished the project on time.
```

Weitere Beispiele:

```
If he were not so lazy, he would have passed the exam.
If I did not have so much work, I would have gone to the party last night.
```

Hier beschreibt der if-Satz keine einmalige vergangene Handlung, sondern eine
**dauerhafte Charaktereigenschaft oder einen Zustand** (organisiert sein, faul sein,
viel Arbeit haben) — deshalb Simple Past statt Past Perfect.

## Warum das nützlich ist

Im echten Leben hängen Gegenwart und Vergangenheit oft zusammen: eine Entscheidung
von früher wirkt sich heute aus, oder eine dauerhafte Eigenschaft hat in der
Vergangenheit ein bestimmtes Ergebnis verhindert. Die klassischen drei Conditionals
reichen dafür nicht aus — Mixed Conditionals schließen diese Lücke.

## Übersicht

| Muster | if-Satz | Hauptsatz | Bedeutung |
| ------- | -------- | ----------- | ----------- |
| Vergangenheit → Gegenwart | Past Perfect | would + Infinitiv | unerfüllte Bedingung früher, Auswirkung jetzt |
| Gegenwart → Vergangenheit | Simple Past | would have + Past Participle | dauerhafter Zustand jetzt, Auswirkung früher |

Der Trick, um Mixed Conditionals sicher zu bilden: Frag dich für JEDEN Satzteil
getrennt, "Bezieht sich das auf die Vergangenheit oder auf die Gegenwart?" — und
wähle die Zeitform für if-Satz und Hauptsatz unabhängig voneinander.
