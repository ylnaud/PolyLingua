Das Third Conditional ist das komplexeste der klassischen Conditionals, weil es sich
komplett auf die Vergangenheit bezieht — es beschreibt Situationen, die **anders hätten
sein können, aber nicht waren**. Man benutzt es oft, um Bedauern (regret) auszudrücken.

## Die Struktur: zwei Vergangenheitsformen kombiniert

```
If + Past Perfect, ... would have + Past Participle
If I had studied, I would have passed the exam.
```

Beide Teile des Satzes schauen zurück in die Vergangenheit — anders als beim First
Conditional (Zukunft) oder Second Conditional (Gegenwart/hypothetisch).

Weitere Beispiele:

- If she had got up earlier, she would not have missed the bus.
- If we had known, we would have helped you.
- If it had rained, the match would have been cancelled.

## Warum Past Perfect und nicht Simple Past?

Der if-Satz braucht das **Past Perfect** (had + Past Participle), weil er sich auf
etwas bezieht, das VOR dem Ergebnis passiert (oder eben nicht passiert) ist:

```
If I had studied, ...
      ↑
  hätte ich VORHER gelernt (aber ich habe es nicht getan)
```

## Der häufigste Fehler: "have" vergessen

Im Hauptsatz ist die Struktur **would have + Past Participle** — nicht einfach "would"
allein. Deutschsprachige Lernende vergessen das "have" besonders oft, weil im Deutschen
"hätte" allein schon reicht ("ich hätte bestanden"):

```
❌ If I had studied, I would passed the exam.
✅ If I had studied, I would have passed the exam.
```

## Verneinte Formen

Sowohl der if-Satz als auch der Hauptsatz können verneint werden:

```
If I hadn't studied, I would have failed the exam.
If she had got up earlier, she would not have missed the bus.
```

## Third Conditional zum Ausdrücken von Bedauern

Das Third Conditional ist die natürliche Struktur, um über verpasste Gelegenheiten oder
Fehler in der Vergangenheit nachzudenken:

```
If I had known you were in town, I would have called you.
If we had left earlier, we would have caught the flight.
```

## Übersicht: die drei Conditionals im Vergleich

| Typ    | if-Satz         | Hauptsatz                   | Zeitbezug            |
| ------ | ---------------- | ----------------------------- | ---------------------- |
| First  | Simple Present   | will + Infinitiv              | Zukunft, real          |
| Second | Simple Past      | would + Infinitiv             | Gegenwart, hypothetisch |
| Third  | Past Perfect     | would have + Past Participle  | Vergangenheit, unerfüllt |

Diese drei Strukturen bilden zusammen das Grundgerüst der englischen Bedingungssätze —
das Third Conditional schließt die Reihe ab, indem es den Blick fest auf das lenkt, was
hätte sein können, aber nie war.
