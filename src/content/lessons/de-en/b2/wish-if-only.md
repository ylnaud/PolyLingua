"Ich wünschte..." — im Englischen gibt es dafür die feste Struktur **wish**, mit
unterschiedlichen Zeitformen je nachdem, ob sich dein Wunsch auf die Gegenwart, die
Vergangenheit oder das Verhalten einer anderen Person bezieht.

## Wunsch/Bedauern über die Gegenwart: wish + Simple Past

Wenn du etwas an der aktuellen Situation anders haben möchtest, benutzt du **wish +
Simple Past** — genau wie beim Second Conditional signalisiert das Past hier keine
Vergangenheit, sondern etwas Hypothetisches:

```
wish + Simple Past
I wish I had more free time.
```

Weitere Beispiele:

```
I wish I lived closer to my family.
She wishes she spoke French fluently.
We wish we had a bigger house.
```

## Bedauern über die Vergangenheit: wish + Past Perfect

Um über etwas zu sprechen, das in der Vergangenheit anders hätte sein sollen,
benutzt du **wish + Past Perfect**:

```
wish + Past Perfect
I wish I had studied harder for the exam.
```

Weitere Beispiele:

```
She wishes she had taken that job.
I wish I hadn't said that.
We wish we had left earlier.
```

## Beschwerde über andere: wish + would

Wenn dich das Verhalten einer **anderen Person** stört und du dir wünschst, dass sie
es ändert, benutzt du **wish + would + Infinitiv**. Diese Form benutzt man NICHT für
sich selbst:

```
wish + Person + would + Infinitiv
I wish you would stop smoking.
```

Weitere Beispiele:

```
I wish it would stop raining.
She wishes her neighbours would be quieter at night.
```

```
❌ I wish I would study more.   (falsch — nicht für sich selbst)
✅ I wish I studied more.        (richtig — wish + Simple Past)
```

## Die Form "were" statt "was"

Genau wie beim Second Conditional benutzt man formell **were** für alle Personen
nach "wish":

```
I wish I were taller.
He wishes he were more confident.
```

## "if only": emotionalere Version von "wish"

**If only** folgt exakt denselben Zeitformregeln wie "wish", klingt aber
emotionaler und dramatischer — oft mit einem Ausrufezeichen:

```
If only I had more time!
If only I hadn't missed the flight!
If only it would stop raining!
```

## Zusammenfassung

| Situation | Struktur | Beispiel |
| ----------- | ---------- | ---------- |
| Bedauern Gegenwart | wish/if only + Simple Past | I wish I had more time. |
| Bedauern Vergangenheit | wish/if only + Past Perfect | I wish I had studied harder. |
| Beschwerde über andere | wish + would + Infinitiv | I wish you would stop smoking. |

Der Schlüssel ist immer derselbe wie bei den Conditionals: die Zeitform nach "wish"
zeigt NICHT die reale Zeit an, sondern wie hypothetisch oder unerfüllt der Wunsch
ist.
