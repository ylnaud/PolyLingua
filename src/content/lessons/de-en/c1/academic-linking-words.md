In akademischen Texten reichen and, but und so nicht mehr aus. C1-Englisch
verlangt praezisere Bindewoerter, die genau zeigen, in welcher logischen Beziehung
zwei Ideen zueinander stehen. Am einfachsten lernst du sie in drei Familien.

## Familie 1: Kontrast

```
nevertheless / nonetheless    (dennoch, trotzdem)
however                          (jedoch)
whereas / while                    (waehrend, im Gegensatz dazu)
notwithstanding                      (ungeachtet, sehr formell)
```

```
The plan has clear risks. Nevertheless, the board approved it.
Profits rose in the first quarter, whereas they fell in the second.
```

## Familie 2: Zusatz

```
furthermore / moreover      (ausserdem, des Weiteren)
in addition                   (zusaetzlich)
```

```
The study is methodologically sound. Furthermore, its sample size is unusually large.
```

## Familie 3: Folge

```
consequently                (folglich)
therefore / thus              (daher, somit)
as a result                    (infolgedessen)
```

```
The company failed to adapt. Consequently, it lost significant market share.
```

## Warum die Unterscheidung wichtig ist

Ein falsch gewaehltes Bindewort veraendert die logische Beziehung zwischen zwei
Saetzen komplett. "Furthermore" statt "Nevertheless" zu benutzen suggeriert
Uebereinstimmung, wo eigentlich ein Gegensatz gemeint war - das ist in einem Essay
oder wissenschaftlichen Text ein inhaltlicher, kein bloss stilistischer Fehler.
