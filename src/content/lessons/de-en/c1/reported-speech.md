Wenn du wiedergibst, was jemand anderes gesagt hat, benutzt das Englische keine
Anführungszeichen wie das Deutsche mit dem Konjunktiv — es nutzt eine systematische
Verschiebung der Zeitformen, die man **backshift** ("Rückverschiebung") nennt.

## Die Backshift-Regel: ein Schritt zurück

| Direkte Rede        | Indirekte Rede    |
| -------------------- | ------------------ |
| Present Simple       | Past Simple         |
| Present Continuous   | Past Continuous     |
| Past Simple          | Past Perfect         |
| will                  | would                |
| can                   | could                |
| must                  | had to                |

```
Direkt:     "I am hungry."        →  Indirekt: She said she was hungry.
Direkt:     "I will help you."    →  Indirekt: He said he would help me.
```

## Weitere Änderungen, die mit dem Backshift einhergehen

Nicht nur das Verb ändert sich — auch Zeit- und Ortsangaben:

| Direkt   | Indirekt      |
| -------- | -------------- |
| now      | then            |
| today    | that day          |
| tomorrow | the next day       |
| here     | there                |
| this     | that                  |

```
Direkt:     "I'll finish it tomorrow."
Indirekt:   He said he would finish it the next day.
```

## Die Ausnahme, die nach fortgeschrittenem Niveau klingt

Wenn das Gesagte weiterhin wahr, heute noch gültig oder eine allgemeine Regel ist,
**darf** ein fortgeschrittener Sprecher den Backshift weglassen:

```
"The Earth is round." → She said the Earth is round. (oder "was round", beides ist korrekt)
```

Zu erkennen, wann du diese Regel ignorieren darfst — ohne falsch zu klingen —, ist genau
das, was ein C1-Englisch von einem mechanischen, überkorrigierten Englisch unterscheidet.
