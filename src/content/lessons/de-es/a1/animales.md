Tiere gehören zu den ersten Themen, über die man im Alltag spricht — sei es
über Haustiere, den Bauernhof oder einen Zoobesuch. Mit diesem Grundwortschatz
und dem Verb "tener" (haben) kannst du bereits einfache Sätze bilden.

## Haustiere

| Spanisch  | Deutsch |
| ---------- | -------- |
| el perro   | der Hund |
| el gato    | der Kater / die Katze |
| el pájaro  | der Vogel |
| el pez     | der Fisch |

## Bauernhof- und Wildtiere

| Spanisch   | Deutsch |
| ----------- | -------- |
| el caballo  | das Pferd |
| la vaca     | die Kuh  |
| la oveja    | das Schaf |
| el león     | der Löwe |

## Männlich und weiblich bei Tieren

Bei vielen spanischen Tierbezeichnungen zeigt die Endung das Geschlecht an:

```
el gato   → männlich (Kater)
la gata   → weiblich (Katze)

el perro  → männlich (Rüde)
la perra  → weiblich (Hündin)
```

Endet das Wort auf -o, ist es meist maskulin; endet es auf -a, meist feminin.
Das funktioniert nicht bei allen Tieren (z. B. bei "el pez", Fisch, das immer
maskulin bleibt), aber bei sehr vielen Haustieren ist es eine zuverlässige
Faustregel — anders als im Deutschen, wo Wortgeschlecht und Endung viel
seltener zusammenhängen.

## "Tener" benutzen, um über Haustiere zu sprechen

"Tener" bedeutet "haben" und ist das zentrale Verb, um über eigene Tiere zu
sprechen:

```
Tengo un perro.        (Ich habe einen Hund.)
Tengo una gata.         (Ich habe eine Katze.)
¿Tienes un animal?      (Hast du ein Tier?)
```

## Zusammenfassung

Mit diesen acht Wörtern und dem Verb "tener" kannst du bereits erzählen,
welche Tiere du hast oder magst — ein kleiner, aber sehr nützlicher
Grundwortschatz für den Alltag.
