Im Deutschen kennst du drei Genera: der, die, das. Das Spanische reduziert das auf
**zwei**: maskulin und feminin — ein neutrales Genus wie "das" gibt es nicht. Die gute
Nachricht: anders als im Deutschen lässt sich das Genus bei den meisten Wörtern gut an
der Endung erkennen.

## Die bestimmten und unbestimmten Artikel

| Genus    | bestimmt Sg. | bestimmt Pl. | unbestimmt Sg. | unbestimmt Pl. |
| -------- | ------------- | ------------- | --------------- | --------------- |
| maskulin | el            | los           | un              | unos             |
| feminin  | la            | las           | una             | unas             |

## Genus an der Wortendung erkennen

Anders als im Deutschen, wo die Endung kaum etwas über das Genus verrät, hilft dir im
Spanischen eine einfache Faustregel:

| Endung          | Genus fast immer | Beispiel              |
| ---------------- | ------------------ | ----------------------- |
| -o                | maskulin           | el libro, el sol         |
| -a                | feminin            | la mesa, la casa         |
| -ción, -sión      | feminin            | la información, la pasión |
| -dad, -tud        | feminin            | la ciudad, la actitud     |

## Die Ausnahmen: -a, aber maskulin

Eine kleine Gruppe von Wörtern griechischen Ursprungs endet auf -a, ist aber trotzdem
maskulin — eine feste Liste, die man auswendig lernt:

```
el mapa       →  die Karte
el día        →  der Tag
el problema   →  das Problem
el sistema    →  das System
```

Umgekehrt gibt es auch feminine Wörter mit -o-Endung, allen voran **la mano** (die
Hand) — eine Einzelausnahme, die jeder Anfänger irgendwann lernt.

## El agua: der phonetische Sonderfall

Vor femininen Wörtern, die mit einem BETONTEN a-Laut beginnen, wird aus la
automatisch el — nicht weil sich das Genus ändert, sondern weil zwei betonte a-Laute
hintereinander (la agua) unangenehm klingen:

```
el agua fría   →  das kalte Wasser   (agua bleibt feminin!)
las aguas      →  die Wasser (Plural, la kehrt zurück)
```

Das Adjektiv (fría) bleibt feminin — nur der Artikel wechselt kurz zu el, rein aus
Aussprachegründen. Dieselbe Logik gilt für el águila (der Adler, feminin) oder el aula
(der Klassenraum, feminin).

## Die Falle: deutsches Genus ist kein Vorbild

Verlass dich niemals auf das deutsche Genus, um das spanische vorherzusagen:

| Spanisch    | Genus im Spanischen | Deutsch     | Genus im Deutschen |
| ------------ | --------------------- | ------------ | -------------------- |
| el sol       | maskulin               | die Sonne    | feminin               |
| el puente    | maskulin               | die Brücke   | feminin               |
| la leche     | feminin                | die Milch    | feminin               |
| el libro     | maskulin               | das Buch     | neutral               |

Es gibt keinen Trick, der dir das Genus vom Deutschen ableitet — du musst es für jedes
Wort einzeln lernen, am besten direkt zusammen mit dem Artikel.

## Zusammenfassung

Lerne jedes neue Substantiv sofort MIT seinem Artikel zusammen, als wäre es ein
einziges Wort — "el mapa", nicht nur "mapa". Verlass dich auf die -o/-a-Regel als
ersten Anhaltspunkt, aber merke dir die Ausnahmen (el mapa, el día, la mano) und den
Sonderfall el agua als feste Extras.
