Einkaufen ist eine der ersten Alltagssituationen, in der du dein Spanisch im
echten Leben brauchst — sei es im Supermarkt, im kleinen Geschäft oder auf
dem Markt. Mit diesem Wortschatz kommst du durch jedes Einkaufsgespräch.

## Wo einkaufen?

| Spanisch        | Deutsch |
| ----------------- | -------- |
| el supermercado    | der Supermarkt |
| la tienda          | das Geschäft |
| el mercado         | der Markt |
| la caja            | die Kasse |

## Nach dem Preis fragen

Die wichtigste Frage beim Einkaufen:

```
¿Cuánto cuesta esto?     (Wie viel kostet das?)
¿Cuánto cuestan?          (Wie viel kosten sie? — Plural)
```

Anders als im Deutschen ("Was kostet das?") brauchst du im Spanischen immer
das Fragewort **cuánto** (wie viel) zusammen mit dem Verb **costar** (kosten)
— "¿Qué cuesta esto?" klingt für Muttersprachler ungewöhnlich.

## Höflich etwas kaufen wollen

```
Quisiera comprar pan.        (Ich möchte Brot kaufen.)
Quisiera esto, por favor.     (Ich möchte das, bitte.)
```

**Quisiera** ist die höfliche Form von "querer" (wollen) — vergleichbar mit
dem deutschen "ich möchte" im Gegensatz zum direkteren "ich will" (quiero).
Für ein Geschäft klingt "quisiera" freundlicher und ist die übliche Wahl.

## Wichtige Wörter rund ums Bezahlen

| Spanisch    | Deutsch |
| ------------ | -------- |
| el precio    | der Preis |
| el dinero    | das Geld |
| pagar        | bezahlen |
| la caja      | die Kasse |

## Ein typisches Gespräch

```
Cliente: ¿Cuánto cuesta esto?         (Kunde: Wie viel kostet das?)
Vendedor: Cuesta diez euros.          (Verkäufer: Das kostet zehn Euro.)
Cliente: Quisiera pagar en la caja.   (Kunde: Ich möchte an der Kasse bezahlen.)
```

## Zusammenfassung

Mit "¿Cuánto cuesta...?", "Quisiera comprar..." und den Wörtern für Geschäft,
Kasse und Preis kannst du bereits ein vollständiges Einkaufsgespräch führen —
egal ob im Supermarkt oder im kleinen Laden um die Ecke.
