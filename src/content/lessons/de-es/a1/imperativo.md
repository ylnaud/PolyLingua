Der Imperativ dient dazu, Befehle zu geben, Bitten auszusprechen oder
Vorschläge zu machen. Das Spanische unterscheidet dabei vier Anredeformen:
**tú** (informell, du), **usted** (formell, Sie), **vosotros** (informell,
ihr — vor allem in Spanien) und **ustedes** (formell oder allgemein, Sie/ihr
— in Lateinamerika die einzige Plural-Anrede).

## Die tú-Form: der Überraschungseffekt

Bei regelmäßigen Verben entspricht die bejahte tú-Form des Imperativs genau
der **er/sie-Form** im Präsens Indikativ — nicht der tú-Form selbst:

```
él habla    →  ¡Habla!      (Sprich!)
él come     →  ¡Come!       (Iss!)
él escribe  →  ¡Escribe!    (Schreib!)
```

Im Deutschen ist der Bezugspunkt für den Imperativ die du-Form selbst (du
sprichst → sprich!). Im Spanischen musst du gedanklich zur er/sie-Form
wechseln — ein Muster, das für Deutschsprachige zunächst ungewohnt ist, sich
aber schnell einprägt.

## Die usted-Form: die "umgekehrte" Endung

Für usted (und ustedes) benutzt du eine Endung, die genau umgekehrt zur
normalen Präsensendung ist:

```
-ar-Verben  → Endung -e/-en   (hable, hablen)
-er-Verben  → Endung -a/-an   (coma, coman)
-ir-Verben  → Endung -a/-an   (escriba, escriban)
```

Beispiele:

```
¡Hable más despacio!      (Sprechen Sie langsamer! — usted)
¡Coma despacio!           (Essen Sie langsam! — usted)
¡Escriban aquí!           (Schreiben Sie hier! — ustedes)
```

## Die vosotros-Form: die einfachste Regel

Für vosotros nimmst du einfach den Infinitiv und ersetzt das End-**r** durch
ein **-d**:

```
hablar → ¡Hablad!     (Sprecht!)
comer  → ¡Comed!      (Esst!)
escribir → ¡Escribid! (Schreibt!)
```

Diese Form ist in Spanien im Alltag sehr präsent, wird in Lateinamerika aber
praktisch nicht benutzt — dort ersetzt **ustedes** sowohl die formelle als
auch die informelle Plural-Anrede.

## Zusammenfassung

| Form | Bildung (hablar) | Beispiel |
| ----- | ------------------ | -------- |
| tú | wie er/sie-Präsens | ¡Habla! |
| usted | umgekehrte Endung | ¡Hable! |
| vosotros | Infinitiv, -r → -d | ¡Hablad! |
| ustedes | umgekehrte Endung + n | ¡Hablen! |

Präg dir vor allem die tú-Form gut ein, denn sie ist die häufigste im
Alltag — und denk daran: Sie sieht aus wie "er/sie spricht", nicht wie "du
sprichst".
