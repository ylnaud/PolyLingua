Im Deutschen ist der Plural eine der größten Hürden: Es gibt mindestens fünf
verschiedene Endungsmuster (-e, -er, -n/-en, -s, oder gar keine Endung), oft
noch kombiniert mit einem Umlaut (der Vater → die Väter). Im Spanischen ist
das viel einfacher — fast alle Wörter folgen einer von zwei klaren Regeln.

## Regel 1: Wort endet auf einen Vokal → +s

Endet ein spanisches Substantiv auf a, e, i, o oder u, hängst du einfach ein
-s an:

```
la mesa    → las mesas    (der Tisch → die Tische)
el libro   → los libros   (das Buch → die Bücher)
la calle   → las calles   (die Straße → die Straßen)
```

Das ist die häufigste Regel, weil die meisten spanischen Substantive auf
einen Vokal enden.

## Regel 2: Wort endet auf einen Konsonant → +es

Endet das Wort auf einen Konsonant (r, l, n, d, s je nach Betonung usw.),
hängst du -es an:

```
el profesor → los profesores  (der Lehrer → die Lehrer)
el papel    → los papeles     (das Papier → die Papiere)
la ciudad   → las ciudades    (die Stadt → die Städte)
```

Denk daran: -es ist immer eine ganze zusätzliche Silbe (pro-fe-SO-res), nicht
nur ein Buchstabe wie im Deutschen "-s".

## Die Sonderregel: Wörter auf -z

Es gibt eine feste Rechtschreibregel im Spanischen: Der Buchstabe **z** kann
nicht direkt vor einem **e** stehen. Deshalb wird bei Wörtern, die auf -z
enden, das z im Plural zu **c**:

```
el lápiz → los lápices   (der Bleistift → die Bleistifte)
la voz   → las voces     (die Stimme → die Stimmen)
```

Das ist keine Ausnahme in der Aussprache, sondern reine Rechtschreibung —
merk sie dir zusammen mit der Konsonantenregel, denn -z zählt für die
Pluralbildung als Konsonant (also +es, nur eben mit c statt z).

## Der Artikel ändert sich mit

Vergiss nicht, dass sich beim Plural auch der bestimmte Artikel ändert:

```
el  → los   (maskulin)
la  → las   (feminin)
```

## Zusammenfassung

| Endung im Singular | Regel | Beispiel |
| ------------------- | ------ | -------- |
| Vokal (a, e, i, o, u) | +s | mesa → mesas |
| Konsonant | +es | profesor → profesores |
| -z | z → c, dann +es | lápiz → lápices |

Zwei Regeln plus eine kleine Rechtschreib-Ausnahme — das ist alles, was du
brauchst, um fast jeden spanischen Plural richtig zu bilden. Kein Umlaut,
keine Wortliste zum Auswendiglernen wie im Deutschen.
