Im Deutschen sind Verbendungen dein bester Freund: ich spiele, du spielst, er spielt —
die Endung verrät fast immer, wer handelt. Im Spanischen darfst du dieses Vertrauen
BEHALTEN: die drei regelmäßigen Verbklassen (-ar, -er, -ir) haben klar unterscheidbare
Endungen.

## Regelmäßige -ar-Verben: hablar (sprechen)

| Pronomen | Form     |
| -------- | -------- |
| yo       | hablo    |
| tú       | hablas   |
| él/ella/usted | habla |
| nosotros | hablamos |
| vosotros | habláis  |
| ellos/ellas/ustedes | hablan |

## Regelmäßige -er-Verben: comer (essen)

| Pronomen | Form    |
| -------- | ------- |
| yo       | como    |
| tú       | comes   |
| él/ella/usted | come |
| nosotros | comemos |
| vosotros | coméis  |
| ellos/ellas/ustedes | comen |

## Regelmäßige -ir-Verben: vivir (leben, wohnen)

| Pronomen | Form    |
| -------- | ------- |
| yo       | vivo    |
| tú       | vives   |
| él/ella/usted | vive |
| nosotros | vivimos |
| vosotros | vivís   |
| ellos/ellas/ustedes | viven |

## Die Falle: usted teilt sich die Form mit él/ella

Im Deutschen bekommt "Sie" eine eigene, großgeschriebene Anredeform, aber grammatisch
verhält es sich wie die 3. Person Plural (Sie sprechen = sie sprechen). Im Spanischen
ist es umgekehrt: **usted** (Sie, formell) benutzt dieselbe Verbform wie él/ella (er/
sie) — die 3. Person SINGULAR, nicht Plural:

```
Usted habla español.   →  Sie sprechen Spanisch. (formell, Singular-Verbform)
Él habla español.       →  Er spricht Spanisch.
```

Für mehrere Personen formell gibt es **ustedes**, das die Pluralform (hablan) nutzt —
mehr dazu in der Lektion über Personalpronomen.

## -ar, -er, -ir: drei feste Muster

Die drei Verbklassen unterscheiden sich nur im Vokal der Endung (a/e/i), das Muster
selbst (Person → Endung) bleibt gleich. Sobald du hablar sicher konjugierst, folgen
comer und vivir demselben Rhythmus, nur mit anderem Vokal.

## Der praktische Trick

Lerne die drei Muster als feste Melodien (hablo-hablas-habla-hablamos-habláis-hablan)
und denke bei usted immer an "er/sie", nicht an "ihr" — dann sitzt die formelle Anrede
sofort richtig, ohne eine eigene Form lernen zu müssen.
