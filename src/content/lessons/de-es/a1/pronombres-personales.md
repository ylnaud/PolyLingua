Die spanischen Personalpronomen sehen den deutschen ähnlich: yo (ich), tú
(du), él/ella (er/sie), nosotros (wir), vosotros (ihr), ellos/ellas (sie).
Der große Unterschied liegt nicht in der Liste selbst, sondern darin, wie
oft du sie tatsächlich brauchst.

## Die Pronomen im Überblick

| Person       | Spanisch          | Deutsch      |
| ------------ | ------------------ | ------------ |
| 1. Sg.       | yo                  | ich          |
| 2. Sg.       | tú                  | du           |
| 3. Sg.       | él / ella           | er / sie     |
| 1. Pl.       | nosotros / nosotras | wir          |
| 2. Pl.       | vosotros / vosotras | ihr          |
| 3. Pl.       | ellos / ellas       | sie          |

Dazu kommen die Höflichkeitsformen **usted** (Singular) und **ustedes**
(Plural), die wie die 3. Person konjugiert werden — vergleichbar mit dem
deutschen "Sie".

## Pro-Drop: das Pronomen darf fallen

Im Deutschen ist ein Pronomen fast immer Pflicht: "komme" ist kein
vollständiger Satz, du brauchst "ich komme". Im Spanischen reicht oft das
Verb allein:

```
Vengo.        → Ich komme.     (statt: Yo vengo.)
Vives aquí.   → Du wohnst hier. (statt: Tú vives aquí.)
Hablamos español. → Wir sprechen Spanisch. (statt: Nosotros hablamos...)
```

Das funktioniert, weil die spanische Verbendung schon eindeutig zeigt, wer
gemeint ist — "-o" ist immer "ich", "-amos" ist immer "wir", und so weiter.
Das Pronomen wäre also nur eine Wiederholung derselben Information.

## Wann setzt man das Pronomen trotzdem?

Zwei Situationen, in denen Spanischsprachige das Pronomen bewusst
verwenden:

**1. Bei él/ella, wo die Verbform mehrdeutig ist:**

```
Habla español.       → Unklar: er, sie oder Sie spricht Spanisch?
Él habla español.     → Er spricht Spanisch. (jetzt klar)
```

**2. Zur Betonung/Kontrast:**

```
Yo estudio alemán, ella estudia francés.
→ ICH lerne Deutsch, SIE lernt Französisch.
```

## vosotros vs. ustedes

Ein regionaler Unterschied, den du früh kennen solltest: In **Spanien**
wird für "ihr" (informell, mehrere Personen) **vosotros/vosotras**
benutzt, mit einer eigenen Verbform. In **Lateinamerika** wird
stattdessen für alle Fälle von "ihr" oder "Sie (Plural)" einfach
**ustedes** verwendet — die formelle Form deckt dort auch die informelle
Anrede im Plural ab.

## Zusammenfassung

Die spanischen Personalpronomen selbst sind dem Deutschen ähnlich — der
Unterschied ist das Pro-Drop-Phänomen: Da die Verbendung das Subjekt
schon verrät, lässt man das Pronomen meistens weg und setzt es nur zur
Klarheit (bei él/ella) oder zur Betonung.
