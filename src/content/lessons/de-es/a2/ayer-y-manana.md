Über gestern und morgen zu sprechen ist eine der ersten Fähigkeiten, die
man beim Sprachenlernen braucht — für Erzählungen, Pläne und Termine. In
dieser Lektion lernst du die wichtigsten spanischen Zeitausdrücke rund um
Vergangenheit und Zukunft.

## Die Tage um heute herum

| Spanisch          | Deutsch       |
| ------------------- | --------------- |
| anteayer            | vorgestern      |
| ayer                | gestern         |
| hoy                 | heute           |
| mañana              | morgen          |
| pasado mañana       | übermorgen      |

Achtung bei der Falle: `pasado mañana` bedeutet **übermorgen**, nicht
"vergangenes Morgen"! Der Grund ist, dass `pasado` hier auf "nachdem der
morgige Tag vorbei ist" verweist, nicht auf die Vergangenheit. Und
`anteayer` (ante = vor) bedeutet **vorgestern**, nicht "nach-gestern".

```
Anteayer llovió mucho.               (Vorgestern hat es stark geregnet.)
Pasado mañana tengo un examen.       (Übermorgen habe ich eine Prüfung.)
```

## Wochen und Monate

| Spanisch                | Deutsch         |
| --------------------------- | ------------------ |
| la semana pasada            | letzte Woche       |
| esta semana                 | diese Woche        |
| la semana que viene         | nächste Woche       |
| el mes pasado               | letzter Monat       |
| el mes que viene            | nächster Monat      |

```
La semana pasada estuve enfermo.     (Letzte Woche war ich krank.)
La semana que viene tengo vacaciones. (Nächste Woche habe ich Urlaub.)
```

## "hace" für die Vergangenheit

Um auszudrücken, wie lange etwas her ist, benutzt du `hace` + Zeitangabe:

```
Hace dos días fui al médico.         (Vor zwei Tagen war ich beim Arzt.)
Hace una semana llegué a España.     (Vor einer Woche bin ich in Spanien angekommen.)
```

## Zeitausdrücke kombinieren

```
Ayer trabajé mucho, hoy descanso y mañana viajo.
(Gestern habe ich viel gearbeitet, heute ruhe ich mich aus und morgen reise ich.)
```

## Ein ganzer Dialog

```
— ¿Cuándo es la fiesta?
— Pasado mañana, no mañana.
— ¡Ah, entonces tengo tiempo! La semana pasada estuve muy ocupado.
```

(— Wann ist die Party? — Übermorgen, nicht morgen. — Ah, dann habe ich
Zeit! Letzte Woche war ich sehr beschäftigt.)

Mit diesen Zeitausdrücken kannst du klar über Vergangenheit und Zukunft
sprechen, ohne dich bei `pasado mañana` oder `anteayer` zu verwirren.
