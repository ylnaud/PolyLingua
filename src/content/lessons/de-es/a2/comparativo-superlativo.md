Im Deutschen bildest du den Komparativ mit einer Endung: *schnell → schneller → am
schnellsten*. Im Spanischen funktioniert das komplett anders — hier bleibt das
Adjektiv **unverändert**, und du baust die Steigerung mit zusätzlichen Wörtern.

## Komparativ: drei Muster

| Muster       | Struktur                | Beispiel                          |
| ------------ | ------------------------ | ---------------------------------- |
| Überlegenheit | más + Adjektiv + que    | más rápido que (schneller als)     |
| Unterlegenheit | menos + Adjektiv + que | menos caro que (weniger teuer als) |
| Gleichheit    | tan + Adjektiv + como   | tan alto como (so groß wie)        |

```
Mi hermano es más alto que yo.
Mein Bruder ist größer als ich.

Este libro es menos caro que aquel.
Dieses Buch ist weniger teuer als jenes.

Ana es tan inteligente como su hermana.
Ana ist so intelligent wie ihre Schwester.
```

## Der strukturelle Unterschied zum Deutschen

Deutsch hängt eine Endung ans Adjektiv: **schnell → schnell-er**. Das Adjektiv selbst
verändert sich.

Spanisch dagegen lässt das Adjektiv unangetastet und stellt ein eigenes Wort davor:
**rápido → más rápido**. Es gibt keine Endung wie "-er" im Spanischen — das musst du
dir bewusst abgewöhnen, wenn du aus dem Deutschen kommst.

## Superlativ: der bestimmte Artikel ist Pflicht

Für "der/die/das Beste" brauchst du den bestimmten Artikel **vor** más:

```
el más alto de la clase       (der Größte der Klasse)
la más inteligente de todas   (die Intelligenteste von allen)
```

Ohne Artikel ist es nur ein Komparativ, kein Superlativ. Der Artikel signalisiert:
"unter allen ist das die Spitze".

## Unregelmäßige Formen

Wie im Deutschen (gut → besser, nicht "guter") gibt es auch im Spanischen
Unregelmäßigkeiten:

| Adjektiv | Komparativ | Deutsch          |
| -------- | ---------- | ----------------- |
| bueno    | mejor      | gut → besser      |
| malo     | peor       | schlecht → schlechter |
| grande   | mayor      | groß → älter/größer |
| pequeño  | menor      | klein → jünger/kleiner |

Diese vier Formen musst du auswendig lernen — "más bueno" oder "más malo" klingt für
Muttersprachler falsch.

Mit diesen Mustern kannst du jetzt Dinge, Personen und Situationen auf Spanisch
vergleichen, ohne eine einzige neue Endung lernen zu müssen.
