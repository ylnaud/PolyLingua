Ob im Café, im Supermarkt oder im Restaurant — Geldvokabular brauchst du im
Alltag ständig. In dieser Lektion lernst du, wie du nach Preisen fragst,
bezahlst und Rechnungen verstehst.

## Nach dem Preis fragen

| Spanisch          | Deutsch                    |
| ------------------- | ---------------------------- |
| ¿Cuánto cuesta?     | Wie viel kostet das?         |
| ¿Cuánto es?         | Wie viel macht das? (an der Kasse) |
| ¿Cuál es el precio? | Was ist der Preis?           |

```
¿Cuánto cuesta esta camisa?     (Wie viel kostet dieses Hemd?)
¿Cuánto es todo, por favor?     (Wie viel macht das alles, bitte?)
```

## Bezahlen

| Spanisch          | Deutsch               |
| ------------------- | ------------------------ |
| pagar en efectivo   | bar bezahlen             |
| pagar con tarjeta   | mit Karte bezahlen       |
| el recibo           | die Quittung             |
| el cambio           | das Wechselgeld          |

```
¿Puedo pagar con tarjeta?       (Kann ich mit Karte bezahlen?)
Aquí tiene su cambio.           (Hier ist Ihr Wechselgeld.)
```

## Im Restaurant

Am Ende eines Restaurantbesuchs bittest du um die Rechnung mit:

```
La cuenta, por favor.           (Die Rechnung, bitte.)
¿Está incluida la propina?      (Ist das Trinkgeld inbegriffen?)
```

## Preise beschreiben

| Spanisch      | Deutsch     |
| --------------- | ------------- |
| caro/a          | teuer         |
| barato/a        | billig        |
| gratis          | kostenlos     |
| una oferta      | ein Angebot   |

```
Este restaurante es muy caro.        (Dieses Restaurant ist sehr teuer.)
Encontré una oferta muy barata.      (Ich habe ein sehr günstiges Angebot gefunden.)
```

## Ein ganzer Dialog

```
— ¿Cuánto cuesta este jersey?
— Cuesta veinte euros. ¿Va a pagar en efectivo o con tarjeta?
— Con tarjeta, por favor.
```

(— Wie viel kostet dieser Pullover? — Er kostet zwanzig Euro. Zahlen Sie
bar oder mit Karte? — Mit Karte, bitte.)

Mit diesem Vokabular kannst du in jedem spanischsprachigen Geschäft
selbstbewusst einkaufen und bezahlen.
