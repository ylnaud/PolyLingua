Beim Arztbesuch brauchst du Vokabular, um Symptome präzise zu beschreiben.
In dieser Lektion lernst du, wie man Schmerzen ausdrückt, einen Termin
vereinbart und mit dem Arzt oder der Ärztin spricht.

## Schmerzen mit "doler" beschreiben

Das Verb `doler` (wehtun) funktioniert wie `gustar`: Es richtet sich nach
dem Körperteil, nicht nach der Person.

| Spanisch                 | Deutsch                  |
| -------------------------- | --------------------------- |
| Me duele la cabeza.        | Mir tut der Kopf weh. (Singular) |
| Me duelen los pies.        | Mir tun die Füße weh. (Plural) |
| Me duele el estómago.      | Mir tut der Bauch weh.       |

Merke: Singular-Körperteil → `duele`; Plural-Körperteil → `duelen`. Das
Verb stimmt mit dem grammatischen Subjekt überein (dem Körperteil), nicht
mit "ich".

## Weitere Symptome

| Spanisch          | Deutsch              |
| ------------------- | ----------------------- |
| tener fiebre        | Fieber haben            |
| tener tos           | Husten haben            |
| tener náuseas       | Übelkeit haben          |
| estar mareado/a     | schwindlig sein         |
| estar enfermo/a     | krank sein              |

```
Tengo fiebre y tos desde ayer.       (Ich habe seit gestern Fieber und Husten.)
Estoy mareado, necesito sentarme.    (Mir ist schwindlig, ich muss mich setzen.)
```

## Einen Termin vereinbaren

```
Necesito una cita con el médico.     (Ich brauche einen Termin beim Arzt.)
¿Tiene hora libre esta semana?       (Haben Sie diese Woche einen freien Termin?)
```

## Nach dem Arztbesuch

| Spanisch        | Deutsch               |
| ----------------- | ------------------------ |
| la receta         | das Rezept               |
| la farmacia       | die Apotheke             |
| las pastillas     | die Tabletten            |
| el jarabe         | der Hustensaft           |

```
El médico me da una receta.         (Der Arzt gibt mir ein Rezept.)
Voy a la farmacia a comprar pastillas. (Ich gehe zur Apotheke, um Tabletten zu kaufen.)
```

## Ein ganzer Dialog

```
— ¿Qué le pasa?
— Me duele la garganta y tengo fiebre.
— Le voy a dar una receta. Vaya a la farmacia.
```

(— Was fehlt Ihnen? — Mir tut der Hals weh und ich habe Fieber. — Ich gebe
Ihnen ein Rezept. Gehen Sie zur Apotheke.)

Mit diesem Vokabular kannst du beim Arzt klar sagen, was dir fehlt, und
den Anweisungen für die Behandlung folgen.
