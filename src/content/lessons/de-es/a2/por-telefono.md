Telefongespräche laufen oft schnell und ohne Körpersprache ab — deshalb
lohnt es sich besonders, feste Redewendungen zu kennen. In dieser Lektion
lernst du, wie man sich am spanischen Telefon meldet, verbindet, eine
Nachricht hinterlässt und typische Probleme löst.

## Sich melden

In Spanien ist die typische Begrüßung am Telefon nicht der eigene Name,
sondern eine kurze Formel:

| Spanisch     | Deutsch                    |
| ------------- | --------------------------- |
| ¿Diga?        | Hallo? (wörtlich: "Sag!")   |
| ¿Dígame?      | Hallo? (höflicher)          |
| ¿Sí?          | Ja? / Hallo?                |

```
— ¿Diga?
— Hola, soy Marta. ¿Está Juan?
```

(— Hallo? — Hallo, hier ist Marta. Ist Juan da?)

## Nach einer Person fragen

```
¿Puedo hablar con Ana, por favor?     (Kann ich mit Ana sprechen, bitte?)
¿Está el señor López?                 (Ist Herr López da?)
```

Wenn die Person nicht da ist, hörst du oft:

```
Lo siento, no está. ¿Quiere dejar un mensaje?
(Es tut mir leid, er/sie ist nicht da. Möchten Sie eine Nachricht hinterlassen?)
```

## Verbinden und warten

| Spanisch              | Deutsch                     |
| ----------------------- | ---------------------------- |
| Un momento, por favor   | Einen Moment, bitte          |
| Le paso con...          | Ich verbinde Sie mit...      |
| La línea está ocupada   | Die Leitung ist besetzt      |

## Probleme am Telefon

Manchmal ist die Verbindung schlecht oder man hat sich verwählt:

```
No se oye bien.                (Man hört schlecht.)
¿Puede repetir, por favor?     (Können Sie das wiederholen, bitte?)
Se ha equivocado de número.    (Sie haben sich verwählt.)
```

## Ein ganzer Dialog

```
— ¿Diga?
— Hola, ¿puedo hablar con Ana, por favor?
— Un momento, le paso con ella.
— Gracias.
```

(— Hallo? — Hallo, kann ich mit Ana sprechen, bitte? — Einen Moment, ich
verbinde Sie mit ihr. — Danke.)

Mit diesem Vokabular kannst du dich sicher am spanischen Telefon
verständigen, egal ob du selbst anrufst oder abhebst.
