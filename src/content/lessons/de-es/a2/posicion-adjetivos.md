Im Deutschen steht das Adjektiv immer an derselben Stelle: **vor** dem Substantiv — "der
**rote** Wagen", "das **kleine** Haus". Im Spanischen ist das anders, und dieser
Unterschied ist einer der auffälligsten für deutsche Lernende.

## Die Grundregel: nach dem Substantiv

Die meisten spanischen Adjektive stehen **nach** dem Substantiv, das sie beschreiben:

```
el coche rojo
das rote Auto
     ↑ Substantiv  ↑ Adjektiv (danach, nicht davor)

la casa grande
das große Haus
```

Das gilt besonders für Adjektive, die eine **objektive Eigenschaft** beschreiben:
Farbe, Form, Nationalität, Material.

```
un libro interesante   ein interessantes Buch
una mesa grande        ein großer Tisch
un hombre español      ein spanischer Mann
```

## Manche Adjektive stehen auch davor — mit Bedeutungswechsel

Eine kleine Gruppe von Adjektiven kann **vor oder nach** dem Substantiv stehen, und
dabei ändert sich die Bedeutung:

```
un amigo viejo    ein Freund, der alt an Jahren ist
un viejo amigo    ein langjähriger Freund (die Freundschaft ist "alt")
```

```
un hombre grande  ein großer Mann (körperliche Größe)
un gran hombre    ein großartiger Mann (Bedeutung/Ansehen)
```

Im Deutschen ist das undenkbar — "ein alter Freund" bleibt immer zweideutig und der
Kontext muss klären, was gemeint ist. Im Spanischen übernimmt die **Position** diese
Arbeit: vor dem Substantiv wird das Adjektiv oft subjektiver oder übertragener,
danach bleibt es meist wörtlich/objektiv.

## Apokope: grande → gran, bueno → buen

Wenn ein paar häufige Adjektive **vor** einem Singular-Substantiv stehen, verkürzen sie
sich:

| Volle Form | Verkürzt vor Substantiv | Beispiel      |
| ----------- | ------------------------ | -------------- |
| grande      | gran (m/f Singular)      | un gran hombre |
| bueno       | buen (nur maskulin)      | un buen amigo  |
| malo        | mal (nur maskulin)       | un mal día     |

## Merksatz für den Alltag

Als Grundregel: stell dir vor, spanische Adjektive "folgen" dem Substantiv, wie ein
Etikett, das man erst nach dem Ding selbst dranklebt. Nur eine kleine, aber wichtige
Gruppe von Adjektiven springt für einen Bedeutungswechsel nach vorne — den Rest lernst
du am besten in festen Wendungen wie "un viejo amigo" auswendig.
