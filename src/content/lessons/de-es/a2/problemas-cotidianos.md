Im Alltag geht mal etwas kaputt, verloren oder einfach nicht wie erwartet.
In dieser Lektion lernst du, wie du solche Probleme auf Spanisch beschreibst
und höflich um Hilfe bittest.

## Etwas ist kaputt

| Spanisch          | Deutsch               |
| ------------------ | ----------------------- |
| está roto/a        | es ist kaputt           |
| no funciona        | es funktioniert nicht   |
| se ha estropeado   | es ist kaputtgegangen   |
| necesita arreglo   | es muss repariert werden|

```
Mi teléfono está roto.          (Mein Telefon ist kaputt.)
La lavadora no funciona.        (Die Waschmaschine funktioniert nicht.)
```

Beachte: `roto/a` benutzt du mit `estar`, weil es einen Zustand beschreibt,
nicht eine dauerhafte Eigenschaft.

## Etwas ist verloren

```
He perdido las llaves.          (Ich habe die Schlüssel verloren.)
He perdido mi cartera.          (Ich habe mein Portemonnaie verloren.)
```

Für Dinge, die einem "entfallen" sind, gibt es eine besonders praktische
reflexive Konstruktion:

```
Se me ha olvidado el paraguas.  (Mir ist der Regenschirm entfallen.)
Se me ha olvidado la contraseña. (Mir ist das Passwort entfallen.)
```

Diese Form klingt weniger vorwurfsvoll als "he olvidado" (ich habe
vergessen) — sie stellt den Fehler als etwas dar, das einem "passiert" ist.

## Um Hilfe bitten

| Spanisch                    | Deutsch                       |
| ----------------------------- | ------------------------------- |
| ¿Me puede ayudar, por favor?  | Können Sie mir bitte helfen?    |
| Tengo un problema             | Ich habe ein Problem            |
| ¿Puede arreglarlo?            | Können Sie es reparieren?       |
| ¿Sabe qué le pasa?            | Wissen Sie, was los ist?        |

## Ein ganzer Dialog

```
— Mi móvil está roto, no funciona la pantalla.
— ¿Me puede ayudar? Tengo un problema urgente.
— Claro, vamos a ver qué le pasa.
```

(— Mein Handy ist kaputt, der Bildschirm funktioniert nicht. — Können Sie
mir helfen? Ich habe ein dringendes Problem. — Klar, schauen wir mal, was
los ist.)

Mit diesem Vokabular kannst du Alltagsprobleme klar beschreiben und
selbstbewusst um Hilfe bitten, egal ob es um ein kaputtes Gerät oder
verlorene Sachen geht.
