Objektpronomen kennst du aus dem Deutschen gut: "ich sehe **ihn**" (Akkusativ), "ich
gebe **ihr**" (Dativ). Das Spanische hat ein ähnliches System — aber mit einer anderen
Position im Satz, die dich am Anfang überraschen wird.

## Direktes Objekt (Akkusativ): lo, la, los, las

Diese Pronomen ersetzen das direkte Objekt — die Antwort auf "wen/was?":

| Pronomen | Deutsch                     |
| -------- | ---------------------------- |
| lo       | ihn/es (maskulin Singular)   |
| la       | sie/es (feminin Singular)    |
| los      | sie (maskulin Plural)        |
| las      | sie (feminin Plural)         |

```
Compro el libro. → Lo compro.
Ich kaufe das Buch. → Ich kaufe es.
```

## Indirektes Objekt (Dativ): le, les

Diese Pronomen ersetzen das indirekte Objekt — die Antwort auf "wem?":

| Pronomen | Deutsch          |
| -------- | ----------------- |
| le       | ihm/ihr (Singular) |
| les      | ihnen (Plural)     |

```
Escribo una carta a mi madre. → Le escribo una carta.
Ich schreibe meiner Mutter einen Brief. → Ich schreibe ihr einen Brief.
```

Anders als bei lo/la/los/las unterscheidet le/les **nicht** nach Geschlecht — le passt
für "ihm" und "ihr" gleichermaßen.

## Die Position: der große Unterschied zum Deutschen

Im Deutschen steht das Pronomen normalerweise **nach** dem konjugierten Verb: "ich
kaufe **es**". Im Spanischen steht es dagegen **direkt davor**:

```
Lo compro.        (nicht: Compro lo)
Ich kaufe es.
```

Bei drei Verbformen darfst du wählen: Infinitiv, Gerundium und bejahter Imperativ
erlauben, das Pronomen **anzuhängen**, statt es davorzustellen:

```
Quiero comprarlo.  = Lo quiero comprar.
Ich möchte es kaufen.
```

Beide Varianten sind korrekt und gleich häufig — wichtig ist nur, dass das Pronomen
niemals nach einem **konjugierten** Verb frei danebensteht.

## Beide zusammen

Wenn direktes und indirektes Objekt im selben Satz vorkommen, steht das indirekte
Pronomen **vor** dem direkten:

```
Se lo doy.
Ich gebe es ihm/ihr.
```

(le/les wird vor lo/la/los/las zu *se* — das lernst du in einer späteren Lektion
genauer.)

Mit lo/la/los/las und le/les kannst du jetzt Wiederholungen vermeiden und flüssiger
klingen — genau wie im Deutschen mit "ihn", "sie" oder "ihm".
