Sich in einer spanischen Stadt zurechtzufinden ist eine der praktischsten
Fähigkeiten, die du lernen kannst. In dieser Lektion lernst du die
wichtigsten Verkehrsmittel und wie du nach dem Weg fragst — und ihn
verstehst, wenn dir jemand antwortet.

## Verkehrsmittel

| Spanisch    | Deutsch      |
| ----------- | ------------ |
| el tren     | der Zug      |
| el autobús  | der Bus      |
| el metro    | die U-Bahn   |
| el taxi     | das Taxi     |
| el coche    | das Auto     |
| la bicicleta| das Fahrrad  |

```
Voy en tren a Sevilla.        (Ich fahre mit dem Zug nach Sevilla)
Cojo el autobús a las 8.      (Ich nehme den Bus um 8 Uhr)
```

## Orte des öffentlichen Verkehrs

| Spanisch      | Deutsch          |
| -------------- | ---------------- |
| la estación    | der Bahnhof      |
| la parada      | die Haltestelle  |
| el aeropuerto  | der Flughafen    |

## Nach dem Weg fragen

Die Standardfrage lautet **"¿Dónde está...?"** (Wo befindet sich...?):

```
¿Dónde está la estación de tren?    (Wo ist der Bahnhof?)
¿Dónde está la parada más cercana?  (Wo ist die nächste Haltestelle?)
```

## Richtungsangaben verstehen

| Spanisch          | Deutsch          |
| ------------------ | ---------------- |
| a la izquierda     | links            |
| a la derecha       | rechts           |
| todo recto         | immer geradeaus  |
| gira...            | biege ab...      |
| sigue...           | folge / geh...   |

Achtung mit der Verwechslungsgefahr: **derecha** (rechts) vs. **derecho**
(geradeaus) — nur ein Buchstabe unterscheidet die beiden Wörter, aber sie
zeigen in ganz unterschiedliche Richtungen!

```
Gira a la izquierda en la primera calle.   (Biege links in der ersten Straße ab)
Sigue todo recto hasta el semáforo.        (Geh immer geradeaus bis zur Ampel)
```

## Ein ganzer Dialog

```
— ¿Dónde está la estación?
— Gira a la derecha y sigue todo recto. Está cerca del banco.
```

(— Wo ist der Bahnhof? — Biege rechts ab und geh immer geradeaus.
Er liegt in der Nähe der Bank.)

Mit diesem Vokabular kannst du dich in fast jeder spanischen Stadt
zurechtfinden, egal ob du mit dem Zug ankommst oder jemanden nach dem Weg
fragen musst.
