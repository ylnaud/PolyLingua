Das condicional simple ist die spanische Antwort auf den deutschen
Konjunktiv II — und du kennst das Muster seiner Bildung bereits, denn es
funktioniert fast genauso wie das futuro simple aus einer früheren Lektion:
eine einzige Endung, kein Hilfsverb.

## Bildung: Infinitiv + dieselbe Endung wie beim Imperfecto

Bei regelmäßigen Verben hängst du an den **vollständigen Infinitiv**
dieselben Endungen, die du schon vom pretérito imperfecto kennst:

```
hablar → hablaría, hablarías, hablaría,
         hablaríamos, hablaríais, hablarían

comer  → comería, comerías, comería,
         comeríamos, comeríais, comerían

vivir  → viviría, vivirías, viviría,
         viviríamos, viviríais, vivirían
```

Ein einziges Set von Endungen für alle drei Verbklassen — das macht das
condicional simple strukturell einfach.

## Dieselben unregelmäßigen Stämme wie das futuro simple

Die Verben, die im futuro simple einen veränderten Stamm haben, benutzen
genau denselben Stamm auch im condicional:

```
tener  → tendr-   → tendría
hacer  → har-     → haría
decir  → dir-     → diría
poder  → podr-    → podría
saber  → sabr-    → sabría
querer → querr-   → querría
```

Lernst du also die unregelmäßigen Stämme einmal, funktionieren sie in
beiden Zeitformen.

## Der Vergleich mit dem Deutschen: ein Wort statt zwei

Genau wie beim futuro simple (eine Endung statt "werden + Infinitiv")
ersetzt das condicional simple die deutsche würde-Form in einem einzigen
Wort:

```
ich würde gehen    →   iría
ich würde essen    →   comería
ich würde sagen    →   diría
```

Das Deutsche greift für fast alle Verben zur periphrastischen würde-Form,
weil der "echte" Konjunktiv II im Alltag ungebräuchlich klingt (außer bei
wenigen Verben wie wäre, hätte, käme). Das Spanische braucht diesen Umweg
nicht — jedes Verb hat seine eigene, klare condicional-Form.

## Der wichtigste Alltagsgebrauch: Höflichkeit

Der häufigste Einsatz des condicional simple ist die höfliche,
abgeschwächte Bitte oder Aussage:

```
Me gustaría un café.        (Ich hätte gerne einen Kaffee.)
¿Podrías ayudarme?          (Könntest du mir helfen?)
¿Podría cambiar de habitación?  (Könnte ich das Zimmer wechseln?)
```

Vergleiche mit der direkteren Version ohne condicional: "Quiero un café."
klingt fordernder als "Me gustaría un café." — genau wie im Deutschen "Ich
will einen Kaffee" direkter wirkt als "Ich hätte gerne einen Kaffee."

## Merksatz

Infinitiv + -ía-Endung = condicional simple. Dieselben unregelmäßigen
Stämme wie beim futuro simple. Und im Alltag ist die höfliche Bitte mit
gustaría/podría dein wichtigstes Werkzeug — praktisch, wenn du zum Beispiel
später eine Beschwerde im Hotel höflich formulieren willst.
