Du kennst schon den subjuntivo aus Bedingungssätzen. Jetzt geht es um eine
zweite, sehr häufige Auslöser-Gruppe: Ausdrücke der **Erwartung, des
Wunsches oder des Werturteils** vor "que" — genau das Werkzeug, das du
brauchst, um höflich eine Entschädigung zu verlangen.

## Die Faustregel: kein Fakt, sondern Erwartung/Wertung

Immer wenn der Hauptsatz eine Erwartung, einen Wunsch oder ein
Werturteil ausdrückt (nicht eine feststehende Tatsache), steht im
Nebensatz nach "que" der **subjuntivo**:

```
Espero que me devuelvan el dinero.
(Ich hoffe, dass sie mir das Geld zurückgeben.)

Es justo que la empresa asuma responsabilidad.
(Es ist gerecht, dass das Unternehmen Verantwortung übernimmt.)
```

## Häufige Auslöser für diese Situation

| Auslöser          | Bedeutung           |
| -------------------- | ---------------------- |
| espero que            | ich hoffe, dass        |
| es justo que          | es ist gerecht, dass   |
| es necesario que      | es ist nötig, dass     |
| me alegra que         | es freut mich, dass    |
| es una pena que       | es ist schade, dass    |
| quiero que             | ich möchte, dass        |

## Vorsicht bei gleichem Subjekt

Wenn das Subjekt in Haupt- und Nebensatz identisch ist ("ich hoffe, dass
ICH..."), fällt "que" + subjuntivo weg — stattdessen benutzt man den
Infinitiv:

```
Espero recibir una compensación.
(Ich hoffe, eine Entschädigung zu bekommen.) — NICHT: Espero que yo reciba...
```

Erst wenn ein ANDERES Subjekt im Nebensatz auftaucht, brauchst du "que" +
subjuntivo:

```
Espero que ustedes me den una compensación.
(Ich hoffe, dass Sie mir eine Entschädigung geben.)
```

## Wichtige unregelmäßige Formen

Für dieses Thema besonders relevant: Verben mit Stammvokalwechsel und
unregelmäßige Formen behalten ihre Unregelmäßigkeit auch im subjuntivo:

| Verb      | 3. Pl. subjuntivo |
| ----------- | -------------------- |
| devolver    | devuelvan             |
| dar         | den                   |
| poder       | puedan                |
| pagar       | paguen                |

## Nützliche Sätze für eine Beschwerde

```
Espero que resuelvan el problema pronto.
(Ich hoffe, dass sie das Problem bald lösen.)

Es justo que paguen los daños.
(Es ist gerecht, dass sie den Schaden bezahlen.)

Quiero que me den una respuesta por escrito.
(Ich möchte, dass sie mir eine schriftliche Antwort geben.)
```

## Zusammenfassung

Erwartungsausdrücke wie "espero que" oder Werturteile wie "es justo que"
lösen im Nebensatz den subjuntivo aus — außer bei identischem Subjekt,
dann folgt stattdessen der Infinitiv. Mit diesem Muster klingst du beim
Einfordern einer Entschädigung höflich, aber bestimmt.
