Du kennst schon den Konjunktiv II im Deutschen als höfliche Form ("Wenn Sie
könnten..."). Im Spanischen gibt es dafür den **pretérito imperfecto de
subjuntivo** — und du brauchst ihn genau dann, wenn du höflich eine
Hypothese oder einen Wunsch formulierst, zum Beispiel bei einer Beschwerde
im Hotel.

## Bildung: das Erkennungszeichen -ra-/-se-

Der pretérito imperfecto de subjuntivo wird regelmäßig aus der 3. Person
Plural des Pretérito Indefinido gebildet (Endung -ron entfernen, -ra- oder
-se-Endungen anhängen):

| Person       | -ar (hablar) | -er (comer)  | -ir (vivir)  |
| -------------- | -------------- | -------------- | -------------- |
| yo             | habl**ara**    | com**iera**    | viv**iera**    |
| tú             | habl**aras**   | com**ieras**   | viv**ieras**   |
| él/ella        | habl**ara**    | com**iera**    | viv**iera**    |
| nosotros       | habl**áramos**  | com**iéramos**  | viv**iéramos**  |
| vosotros       | habl**arais**  | com**ierais**  | viv**ierais**  |
| ellos          | habl**aran**   | com**ieran**   | viv**ieran**   |

Die -se-Form (hablase, comiese, viviese...) ist gleichbedeutend und in
formellen Texten üblich — im Alltag überwiegt die -ra-Form.

## Die wichtigsten unregelmäßigen Verben

| Verb    | yo / él   |
| --------- | -------------- |
| ser / ir | fuera         |
| estar   | estuviera     |
| tener   | tuviera       |
| haber   | hubiera       |
| poder   | pudiera       |
| hacer   | hiciera       |

## Das höfliche Hypothesen-Muster

Das Standardmuster für höfliche Hypothesen ist:

```
Si + pretérito imperfecto de subjuntivo,   condicional simple
```

Beispiele aus einer Hotelbeschwerde:

```
Si hubiera un problema, lo diría en recepción.
(Wenn es ein Problem gäbe, würde ich es an der Rezeption sagen.)

Si la ducha funcionara, estaría más contento.
(Wenn die Dusche funktionieren würde, wäre ich zufriedener.)

Si la habitación fuera más tranquila, dormiría mejor.
(Wenn das Zimmer ruhiger wäre, würde ich besser schlafen.)
```

## ojalá: Wünsche statt Bedingungssätze

Mit **ojalá** + pretérito imperfecto de subjuntivo drückst du einen Wunsch
aus, der (noch) nicht erfüllt ist:

```
Ojalá tuviera una habitación más tranquila.
(Ich wünschte, ich hätte ein ruhigeres Zimmer.)
```

## Höflichkeit ohne vollständigen Bedingungssatz

Oft reicht schon "Si pudiera..." allein, um eine Bitte höflich einzuleiten,
bevor die eigentliche Beschwerde folgt:

```
Si pudiera, cambiaría de habitación.
(Wenn ich könnte, würde ich das Zimmer wechseln.)
```

## Nützliche Sätze für den Hotelalltag

| Spanisch                                              | Deutsch                                                    |
| --------------------------------------------------------- | -------------------------------------------------------------- |
| Si el wifi funcionara, trabajaría desde aquí.          | Wenn das WLAN funktionieren würde, würde ich von hier arbeiten. |
| Si tuvieran una habitación más tranquila, la querría.  | Wenn Sie ein ruhigeres Zimmer hätten, würde ich es gerne nehmen. |

## Kurz zusammengefasst

```
si + pretérito imperfecto de subjuntivo  +  condicional simple
     (fuera, tuviera, pudiera, funcionara...)   (estaría, querría, dormiría...)

ojalá + pretérito imperfecto de subjuntivo  =  unwahrscheinlicher Wunsch
```

Diese Struktur ist dein Werkzeug für höfliche, hypothetische Beschwerden —
sie klingt weniger direkt als eine einfache Feststellung im Indicativo und
wird in Servicesituationen sehr geschätzt.
