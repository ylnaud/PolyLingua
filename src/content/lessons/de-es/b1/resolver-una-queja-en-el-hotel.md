Du kennst aus dem Deutschen den Unterschied zwischen Vorgangspassiv
("wird gelöst") und Zustandspassiv ("ist gelöst"). Im Spanischen gibt es
eine ganz ähnliche Unterscheidung, um am Ende einer Hotelbeschwerde zu
sagen, dass das Problem behoben wurde — nur mit anderen Bausteinen.

## Vorgang: pretérito perfecto compuesto (haber + Partizip)

Um die **Handlung** zu betonen — dass jemand etwas GETAN hat —, benutzt
du das pretérito perfecto compuesto: **haber** (Präsens) + Partizip:

```
El hotel ha resuelto el problema.
(Das Hotel hat das Problem gelöst.)

Ya han solucionado el problema del wifi.
(Sie haben das WLAN-Problem bereits gelöst.)
```

Wichtig: Nach **haber** als Hilfsverb bleibt das Partizip **immer
unverändert** auf -o, egal welches Genus/Numerus das Subjekt hat.

## Zustand: estar + Partizip

Um dagegen nur den **erreichten Endzustand** zu beschreiben — ohne die
Handlung selbst zu betonen —, benutzt du **estar** + Partizip:

```
El problema está resuelto.
(Das Problem ist gelöst.)

La queja está resuelta.
(Die Beschwerde ist gelöst.)
```

Nach **estar** verhält sich das Partizip wie ein normales Adjektiv und
**konkordiert** in Genus und Numerus mit dem Subjekt: resuelto/resuelta,
resueltos/resueltas.

## Der direkte Vergleich

| Konstruktion              | Betont          | Beispiel                        |
| ---------------------------- | ---------------- | ---------------------------------- |
| haber (Präsens) + Partizip    | die Handlung      | Han resuelto la queja.             |
| estar (Präsens) + Partizip    | den Endzustand    | La queja está resuelta.            |

Genau wie im Deutschen: "Sie haben die Beschwerde gelöst" (Handlung) vs.
"Die Beschwerde ist gelöst" (Zustand) — dasselbe Ergebnis, aber ein
anderer Fokus.

## Häufige unregelmäßige Partizipien

Für dieses Thema besonders wichtig — einige Partizipien sind
unregelmäßig und werden in beiden Konstruktionen genutzt:

| Infinitiv  | Partizip  |
| ------------ | ----------- |
| resolver     | resuelto    |
| hacer        | hecho       |
| escribir     | escrito     |
| poner        | puesto      |
| ver          | visto       |

## Ein typischer Gesprächsverlauf im Hotel

```
Cliente: ¿Ya han resuelto el problema de la ducha?
(Haben Sie das Duschproblem schon gelöst?)

Recepción: Sí, el problema ya está resuelto. Puede subir a su habitación.
(Ja, das Problem ist jetzt gelöst. Sie können auf Ihr Zimmer gehen.)
```

## Zusammenfassung

Für den Vorgang (die abgeschlossene Handlung) benutzt du **haber +
Partizip** (invariabel), für den erreichten Endzustand **estar +
Partizip** (konkordierend wie ein Adjektiv) — dieselbe Logik wie das
deutsche Vorgangs-/Zustandspassiv, nur mit spanischen Bausteinen.
