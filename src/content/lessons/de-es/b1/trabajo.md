Für die Arbeitswelt brauchst du zwei Dinge: den passenden Wortschatz für
Bewerbung und Büroalltag — und eine geschärfte Version einer Regel, die du
schon kennst: ser vs. estar.

## Bewerbung: der Wortschatz

```
el currículum            (der Lebenslauf)
la entrevista de trabajo (das Vorstellungsgespräch)
el contrato              (der Arbeitsvertrag)
el sueldo                (das Gehalt)
```

Ein typischer Satz aus dem Bewerbungsprozess:

```
Mañana tengo una entrevista de trabajo para un puesto con un buen sueldo.
(Ich habe morgen ein Vorstellungsgespräch für eine Stelle mit gutem Gehalt.)
```

## ser + Beruf: kein Artikel

Beim einfachen ser + Beruf entfällt der unbestimmte Artikel im Spanischen —
anders als im Deutschen, wo "ein/eine" oft auch wegfällt, aber aus einem
anderen Grund:

```
Soy ingeniera.        (Ich bin Ingenieurin.)
Es abogado.            (Er ist Anwalt.)
```

Der Artikel taucht erst dann wieder auf, wenn ein Adjektiv den Beruf näher
beschreibt:

```
Soy una ingeniera excelente.  (Ich bin eine ausgezeichnete Ingenieurin.)
```

## estar + Arbeitszustand: temporär, veränderlich

Für den aktuellen beruflichen Zustand — der sich jederzeit ändern kann —
benutzt du estar, nicht ser:

```
Estoy en paro.          (Ich bin arbeitslos.)
Estoy de baja.          (Ich bin krankgeschrieben.)
Estoy de vacaciones.    (Ich bin im Urlaub.)
```

Der Unterschied zu ser + Beruf ist klar: "Soy ingeniera" beschreibt eine
dauerhafte berufliche Identität, "Estoy en paro" einen momentanen, sich
verändernden Zustand — selbst eine Ingenieurin kann zeitweise "en paro"
sein, ohne aufzuhören, Ingenieurin zu sein.

## Büroalltag: weiterer Wortschatz

```
el jefe / la jefa            (der Chef / die Chefin)
el aumento de sueldo         (die Gehaltserhöhung)
jubilarse                    (in Rente gehen)
```

Ein Beispiel, das ser und estar kombiniert:

```
Mi hermano es ingeniero, pero ahora está en paro desde marzo.
(Mein Bruder ist Ingenieur, aber momentan seit März arbeitslos.)
```

## Merksatz

Beruf als feste Identität → ser, ohne Artikel (Soy profesora). Aktueller,
veränderlicher Arbeitszustand → estar (Estoy en paro, estoy de baja).
Derselbe Mensch kann beides gleichzeitig sein: einen festen Beruf haben und
sich trotzdem gerade in einem temporären Zustand befinden.
