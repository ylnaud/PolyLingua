Das Deutsche braucht für "ich hätte gesprochen" den Konjunktiv II — eine eigene,
markierte Verbform. Das Spanische löst dieselbe Bedeutung ohne separaten Modus: Es
kombiniert einfach das Condicional simple von **haber** (habría) mit dem ganz
normalen Partizip, das du schon aus dem Pretérito perfecto compuesto kennst
("he hablado").

## Die Bildung

```
haber (Condicional simple)  +  participio
```

| Person             | haber (Condicional simple) | + participio |
| -------------------- | ----------------------------- | -------------- |
| yo                    | habría                         | hablado        |
| tú                     | habrías                        | hablado        |
| él/ella/usted           | habría                         | hablado        |
| nosotros                | habríamos                      | hablado        |
| ellos/ellas/ustedes      | habrían                        | hablado        |

## Bedeutung: die unerfüllte Vergangenheit

Genau wie der deutsche Konjunktiv II der Vergangenheit drückt das Condicional
compuesto eine Möglichkeit aus, die NICHT eingetreten ist:

```
Yo habría estudiado más.        (Ich hätte mehr gelernt — habe es aber nicht.)
Habríamos ido, pero llovió.     (Wir wären gegangen, aber es hat geregnet.)
```

## Der klassische Kontext: der irreale Bedingungssatz

Wie im Deutschen ("Wenn ich Zeit gehabt hätte, wäre ich gekommen") taucht diese Form
am häufigsten im doppelten Konjunktiv-II-Satz auf. Im Spanischen sieht die Formel so
aus:

```
Si + Pluscuamperfecto de subjuntivo,  ...  Condicional compuesto

Si hubiera estudiado más,  habría aprobado el examen.
(Wenn ich mehr gelernt hätte,  hätte ich die Prüfung bestanden.)
```

Beachte die Parallele zum Deutschen: Beide Sprachen brauchen im "Wenn"-Satz UND im
Hauptsatz eine Vergangenheitsform des irrealen Modus — nur dass Spanisch dafür zwei
verschiedene Bausteine kombiniert (Pluscuamperfecto de subjuntivo + Condicional
compuesto), während Deutsch beide Sätze mit demselben "hätte" bildet.

## Die spanische Besonderheit: zwei Formen für ein deutsches "hätte"

Anders als im Deutschen erlaubt Spanisch im Hauptsatz zwei austauschbare Formen:

```
Si hubiera estudiado más, habría aprobado el examen.
Si hubiera estudiado más, hubiera aprobado el examen.
```

Beide Sätze bedeuten exakt dasselbe. "hubiera" (dieselbe Form wie im Nebensatz) ist
in der gesprochenen Sprache sogar häufiger als "habría". Für dich als
Deutschsprachigen heißt das: Ein einziges deutsches "hätte" entspricht im Spanischen
zwei gleichwertigen Werkzeugen — du musst nur eines aktiv beherrschen, solltest aber
beide beim Hören/Lesen erkennen.

## Der entscheidende Unterschied zum Deutschen

Deutsch: "hätte" ist eine eigene, unregelmäßige Konjunktiv-II-Form von haben, komplett
verschieden vom Indikativ "habe".

Spanisch: "habría" ist einfach die reguläre Condicional-simple-Form von haber —
derselbe Baustein, den du auch außerhalb von Konjunktiv-Kontexten verwendest, etwa in
Höflichkeitsformen ("Me gustaría..." — Ich hätte gern...). Du musst also keine
separate Verbklasse lernen, nur diese eine vertraute Zeitform mit dem Partizip
kombinieren.
