Diese Lektion ist anders als die vorherigen: Hier kannst du nicht auf ein deutsches
Muster zurückgreifen, weil das Deutsche gar keine eigene grammatikalisierte
Verlaufsform besitzt. "Ich lese" kann im Deutschen sowohl eine allgemeine Aussage sein
("Ich lese jeden Abend") als auch eine Handlung im Verlauf beschreiben ("Ich lese
gerade") — der Unterschied liegt nur im Kontext, nicht in der Verbform.

## Die Bildung des Gerundio

| Endung | Beispiel          | Gerundio  |
| ------- | ------------------ | ---------- |
| -ar     | hablar (sprechen)  | hablando   |
| -er/-ir | comer (essen)      | comiendo   |
| -er/-ir | partir (abfahren)  | partiendo  |

Das Gerundio selbst ist unveränderlich — es kongruiert nicht mit Genus oder Numerus,
anders als das Partizip in der Voz pasiva.

### Unregelmäßigkeiten

Zwei Gruppen weichen von der Grundregel ab:

```
Vokal + -er/-ir → -yendo:   leer → leyendo, oír → oyendo, construir → construyendo
Vokalwechsel bei -ir-Verben: dormir → durmiendo, pedir → pidiendo, decir → diciendo
```

## estar + Gerundio: die spanische Verlaufsform

Um "ich tue gerade etwas" auszudrücken, verwendet Spanisch **estar + Gerundio** — eine
feste, grammatikalisierte Konstruktion:

```
Estoy leyendo.        (Ich lese gerade.)
¿Estás comiendo?       (Isst du gerade?)
Estamos estudiando.    (Wir studieren gerade.)
```

Anders als im Deutschen, wo du "gerade" nur bei Bedarf als Adverb einfügst, ist die
spanische Verlaufsform grammatisch verpflichtend, sobald du eine Handlung wirklich als
"im Verlauf, genau jetzt" markieren willst — sonst klingt der Satz im Kontext
mehrdeutig.

## Wo das Gerundio sonst noch vorkommt

Das Gerundio wird auch adverbial benutzt, um die Art und Weise einer Handlung zu
beschreiben:

```
Salió corriendo.        (Er ging rennend hinaus.)
Entró sonriendo.        (Sie kam lächelnd herein.)
```

Das ist mit dem seltenen deutschen Partizip-I-Adverbial vergleichbar ("er kam
lächelnd herein"), aber im Spanischen deutlich produktiver und alltäglicher. Auch mit
anderen Hilfsverben bildet das Gerundio feste Konstruktionen, etwa "seguir + Gerundio"
(weiterhin etwas tun): "Sigo estudiando español" (Ich lerne weiterhin Spanisch).

## Merksatz für Deutschsprachige

Weil dein Deutsch dir hier kein Muster liefert, hilft eine feste Eselsbrücke: Immer
wenn du im Deutschen "gerade" einfügen könntest ("ich lese GERADE"), brauchst du im
Spanischen **estar + Gerundio**. Für alles andere — allgemeine Aussagen, Gewohnheiten
— bleibt das einfache Präsens (leo, como, parto).
