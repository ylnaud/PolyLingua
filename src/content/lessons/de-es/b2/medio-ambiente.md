Um über Umwelt- und Gesellschaftsthemen zu diskutieren, brauchst du ein
Set an Grundvokabular — vieles davon erkennst du dank internationaler
Fachwörter fast automatisch.

## Grundbegriffe rund um den Klimawandel

```
el cambio climático        (der Klimawandel)
el calentamiento global    (die globale Erwärmung)
las emisiones de CO2       (die CO2-Emissionen)
el efecto invernadero      (der Treibhauseffekt)
```

## Verschmutzung und ihre Quellen

```
la contaminación           (die Verschmutzung)
la contaminación del aire   (die Luftverschmutzung)
los residuos                (der Abfall)
el plástico de un solo uso  (Einwegplastik)
```

## Lösungsorientierter Wortschatz

```
reciclar / el reciclaje              (recyceln / das Recycling)
reducir el consumo                    (den Verbrauch reduzieren)
las energías renovables               (die erneuerbaren Energien)
la sostenibilidad / sostenible        (die Nachhaltigkeit / nachhaltig)
proteger el medio ambiente            (die Umwelt schützen)
```

## Nützliche Redewendungen

```
Es importante cuidar el planeta.
(Es ist wichtig, den Planeten zu pflegen.)

Debemos reducir nuestra huella de carbono.
(Wir müssen unseren CO2-Fußabdruck reduzieren.)

Cada vez más gente apuesta por un estilo de vida sostenible.
(Immer mehr Menschen setzen auf einen nachhaltigen Lebensstil.)
```

## Zusammenfassung

Mit diesem Grundwortschatz kannst du bereits über die wichtigsten
Umweltthemen sprechen — Klimawandel, Verschmutzung, Recycling und
Nachhaltigkeit. Viele Begriffe sind internationale Fachwörter mit
spanischer Rechtschreibung, sodass du sie oft leichter wiedererkennst als
lernen musst.
