Wenn du im Deutschen berichtete Rede bildest, wechselst du den Modus: "Er sagte, er sei
müde." Das Spanische löst dasselbe Problem völlig anders — mit einer Zeitverschiebung.

## Das Prinzip: Modus bleibt, Zeit verschiebt sich

Im estilo indirecto bleibt der Modus der ursprünglichen Aussage meistens erhalten
(Indikativ bleibt Indikativ, subjuntivo bleibt subjuntivo) — was sich verändert, ist die
**Zeitform**, sobald das Einleitungsverb (dijo, contó, explicó) in der Vergangenheit
steht. Das ist der zentrale Unterschied zum Deutschen: Du musst nicht lernen, wann du
in den Konjunktiv wechselst, sondern wann du eine Zeitform nach hinten verschiebst.

## Die Umwandlungstabelle

| Direkte Rede (presente)        | Estilo indirecto (Vergangenheit) |
| --------------------------------- | ----------------------------------- |
| presente (estoy)                | pretérito imperfecto (estaba)    |
| pretérito perfecto (he ido)     | pluscuamperfecto (había ido)     |
| pretérito indefinido (fui)      | pluscuamperfecto (había ido)     |
| futuro (iré)                    | condicional (iría)               |
| imperativo (¡ven!)              | subjuntivo imperfecto (que viniera) |

## Zeit- und Ortsangaben verschieben sich mit

| Direkte Rede | Estilo indirecto |
| -------------- | ------------------- |
| hoy           | ese día             |
| mañana        | al día siguiente    |
| ayer          | el día anterior     |
| aquí          | allí                |
| este/esta     | ese/esa             |

## Wann die Zeit NICHT verschoben wird

Steht das Einleitungsverb im Präsens ("Dice que..."), bleibt die Zeitform der Aussage
unverändert: "Dice que está cansada" (Er/Sie sagt, dass er/sie müde ist). Die
Verschiebung passiert ausschließlich, wenn das Einleitungsverb selbst in der
Vergangenheit steht — ein Konzept, das dem deutschen System der Zeitenfolge in
Nebensätzen mit "dass" strukturell ähnelt, nur dass das Deutsche dort keine
verpflichtende Verschiebung kennt.

## Die C1-Nuance: Imperativ wird zu subjuntivo

Ein Sonderfall, der Lernende oft überrascht: Ein Imperativ in direkter Rede ("¡Ven
aquí!") wird im estilo indirecto nicht einfach zu einem anderen Indikativ-Tempus,
sondern zum subjuntivo imperfeito: "Me dijo que viniera aquí" (Er sagte mir, ich solle
herkommen). Das liegt daran, dass ein Befehl per Definition unsicher/nicht realisiert
ist, bis er befolgt wird — genau das Terrain des subjuntivo. Diese Verbindung zwischen
den beiden Lektionen — Zeitenfolge und subjuntivo — ist typisch für das C1-Niveau: Die
Grammatikthemen greifen ineinander, statt isoliert nebeneinanderzustehen.
