Du kennst schon die echte Passivform mit **ser + Partizip** ("La casa es
vendida"). Im Alltag ist diese Form aber selten — Spanischsprachige
benutzen stattdessen viel häufiger die **Pasiva refleja**: "se" plus
Verb.

## Die Grundform

```
Se vende casa.        → Haus zu verkaufen. (Singular)
Se venden casas.       → Häuser zu verkaufen. (Plural)
```

Das Muster: **se + Verb (3. Person) + logisches Objekt**. Das
"logische Objekt" (casa/casas) übernimmt dabei grammatisch die Rolle des
Subjekts — genau deshalb muss das Verb sich in Numerus danach richten.

## Kongruenz: der entscheidende Unterschied zum deutschen "man"

Im Deutschen bleibt "man" immer unverändert, mit einer festen
Singular-Verbform:

```
Man verkauft Häuser.   (man bleibt gleich, egal ob 1 oder 100 Häuser)
```

Im Spanischen dagegen passt sich das Verb an das logische Objekt an:

```
Se vende casa.    (Singular: 1 Haus)
Se venden casas.   (Plural: mehrere Häuser)
```

Das ist der zentrale Punkt, den du dir merken musst: die Pasiva refleja
hat eine **echte grammatische Kongruenz**, die die deutsche
man-Konstruktion nicht kennt.

## Feste Formeln im Alltag

Die Pasiva refleja ist extrem produktiv und taucht in vielen festen
Wendungen auf, die du wahrscheinlich schon gesehen hast:

```
Se habla español.        (Hier spricht man Spanisch — Türschild)
Se prohíbe fumar.         (Rauchen verboten — Schild)
Se busca camarero.         (Kellner gesucht — Stellenanzeige)
¿Cómo se dice "Baum" en español?  (Wie sagt man "Baum" auf Spanisch?)
```

## Wann Pasiva refleja, wann echtes Passiv mit ser?

Als Faustregel: Die Pasiva refleja ist die natürlichere, alltäglichere
Wahl, besonders wenn kein Handelnder genannt wird ("wer" verkauft
spielt keine Rolle). Das echte Passiv mit ser + Partizip wirkt formeller
und wird eher benutzt, wenn der Handelnde ausdrücklich genannt wird (mit
"por"):

```
Pasiva refleja (alltäglich):  Se vendió la casa.
Ser-Passiv (formell, mit Agens): La casa fue vendida por la empresa.
```

## Zusammenfassung

Die Pasiva refleja ("se" + Verb) ist im spanischen Alltag viel häufiger
als das echte Passiv mit ser. Der entscheidende Unterschied zum
deutschen "man": Das spanische Verb passt sich in Numerus an das
logische Objekt an (se vende / se venden), während "man" im Deutschen
immer unveränderlich bleibt.
