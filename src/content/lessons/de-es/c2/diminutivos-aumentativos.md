Deutsch hat mit -chen/-lein zwar auch Diminutive, aber sie sind stilistisch
eng begrenzt. Das spanische System mit -ito/-ita (Diminutiv) und -ón/-ona
(Augmentativ) ist dagegen hochproduktiv — und drückt viel mehr aus als
nur Größe.

## -ito/-ita: nicht nur klein

Die wörtliche Bedeutung "klein" ist im Alltag oft die am wenigsten
wichtige Funktion. Viel häufiger drückt -ito/-ita aus:

**Zuneigung** (unabhängig von der Größe):
```
mi hijito       (mein Söhnchen — auch bei einem erwachsenen Sohn liebevoll gemeint)
mi perrito       (mein Hündchen — auch bei einem großen Hund)
```

**Höflichkeit/Abmilderung:**
```
un momentito     (ein kleiner Moment — höflicher als "un momento")
una preguntita    (eine kleine Frage — mildert die Bitte ab)
```

**Manchmal auch Ironie**, je nach Tonfall:
```
¡Qué buenecito eres!    (Wie brav du doch bist! — kann sarkastisch klingen)
```

## -ón/-ona: mehr als nur groß

Das Augmentativ funktioniert spiegelbildlich — es drückt oft zusätzlich
Intensität oder sogar eine Charaktereigenschaft aus, nicht nur physische
Größe:

```
un problemón        (ein RIESIGES Problem — Intensität)
un llorón / una llorona   (ein Heulsuse — Charaktereigenschaft, von llorar)
un cabezón            (ein Sturkopf — von cabeza, wörtlich "Großkopf")
```

## Der Vergleich zum Deutschen

| Deutsch                          | Spanisch                        |
| ----------------------------------- | ----------------------------------- |
| eng begrenzt, oft kindlich/altmodisch | hochproduktiv, in jedem Register normal |
| meist nur physische Größe            | Größe, Zuneigung, Höflichkeit, Ironie, Charakter |
| Häuschen, Kaninchen, Mädchen (feste Wörter) | in Echtzeit auf fast jedes Substantiv/Adjektiv anwendbar |

## Zusammenfassung

Diminutive und Augmentative sind im Spanischen ein lebendiges,
alltägliches Werkzeug für viel mehr als Größenangaben — sie transportieren
Emotion, Höflichkeit und manchmal Ironie. Das ist der eigentliche Grund,
warum sie in jedem Register (auch unter Erwachsenen, auch formell) so
häufig vorkommen — ganz anders als das eingeschränkte deutsche
-chen/-lein.
