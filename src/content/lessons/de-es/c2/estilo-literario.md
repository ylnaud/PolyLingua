Gehobener spanischer Erzählstil unterscheidet sich vom Alltagsspanisch
durch mehrere klare, wiedererkennbare Merkmale.

## Vorangestellte Adjektive: schmücken statt unterscheiden

Im Alltag steht das Adjektiv meist NACH dem Substantiv und unterscheidet
(eine bestimmte Eigenschaft von anderen möglichen):

```
la nieve blanca     (der weiße Schnee — unter anderen Schneearten)
```

In literarischer Prosa wird das Adjektiv oft VOR das Substantiv gestellt
— dann wirkt es rein schmückend, nicht unterscheidend:

```
la blanca nieve     (der [poetisch beschriebene] weiße Schnee)
```

Dieses Signal erkennst du sofort als typisch literarisch.

## Hypotaktischer Satzbau

Literarische/essayistische Prosa verschachtelt gerne mehrere Nebensätze
ineinander, statt kurze Hauptsätze aneinanderzureihen:

```
Parataktisch (Alltag): Llegó a casa. Estaba cansado. Se sentó.
Hypotaktisch (Literatur): Cuando llegó a casa, cansado tras un día que
   parecía no tener fin, se dejó caer en el sillón sin decir palabra.
```

## Der pretérito imperfecto de subjuntivo als Höflichkeitsform

In gehobener/formeller Sprache ersetzt der pretérito imperfecto de
subjuntivo manchmal höflich den condicional:

```
Quisiera hacerle una pregunta.
(Ich würde Ihnen gerne eine Frage stellen. — gehobener als "querría")
```

## Gehobener Wortschatz

Literarische Texte bevorzugen oft seltenere, lateinisch geprägte
Synonyme statt der gängigen Alltagswörter:

| Alltag  | Gehoben   |
| --------- | ----------- |
| regalo    | obsequio    |
| casa      | morada      |
| empezar   | comenzar    |
| ver       | contemplar  |

## Zusammenfassung

Vorangestellte Adjektive, hypotaktischer Satzbau, der pretérito imperfecto
de subjuntivo als Höflichkeitsform und ein gehobener, lateinisch geprägter
Wortschatz sind die vier zuverlässigsten Signale, um literarischen Stil im
Spanischen wiederzuerkennen und selbst zu produzieren.
