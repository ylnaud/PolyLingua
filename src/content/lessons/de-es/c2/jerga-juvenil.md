Wie das Deutsche mit "chillen" oder "cringe" verwandelt die spanische
Jugendsprache englische Wörter in eigene Verben und Ausdrücke — dieselbe
Strategie, andere Endungen.

## Kernvokabular der Alltags-Jugendsprache

```
guay          (cool, toll)
molar         (gefallen, cool sein — "me mola" = ich finde es cool)
flipar        (ausflippen, überwältigt/begeistert sein)
un rollo       (eine langweilige/nervige Sache — "qué rollo" = wie nervig)
```

## Anglizismen mit spanischer Verbendung

Genau wie das Deutsche englische Verben eindeutscht (chillen, canceln,
googeln), hängt das Spanische spanische Endungen an — meist -ear oder
-ar:

| Englisch  | Spanisch    | Deutsch (Vergleich) |
| ----------- | ------------- | ---------------------- |
| to post     | postear       | posten                  |
| to chat     | chatear       | chatten                  |
| to stalk    | stalkear      | stalken                 |
| to google   | googlear      | googeln                  |

## Feste Ausdrücke aus dem Dating-/Social-Media-Kontext

```
Hacer match       (ein Match haben, Dating-Apps)
Dar like           (liken)
Estar en línea      (online sein)
```

## Ein Beispieldialog

```
— ¿Has visto la peli nueva? ¡Es muy guay!
  (Hast du den neuen Film gesehen? Der ist total cool!)
— Sí, ¡estoy flipando con los efectos especiales!
  (Ja, ich flippe total aus wegen der Spezialeffekte!)
— Voy a postear una reseña en mi cuenta.
  (Ich poste eine Rezension auf meinem Account.)
```

## Regionale Vorsicht

Ein wichtiger Hinweis: "guay" und "molar" sind vor allem typisch für
Spanien — in Lateinamerika gibt es eigene, regional unterschiedliche
Jugendwörter (z. B. "chido" in Mexiko, "chévere" in vielen Teilen
Südamerikas). Jerga verändert sich außerdem schnell, deshalb solltest du
sie eher zum Verstehen als zum aktiven, dauerhaften Sprachgebrauch lernen.

## Zusammenfassung

Die spanische Jugendsprache übernimmt Anglizismen mit derselben Strategie
wie das Deutsche — eigene Verbendung statt direkter Übernahme — und hat
daneben ein eigenes Set an Kernwörtern (guay, molar, flipar), die du beim
Verstehen von Alltagsgesprächen unter jungen Muttersprachlern brauchst.
