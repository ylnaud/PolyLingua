Im Deutschen kennst du drei Genera: der, die, das. Das Französische reduziert das auf
zwei: **le** (männlich) und **la** (weiblich) — das neutrale Genus gibt es dort schlicht
nicht. Das klingt einfacher, ist aber eine echte Falle: jedes deutsche "das"-Wort muss
sich im Französischen für eins der beiden Genera entscheiden, und du kannst nicht
vorhersagen, für welches.

## Die bestimmten Artikel

| Genus                   | Singular | Beispiel                |
| ------------------------ | -------- | ------------------------ |
| männlich                 | le       | le livre (das Buch)      |
| weiblich                 | la       | la table (der Tisch)     |
| vor Vokal (beide Genera) | l'       | l'ami (der Freund)       |
| Plural (beide Genera)    | les      | les livres / les tables  |

## Die unbestimmten Artikel

| Genus     | Singular | Plural |
| --------- | -------- | ------ |
| männlich  | un       | des    |
| weiblich  | une      | des    |

Bemerkenswert: im Plural unterscheidet das Französische **kein Genus mehr** beim
unbestimmten Artikel — "des" gilt für beide. Genau wie im Deutschen der bestimmte
Artikel im Plural immer "die" ist (der Tisch → die Tische, das Buch → die Bücher),
verschwindet auch im Französischen die Genus-Unterscheidung im Plural komplett
(le livre → les livres, la table → les tables). Diese eine Regel ist in beiden
Sprachen identisch gebaut.

## Die Falle: drei Genera werden zu zwei

Jedes deutsche neutrale Nomen ("das ...") muss sich im Französischen entscheiden:

| Deutsch (neutral) | Französisch    | Genus im Französischen |
| ------------------ | -------------- | ----------------------- |
| das Auto            | la voiture     | weiblich                 |
| das Buch            | le livre       | männlich                 |
| das Schloss         | le château     | männlich                 |

Es gibt keinen Trick, der dir vorhersagt, wohin ein "das"-Wort wandert — du musst es
für jedes Wort einzeln lernen.

## Muster, die wirklich helfen

Manche Endungen sind sehr zuverlässige Hinweise auf das Genus:

| Endung        | Genus fast immer | Beispiel                  |
| -------------- | ----------------- | -------------------------- |
| -tion, -sion   | weiblich          | la nation, la télévision   |
| -ment          | männlich           | le gouvernement            |
| -eau           | männlich           | le bureau, le château      |
| -e (viele Fälle) | weiblich          | la chaise, la porte        |

## Verschmelzung vor Vokal — im Deutschen unbekannt

Vor einem Vokal (oder stummem h) verschmelzen le und la immer zu **l'**, egal ob das
Wort eigentlich männlich oder weiblich ist:

```
le + ami  →  l'ami
la + université → l'université
```

Diese Verschmelzung gibt es im Deutschen nicht: der, die, das bleiben immer
unverändert, ob das nächste Wort mit Vokal beginnt oder nicht.

## Der praktische Trick

Verlass dich niemals auf dein deutsches Sprachgefühl: "le lait" (die Milch), "le
soleil" (die Sonne), "la voiture" (das Auto) — manchmal stimmt das Genus zufällig mit
dem Deutschen überein, oft nicht. Der einzig sichere Weg: jedes Substantiv **zusammen
mit seinem Artikel** lernen, als wäre es ein einziges Wort.
