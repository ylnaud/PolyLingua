Essen gehen in Frankreich ist ein kulturelles Erlebnis, und wenn du die
richtigen Sätze kennst, genießt du es ohne Stress. Die Formeln sind fast
immer dieselben — nur was du bestellst, ändert sich.

## 1. Ankommen und Platz nehmen

```
Bonjour! Une table pour deux, s'il vous plaît.
Guten Tag! Einen Tisch für zwei, bitte.
```

Hast du reserviert:

```
J'ai une réservation au nom de Müller.
Ich habe eine Reservierung auf den Namen Müller.
```

## 2. Die Speisekarte erbitten

```
La carte, s'il vous plaît.     Die Speisekarte, bitte.
```

Wichtiger Unterschied — auch ein falscher Freund für Deutschsprachige: **la
carte** ist die vollständige Speisekarte mit allen einzelnen Gerichten.
**Le menu** (oder **la formule**) ist dagegen ein Festpreis-Menü, meist mit
drei Gängen: entrée (Vorspeise), plat (Hauptgang) und dessert (Nachtisch).
Das deutsche Wort "Menü" meint oft die ganze Karte — im Französischen ist
es genau das Gegenteil: nur ein festes Angebot.

## 3. Fragen und bestellen

```
Qu'est-ce que vous recommandez?      Was empfehlen Sie?
Je voudrais le plat du jour.          Ich hätte gern das Tagesgericht.
Je voudrais un steak, s'il vous plaît.  Ich hätte gern ein Steak, bitte.
```

Bestellst du Fleisch, fragt der Kellner meist **"Quelle cuisson?"** (welchen
Garpunkt):

| Französisch | Deutsch                |
| ----------- | ------------------------ |
| saignant    | blutig / englisch          |
| à point     | medium                       |
| bien cuit   | durchgebraten                  |

## 4. Getränke

```
Une carafe d'eau, s'il vous plaît.       Eine Karaffe Leitungswasser, bitte.
Un verre de vin rouge, s'il vous plaît.  Ein Glas Rotwein, bitte.
```

Kultureller Unterschied zu Deutschland: In Frankreich ist Leitungswasser
trinkbar und in Restaurants kostenlos. Bestell **"une carafe d'eau"** und
es wird dir nichts berechnet. Bestellst du nur "de l'eau" ohne genauere
Angabe, bekommst du unter Umständen kostenpflichtiges Flaschenwasser.

## 5. Während des Essens

```
C'est délicieux!            Das ist köstlich!
Encore un peu de pain?      Noch etwas Brot?
```

Brot ist in französischen Restaurants meist gratis und wird nachgelegt.

## 6. Die Rechnung erbitten

```
L'addition, s'il vous plaît.       Die Rechnung, bitte.
```

Der Kellner bringt dir die Rechnung **nicht von selbst** — das gilt als
höflich, dich nicht zu drängen. Anders als in manchen deutschen Lokalen
musst du also aktiv danach fragen.

## Das Trinkgeld

Der Service ist in Frankreich per Gesetz im Preis enthalten. Du musst kein
Trinkgeld geben, aber ein bis zwei Euro sind eine nette Geste bei gutem
Service. Anders als in Deutschland, wo man häufig auf den nächsten runden
Betrag aufrundet, wird in Frankreich kein festes Prozent erwartet.
