Einkaufen in Frankreich lässt sich mit einer Handvoll Sätzen bewältigen,
die immer wieder auftauchen. Lern sie als feste Bausteine, und du kommst
in jedem Geschäft und Supermarkt zurecht, ohne improvisieren zu müssen.

## 1. Ein Produkt erbitten oder suchen

```
Je voudrais une baguette, s'il vous plaît.   Ich hätte gern eine Baguette, bitte.
Je cherche du pain.                           Ich suche Brot.
Vous avez des tomates?                        Haben Sie Tomaten?
```

**Je voudrais** ist die höfliche Bitte-Form, vergleichbar mit "ich hätte
gern" im Deutschen. Vermeide "je veux" (ich will), das direkter und weniger
höflich klingt.

## 2. Nach dem Preis fragen

```
Combien ça coûte?       Wie viel kostet das?
C'est combien?          Was macht das? (informeller)
```

Findest du den Preis zu hoch:

```
C'est trop cher.        Das ist zu teuer.
```

## 3. Sich entscheiden

```
Je prends ça.            Ich nehme das.
Je prends celui-là.      Ich nehme das da.
```

## 4. Bezahlen

```
Je paie par carte.       Ich bezahle mit Karte.
Je paie en espèces.      Ich bezahle bar.
Un sac, s'il vous plaît.  Eine Tüte, bitte.
Merci, c'est tout.       Danke, das ist alles.
```

Genau wie in Deutschland kostet die Tüte oft extra — frag also ruhig danach.

## Die spezialisierten Geschäfte

In Frankreich kaufen viele Menschen zusätzlich zum Supermarkt noch in
spezialisierten Läden ein — ein Muster, das dir aus Deutschland mit
Bäckerei und Metzgerei durchaus vertraut ist, in Frankreich aber noch
verbreiteter ist:

| Geschäft       | Was es verkauft         |
| -------------- | ------------------------ |
| la boulangerie | Brot und Baguettes        |
| la pâtisserie  | Kuchen und Süßspeisen      |
| la boucherie   | Fleisch                     |
| la fromagerie  | Käse                          |
| le marché      | Freiluftmarkt                   |
| le supermarché | Supermarkt                        |

## Der Ablauf in einem kleinen Geschäft

1. Beim Eintreten: **"Bonjour!"**
2. Das Verkaufspersonal fragt: "Qu'est-ce que je vous sers?" (Was darf es
   sein?)
3. Du bestellst: **"Je voudrais..., s'il vous plaît"**
4. Man fragt, ob du noch etwas möchtest: "Et avec ceci?" (Sonst noch
   etwas?)
5. Wenn nicht: **"Merci, c'est tout"**
6. Du bezahlst und sagst beim Rausgehen: **"Merci, au revoir!"**
