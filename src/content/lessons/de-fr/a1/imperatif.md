Der Imperativ dient dazu, Befehle, Anweisungen, Ratschläge oder Einladungen
auszusprechen. Wie im Deutschen mit du/ihr/Sie kennt auch das Französische
drei Formen — allerdings anders aufgeteilt: **tu**, **nous** und **vous**,
jeweils ohne das Pronomen davorzustellen.

## Wie der Imperativ gebildet wird

Man nimmt die Präsensform und lässt einfach das Pronomen weg:

| Person | Präsens        | Imperativ  |
| ------ | -------------- | ---------- |
| tu     | tu finis       | Finis!     |
| nous   | nous finissons | Finissons! |
| vous   | vous finissez  | Finissez!  |

## Die Sonderregel bei -er-Verben

Bei Verben der ersten Gruppe (auf -er) verliert die tu-Form ihr **Schluss-s**:

```
tu parles    ->    Parle!     (nicht "Parles!")
tu manges    ->    Mange!     (nicht "Manges!")
tu regardes  ->    Regarde!   (nicht "Regardes!")
```

Diese Regel betrifft nur die tu-Form der -er-Verben. Verben der zweiten
(-ir) und dritten Gruppe behalten ihr -s ganz normal:

```
tu finis     ->    Finis!     (mit -s, wie erwartet)
tu écris     ->    Écris!     (mit -s, wie erwartet)
```

## Die nous-Form: eine Konstruktion, die es im Deutschen so nicht gibt

Während Deutsch für "Lass uns essen!" eine ganze Umschreibung braucht,
besitzt das Französische dafür eine eigene, einfache Verbform:

```
Mangeons!     Lass uns essen!
Partons!      Lass uns losgehen!
```

Diese nous-Form lohnt sich besonders zu merken, weil sie im Deutschen keine
direkte Verbentsprechung hat — du musst sie als eigenes Werkzeug lernen,
nicht als Übersetzung eines deutschen Musters.

## Drei unregelmäßige Imperative

Drei sehr häufige Verben haben einen völlig unregelmäßigen Imperativ:

### Être (sein)

| Person | Imperativ |
| ------ | --------- |
| tu     | sois      |
| nous   | soyons    |
| vous   | soyez     |

```
Sois sage!            Sei brav!
Soyons patients!      Seien wir geduldig!
Soyez les bienvenus!  Seid willkommen!
```

### Avoir (haben)

| Person | Imperativ |
| ------ | --------- |
| tu     | aie       |
| nous   | ayons     |
| vous   | ayez      |

```
Aie confiance!        Hab Vertrauen!
Ayons du courage!     Lass uns mutig sein!
N'ayez pas peur!      Habt keine Angst!
```

### Savoir (wissen)

| Person | Imperativ |
| ------ | --------- |
| tu     | sache     |
| nous   | sachons   |
| vous   | sachez    |

```
Sache que je suis là.       Wisse, dass ich hier bin.
Sachez que c'est interdit.  Wisst, dass das verboten ist.
```

## Der verneinte Imperativ

Für die Verneinung wird das Verb einfach zwischen "ne" und "pas"
eingeschlossen — genau wie bei jeder anderen Verneinung:

```
Ne parle pas!            Sprich nicht!
Ne mangeons pas ici!     Lass uns hier nicht essen!
N'ayez pas peur!         Habt keine Angst!
```

## Vous: eine Form, zwei Bedeutungen

Ein wichtiger Unterschied zum Deutschen: Während Deutsch zwischen **ihr**
(mehrere Personen, informell) und **Sie** (Höflichkeitsform) unterscheidet,
deckt das französische **vous** beides ab. "Écoutez!" kann also sowohl
"Hört zu!" (an mehrere Freunde) als auch "Hören Sie zu!" (höflich an eine
einzelne Person) bedeuten — der Kontext entscheidet.

## Alltägliche Verwendung

Der Imperativ dient nicht nur zum Befehlen. Er wird auch benutzt für:

- **Einladungen**: Mangeons ensemble! (Lass uns zusammen essen!)
- **Ratschläge**: Fais attention! (Pass auf!)
- **Anweisungen**: Tournez à droite. (Biegen Sie rechts ab.)
- **Ermutigung**: Sois courageux! (Sei mutig!)
