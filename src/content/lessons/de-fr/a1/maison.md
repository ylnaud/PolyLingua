Über die eigene Wohnung zu sprechen gehört zu den häufigsten Gesprächen,
wenn man neue Leute kennenlernt oder eine Wohnung sucht. Hier findest du
das wichtigste Vokabular zu Zimmern und Möbeln, zusammen mit der Formel
"il y a", um sie zu beschreiben.

## Die Zimmer

| Französisch        | Deutsch       |
| -------------------- | -------------- |
| la cuisine            | die Küche       |
| la chambre            | das Schlafzimmer|
| la salle de bains     | das Badezimmer   |
| le salon              | das Wohnzimmer    |

## Die Grundmöbel

| Französisch  | Deutsch     |
| ------------- | ------------ |
| le lit        | das Bett      |
| la table      | der Tisch      |
| la chaise     | der Stuhl       |
| le canapé     | das Sofa         |

## "Il y a": die Formel zum Beschreiben

"Il y a" bedeutet "es gibt" und ist unveränderlich: es wird für eine Sache
genauso benutzt wie für mehrere, im Singular wie im Plural.

```
Il y a une table dans la cuisine.        (Es gibt einen Tisch in der Küche)
Il y a un lit dans la chambre.           (Es gibt ein Bett im Schlafzimmer)
Il y a une chaise dans le salon.         (Es gibt einen Stuhl im Wohnzimmer)
```

## Der Trick bei "il y a"

Anders als die meisten französischen Verben ändert sich "il y a" niemals —
weder mit der Anzahl der Dinge noch mit ihrem Geschlecht. Genau wie das
deutsche "es gibt", das ebenfalls immer gleich bleibt. Hast du diese
Formel einmal gelernt, kannst du jedes Zimmer deines Zuhauses beschreiben,
indem du nur das Substantiv und den Ort änderst.
