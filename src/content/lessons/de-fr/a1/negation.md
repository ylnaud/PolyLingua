Verneinen ist im Deutschen unkompliziert: ein einziges "nicht" reicht. Im
Französischen brauchst du dagegen ein Wortpaar, das sich um das Verb legt — eine
Struktur, die es im Deutschen so nicht gibt.

## Der Grundbau: ne + Verb + pas

```
Je parle français.        →  Je ne parle pas français.
(Ich spreche Französisch)     (Ich spreche kein Französisch)
```

**ne** steht direkt vor dem konjugierten Verb, **pas** direkt danach — beide Teile
zusammen bilden die Verneinung, keiner davon funktioniert allein.

| Bejaht                  | Verneint                        |
| ------------------------- | ---------------------------------- |
| Je parle français.        | Je ne parle pas français.           |
| Tu aimes le café.         | Tu n'aimes pas le café.             |
| Il fume.                  | Il ne fume pas.                     |

## ne vor Vokal: Elision zu n'

Genau wie der Artikel le/la vor einem Vokal zu l' wird, verschmilzt auch **ne** vor
einem Vokal (oder stummem h) zu **n'**:

```
je ne aime pas   →   je n'aime pas
je ne ai pas     →   je n'ai pas
```

## Die gesprochene Falle: ne verschwindet oft

Im lockeren Alltagsfranzösisch, besonders im Gespräch, fällt das **ne** sehr häufig
komplett weg:

```
Geschrieben/formell:   Je ne parle pas anglais.
Gesprochen/leger:      Je parle pas anglais.
```

Das bedeutet: wenn du gesprochenes Französisch hörst, verlass dich nicht darauf,
dass du "ne" hörst, um eine Verneinung zu erkennen — oft ist **pas** allein schon
das einzige hörbare Signal. Schriftlich, in offiziellen Texten und im formellen
Sprechen bleibt "ne" dagegen erhalten.

## Verneinung + unbestimmter Artikel: un/une/des wird zu de

Eine Zusatzregel ohne deutsche Entsprechung: nach einer Verneinung wird der
unbestimmte Artikel (un, une, des) meist zu **de**:

```
J'ai un chat.        →  Je n'ai pas de chat.
(Ich habe eine Katze)    (Ich habe keine Katze)

J'ai des amis.       →  Je n'ai pas d'amis.
(Ich habe Freunde)       (Ich habe keine Freunde)
```

## Verneinung mit Infinitiv

Vor einem Infinitiv bleiben ne und pas als Einheit zusammen und stehen **beide vor**
dem Verb:

```
ne pas fumer     nicht rauchen
ne pas parler    nicht sprechen
```

## Der praktische Trick

Denk an ne...pas als eine **Zange**, die sich um das konjugierte Verb schließt —
nicht als ein einzelnes Wort wie das deutsche "nicht". Und gewöhne dein Ohr früh
daran, dass im gesprochenen Französisch oft nur die zweite Hälfte der Zange, "pas",
tatsächlich zu hören ist.
