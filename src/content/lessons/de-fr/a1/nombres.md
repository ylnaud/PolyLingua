Bis 69 folgen die französischen Zahlen einer Logik, die dem Deutschen sogar überlegen
ist. Ab 70 wird es dann anders als alles, was du aus dem Deutschen kennst.

## 0 bis 20: die Basis

| Zahl | Französisch | Zahl | Französisch |
| ---- | ----------- | ---- | ----------- |
| 0    | zéro        | 11   | onze        |
| 1    | un/une      | 12   | douze       |
| 2    | deux        | 13   | treize      |
| 3    | trois       | 14   | quatorze    |
| 4    | quatre      | 15   | quinze      |
| 5    | cinq        | 16   | seize       |
| 6    | six         | 17   | dix-sept    |
| 7    | sept        | 18   | dix-huit    |
| 8    | huit        | 19   | dix-neuf    |
| 9    | neuf        | 20   | vingt       |
| 10   | dix         |      |             |

## 21 bis 69: Zehner + Einer (logischer als Deutsch)

| Zahl | Französisch  | Deutsch zum Vergleich |
| ---- | ------------ | ----------------------- |
| 21   | vingt et un  | einundzwanzig            |
| 30   | trente       | dreißig                  |
| 40   | quarante     | vierzig                  |
| 50   | cinquante    | fünfzig                  |
| 60   | soixante     | sechzig                  |

Hier ist das Französische sogar aufgeräumter: "vingt et un" nennt zuerst den Zehner,
dann den Einer — die natürliche Reihenfolge. Das Deutsche macht es andersherum
("einundzwanzig" = eins-und-zwanzig) und dreht damit die Ziffern beim Sprechen um.

**Achtung bei den x1-Zahlen:** 21, 31, 41, 51, 61 benutzen "et" (vingt **et** un,
trente **et** un) — ab 22 fällt "et" weg und es wird mit Bindestrich geschrieben:
vingt-deux, vingt-trois.

## 70 bis 99: die Zwanzigerlogik ohne deutsche Parallele

Ab hier hat das Standardfranzösisch aus Frankreich **keine eigenen Wörter** mehr für
die Zehner — es rechnet in Zwanzigerschritten weiter:

| Zahl | Französisch       | Wörtliche Bedeutung  |
| ---- | ------------------ | ---------------------- |
| 70   | soixante-dix       | sechzig + zehn          |
| 71   | soixante et onze   | sechzig + elf            |
| 72   | soixante-douze     | sechzig + zwölf          |
| 80   | quatre-vingts      | vier mal zwanzig         |
| 81   | quatre-vingt-un    | vier mal zwanzig + eins (kein -s mehr!) |
| 90   | quatre-vingt-dix   | vier mal zwanzig + zehn  |
| 91   | quatre-vingt-onze  | vier mal zwanzig + elf   |

Das Deutsche hat für jede dieser Zehnerzahlen ein eigenes, kompaktes Wort (siebzig,
achtzig, neunzig) — dafür gibt es im Standardfranzösisch keine Entsprechung. (In der
Schweiz und in Belgien sagt man tatsächlich "septante", "huitante/octante" und
"nonante" — aber das ist nicht das Französisch, das in Frankreich Standard ist.)

## 100

**cent** = 100. Ab 200 wird es "deux cents" (mit -s), aber sobald eine weitere Zahl
folgt, fällt das -s wieder weg: "deux cent un" (201).

## Der praktische Trick

Lerne 70, 80 und 90 nicht als Vokabel, sondern als **Rechnung**: 70 = 60+10, 80 =
4×20, 90 = 4×20+10. Sprich sie laut als Rechnung mit, bis dein Ohr sich daran
gewöhnt — es gibt im Deutschen keine Abkürzung, die dir diesen Schritt erspart.
