Im Deutschen gibt es viele verschiedene Pluralendungen und oft einen Vokalwechsel
(Buch → Bücher, Haus → Häuser). Im Französischen ist die Grundregel dagegen
erfreulich einfach — die Schwierigkeit liegt woanders: im **Hören**, nicht im
Schreiben.

## Die Grundregel: -s anhängen

Für die meisten Nomen hängt man einfach ein -s an, das **stumm** bleibt:

```
le livre  →  les livres   (das Buch → die Bücher)
la table  →  les tables   (der Tisch → die Tische)
la voiture → les voitures (das Auto → die Autos)
```

Wichtig: Du hörst dieses -s praktisch nie. Der Unterschied zwischen Singular und
Plural steckt vor allem im Artikel: **le/la** → **les**.

## Nomen, die sich nicht ändern: -s, -x, -z

Nomen, die im Singular schon auf -s, -x oder -z enden, bleiben im Plural
unverändert:

```
le prix  →  les prix    (der Preis → die Preise)
la voix  →  les voix    (die Stimme → die Stimmen)
le nez   →  les nez     (die Nase → die Nasen)
```

## -eau und -eu → -x

Nomen auf -eau und die meisten auf -eu bilden den Plural mit -x statt -s:

| Singular | Plural | Deutsch |
| --- | --- | --- |
| le bureau | les bureaux | der Schreibtisch |
| le château | les châteaux | das Schloss |
| le jeu | les jeux | das Spiel |

Ausnahme, die man einfach lernen muss: le pneu → les pneus (der Reifen).

## -al → -aux

Viele Nomen auf -al ersetzen die Endung im Plural durch -aux:

```
le journal  →  les journaux   (die Zeitung → die Zeitungen)
le cheval   →  les chevaux    (das Pferd → die Pferde)
```

Auch hier gibt es Ausnahmen, die -als behalten: le festival → les festivals,
le bal → les bals.

## Unregelmäßige Formen

Ein paar Nomen weichen komplett von den Regeln ab, ähnlich wie im Deutschen
"Auge → Augen" auch keiner festen Endungsregel folgt:

```
l'œil    →  les yeux     (das Auge → die Augen)
monsieur →  messieurs    (der Herr → die Herren)
madame   →  mesdames     (die Dame → die Damen)
```

## Der praktische Trick

Da das Plural-s beim Sprechen kaum hörbar ist, konzentrier dich beim Zuhören auf
den Artikel (le/la → les) statt auf das Nomen selbst — genau dort liegt der
eigentliche Unterschied.
