Im Deutschen ist die Verbkonjugation dein bester Freund: die Endung verrät dir fast
immer, welche Person handelt. Im Französischen musst du dieses Vertrauen ablegen — bei
den häufigsten Verben, den -er-Verben, klingen mehrere Formen exakt gleich.

## Regelmäßige -er-Verben: parler (sprechen)

| Pronomen | Form       | Aussprache-Hinweis          |
| -------- | ---------- | ----------------------------- |
| je       | parle      | -e ist stumm                  |
| tu       | parles     | -es ist stumm                 |
| il/elle  | parle      | -e ist stumm                  |
| nous     | parlons    | -ons wird hörbar ausgesprochen |
| vous     | parlez     | -ez wird hörbar ausgesprochen  |
| ils/elles | parlent   | -ent ist stumm                |

## Die Falle: vier Formen, ein Klang

Sprich diese vier Formen laut aus:

```
je parle
tu parles
il parle
ils parlent
```

Sie klingen — abgesehen vom Pronomen — **identisch**. Im Deutschen ist das
undenkbar: "ich spiele, du spielst, er spielt, sie spielen" hat vier klar
unterscheidbare Endungen. Im Französischen trägt bei -er-Verben nur das Pronomen die
eigentliche Information; die Verbendung selbst ist beim Zuhören fast wertlos.

## être (sein) — komplett unregelmäßig

| Pronomen | Form   |
| -------- | ------ |
| je       | suis   |
| tu       | es     |
| il/elle  | est    |
| nous     | sommes |
| vous     | êtes   |
| ils/elles | sont  |

Genau wie im Deutschen ("ich bin, du bist, er ist, wir sind, ihr seid, sie sind")
haben die Formen von être kaum eine gemeinsame Wurzel — das musst du auswendig lernen,
ähnlich wie du es im Deutschen schon getan hast.

## avoir (haben) — auch unregelmäßig

| Pronomen | Form  |
| -------- | ----- |
| je       | ai    |
| tu       | as    |
| il/elle  | a     |
| nous     | avons |
| vous     | avez  |
| ils/elles | ont  |

## Warum das im Deutschen anders läuft

Deutsche Verbendungen sind ein verlässliches Ohr-Signal: -e, -st, -t, -en, -t, -en.
Jede Person hat (fast) ihre eigene, hörbare Endung. Das Französische arbeitet bei
-er-Verben fast umgekehrt: die Schreibung unterscheidet die Formen (parle, parles,
parlent), aber die Aussprache tut es bei vier von sechs Formen NICHT. Verlass dich beim
Hören und Sprechen also nicht auf die Verbendung — verlass dich auf das Pronomen davor.

## Der praktische Trick

Übe -er-Verben laut, aber konzentriere dich auf das Pronomen als Träger der
Information, nicht auf die Verbendung. Bei être und avoir hilft nur eins: die sechs
Formen wie ein kleines Gedicht auswendig lernen, so wie du es im Deutschen mit "sein"
und "haben" auch getan hast.
