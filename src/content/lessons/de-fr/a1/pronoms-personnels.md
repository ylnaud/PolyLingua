Die französischen Subjektpronomen sehen auf den ersten Blick harmlos aus — bis du
merkst, dass eins der deutschen Pronomen im Französischen einfach fehlt.

## Die Übersicht

| Französisch | Deutsch          | Anmerkung                          |
| ------------ | ----------------- | -------------------------------------- |
| je           | ich                |                                          |
| tu           | du                 | vertraute Form                          |
| il           | er                 | auch für männliche Sachen               |
| elle         | sie (Sg.)          | auch für weibliche Sachen               |
| on           | man / informell: wir | wird wie il/elle konjugiert            |
| nous         | wir                |                                          |
| vous         | ihr / Sie          | Höflichkeitsform, wie deutsch "Sie"      |
| ils          | sie (Pl., m. oder gemischt) |                                 |
| elles        | sie (Pl., nur f.)  |                                          |

## Die zentrale Lücke: kein "es"

Das Deutsche hat drei Genera und drei passende Pronomen: er, sie, es. Das
Französische hat nur zwei Genera — männlich und weiblich — und deshalb auch nur zwei
Pronomen: **il** und **elle**. Ein neutrales "es" existiert schlicht nicht.

Das bedeutet: jeder Gegenstand, den du im Deutschen mit "es" ersetzt, bekommt im
Französischen stattdessen "il" oder "elle" — abhängig vom **grammatischen Genus**
des französischen Wortes, nicht vom deutschen:

| Deutsch                              | Französisch                          |
| -------------------------------------- | ---------------------------------------- |
| Das Auto ist rot. Es ist schön.        | La voiture est rouge. Elle est belle.     |
| Das Buch ist neu. Es ist interessant.  | Le livre est neuf. Il est intéressant.    |

"Das Auto" ist im Deutschen neutral ("es"), aber "la voiture" ist im Französischen
weiblich, also "elle". "Das Buch" ist im Deutschen ebenfalls neutral, aber "le
livre" ist im Französischen männlich, also "il". Es gibt keine Abkürzung — du musst
das Genus des französischen Wortes kennen, um das richtige Pronomen zu wählen.

## on: informell "wir", grammatisch "er/sie"

Im gesprochenen Alltag ersetzt **on** sehr häufig **nous**:

```
Formell:    Nous parlons français.
Informell:  On parle français.
```

Wichtig: "on" wird dabei wie "il/elle" konjugiert (3. Person Singular), auch wenn
es inhaltlich "wir" bedeutet — eine grammatische Eigenheit ohne deutsche Parallele.

## tu vs. vous: wie du/Sie im Deutschen

```
tu    →  vertraut, wie "du" (Familie, Freunde, Kinder)
vous  →  höflich, wie "Sie" (fremde Erwachsene, formelle Situationen) — UND normaler Plural für "ihr"
```

## Der praktische Trick

Wenn du im Deutschen "es" sagen würdest, stopp kurz und frag dich: "Welches Genus
hat das französische Wort dafür — männlich oder weiblich?" Erst dann weißt du, ob
"il" oder "elle" richtig ist. Es gibt in dieser Sprache keinen neutralen Ausweg.
