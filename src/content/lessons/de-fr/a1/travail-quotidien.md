Léa schlägt die Augen auf, wirft einen Blick auf die Uhr und startet in
ihren Tag: In dieser Lektion begleitest du sie durch ihren Arbeitsalltag
auf Französisch — mit dem Vokabular, das du brauchst, um auch von deinem
eigenen Job zu erzählen.

## Die Frage, die man dir stellen wird

```
Qu'est-ce que tu fais dans la vie?     (Was machst du beruflich?)
```

Beachte: Das Verb ist **"faire"** (machen), nicht "travailler" — wörtlich
"was machst du im Leben?". Das kommt dir bekannt vor: auch im Deutschen
fragen wir oft "Was machst du beruflich?" mit dem Verb "machen".

## Die Antworten folgen immer demselben Muster

```
Je travaille dans un bureau.       (Ich arbeite in einem Büro)
Je travaille dans un magasin.      (Ich arbeite in einem Geschäft)
Léa travaille dans un magasin.      (Léa arbeitet in einem Geschäft)
```

## Die Arbeitszeit: de ... à ...

```
Je travaille de neuf heures à dix-sept heures.   (Ich arbeite von neun bis fünf)
Je fais une pause à onze heures.                  (Ich mache um elf eine Pause)
J'ai une réunion à trois heures.                   (Ich habe um drei eine Besprechung)
```

## Vokabular rund ums Büro

| Französisch      | Deutsch          |
| ----------------- | ----------------- |
| le travail        | die Arbeit          |
| le bureau         | das Büro              |
| le patron         | der Chef                |
| la réunion        | die Besprechung           |
| faire une pause   | eine Pause machen           |

## Ein vollständiger Satz

```
Je travaille dans un bureau, de neuf heures à dix-sept heures, et je fais une pause à onze heures.
(Ich arbeite in einem Büro, von neun bis fünf, und mache um elf eine Pause)
```

## Der Trick zum Üben

Erzähl deinen eigenen Arbeitstag in drei Sätzen: wo du arbeitest, deine
Arbeitszeit und wann du eine Pause machst. Benutze dabei immer dieselbe
Struktur und ändere nur die Angaben — genau wie Léa es getan hat, um dir
ihren Tag zu beschreiben.
