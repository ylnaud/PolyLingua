Léa schließt die Woche ab und denkt über ihre Ausgaben nach: Sie spart für eine
Reise, also sind das die Geld-Sätze, die sie am häufigsten braucht.

## Die Frage, die man zuerst stellen sollte

```
Je peux payer par carte?               Kann ich mit Karte zahlen?
— Seulement en liquide, s'il vous plaît. Nur Bargeld, bitte.
```

Es lohnt sich, das **vorher** zu fragen, nicht erst nach der Bestellung.

## Geld abheben

```
Je dois retirer de l'argent.       Ich muss Geld abheben.
Où est un distributeur?             Wo gibt es einen Geldautomaten?
Je n'ai pas de liquide sur moi.     Ich habe kein Bargeld dabei.
```

"Liquide" bedeutet Bargeld im Französischen — nicht mit "flüssig" im wörtlichen
Sinn verwechseln.

## Sparen und Ausgaben

```
J'économise pour un voyage.        Ich spare für eine Reise.
Combien je te dois?                 Wie viel schulde ich dir?
```

## Ein vollständiger Satz

```
Je dois retirer de l'argent parce que j'économise pour un voyage.
(Ich muss Geld abheben, weil ich für eine Reise spare)
```

## Der Trick zum Üben

Merk dir zuerst **"Je peux payer par carte?"** — den brauchst du am häufigsten, so
wie Léa vor jedem Einkauf. Danach kommt "J'économise pour ...", das für jedes
Sparziel passt.
