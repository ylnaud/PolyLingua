Das ist deine erste und nützlichste Zukunftsform im Französischen — die Struktur,
die du im Alltagsgespräch wirklich hörst und benutzt.

## Die Formel

```
aller (konjugiert)  +  Infinitiv

Je vais    manger.
```

## Konjugation von "aller" im Präsens (Wiederholung)

| Pronomen  | aller  |
| --------- | ------ |
| je        | vais   |
| tu        | vas    |
| il/elle   | va     |
| nous      | allons |
| vous      | allez  |
| ils/elles | vont   |

## Vollständige Beispiele

```
Je vais manger.              (Ich werde gleich essen)
Tu vas partir demain?         (Fährst du morgen los?)
Nous allons voyager en été.   (Wir werden im Sommer reisen)
```

## Futur proche vs. Futur simple

|              | Verwendung                                       | Beispiel                     |
| ------------ | ------------------------------------------------- | ------------------------------ |
| Futur proche | Nahe Pläne, Alltagsgespräch                        | Je vais appeler ma mère.       |
| Futur simple | Ferne Pläne, formelle Versprechen, Vorhersagen     | Un jour, je vivrai à Paris.    |

## Das futur proche verneinen

Die Verneinung umschließt nur das Verb "aller", nicht den Infinitiv:

```
Je ne vais pas manger.     (Ich werde nicht essen — nicht "je vais ne pas manger")
```

## Der praktische Trick

Zögerst du zwischen futur proche und futur simple, denk ans Deutsche: Sagst du "ich
gehe gleich etwas machen" oder benutzt das Präsens für die nahe Zukunft, nimm das
futur proche; sagst du eher "ich werde etwas tun" in einem formelleren oder
langfristigeren Kontext, passt das futur simple besser. Das futur proche ist mit
Abstand das, was du im echten Gespräch am meisten brauchen wirst.
