Diese unpersönlichen Ausdrücke sind im Alltagsfranzösisch extrem häufig — "il"
bezieht sich auf niemanden Bestimmtes, es ist nur das feste grammatische Subjekt der
Formel, genau wie "es" im deutschen "es regnet" oder "es gibt".

## il faut: die allgemeine Verpflichtung

```
il faut + Infinitiv         (allgemeine Verpflichtung, ohne bestimmtes Subjekt)

Il faut manger pour vivre.      (Man muss essen, um zu leben)
Il faut être patient.            (Man muss geduldig sein)
```

## il faut que + Subjonctif: mit bestimmtem Subjekt

Willst du sagen, WEN die Verpflichtung genau betrifft, brauchst du "que" + Subjekt +
Subjonctif:

```
Il faut que tu partes maintenant.
(Du musst jetzt gehen — beachte den Subjonctif "partes")
```

## il y a: Existenz

```
Il y a un problème.          (Es gibt ein Problem)
Il y a trois livres ici.       (Es gibt drei Bücher hier)
Il n'y a pas de pain.          (Es gibt kein Brot)
```

## Weitere nützliche unpersönliche Ausdrücke

| Ausdruck              | Bedeutung      |
| ---------------------- | --------------- |
| il est important de    | es ist wichtig   |
| il est nécessaire de   | es ist nötig     |
| il est possible de     | es ist möglich   |
| il vaut mieux          | es ist besser    |

```
Il est important de bien dormir.
Il vaut mieux partir tôt.
```

## Der praktische Trick

"Il faut" ist dein Werkzeug, um allgemeine Ratschläge zu geben, ohne zu direkt zu
klingen ("du musst...") — viel natürlicher und häufiger im Französischen als bei
jeder Alltagsempfehlung "tu dois" zu sagen. Im Deutschen entspricht das genau dem
unpersönlichen "man muss" statt einem direkten "du musst".
