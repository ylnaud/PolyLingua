Wenn ein Franzose erzählt, was er gestern gemacht hat, benutzt er fast immer das
**passé composé**. Kennst du das deutsche Perfekt, kommt dir die Struktur sofort
bekannt vor — beide Sprachen bauen die Vergangenheit aus einem Hilfsverb plus einer
Partizipform.

## Die Formel: zwei Zutaten

```
avoir oder être (konjugiert)  +  participe passé

Ich habe    gegessen    (Perfekt, zum Vergleich)
J'ai        mangé       une pizza hier.
```

## avoir oder être?

- **avoir** → die große Mehrheit der Verben (der "Normalfall")
- **être** → eine geschlossene Gruppe von rund 14 Bewegungs-/Zustandswechselverben:
  aller, venir, partir, arriver, entrer, sortir, monter, descendre, naître, mourir,
  retourner, rester, tomber, passer (und ihre Ableitungen)

Das ist strukturell sehr ähnlich zum Deutschen: Auch dort benutzt du "sein" bei
Bewegungs- und Zustandsverben (ich bin gegangen, ich bin gefallen) und "haben" bei
fast allem anderen (ich habe gegessen, ich habe gesehen). Die Grundidee überträgt sich
also fast 1:1 — nur die genaue Verbliste unterscheidet sich in Details.

## Das Detail, das nur mit "être" passiert

Wenn das Hilfsverb être ist, **stimmt das Partizip in Genus und Numerus** mit dem
Subjekt überein, fast wie ein Adjektiv:

```
Il est allé.        (maskulin Singular)
Elle est allée.     (feminin Singular — beachte das 'e')
Ils sont allés.     (maskulin Plural — beachte das 's')
Elles sont allées.  (feminin Plural — 'e' + 's')
```

Das ist der große Unterschied zum deutschen Perfekt, wo das Partizip **niemals**
seine Form ändert: "sie ist gegangen" und "er ist gegangen" benutzen dasselbe
Partizip "gegangen". Im Französischen musst du also bei être-Verben immer zusätzlich
ans Subjekt denken.

Mit "avoir" dagegen ändert sich das Partizip normalerweise **nicht**: J'ai mangé
sagt sowohl ein Mann als auch eine Frau — genau wie im Deutschen "ich habe
gegessen" unabhängig vom Geschlecht bleibt.

## Das Partizip Perfekt bilden

| Gruppe                    | Regel                   | Beispiel                             |
| -------------------------- | ------------------------ | ------------------------------------- |
| Verben auf -er              | Stamm + é                | parler → parlé                        |
| Verben auf -ir (regelmäßig) | Stamm + i                | finir → fini                          |
| Verben auf -re (regelmäßig) | Stamm + u                | vendre → vendu                        |
| Unregelmäßige Verben        | einzeln auswendig lernen | avoir → eu, être → été, faire → fait  |
