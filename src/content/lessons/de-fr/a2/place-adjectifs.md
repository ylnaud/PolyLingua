Im Deutschen steht ein attributives Adjektiv fast ausnahmslos vor dem Substantiv:
"das rote Auto", "der große Mann" — eine Regel ohne große Diskussion. Im
Französischen gilt das Gegenteil als Regel: Die meisten Adjektive stehen NACH dem
Substantiv, und eine kleine Gruppe steht davor — und kann dabei sogar die Bedeutung
verändern.

## Die allgemeine Regel: die meisten stehen DANACH

```
une voiture rouge         (ein rotes Auto)
un livre intéressant       (ein interessantes Buch)
une idée importante         (eine wichtige Idee)
```

Das ist der wichtigste Unterschied zum Deutschen: Wo du gewohnt bist, das Adjektiv
automatisch vor das Substantiv zu setzen, musst du im Französischen erst prüfen, ob
es zur kleinen Ausnahmegruppe gehört.

## Die BAGS-Gruppe: die, die DAVOR stehen

Eine kleine, gut merkbare Gruppe häufiger Adjektive steht vor dem Substantiv:

| Kategorie          | Adjektive               | Beispiel            |
| -------------------- | ------------------------ | --------------------- |
| Beauty (Schönheit)    | beau, joli                | un beau jardin         |
| Age (Alter)            | jeune, vieux, nouveau     | une vieille maison      |
| Goodness (Güte)        | bon, mauvais              | un bon restaurant       |
| Size (Größe)           | grand, petit, gros        | un petit chat           |

## Wenn die Position die Bedeutung ändert

Eine kleine Gruppe von Adjektiven ändert je nach Position ihre Bedeutung:

| Adjektiv | Vor dem Substantiv        | Nach dem Substantiv |
| --------- | --------------------------- | ---------------------- |
| grand      | groß (Bedeutung/Wichtigkeit)  | groß (körperliche Größe) |
| ancien     | ehemalig                       | alt (physisch)           |
| propre     | eigen (Besitz)                 | sauber                   |

```
mon ancien professeur    (mein ehemaliger Lehrer)
un livre ancien            (ein altes, physisch abgenutztes Buch)

ma propre chambre          (mein eigenes Zimmer)
une chambre propre          (ein sauberes Zimmer)
```

## Der praktische Trick

Merke dir das Akronym BAGS für die kleine Gruppe, die davor steht — alles andere
steht standardmäßig danach. Bei den Adjektiven mit doppelter Bedeutung lohnt sich
besondere Aufmerksamkeit, denn eine einfache Positionsänderung verändert, was du
wirklich sagen willst — ein Konzept, das es im Deutschen bei attributiven Adjektiven
so nicht gibt.
