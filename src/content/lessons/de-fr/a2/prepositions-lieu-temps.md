Objekte und Zeitpunkte richtig zu verorten ist im Französischen genauso wichtig wie im
Deutschen — nur sind es andere Wörter, und "à", "en" und "dans" verteilen sich anders
auf die Zeit, als du es aus dem Deutschen mit "um", "im" und "in" gewohnt bist. Hier
sind die wichtigsten Orts- und Zeitpräpositionen mit klaren Beispielen.

## Ortspräpositionen

| Französisch | Deutsch    |
| ----------- | ---------- |
| à           | in / an    |
| dans        | in         |
| sur         | auf        |
| sous        | unter      |
| devant      | vor        |
| derrière    | hinter     |
| entre       | zwischen   |

```
Le chat est sous la table.        (Die Katze ist unter dem Tisch)
Le livre est sur la table.        (Das Buch liegt auf dem Tisch)
La voiture est devant la maison.  (Das Auto steht vor dem Haus)
Le jardin est derrière la maison. (Der Garten liegt hinter dem Haus)
```

## Präpositionen für einen genauen Zeitpunkt

Bei der Zeit sind "à", "en" und "dans" nicht austauschbar — jede markiert eine andere
Art von Zeitpunkt, ganz ähnlich wie im Deutschen "um" nicht dasselbe ist wie "im":

| Verwendung                     | Präposition | Beispiel             |
| ------------------------------- | ----------- | --------------------- |
| Genaue Uhrzeit                   | à           | à 8 heures             |
| Monat oder Jahr                  | en          | en janvier, en 2026    |
| Zukunft (in X Zeit)               | dans        | dans trois jours        |

```
Le cours commence à 8 heures.       (Der Kurs beginnt um 8 Uhr)
Mon anniversaire est en janvier.    (Mein Geburtstag ist im Januar)
Nous partons dans trois jours.      (Wir fahren in drei Tagen los)
```

## Der Trick, um sie nicht zu verwechseln

Stell dir drei Fragen: Um welche genaue Uhrzeit? → "à". In welchem Monat oder Jahr? →
"en". Wie viel Zeit vergeht noch, bis etwas passiert? → "dans". Mit diesen drei Fragen
deckst du fast alle Fälle der Zeitangabe im Französischen ab.
