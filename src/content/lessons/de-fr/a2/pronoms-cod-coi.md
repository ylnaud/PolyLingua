Diese Pronomen erlauben dir, ein Substantiv nicht immer wieder zu wiederholen — der
Schlüssel liegt darin, zu erkennen, ob das französische Verb eine versteckte
Präposition vor dem Objekt benutzt oder nicht.

## COD (direktes Objekt): ohne Präposition

| Pronomen | Ersetzt                            |
| -------- | ------------------------------------ |
| le       | direktes Objekt maskulin Singular     |
| la       | direktes Objekt feminin Singular      |
| les      | direktes Objekt Plural (beide Genera) |

```
Je vois le film.    →    Je le vois.       (ich sehe ihn)
Je vois Marie.      →    Je la vois.       (ich sehe sie)
```

## COI (indirektes Objekt): mit versteckter "à"

| Pronomen | Ersetzt                    |
| -------- | ---------------------------- |
| lui      | ihm/ihr (Singular)             |
| leur     | ihnen (Plural)                 |

```
Je parle à Marc.      →    Je lui parle.       (ich spreche mit ihm)
Je parle à mes amis.  →    Je leur parle.      (ich spreche mit ihnen)
```

## Wie erkennst du, ob ein Verb COD oder COI verlangt?

Denk an das Verb im Französischen: brauchst du "à" vor der Person, ist es COI. Wenn
nicht, ist es COD. **Wichtig:** Das lässt sich nicht einfach aus der deutschen
Rektion (Akkusativ/Dativ) ableiten — die beiden Sprachen stimmen bei denselben
Verben oft nicht überein.

| Verb                     | Typ | Beispiel            |
| ------------------------- | --- | --------------------- |
| voir (sehen)               | COD | Je le vois.            |
| aimer (lieben)              | COD | Je l'aime.              |
| aider (helfen)              | COD | Je l'aide.              |
| parler à (sprechen mit)     | COI | Je lui parle.           |
| téléphoner à (anrufen)      | COI | Je lui téléphone.       |

Beachte besonders "aider" (helfen) und "téléphoner à" (anrufen): Im Deutschen
verlangt "helfen" den Dativ (ihm helfen) — im Französischen ist "aider" aber COD
(je l'aide, kein "à"). Umgekehrt verlangt "anrufen" im Deutschen den Akkusativ (ihn
anrufen), im Französischen ist "téléphoner à" aber COI (je lui téléphone, mit "à").
Diese Verben musst du also einzeln mit ihrer französischen Rektion lernen, nicht
aus dem Deutschen übersetzen.

## Position: vor dem konjugierten Verb

```
Je le vois.              (einfaches Präsens)
Je ne le vois pas.        (Verneinung umschließt Pronomen + Verb)
Je l'ai vu.                 (passé composé: vor dem Hilfsverb)
```

## Der praktische Trick

Bevor du das Pronomen wählst, frag dich: "Braucht dieses Verb im Französischen ein
'à' vor der Person?" Wenn ja → lui/leur (COI). Wenn nein → le/la/les (COD). Die
häufigsten Verben mit ihrer französischen Präposition (oder ohne) auswendig zu
lernen ist die Grundlage dieses Themas — und dabei hilft dir dein Deutsch nur
begrenzt.
