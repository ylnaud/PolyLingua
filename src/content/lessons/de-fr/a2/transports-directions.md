Sich in einer französischsprachigen Stadt zurechtzufinden braucht zwei Dinge: das
Verkehrsmittel benennen können, das du nehmen willst, und die Wegbeschreibung
verstehen, die dir jemand auf der Straße gibt. Hier ist beides.

## Verkehrsmittel

| Französisch | Deutsch |
| ----------- | ------- |
| le bus      | der Bus |
| le train    | der Zug |
| le taxi     | das Taxi |
| le métro    | die U-Bahn |

## Grundlegende Wegbeschreibungen

| Französisch        | Deutsch            |
| -------------------- | -------------------- |
| tourner à gauche      | links abbiegen        |
| tourner à droite      | rechts abbiegen       |
| tout droit            | geradeaus              |
| à côté de             | neben                  |
| en face de            | gegenüber von          |
| près de               | in der Nähe von        |

## Nach dem Weg fragen und ihn erklären

```
Comment aller à la gare?             (Wie komme ich zum Bahnhof?)
Tournez à gauche au coin.            (Biegen Sie an der Ecke links ab)
Continuez tout droit.                (Gehen Sie weiter geradeaus)
La banque est en face de la gare.    (Die Bank liegt gegenüber dem Bahnhof)
```

## Der Trick mit "tout droit" vs. "à droite"

Verwechsle "tout droit" (geradeaus, immer weiter nach vorne) nicht mit "à droite"
(rechts, ein Abbiegen). Beide teilen sich das Wort "droit/droite", aber "tout droit"
bedeutet gerade das Gegenteil von einem Abbiegen an der Ecke.
