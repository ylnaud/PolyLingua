Diese Lektion ist ein Geschenk: Du brauchst keine neue Formenwelt zu lernen, sondern
kombinierst zwei Dinge, die du schon kennst.

## Die Bildung: Futur-Stamm + Imparfait-Endungen

```
Conditionnel présent = Futur-Stamm  +  Imparfait-Endungen (-ais, -ais, -ait, -ions, -iez, -aient)
```

Da du die unregelmäßigen Futur-Stämme aus Lektion 3 schon kennst (ser-, aur-, fer-,
ir-, viendr-, pourr-, voudr-...), musst du hier nur noch die vertrauten
Imparfait-Endungen anhängen:

| Person | Endung | être (Stamm: ser-) |
| ------ | ------ | -------------------- |
| je     | -ais   | je serais            |
| tu     | -ais   | tu serais            |
| il/elle | -ait  | il serait             |
| nous   | -ions  | nous serions          |
| vous   | -iez   | vous seriez           |
| ils/elles | -aient | ils seraient        |

**Achtung, Verwechslungsgefahr:** "je serai" (Futur, ohne s vor -ai) bedeutet "ich werde
sein". "je serais" (Conditionnel, mit -ais) bedeutet "ich wäre". Der Unterschied liegt
nur im letzten Buchstaben – aber er ist entscheidend.

## Drei Hauptfunktionen

**1. Höflichkeit** – genau wie im Deutschen "ich hätte gern" statt "ich will":

```
Je voudrais un café, s'il vous plaît.
```

**2. Ratschlag** mit "à ta/votre place" (an deiner/Ihrer Stelle):

```
À ta place, je partirais.
```

**3. Hypothese** in Si-Sätzen vom Typ 2 (Gegenwart/Zukunft, wenig wahrscheinlich):

```
Si + Imparfait,              Conditionnel présent
Si j'avais le temps,         je viendrais.
```

## Vergleich mit dem deutschen Konjunktiv II

Das Conditionnel présent entspricht ziemlich genau dem deutschen Konjunktiv II
("würde" + Infinitiv, oder käme/hätte/wäre):

```
Deutsch:      Wenn ich Zeit hätte, würde ich kommen.
Französisch:  Si j'avais le temps, je viendrais.
```

Die Struktur ist parallel: Der si-Satz (Bedingung) steht im Imparfait, genau wie der
deutsche wenn-Satz im Konjunktiv II (hätte) steht – nur dass das Französische
grammatikalisch die "normale" Vergangenheitsform (Imparfait) recycelt, statt einen
eigenen Konjunktiv zu bilden.
