Gute Nachricht für Sprachlerner: Das Futur simple ist im Französischen eines der
einfachsten Tempi zu bilden, sobald du das Grundprinzip verstanden hast.

## Das Grundprinzip: Infinitiv + Endungen

Anders als im Deutschen, wo du "werden" + Infinitiv brauchst, verschmilzt das
Französische die Zukunft mit dem Verb selbst. Die Endungen sind fast identisch mit den
Präsensformen von "avoir":

| Person | Endung | Beispiel (parler) |
| ------ | ------ | ------------------- |
| je     | -ai    | je parlerai         |
| tu     | -as    | tu parleras          |
| il/elle | -a    | il parlera           |
| nous   | -ons   | nous parlerons       |
| vous   | -ez    | vous parlerez        |
| ils/elles | -ont | ils parleront       |

Bei -er- und -ir-Verben ist der Stamm einfach der komplette Infinitiv:

```
parler → je parlerai
finir  → je finirai
```

Bei -re-Verben fällt das finale, stumme -e weg:

```
prendre → je prendrai
```

## Die wichtigsten unregelmäßigen Stämme

Einige der häufigsten Verben haben einen komplett unregelmäßigen Futur-Stamm – die
Endungen bleiben aber immer gleich:

| Verb    | Futur-Stamm | Beispiel     |
| ------- | ------------ | ------------ |
| être    | ser-         | je serai     |
| avoir   | aur-         | j'aurai      |
| aller   | ir-          | j'irai       |
| faire   | fer-         | je ferai     |
| venir   | viendr-      | je viendrai  |
| pouvoir | pourr-       | je pourrai   |
| vouloir | voudr-       | je voudrai   |
| voir    | verr-        | je verrai    |
| savoir  | saur-        | je saurai    |
| devoir  | devr-        | je devrai    |

Diese zehn Stämme lohnt es sich auswendig zu lernen – sie kommen ständig vor, auch in
anderen Konstruktionen wie dem Conditionnel présent (die nächste Lektion baut genau
darauf auf).

## Ein Wort statt zwei

```
Deutsch:      Ich  werde  sprechen.   (zwei Wörter)
Französisch:  Je   parlerai.          (ein Wort)
```

Das macht das Futur simple im gesprochenen Französisch besonders schnell und
kompakt – ein einziges angehängtes Suffix reicht.
