Dies ist eines der Konzepte, die es im Deutschen schlicht nicht gibt – deshalb fühlt es
sich am Anfang fremd an. Sobald du das Prinzip verstehst, wird es aber zur Gewohnheit.

## "y": ersetzt "à" + Ort oder Sache

"y" ersetzt eine Ortsangabe mit "à" oder auch "à" + eine Sache (bei Verben wie
"penser à", "réfléchir à"):

```
Tu vas à Paris ?     — Oui, j'y vais.        (dorthin)
Tu penses à l'examen ? — Oui, j'y pense.      (daran)
```

## "en": ersetzt "de" + Sache oder eine Menge

"en" ersetzt "de" + eine Sache, oder eine Mengenangabe (mit Zahlen, "beaucoup de",
"combien de" usw.):

```
Tu manges des pommes ?   — Oui, j'en mange.       (davon)
Tu as combien de frères ? — J'en ai deux.          (davon zwei)
```

## Wo stehen "y" und "en" im Satz?

Genau wie andere Objektpronomen (le, la, les, lui...) stehen sie **direkt vor dem
konjugierten Verb**:

```
J'y   vais.
J'en  mange.
```

Bei einem Verb + Infinitiv-Konstruktion stehen sie vor dem Infinitiv:

```
Je vais y aller.
Je veux en manger.
```

## Die deutsche Krücke: "da(r)-"-Wörter

Es gibt keine 1:1-Entsprechung im Deutschen, aber die "da(r)-"-Zusammensetzungen kommen
der Idee am nächsten:

```
y  ≈ "dorthin" / "daran" / "darüber"
en ≈ "davon" / "darüber"
```

Der Trick zum Merken: **y** = Finger, der auf einen ORT zeigt. **en** = Sack, der eine
MENGE oder eine mit "de" eingeführte Sache trägt. Übe diese zwei Fragen laut, bis die
Antwort automatisch kommt:

```
Tu vas à Paris ? → Oui, j'y vais.
Tu as combien de frères ? → J'en ai deux.
```
