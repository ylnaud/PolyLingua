In dieser Lektion geht es weniger um neue Grammatik als um praktischen Wortschatz, den
du im Berufsalltag ständig brauchst – vom Bewerbungsgespräch bis zum Büroalltag.

## Berufe nennen: kein Artikel nötig

Eine seltene Übereinstimmung zwischen Deutsch und Französisch: Nach "être" steht bei
Berufsbezeichnungen **kein unbestimmter Artikel**:

```
Je suis professeur.      (Ich bin Lehrer.)
Elle est ingénieure.     (Sie ist Ingenieurin.)
```

Sobald aber ein Adjektiv dazukommt, brauchst du den Artikel doch:

```
C'est un bon professeur.   (Er ist ein guter Lehrer.)
```

## Rund ums Büro

| Französisch | Deutsch |
| ----------- | ------- |
| le collègue / la collègue | der/die Kollege/Kollegin |
| le patron / la patronne   | der/die Chef(in)          |
| le bureau                 | das Büro                  |
| la réunion                | die Besprechung           |
| le salaire                | das Gehalt                |

## Bewerbung und Anstellung

| Französisch | Deutsch |
| ----------- | ------- |
| postuler (pour un poste) | sich bewerben (auf eine Stelle) |
| un entretien d'embauche  | ein Bewerbungsgespräch |
| embaucher                | einstellen |
| licencier                | entlassen, kündigen |
| être au chômage          | arbeitslos sein |
| avoir un emploi          | eine Stelle haben |

**Verwechslungsgefahr:** "embaucher" und "licencier" sind genaue Gegensätze – merk dir
sie am besten als Paar, damit du sie nicht durcheinanderbringst.

## Ein typischer Satz zum Üben

```
J'ai un entretien d'embauche demain. J'espère qu'ils vont m'embaucher !
(Ich habe morgen ein Bewerbungsgespräch. Ich hoffe, sie stellen mich ein!)
```

Übe, ein paar Sätze über deinen eigenen (echten oder erträumten) Beruf zu bilden –
das ist der schnellste Weg, diesen Wortschatz wirklich zu verinnerlichen.
