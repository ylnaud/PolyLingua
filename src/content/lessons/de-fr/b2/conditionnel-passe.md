Kennst du den deutschen Konjunktiv II der Vergangenheit — "ich wäre
gekommen", "ich hätte es gewusst" — dann ist das **conditionnel passé** für
dich fast schon vertraut: dieselbe Struktur, andere Sprache.

## Die Formel

```
avoir/être (conditionnel présent)  +  participe passé

Ich       hätte     gegessen   (Vergleich Deutsch)
J'        aurais    mangé

Ich       wäre      gekommen   (Vergleich Deutsch)
Je        serais    venu(e)
```

Die Wahl zwischen avoir und être folgt genau denselben Regeln wie beim passé
composé (siehe B1): die geschlossene Gruppe der Bewegungs-/
Zustandswechselverben (aller, venir, partir...) nimmt être, alle anderen
avoir.

## conditionnel présent von avoir und être

| Person | avoir | être |
| --- | --- | --- |
| je | aurais | serais |
| tu | aurais | serais |
| il/elle | aurait | serait |
| nous | aurions | serions |
| vous | auriez | seriez |
| ils/elles | auraient | seraient |

## Wofür benutzt man es?

### 1. Reue oder verpasste Gelegenheiten

```
J'aurais aimé venir, mais je n'ai pas pu.
Ich WÄRE GERNE gekommen, aber ich konnte nicht.
```

### 2. Irreale Bedingungssätze in der Vergangenheit (Typ 3)

Das ist der häufigste Fall, genau wie im Deutschen "wenn ich es gewusst
hätte, wäre ich gekommen":

```
Si + plus-que-parfait,  conditionnel passé

Si j'avais su,          je serais venu(e).
Wenn ich gewusst hätte,  wäre ich gekommen.
```

Die Bedingung (si-Satz) steht im **plus-que-parfait**, der Hauptsatz im
**conditionnel passé** — genau spiegelbildlich zum Deutschen mit
"wäre/hätte + Partizip" im Hauptsatz und "hätte/wäre + Partizip" im
wenn-Satz.

### 3. Nicht bestätigte Information (Journalismus)

```
Le suspect aurait quitté le pays.
Der Verdächtige SOLL das Land VERLASSEN HABEN.
```

## Das Partizip stimmt bei être-Verben überein

Wie beim passé composé passt sich das Partizip bei être-Verben an das
Subjekt an:

```
Il serait venu.       (maskulin Singular)
Elle serait venue.    (feminin Singular)
Ils seraient venus.   (maskulin Plural)
Elles seraient venues. (feminin Plural)
```
