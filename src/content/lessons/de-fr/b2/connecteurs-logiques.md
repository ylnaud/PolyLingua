Ein B2-Text lebt davon, Ideen logisch zu verknüpfen, statt sie mit "et" und
"mais" aneinanderzureihen. Die folgenden Konnektoren strukturieren einen Text
in vier Funktionen.

## 1. Addition: ein weiteres Argument in dieselbe Richtung

```
de plus       außerdem
en outre       darüber hinaus
par ailleurs   im Übrigen
```

```
Ce restaurant est excellent. De plus, les prix sont raisonnables.
Dieses Restaurant ist ausgezeichnet. Außerdem sind die Preise vernünftig.
```

## 2. Gegensatz: die Richtung kippt

```
cependant      jedoch (mild)
néanmoins      dennoch, nichtsdestotrotz
en revanche    dagegen, im Gegenzug (stärkerer Kontrast)
```

```
Il est intelligent ; en revanche, il manque de motivation.
Er ist intelligent; dagegen fehlt es ihm an Motivation.
```

## 3. Zugeständnis: trotz eines Gegenarguments bleibt die Aussage bestehen

Diese Gruppe ist besonders für Deutschsprachige tückisch, weil sie den
**subjonctif** verlangt:

```
bien que + subjonctif    obwohl
quoique + subjonctif      obgleich
malgré + Nomen            trotz (kein Subjonctif, da keine Verbform folgt)
```

```
Bien qu'il pleuve, nous sortons.
Obwohl es regnet, gehen wir raus.

Malgré la pluie, nous sortons.
Trotz des Regens gehen wir raus.
```

## 4. Zusammenfassung: der Text kommt zum Schluss

```
en somme       zusammenfassend, kurzum
bref            kurz gesagt
en conclusion   abschließend
```

```
En somme, ce projet mérite d'être soutenu.
Zusammenfassend verdient dieses Projekt Unterstützung.
```

## Der Aufbau eines strukturierten Textes

```
1. Einleitung + erstes Argument
2. de plus / en outre → zweites Argument (Addition)
3. cependant / en revanche → Gegenargument (Gegensatz)
4. bien que ... → Zugeständnis, aber die These bleibt bestehen
5. en somme → Zusammenfassung
```

Mit diesen Bauklötzen wirkt ein französischer Text sofort argumentativer und
weniger wie eine reine Aneinanderreihung von Sätzen.
