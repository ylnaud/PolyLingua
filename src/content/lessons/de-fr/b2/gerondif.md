Das Deutsche hat mehrere Wörter für Gleichzeitigkeit: "beim", "während",
"indem". Das Französische braucht dafür nur eine einzige Struktur — das
**gérondif**.

## Die Formel

```
en  +  participe présent (Verbstamm + -ant)

en mangeant     beim Essen / während man isst
en conduisant   beim Fahren
en travaillant  beim Arbeiten
```

## Das participe présent bilden

Nimm die **nous-Form im Präsens**, streiche das -ons und hänge -ant an:

| Infinitiv | nous-Form | participe présent |
| --- | --- | --- |
| manger | nous mangeons | mangeant |
| finir | nous finissons | finissant |
| conduire | nous conduisons | conduisant |
| faire | nous faisons | faisant |

## Drei Ausnahmen zum Auswendiglernen

Nur drei Verben folgen nicht dieser Regel:

```
être   → étant
avoir  → ayant
savoir → sachant
```

## Wofür benutzt man das gérondif?

### 1. Gleichzeitigkeit (die häufigste Bedeutung)

Zwei Handlungen desselben Subjekts, die zur selben Zeit passieren:

```
Il téléphone en conduisant.
Er telefoniert BEIM Fahren. (Er macht beides gleichzeitig.)
```

### 2. Art und Weise (das "Wie")

```
Elle a appris le français en regardant des films.
Sie hat Französisch gelernt, INDEM sie Filme geschaut hat.
```

### 3. Bedingung

```
En travaillant plus, tu réussirais.
WENN du mehr arbeitest, würdest du Erfolg haben.
```

## Achtung: gleiches Subjekt nötig

Das gérondif funktioniert nur, wenn **beide Handlungen dasselbe Subjekt**
haben. Sind es zwei verschiedene Subjekte, brauchst du eine andere Struktur
(z. B. pendant que):

```
✅ Il mange en regardant la télé. (er isst UND er schaut — dasselbe "er")
❌ Il mange en regardant la télé, elle dort.
   → besser: Pendant qu'il mange, elle dort.
```

## Tout en + gérondif: Betonung des Gegensatzes

Mit "tout" davor betont man einen Kontrast oder eine überraschende
Gleichzeitigkeit:

```
Tout en sachant la vérité, il n'a rien dit.
OBWOHL er die Wahrheit wusste, hat er nichts gesagt.
```
