Auf Deutsch sagst du "meiner", "deiner", "seiner", wenn du das besessene
Nomen nicht wiederholen willst: "Ich habe mein Buch, er hat seins." Das
französische Äquivalent sind die **pronoms possessifs** — aber mit einer
Regel, die im Deutschen keine echte Entsprechung hat.

## Die Grundregel: Genus vom Objekt, nicht vom Besitzer

Das ist die wichtigste Falle dieser Lektion. Anders als du vielleicht
erwartest, bestimmt **das besessene Ding** das Genus des Pronomens — der
Besitzer spielt dafür keine Rolle:

```
Paul a sa voiture.   → la voiture (feminin) → le pronom: la sienne
Marie a sa voiture.  → la voiture (feminin) → le pronom: la sienne
```

Egal ob Paul (männlich) oder Marie (weiblich) besitzt — "la sienne" bleibt
immer feminin, weil "voiture" feminin ist.

## Die vollständige Tabelle

| Besitzer | maskulin Sg. | feminin Sg. | maskulin Pl. | feminin Pl. |
| --- | --- | --- | --- | --- |
| ich | le mien | la mienne | les miens | les miennes |
| du | le tien | la tienne | les tiens | les tiennes |
| er/sie | le sien | la sienne | les siens | les siennes |
| wir | le nôtre | la nôtre | les nôtres | les nôtres |
| ihr/Sie | le vôtre | la vôtre | les vôtres | les vôtres |
| sie (Pl.) | le leur | la leur | les leurs | les leurs |

## le sien: die deutsche Doppeldeutigkeit verschwindet nicht

"le sien" / "la sienne" bedeutet sowohl "seiner" als auch "ihrer" — das
Französische unterscheidet hier nicht nach Geschlecht des Besitzers, genauso
wenig wie das Genus des Pronomens es tut. Nur der Kontext klärt, wer gemeint
ist:

```
Paul a perdu son téléphone, mais il a retrouvé le sien.
Paul hat sein Telefon verloren, aber er hat SEINS wiedergefunden.

Marie a perdu son téléphone, mais elle a retrouvé le sien.
Marie hat ihr Telefon verloren, aber sie hat IHRS wiedergefunden.
```

## Achtung bei le nôtre / le vôtre: der Zirkumflex

Das Possessivadjektiv (notre maison) hat **keinen** Zirkumflex. Das Pronomen
(le nôtre) hat **einen**. Nur dieser kleine Akzent unterscheidet beide
Wortarten optisch:

```
notre maison  →  la nôtre   (unser Haus → unseres)
votre voiture →  la vôtre   (euer/Ihr Auto → euer(e)s/Ihres)
```

## Possessivadjektiv vs. Possessivpronomen

Verwechsle diese beiden Wortarten nicht:

```
son livre  → Possessivadjektiv, begleitet ein Nomen ("sein Buch")
le sien    → Possessivpronomen, ERSETZT das Nomen ("seins")
```
