Im Deutschen wählst du das Relativpronomen nach Genus, Numerus UND Fall (der,
die, das, den, dem, dessen...). Im Französischen fällt das Fallsystem
komplett weg — stattdessen zählt nur eine Frage: **Welche Funktion hat das
Wort im Nebensatz?**

## Die vier Grundpronomen

| Pronomen | Funktion | Beispiel |
| --- | --- | --- |
| qui | Subjekt | L'homme qui parle... |
| que | direktes Objekt | Le livre que je lis... |
| dont | ersetzt "de + Nomen" | Le livre dont je parle... |
| où | Ort oder Zeit | La ville où je suis né... |

## qui — das Subjekt

"qui" ersetzt das Subjekt des Nebensatzes, egal ob Person oder Sache:

```
L'homme parle.  →  L'homme qui parle est mon voisin.
Der Mann spricht. → Der Mann, DER spricht, ist mein Nachbar.
```

Wichtig: "qui" wird **nie** verkürzt (nie qu' vor Vokal), im Gegensatz zu
"que".

## que — das direkte Objekt

"que" ersetzt ein direktes Objekt — etwas, das direkt "getan" wird, ohne
Präposition:

```
Je lis le livre.  →  Le livre que je lis est passionnant.
Ich lese das Buch. → Das Buch, DAS ich lese, ist spannend.
```

Vor einem Vokal wird "que" zu "qu'": le livre qu'il lit.

## dont — wenn ein "de" im Spiel ist

Das ist der Fall ohne echte deutsche Entsprechung. Viele französische Verben
verlangen "de": parler DE, avoir besoin DE, être content DE, se souvenir DE.
Statt dieses "de" umständlich mitzuschleppen, ersetzt "dont" das ganze
Konstrukt:

```
Je te parle de ce livre.  →  Le livre dont je te parle...
(falsch: le livre que je te parle de)
```

"dont" funktioniert auch für Besitz, ähnlich wie "dessen" im Deutschen:

```
La fille dont le père est médecin.
Das Mädchen, DESSEN Vater Arzt ist.
```

## où — Ort und Zeit

"où" bedeutet wörtlich "wo", wird aber auch für Zeitangaben benutzt — das ist
im Deutschen ungewohnt, weil dort meist "als" oder "in dem" steht:

```
La ville où je suis né.       (Ort)
Die Stadt, IN DER ich geboren bin.

Le jour où je suis né.        (Zeit)
Der Tag, AN DEM ich geboren wurde.
```

## Der Test, um schnell zu entscheiden

Frage dich in dieser Reihenfolge:

1. Ist es ein Ort oder eine Zeitangabe? → **où**
2. Steht ein "de" dabei (Verb mit de, oder Besitz)? → **dont**
3. Handelt das Wort selbst (Subjekt)? → **qui**
4. Wird das Wort direkt betroffen (Objekt)? → **que**
