Im Deutschen bildest du das Passiv mit **werden**: "Das Haus wird gebaut." Im
Französischen übernimmt **être** genau diese Rolle — auch wenn das Wort sonst
"sein" bedeutet, ist es hier ein reines Hilfsverb ohne eigene Bedeutung.

## Die Formel

```
être (konjugiert)  +  participe passé

Das Haus   wird       gebaut       (Vergleich Deutsch)
La maison  est        construite   par un architecte.
```

Anders als im Deutschen, wo "werden" für das Passiv reserviert ist, sieht das
französische Passiv fast identisch aus wie ein normaler être-Satz mit
Adjektiv. Der Kontext (und das Partizip statt eines echten Adjektivs) macht
den Unterschied klar.

## Das Partizip stimmt mit dem Subjekt überein

Das ist der Teil, der im Deutschen keine Entsprechung hat: Das Partizip
verhält sich im Passiv wie ein Adjektiv und passt sich an **Genus und
Numerus** des Subjekts an:

```
Le pont est construit.        (maskulin Singular)
La maison est construite.     (feminin Singular — beachte das 'e')
Les ponts sont construits.    (maskulin Plural — 's')
Les maisons sont construites. (feminin Plural — 'e' + 's')
```

## par: der Handelnde

Willst du sagen, WER die Handlung ausführt, benutzt du **par** — genau wie
"von" im deutschen Passiv:

```
Ce livre est écrit par Victor Hugo.
Dieses Buch wird von Victor Hugo geschrieben.
```

Der Handelnde ist optional: "La maison est construite" ist ein vollständiger
Satz, auch ohne zu sagen, wer baut.

## Zustand oder Vorgang? Ein wichtiger Unterschied

Wie im Deutschen unterscheidet Französisch zwischen zwei Situationen:

| Struktur | Bedeutung | Beispiel |
| --- | --- | --- |
| être (Präsens) + participe | Zustand, jetzt so | Le magasin est fermé. (Es ist gerade zu.) |
| avoir été + participe | Abgeschlossener Vorgang | Le magasin a été fermé à 18h. (Es wurde um 18 Uhr geschlossen.) |

Das entspricht ziemlich genau dem deutschen Unterschied zwischen "Das
Geschäft ist geschlossen" (Zustand) und "Das Geschäft wurde geschlossen"
(Vorgang in der Vergangenheit).

## In allen Zeiten

Das Passiv funktioniert in jeder Zeit — du konjugierst einfach être:

```
Présent:        La lettre est écrite.
Passé composé:  La lettre a été écrite.
Futur:          La lettre sera écrite.
Imparfait:       La lettre était écrite.
```

Merke dir: être trägt die Zeit, das participe passé bleibt (bis auf die
Endung fürs Genus/Numerus) gleich.
