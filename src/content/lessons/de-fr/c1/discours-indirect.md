Wenn du im Französischen berichtest, was jemand gesagt hat, und dein
einleitendes Verb (dire, annoncer, expliquer...) in der Vergangenheit steht,
verschieben sich die Zeiten im berichteten Satz nach einem festen Muster —
der **concordance des temps**. Das Prinzip kennst du aus dem Deutschen
("Ich komme morgen" → "Er sagte, dass er morgen komme"), aber im
Französischen ist die Verschiebung strikter und mechanischer.

## Die Grundregel

Solange das einleitende Verb im Präsens steht, ändert sich nichts:

```
Il dit : "Je pars." → Il dit qu'il part.
```

Steht das einleitende Verb dagegen in der Vergangenheit (meist passé
composé), verschiebt sich die Zeit im Nebensatz um "eine Stufe":

| Direkte Rede    | Indirekte Rede (nach Vergangenheit) |
| --------------- | ------------------------------------ |
| présent          | imparfait                            |
| passé composé     | plus-que-parfait                      |
| imparfait         | imparfait (keine Änderung)            |
| futur simple       | conditionnel présent                   |
| futur antérieur     | conditionnel passé                     |

## Beispiele im Detail

```
"Je travaille."         → Il a dit qu'il travaillait.
"J'ai terminé."          → Il a dit qu'il avait terminé.
"Je travaillerai."        → Il a dit qu'il travaillerait.
"J'aurai terminé avant midi." → Il a dit qu'il aurait terminé avant midi.
```

## Zeit- und Ortsangaben verschieben sich mit

Weil sich der Bezugspunkt vom "jetzt" des Sprechers zum "damals" des
Berichtenden verschiebt, müssen auch Zeitausdrücke angepasst werden:

| Direkte Rede | Indirekte Rede (Vergangenheit) |
| ------------ | -------------------------------- |
| aujourd'hui   | ce jour-là                        |
| hier          | la veille                         |
| demain        | le lendemain                       |
| maintenant     | à ce moment-là                      |
| la semaine prochaine | la semaine suivante            |

```
"Je pars demain", a-t-elle dit. → Elle a dit qu'elle partait le lendemain.
```

## Die Falle für Deutschsprachige

Im Deutschen bleibt bei der indirekten Rede oft der Konjunktiv I oder II
unabhängig von der Zeit des einleitenden Verbs. Im Französischen dagegen ist
die Verschiebung **zeitabhängig und mechanisch**: Steht "il a dit" in der
Vergangenheit, verschiebt sich IMMER die Zeit des Nebensatzes — es gibt hier
keinen Interpretationsspielraum wie im deutschen Konjunktiv.
