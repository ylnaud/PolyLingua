Redewendungen sind eines der sichersten Erkennungsmerkmale für ein hohes
Sprachniveau — wer sie beherrscht, klingt nicht mehr "übersetzt", sondern
natürlich. Anders als grammatische Regeln lassen sie sich nicht logisch
herleiten, sie müssen als feste Einheiten gelernt werden. Diese Lektion
sammelt die im Alltag häufigsten.

## Gefühle und Zustände

```
avoir le cafard          niedergeschlagen, deprimiert sein
tomber dans les pommes     ohnmächtig werden
avoir un chat dans la gorge  einen Frosch im Hals haben (heiser sein)
en avoir marre           die Nase voll haben
```

```
Depuis qu'il a perdu son travail, il a le cafard.
Elle a eu si peur qu'elle est tombée dans les pommes.
```

## Geld und Wert

```
coûter les yeux de la tête    ein Vermögen kosten
c'est donné              das ist geschenkt (sehr günstig)
être fauché              pleite sein
```

## Zwischenmenschliches

```
poser un lapin à quelqu'un       jemanden versetzen
casser les pieds à quelqu'un      jemandem auf die Nerven gehen
mettre les pieds dans le plat      ins Fettnäpfchen treten
faire la tête               schmollen, beleidigt sein
```

```
Il m'a posé un lapin pour la deuxième fois — je ne l'appelle plus.
Arrête de me casser les pieds avec tes questions !
```

## Warum wörtliche Übersetzung nicht funktioniert

Das Bild hinter einer Redewendung ergibt im Deutschen oft keinen Sinn:
"die Füße ins Gericht stecken" (mettre les pieds dans le plat) klingt
absurd, bis man weiß, dass es "taktlos etwas Peinliches ansprechen"
bedeutet. Der Trick ist, das französische Bild direkt mit der Bedeutung zu
verknüpfen, statt über die deutsche Übersetzung nachzudenken — genau wie
Muttersprachler es tun, ohne über die wörtliche Bedeutung nachzudenken.

## Register beachten

Die meisten dieser Ausdrücke gehören zum informellen bis neutralen Register
— sie passen in Gespräche unter Freunden oder in lockere Texte, aber nicht
in einen offiziellen Geschäftsbrief. Für die formelle Ebene gilt: erkennen
und verstehen ja, in geschäftlichen Kontexten selbst benutzen eher nicht.
