Das futur antérieur ("die vollendete Zukunft") ist eine echte Stolperfalle für
Deutschsprachige — nicht weil es kompliziert zu bilden wäre, sondern weil das
Deutsche in derselben Situation oft eine ganz andere Zeitform benutzt.

## Bildung: futur simple + participe passé

```
avoir (futur simple)  +  participe passé
j'aurai       fini       (ich werde fertig gemacht haben)
tu auras      mangé      (du wirst gegessen haben)
```

```
être (futur simple)  +  participe passé
je serai      arrivé(e)   (ich werde angekommen sein)
elle sera     partie      (sie wird gegangen sein)
```

Die Wahl zwischen avoir und être folgt derselben Liste wie beim passé
composé und beim plus-que-parfait.

## Wann benutzt man das futur antérieur?

Immer dann, wenn zwei Handlungen in der Zukunft liegen und die eine
abgeschlossen sein muss, bevor die andere beginnt:

```
Quand j'aurai fini mes devoirs, je sortirai.
```

1. "j'aurai fini" (futur antérieur) → muss ZUERST abgeschlossen sein
2. "je sortirai" (futur simple) → passiert DANACH

## Die deutsche Falle

Im Deutschen sagt man in dieser Situation fast nie das Futur II ("wenn ich
fertig gemacht haben werde"), sondern meist einfach:

```
Deutsch (natürlich): Wenn ich fertig bin, gehe ich raus.
Französisch (Pflicht): Quand j'aurai fini, je sortirai.
```

Das Französische verlangt hier zwingend das futur antérieur — ein
wörtlicher Griff zum französischen Präsens ("quand je finis...") wäre
falsch, wenn beide Handlungen eindeutig in der Zukunft liegen.

## Typische Konjunktionen

Diese Konstruktion taucht besonders häufig nach folgenden Konjunktionen
auf, wenn der Hauptsatz im futur simple steht:

| Konjunktion | Deutsch |
| --- | --- |
| quand | wenn, als |
| dès que | sobald |
| lorsque | als, wenn (formeller) |
| aussitôt que | sobald |

```
Dès que tu auras terminé, appelle-moi.
Sobald du fertig bist, ruf mich an.

Lorsqu'elle sera arrivée, nous commencerons la réunion.
Wenn sie angekommen ist, fangen wir mit dem Meeting an.
```

## Der praktische Trick

Frage dich bei jedem "wenn/sobald + Zukunft"-Satz: Ist die Handlung im
Nebensatz VOR der Handlung im Hauptsatz abgeschlossen? Wenn ja, brauchst du
im Nebensatz das futur antérieur — auch wenn dein deutsches Sprachgefühl
dir ein einfaches Präsens vorschlägt.
