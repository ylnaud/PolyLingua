Im Deutschen betonen wir ein Satzglied oft mit Intonation ("MARIE hat die
Feier organisiert") oder mit Umstellung. Das Französische hat dafür eine
feste grammatische Konstruktion: die **mise en relief** (Hervorhebung) mit
c'est...qui/que. Sie ist in gesprochener und geschriebener Sprache extrem
häufig und ein sicheres Zeichen für ein gehobenes Sprachniveau, wenn korrekt
eingesetzt.

## Die Grundkonstruktion

```
C'est  +  hervorgehobenes Element  +  qui/que  +  Rest des Satzes
```

Die Wahl zwischen "qui" und "que" hängt NICHT davon ab, ob das Element eine
Person oder eine Sache ist (anders als bei "qui/que" als normale
Relativpronomen), sondern ausschließlich von seiner **grammatischen
Funktion** im Nebensatz:

```
C'est Marie qui a organisé la fête.       (Marie = Subjekt von "a organisé")
C'est ce livre que je préfère.            (ce livre = Objekt von "préfère")
```

## Der Test: fehlt ein Subjekt nach dem Verb?

Frage dich: Wenn ich den Nebensatz allein lese, fehlt dann noch ein Subjekt?

```
"... a organisé la fête"   → fehlt ein Subjekt → qui
"je préfère ..."          → hat schon ein Subjekt (je), das Element ist Objekt → que
```

## Mit Präpositionen: dont und où

Wird das hervorgehobene Element mit einer Präposition angeschlossen, ändert
sich das Bindewort entsprechend:

```
C'est de ce projet dont nous parlons.   (parler DE quelque chose → dont)
C'est là où j'ai grandi.          (Ort → où)
```

## Ganze Inhalte hervorheben: ce qui / ce que...c'est

Um nicht ein einzelnes Wort, sondern einen ganzen Sachverhalt zu betonen
("was mich interessiert...", "was ich will..."), nutzt man ce qui oder ce
que, je nach Funktion im ersten Teilsatz:

```
Ce qui m'intéresse, c'est la musique.     (m'intéresse braucht ein Subjekt → ce qui)
Ce que je veux, c'est la paix.          (veux braucht ein Objekt → ce que)
```

Diese Struktur wirkt im geschriebenen Französisch oft eleganter und
nachdrücklicher als eine einfache Aussage — sie lenkt die Aufmerksamkeit
gezielt auf den zweiten Teil des Satzes.
