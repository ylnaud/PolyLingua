Das passé simple ist eine der ersten Zeiten, die einem Deutschsprachigen
beim Lesen eines französischen Romans auffallen: Formen wie "il fut",
"elle dit" oder "ils partirent" tauchen nie im Gespräch auf, aber ständig
auf der gedruckten Seite. Auf C1-Niveau ist das Ziel nicht, aktiv im
passé simple zu schreiben, sondern es beim Lesen sicher zu erkennen.

## Die Rollenverteilung: passé simple vs. passé composé

Beide Zeiten übersetzen das deutsche Präteritum/Perfekt einer
abgeschlossenen Handlung, aber sie sind funktional getrennt:

```
passé composé  →  gesprochene Sprache, informelle Texte, E-Mails
passé simple    →  Literatur, Märchen, historische Erzählungen, Zeitungsartikel über Geschichte
```

Ein Muttersprachler benutzt in einem Gespräch niemals "il parla" — er sagt
"il a parlé". Aber jeder Roman ist voll von Formen wie "il parla",
"elle regarda", "ils partirent".

## Bildung: regelmäßige Verben

| Gruppe   | Endungen                                  | Beispiel (il/elle) |
| -------- | ------------------------------------------ | -------------------- |
| -er      | -ai, -as, -a, -âmes, -âtes, -èrent          | il parla              |
| -ir/-re  | -is, -is, -it, -îmes, -îtes, -irent          | il finit, il vendit     |

```
parler:  je parlai, tu parlas, il parla, nous parlâmes, vous parlâtes, ils parlèrent
finir:   je finis, tu finis, il finit, nous finîmes, vous finîtes, ils finirent
```

## Die wichtigsten unregelmäßigen Formen (3. Person)

| Verb    | il/elle | ils/elles |
| ------- | ------- | --------- |
| être    | fut     | furent    |
| avoir   | eut     | eurent    |
| faire   | fit     | firent    |
| venir   | vint    | vinrent   |
| voir    | vit     | virent    |
| dire    | dit     | dirent    |
| prendre | prit    | prirent   |

Diese Tabelle lohnt sich auswendig zu lernen, denn die 3. Person Singular
und Plural sind die mit Abstand häufigsten Formen in Erzähltexten — als
Leser begegnest du kaum je der 1. oder 2. Person.

## Erkennungsstrategie beim Lesen

Wenn ein Verb ungewohnt aussieht, aber im Kontext eindeutig Vergangenheit
bedeutet, prüfe die typischen Endungen -a, -it, -ut, -int am Wortende — das
sind fast immer Signale für das passé simple, nicht für einen unbekannten
Verbstamm.
