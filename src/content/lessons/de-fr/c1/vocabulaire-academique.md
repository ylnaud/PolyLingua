Ein französischer Aufsatz oder Vortrag auf C1-Niveau unterscheidet sich von
der Alltagssprache vor allem durch zwei Dinge: präzise Verben, um eine
Argumentation aufzubauen, und Konnektoren, die die logische Struktur des
Textes sichtbar machen.

## Verben zum Argumentieren

| Verb        | Bedeutung                      |
| ----------- | -------------------------------- |
| analyser     | analysieren                       |
| démontrer     | nachweisen, beweisen               |
| souligner     | unterstreichen, hervorheben          |
| constater     | feststellen                         |
| nuancer      | differenzieren, abschwächen           |
| remettre en question | infrage stellen                |

```
Cette étude démontre que le phénomène est plus complexe qu'on ne le pensait.
Il convient de nuancer cette affirmation.
```

## Konnektoren: die Logik sichtbar machen

**Folge:** par conséquent, ainsi, de ce fait, dès lors
**Gegensatz:** en revanche, toutefois, cependant, or
**Einschränkung:** néanmoins, malgré tout, il n'en reste pas moins que
**Beispiel:** notamment, par exemple, à titre d'illustration
**Bedingung:** dans la mesure où, à condition que, pour autant que

```
Le budget a été réduit ; par conséquent, le projet a pris du retard.
Les résultats sont encourageants ; néanmoins, l'échantillon reste limité.
```

## Feste akademische Wendungen

Bestimmte unpersönliche Konstruktionen strukturieren einen formellen Text
und wirken deutlich professioneller als einfache Aussagen:

```
Il convient de + Infinitiv     (es ist angebracht zu)
Force est de constater que      (man muss feststellen, dass)
Il n'en demeure pas moins que    (es bleibt dennoch, dass)
Encore faut-il + Infinitiv       (allerdings muss man auch)
```

```
Force est de constater que les résultats divergent selon les études.
Encore faut-il vérifier la fiabilité des sources.
```

## Ein Tipp gegen Wiederholungen

Statt "il est important de" in jedem Absatz zu wiederholen, wechsle
zwischen Synonymen wie "il convient de", "il s'avère nécessaire de" oder
"il importe de" — Variation im Vokabular ist eines der Hauptkriterien, an
denen ein C1-Text von einem B2-Text unterschieden wird.
