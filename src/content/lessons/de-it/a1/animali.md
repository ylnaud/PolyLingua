Tiere gehören zum grundlegenden Wortschatz, der in Alltagsgesprächen, Geschichten und
Beschreibungen ständig vorkommt — hier sind die häufigsten mit einsatzbereiten Sätzen.

## Haustiere

| Italienisch  | Deutsch    |
| ------------- | ----------- |
| il cane       | der Hund     |
| il gatto      | die Katze    |
| il pesce      | der Fisch    |
| l'uccello     | der Vogel    |

## Bauernhof- und Wildtiere

| Italienisch    | Deutsch     |
| --------------- | ------------ |
| la mucca        | die Kuh       |
| il cavallo      | das Pferd      |
| il leone        | der Löwe        |
| l'elefante      | der Elefant      |

## Tiere mit "essere" und "avere" beschreiben

```
Il cane è grande.        (Der Hund ist groß — essere für Eigenschaften)
Ho un gatto.              (Ich habe eine Katze — avere für Besitz)
Ho un gatto piccolo.      (Ich habe eine kleine Katze)
```

"Essere" (sein) beschreibt, wie das Tier ist (grande, piccolo, bello); "avere"
(haben) drückt aus, dass dir das Tier gehört oder du es hast — verwechsle die beiden
Verben nicht, sie haben klar getrennte Funktionen.

## Der Trick für Wildtiere

Wörter wie "leone" und "elefante" sind fast identisch mit ihren deutschen
Entsprechungen, nur mit typisch italienischer Endung auf "-e". Stößt du auf ein
Wildtier, das du nicht kennst, probier zuerst, ob eine internationale oder lateinisch
klingende Version des deutschen Wortes funktioniert — das klappt öfter, als man
denkt.
