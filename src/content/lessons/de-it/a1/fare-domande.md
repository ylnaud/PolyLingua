Im Deutschen ist die Regel bei Ja/Nein-Fragen streng: Verb und Subjekt tauschen den
Platz — "Du sprichst Italienisch" wird zu "Sprichst du Italienisch?". Im Italienischen
kannst du dir diese Umstellung oft sparen.

## Ja/Nein-Fragen: Intonation statt Inversion

```
Parli italiano.    →  Aussage: Du sprichst Italienisch.
Parli italiano?     →  Frage: Sprichst du Italienisch?
```

Wortwörtlich derselbe Satz — nur die Sprechmelodie (im Schriftlichen: das
Fragezeichen) macht den Unterschied. Eine Umstellung wie im Deutschen ist zwar
möglich (Parli tu italiano?), aber meist unnötig und im Alltag selten.

## Fragewörter: am Satzanfang, wie im Deutschen

| Italienisch | Deutsch          |
| ------------- | ------------------ |
| chi            | wer                |
| che cosa / cosa | was               |
| dove           | wo                 |
| quando         | wann               |
| come           | wie                |
| perché         | warum / weil       |
| quanto/a/i/e   | wie viel / wie viele |
| quale          | welcher/welche/welches |

Genau wie im Deutschen steht das Fragewort direkt am Satzanfang:

```
Dove abiti?     →  Wo wohnst du?
Quando arrivi?  →  Wann kommst du an?
```

## Die Falle: perché heißt beides

Anders als im Deutschen, wo "warum" und "weil" zwei verschiedene Wörter sind, benutzt
das Italienische **perché** für beide:

```
Perché non vieni?          →  Warum kommst du nicht?
Non vengo perché sono stanco. →  Ich komme nicht, weil ich müde bin.
```

Den Unterschied erkennst du nur am Kontext — steht perché am Satzanfang (mit
Fragezeichen), ist es eine Frage; steht es mitten im Satz, leitet es eine Begründung
ein.

## quanto passt sich an

Wie ein Adjektiv passt sich **quanto** an das nachfolgende Nomen an:

```
quanti fratelli?   →  wie viele Brüder? (maskulin Plural)
quante sorelle?     →  wie viele Schwestern? (feminin Plural)
```

## Warum Inversion im Italienischen selten nötig ist

Italienisch lässt das Subjektpronomen ohnehin meist weg (mehr dazu in der Lektion über
Personalpronomen) — es gibt also oft gar kein Subjekt, das man umstellen könnte.
"Parli italiano?" braucht keine Inversion, weil "tu" sowieso schon fehlt.

## Der praktische Trick

Übe zuerst Ja/Nein-Fragen einfach mit steigender Betonung am Satzende — die
Wortstellung bleibt dabei immer identisch zur Aussage. Für W-Fragen lerne die
Fragewörter als feste Satzanfänge (Dove...? Quando...? Perché...?), genau wie du es
im Deutschen mit "Wo...? Wann...? Warum...?" schon gewohnt bist.
