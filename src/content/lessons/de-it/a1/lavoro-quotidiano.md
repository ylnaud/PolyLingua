Giulia öffnet die Augen, schaut auf die Uhr und startet in ihren Tag: In dieser
Lektion begleitest du sie durch ihren Arbeitsalltag auf Italienisch — mit dem
Wortschatz, den du brauchst, um auch von deiner eigenen Arbeit zu erzählen.

## Die Frage, die man dir stellen wird

```
Che lavoro fai?          (Was machst du beruflich?)
```

Achte auf das Verb: es ist **"fare"** (machen/tun), nicht "lavorare" — wörtlich
"was für eine Arbeit machst du?".

## Die Antworten folgen immer demselben Muster

```
Lavoro in ufficio.        (Ich arbeite in einem Büro)
Lavoro in un negozio.     (Ich arbeite in einem Geschäft)
Giulia lavora in un negozio.  (Giulia arbeitet in einem Geschäft)
```

## Die Arbeitszeit: dalle ... alle ...

```
Lavoro dalle nove alle sei.       (Ich arbeite von neun bis sechs)
Faccio una pausa alle undici.     (Ich mache um elf eine Pause)
Ho una riunione alle tre.          (Ich habe um drei ein Meeting)
```

## Wortschatz rund ums Büro

| Italienisch    | Deutsch          |
| --------------- | ------------------ |
| il lavoro       | die Arbeit           |
| l'ufficio       | das Büro              |
| il capo         | der Chef               |
| la riunione     | das Meeting             |
| fare una pausa  | eine Pause machen        |

## Ein vollständiger Satz

```
Lavoro in ufficio, dalle nove alle sei, e faccio una pausa alle undici.
(Ich arbeite in einem Büro, von neun bis sechs, und mache um elf eine Pause)
```

## Der Trick zum Üben

Erzähl von deinem eigenen Arbeitstag in drei Sätzen: wo du arbeitest, deine
Arbeitszeit und wann du Pause machst. Benutz immer dieselbe Struktur und ändere nur
die Angaben — genau so, wie Giulia dir ihren Tag erzählt hat.
