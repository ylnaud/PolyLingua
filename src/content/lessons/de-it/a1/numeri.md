Zahlen sind im Italienischen weniger tückisch als im Deutschen, wo lange
zusammengesetzte Wörter entstehen ("einhundertsiebenundvierzig") — aber es gibt eine
Regel, die dir hier komplett neu sein wird: manche Zehnerzahlen VERSCHLUCKEN einen
Buchstaben, wenn eine bestimmte Einerzahl folgt.

## Die Elisions-Regel: venti verliert seinen Vokal

Ab 20 werden Zehner und Einer zu EINEM Wort zusammengeschrieben — genau wie im
Deutschen "einundzwanzig". Der Unterschied: im Italienischen steht die Zehnerzahl
ZUERST (venti + uno statt uno + venti):

```
venti + due    →  ventidue
venti + tre    →  ventitré
venti + sette  →  ventisette
```

Das funktioniert normalerweise ohne Änderung. Aber vor **uno** und **otto** verliert
die Zehnerzahl ihren letzten Vokal, weil zwei Vokale hintereinander im Italienischen
vermieden werden:

```
venti + uno    →  ventuno   (NICHT ventiuno)
venti + otto   →  ventotto  (NICHT ventiotto)
trenta + uno   →  trentuno
trenta + otto  →  trentotto
```

Diese Regel gilt für ALLE Zehner von 20 bis 90 — merke sie dir einmal, und sie
funktioniert überall gleich.

## Die Akzent-Regel bei -tre

Ab 23 bekommt jede Zahl, die auf **-tre** endet, einen Akzent auf dem letzten
Buchstaben — eine Besonderheit, die es im Deutschen nicht gibt:

```
venti + tre     →  ventitré
trenta + tre    →  trentatré
quaranta + tre  →  quarantatré
```

Ohne Akzent (tre) bedeutet das Wort einfach "drei" — mit Akzent (-tré) am Wortende
signalisiert es, dass eine größere Zahl folgt.

## Der praktische Trick

Lerne die Zehner (venti, trenta, quaranta ... novanta) als feste Liste, und übe dann
gezielt die Kombination mit uno, otto und tre laut — genau diese drei Fälle sind die
einzigen, die vom regelmäßigen Muster abweichen. Alle anderen Kombinationen (ventidue,
ventiquattro, ventisette...) folgen einfach Zehner + Einer ohne Änderung.
