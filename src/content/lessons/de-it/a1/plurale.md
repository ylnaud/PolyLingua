Im Deutschen gibt es viele verschiedene Pluralendungen (-e, -er, -n, -s) und oft
zusätzlich einen Vokalwechsel: Buch → Bücher, Haus → Häuser. Im Italienischen ist das
Prinzip anders, aber überraschend regelmäßig: Es wird nicht angehängt, sondern der
**letzte Vokal des Wortes wird ausgetauscht**. Mit drei Regeln deckst du 90 % aller
Fälle ab.

## Die drei Grundregeln

### 1. Wörter auf -o (meist männlich) → -i

| Singular   | Plural    | Deutsch    |
| ---------- | --------- | ---------- |
| il libro   | i libri   | das Buch   |
| il ragazzo | i ragazzi | der Junge  |
| il tavolo  | i tavoli  | der Tisch  |

### 2. Wörter auf -a (meist weiblich) → -e

| Singular   | Plural     | Deutsch      |
| ---------- | ---------- | ------------ |
| la casa    | le case    | das Haus     |
| la ragazza | le ragazze | das Mädchen  |
| la penna   | le penne   | der Kugelschreiber |

### 3. Wörter auf -e (männlich oder weiblich) → -i

| Singular    | Plural       | Deutsch         |
| ----------- | ------------ | --------------- |
| il pane     | i pani       | das Brot        |
| la notte    | le notti     | die Nacht       |
| lo studente | gli studenti | der Student     |

## Die Artikel ändern sich mit

Wichtig: Beim Übergang in den Plural verändert sich auch der Artikel:

| Singular   | Plural |
| ---------- | ------ |
| il         | i      |
| lo         | gli    |
| la         | le     |
| l' (mask.) | gli    |
| l' (fem.)  | le     |

## Sonderfälle: Wörter auf -ca und -ga

Wenn ein weibliches Wort auf **-ca** oder **-ga** endet, bekommt der Plural ein
eingeschobenes **h**, damit der harte Konsonantenklang erhalten bleibt:

```
amica   →   amiche     (nicht "amice", das würde weich klingen)
bottega →   botteghe   (nicht "bottege")
```

Bei männlichen Wörtern auf **-co** und **-go** ist es ähnlich, aber mit mehr
Ausnahmen:

```
amico   →   amici      (der k-Laut wird weich — eine häufige Ausnahme)
lago    →   laghi      (der harte Klang bleibt mit h erhalten)
```

## Unregelmäßige Plurale, die man auswendig lernen muss

Ein paar Wörter folgen gar keiner Regel:

| Singular   | Plural     | Deutsch    |
| ---------- | ---------- | ---------- |
| l'uomo     | gli uomini | der Mann   |
| il dito    | le dita    | der Finger |
| il braccio | le braccia | der Arm    |
| l'uovo     | le uova    | das Ei     |

Solche unregelmäßigen Plurale sind selten, aber häufig im Wortschatz. Viele stammen
aus dem lateinischen Neutrum und wechseln dabei das Genus (männlicher Singular →
weiblicher Plural) — ein Phänomen, das es im Deutschen so nicht gibt.

## Unveränderliche Wörter

Manche Wörter bleiben im Plural gleich:

- Wörter, die auf einen **Konsonanten** enden (meist Fremdwörter): _il bar → i bar_,
  _il film → i film_
- Wörter, die auf einen **betonten Vokal** enden: _la città → le città_, _il caffè →
  i caffè_
- Abkürzungen: _la foto → le foto_, _la moto → le moto_

## Kurz zusammengefasst

```
-o  →  -i    (libro → libri)
-a  →  -e    (casa → case)
-e  →  -i    (notte → notti)
-ca →  -che  (amica → amiche)
-ga →  -ghe  (bottega → botteghe)
```

Mit diesen Regeln kannst du bereits den Plural der allermeisten italienischen
Substantive korrekt bilden.
