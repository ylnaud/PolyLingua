Im Deutschen sind Verbendungen dein bester Freund: ich spiele, du spielst, er spielt —
die Endung verrät fast immer, wer handelt. Im Italienischen darfst du dieses Vertrauen
BEHALTEN: die drei regelmäßigen Verbklassen (-are, -ere, -ire) haben klar
unterscheidbare Endungen, ähnlich zuverlässig wie im Deutschen.

## Regelmäßige -are-Verben: parlare (sprechen)

| Pronomen  | Form     |
| --------- | -------- |
| io        | parlo    |
| tu        | parli    |
| lui/lei   | parla    |
| noi       | parliamo |
| voi       | parlate  |
| loro      | parlano  |

## Regelmäßige -ere-Verben: vedere (sehen)

| Pronomen  | Form    |
| --------- | ------- |
| io        | vedo    |
| tu        | vedi    |
| lui/lei   | vede    |
| noi       | vediamo |
| voi       | vedete  |
| loro      | vedono  |

## Regelmäßige -ire-Verben: dormire (schlafen)

| Pronomen  | Form     |
| --------- | -------- |
| io        | dormo    |
| tu        | dormi    |
| lui/lei   | dorme    |
| noi       | dormiamo |
| voi       | dormite  |
| loro      | dormono  |

## Die Falle: -ire-Verben mit -isc-

Eine große Gruppe von -ire-Verben (capire, finire, preferire, pulire...) baut sich
anders auf: sie schieben zwischen Stamm und Endung ein zusätzliches **-isc-** ein —
außer in der noi- und der voi-Form.

| Pronomen  | capire (verstehen) |
| --------- | ------------------- |
| io        | capisco              |
| tu        | capisci              |
| lui/lei   | capisce              |
| noi       | capiamo              |
| voi       | capite               |
| loro      | capiscono            |

Es gibt keine Regel, die dir vorhersagt, ob ein -ire-Verb -isc- braucht oder nicht —
das musst du pro Verb lernen, wie ein kleines Vokabelmerkmal.

## Das Muster, das überall gleich ist: -iamo

Egal welche Verbklasse: die noi-Form endet fast immer auf **-iamo** — parliamo,
vediamo, dormiamo, capiamo. Das gilt sogar für die meisten unregelmäßigen Verben und
ist damit einer der zuverlässigsten Anker beim Konjugieren.

## Warum das für dich als Deutschsprachiger leichter ist als für Französisch-Lerner

Deutsche Verbendungen sind ein verlässliches Ohr-Signal: -e, -st, -t, -en, -t, -en.
Italienisch funktioniert ähnlich gut: parlo, parli, parla, parliamo, parlate, parlano
— sechs klar unterscheidbare Formen. Verlass dich also ruhig auf das, was du beim
Deutschen schon gewohnt bist: genau hinhören auf die Endung.

## Der praktische Trick

Lerne die drei Muster (-are, -ere, -ire) als feste Melodien, und merke dir bei jedem
neuen -ire-Verb extra dazu, ob es zur -isc-Gruppe gehört — am besten direkt mit der
io-Form (capisco, nicht capo), damit du es beim Sprechen sofort parat hast.
