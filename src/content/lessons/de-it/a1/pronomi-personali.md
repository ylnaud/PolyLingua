Im Deutschen ist das Subjektpronomen unverzichtbar: "spreche Italienisch" ist kein
vollständiger Satz, es muss "ich spreche Italienisch" heißen. Im Italienischen ist das
anders — und das ist die wichtigste Lektion dieses Kapitels.

## Die Pronomen

| Italienisch | Deutsch          |
| ------------- | ------------------ |
| io             | ich                |
| tu             | du                 |
| lui            | er                 |
| lei            | sie                |
| Lei            | Sie (formell, großgeschrieben) |
| noi            | wir                |
| voi            | ihr                |
| loro           | sie (Plural)       |

## pro-drop: warum "io" oft überflüssig ist

Erinnere dich an die Präsens-Lektion: parlo, parli, parla, parliamo, parlate, parlano
— jede Form ist für sich schon eindeutig. Genau deshalb lässt Italienisch das
Subjektpronomen meist weg:

```
Parlo italiano.        →  Ich spreche Italienisch. (statt: Io parlo italiano.)
Parliamo bene.          →  Wir sprechen gut.
```

Dieses Phänomen nennt man **pro-drop** (das Pronomen wird "fallen gelassen"). Im
Deutschen ist das Gegenteil der Fall: das Pronomen bleibt immer stehen, weil viele
Verbformen sonst mehrdeutig wären (z. B. "spielen" für wir/sie/Sie).

## Wann das Pronomen doch gebraucht wird

Trotz pro-drop tauchen Pronomen in drei Situationen wieder auf:

1. **Betonung/Kontrast:** Io parlo italiano, tu parli francese. (Ich..., DU
   dagegen...)
2. **Klärung bei lui/lei:** lui parla und lei parla haben dieselbe Verbform — ohne
   Pronomen (oder eindeutigen Kontext) bleibt offen, ob von einem Mann oder einer
   Frau die Rede ist.
3. **Höflichkeitsform:** Lei parla italiano? — hier macht das Pronomen den
   Registerwechsel (informell/formell) deutlich.

## Die Höflichkeitsform: Lei

Für "Sie" (formell, Einzahl) benutzt Italienisch **Lei** — großgeschrieben, um es von
"lei" (sie) zu unterscheiden — aber grammatisch mit derselben 3.-Person-Singular-Form
wie lui/lei:

```
Lei parla italiano?   →  Sprechen Sie Italienisch?
```

## Der praktische Trick

Gewöhne dich beim Sprechen daran, das Pronomen bewusst WEGZULASSEN, außer wenn du
etwas betonen willst oder lui/lei sonst mehrdeutig wäre — das ist die größte
Umstellung gegenüber dem Deutschen, wo das Pronomen nie fehlen darf.
