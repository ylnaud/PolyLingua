Giulia geht auf dem Weg nach Hause noch über den Markt: Begleite sie durch einen
kompletten Einkauf, aufgeteilt in vier feste Schritte.

## 1. Höflich bestellen

```
Vorrei un caffè.       Ich hätte gerne einen Kaffee.
Vorrei del pane.        Ich hätte gerne Brot.
```

"Vorrei" (statt "voglio") ist die höfliche Art zu bestellen — ähnlich wie "ich hätte
gerne" im Deutschen höflicher klingt als "ich will".

## 2. Nach dem Preis fragen

```
Quanto costa?          Was kostet das?
È troppo caro.          Das ist zu teuer.
```

## 3. Entscheiden

```
Lo prendo.              Ich nehme es.
```

## 4. Bezahlen

```
Posso pagare con la carta?   Kann ich mit Karte bezahlen?
Pago in contanti.             Ich bezahle bar.
Grazie, è tutto.               Danke, das ist alles.
```

## Ein vollständiger Satz

```
Vorrei del pane, quanto costa? — Ah, è economico. Lo prendo. Posso pagare con la carta?
(Ich hätte gerne Brot, was kostet das? — Ah, das ist günstig. Ich nehme es. Kann ich mit Karte bezahlen?)
```

## Der Trick zum Üben

Bevor du einkaufen gehst, sag die vier Sätze laut in der richtigen Reihenfolge auf,
so wie Giulia auf dem Markt. Sie bleiben immer gleich: nur das Produkt ändert sich.
