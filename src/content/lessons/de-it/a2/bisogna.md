Diese unpersönlichen Ausdrücke sind im italienischen Alltag extrem häufig — perfekt,
um Ratschläge zu geben und über Notwendigkeiten zu sprechen, ohne auf eine bestimmte
Person zu zeigen.

## bisogna: die allgemeine Verpflichtung

```
bisogna + Infinitiv         (allgemeine Verpflichtung, ohne konkretes Subjekt)

Bisogna mangiare per vivere.      (Man muss essen, um zu leben)
Bisogna essere pazienti.            (Man muss geduldig sein)
```

Das funktioniert genau wie das deutsche unpersönliche "man muss" — kein konkretes
Subjekt, eine allgemeingültige Aussage.

## bisogna che + congiuntivo: mit konkretem Subjekt

Wenn du zeigen willst, WEM die Verpflichtung genau gilt, brauchst du "che" + Subjekt +
congiuntivo:

```
Bisogna che tu parta adesso.
(Du musst jetzt gehen — beachte den congiuntivo "parta")
```

## ci vuole / ci vogliono: was gebraucht wird

```
Ci vuole tempo.               (Man braucht Zeit — Singular)
Ci vogliono due ore.            (Man braucht zwei Stunden — Plural)
```

Die Form ändert sich je nachdem, ob das Benötigte im Singular oder Plural steht.

## Weitere nützliche unpersönliche Ausdrücke

| Ausdruck     | Bedeutung       |
| ------------ | ---------------- |
| è importante | es ist wichtig    |
| è necessario | es ist notwendig  |
| è possibile  | es ist möglich    |
| è meglio     | es ist besser     |

```
È importante dormire bene.
È meglio partire presto.
```

## Der praktische Trick

"Bisogna" ist dein Werkzeug für allgemeine Ratschläge, ohne zu direkt zu klingen
("devi..." wäre direkter) — viel natürlicher und häufiger im italienischen Alltag, um
über Notwendigkeiten oder allgemeine Empfehlungen zu sprechen.
