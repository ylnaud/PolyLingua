Das italienische Alltagsitalienisch hat zwei natürliche Wege, über die nahe Zukunft zu
sprechen, ohne auf das formale Futur zurückzugreifen, das du später kennenlernst.

## Das Präsens für nahe Pläne

```
Domani parto per Roma.        (Morgen fahre ich nach Rom)
Stasera vediamo un film.        (Heute Abend schauen wir einen Film)
```

Genau wie im Deutschen ("morgen fahre ich nach Rom" statt "morgen werde ich fahren")
bevorzugt das Italienische das Präsens + Zeitangabe für bereits feststehende Pläne.

## "stare per": das, was GENAU JETZT gleich passiert

```
stare (konjugiert) + per + Infinitiv

Sto per partire.        (Ich bin gleich weg)
Il film sta per iniziare. (Der Film fängt gleich an)
```

Das entspricht ungefähr dem deutschen "im Begriff sein, etwas zu tun" oder einfach
"gleich" — ein Signal für unmittelbare Nähe, nicht für einen Plan mit Datum.

## Die beiden nahen Zukunftsformen im Vergleich

| Struktur               | Verwendung                    | Beispiel          |
| ----------------------- | ------------------------------ | ------------------ |
| Präsens + Zeitangabe    | Zukunftsplan mit Datum         | Parto domani.      |
| stare per + Infinitiv   | Etwas Unmittelbares, jetzt gleich | Sto per partire. |

## Konjugation von "stare" (Wiederholung)

| Pronomen | stare  |
| --------- | ------ |
| io        | sto    |
| tu        | stai   |
| lui/lei   | sta    |
| noi       | stiamo |
| voi       | state  |
| loro      | stanno |

## Der praktische Trick

Für Pläne mit konkretem Datum benutzt du das Präsens. Für etwas, das in genau diesem
Moment passiert (der Zug, der schon fast ankommt, der Film, der gleich anfängt),
benutzt du "stare per" — der Unterschied liegt in der Unmittelbarkeit, nicht nur in
der Zeitform.
