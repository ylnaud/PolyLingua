Wenn ein Italiener erzählt, was er gestern gemacht hat, benutzt er fast immer das
**passato prossimo**. Es ist deine direkte Eintrittskarte zu echten Gesprächen über die
Vergangenheit — und das Prinzip kennst du bereits aus dem Deutschen.

## Die Formel: zwei Zutaten

```
avere oder essere (konjugiert)  +  participio passato
```

```
Ho    mangiato    una pizza ieri.
(Hilfsverb) (Partizip)
```

Genau wie im deutschen Perfekt ("ich habe gegessen", "ich bin gegangen") braucht das
Italienische ein konjugiertes Hilfsverb plus das Partizip Perfekt.

## avere oder essere?

- **avere** → die meisten Verben (der "Standardfall")
- **essere** → Bewegungsverben (andare, venire, partire, arrivare) und
  Zustandsänderungen (nascere, morire, diventare, restare)

Auch das kennst du aus dem Deutschen: "Ich habe gegessen" (haben), aber "ich bin
gegangen" (sein) — die Logik ist fast identisch, auch wenn nicht immer dieselben Verben
betroffen sind.

## Der Unterschied, den es im Deutschen nicht gibt

Mit essere als Hilfsverb passt sich das Partizip **in Geschlecht und Zahl** an das
Subjekt an, wie ein ganz normales Adjektiv:

```
Lui è andato.        (maskulin Singular)
Lei è andata.        (feminin Singular)
Loro sono andati.    (maskulin/gemischt Plural)
Loro sono andate.    (feminin Plural)
```

Im Deutschen bleibt das Partizip immer gleich ("er ist gegangen" / "sie ist gegangen") —
im Italienischen ändert sich mit essere die Endung des Partizips.

Mit avere dagegen ändert sich das Partizip normalerweise nicht: "Ho mangiato" bleibt
gleich, egal ob ein Mann oder eine Frau spricht.

## Das Partizip bilden

| Gruppe             | Regel          | Beispiel                    |
| ------------------- | -------------- | --------------------------- |
| Verben auf -are     | Stamm + -ato   | parlare → parlato           |
| Verben auf -ere     | Stamm + -uto   | credere → creduto           |
| Verben auf -ire     | Stamm + -ito   | dormire → dormito           |
| Häufige Unregelmäßige | auswendig lernen | fare → fatto, dire → detto |

Mit diesen Regeln kannst du schon die meisten deiner Geschichten über die Vergangenheit
auf Italienisch erzählen.
