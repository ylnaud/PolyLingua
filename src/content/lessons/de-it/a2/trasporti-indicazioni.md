Sich in einer italienischen Stadt zurechtzufinden braucht zwei Dinge: das
Verkehrsmittel benennen können, das du nehmen willst, und die Wegbeschreibung
verstehen, die dir jemand auf der Straße gibt. Hier ist beides.

## Verkehrsmittel

| Italienisch | Deutsch    |
| ----------- | ---------- |
| l'autobus   | der Bus    |
| il treno    | der Zug    |
| il taxi     | das Taxi   |
| la metro    | die U-Bahn |

## Grundlegende Wegbeschreibungen

| Italienisch      | Deutsch            |
| ------------------ | -------------------- |
| girare a sinistra    | links abbiegen         |
| girare a destra       | rechts abbiegen        |
| sempre dritto          | geradeaus                |
| accanto a               | neben                     |
| di fronte a               | gegenüber von               |
| vicino a                    | in der Nähe von                |

## Nach dem Weg fragen und ihn erklären

```
Come arrivo alla stazione?           (Wie komme ich zum Bahnhof?)
Gira a sinistra all'angolo.          (Biege an der Ecke links ab)
Continua sempre dritto.               (Geh immer weiter geradeaus)
La banca è di fronte alla stazione.   (Die Bank liegt gegenüber dem Bahnhof)
```

## Der Trick mit "sempre dritto" vs. "a destra"

Verwechsle "sempre dritto" (geradeaus, immer weiter nach vorne) nicht mit "a destra"
(rechts, ein Abbiegen). Die Wörter "dritto" und "destra" klingen im ersten Moment
ähnlich, bedeuten aber fast das Gegenteil: das eine schickt dich geradeaus weiter,
das andere lässt dich an der Ecke abbiegen.
