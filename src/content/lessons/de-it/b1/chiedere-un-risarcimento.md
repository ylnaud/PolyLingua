Wenn du eine Entschädigung verlangst, drückst du meist eine **Erwartung** oder eine
**Hoffnung** aus, kein festes Faktum. Genau dafür braucht das Italienische den
congiuntivo.

## Die Grundregel

```
Verb der Erwartung/Hoffnung/Wertung  +  che  +  anderes Subjekt  +  congiuntivo
```

Typische Auslöser: **mi aspetto che** (ich erwarte, dass), **spero che** (ich hoffe,
dass), **vorrei che** (ich möchte, dass), **è giusto che** (es ist richtig, dass).

```
Mi aspetto che l'hotel mi rimborsi la notte.
(Ich erwarte, dass das Hotel mir die Nacht erstattet.)

Spero che riceviate presto la mia richiesta.
(Ich hoffe, dass ihr meine Anfrage bald erhaltet.)

È giusto che io riceva un risarcimento.
(Es ist gerecht, dass ich eine Entschädigung erhalte.)
```

## Congiuntivo presente: schnelle Übersicht

| Person  | -are (rimborsare) | -ere (ricevere) | -ire (risolvere → -isc-Typ) |
| --------- | -------------------- | ------------------ | ------------------------------- |
| io      | rimbors**i**         | ricev**a**         | risolv**a**                     |
| tu      | rimbors**i**         | ricev**a**         | risolv**a**                     |
| lui/lei | rimbors**i**         | ricev**a**         | risolv**a**                     |
| noi     | rimbors**iamo**      | ricev**iamo**      | risolv**iamo**                  |
| voi     | rimbors**iate**      | ricev**iate**      | risolv**iate**                  |
| loro    | rimbors**ino**       | ricev**ano**       | risolv**ano**                   |

## Wenn das Subjekt gleich bleibt: di + Infinitiv

Haben Haupt- und Nebensatz dasselbe Subjekt, vermeidest du "che + congiuntivo" und
benutzt stattdessen "di + Infinitiv":

```
Spero di ricevere un rimborso.
(Ich hoffe, einen Rimbursement zu erhalten. — nicht: Spero che io riceva...)
```

## Congiuntivo passato: wenn die Handlung schon abgeschlossen sein soll

Manchmal bezieht sich deine Erwartung auf etwas, das **vorher** schon passiert sein
soll. Dafür brauchst du den congiuntivo passato: avere/essere im congiuntivo presente +
Partizip Perfekt.

```
Spero che l'hotel abbia già ricevuto il mio reclamo.
(Ich hoffe, dass das Hotel meine Beschwerde schon erhalten hat.)
```

## Kurz zusammengefasst

```
mi aspetto che / spero che / è giusto che  +  congiuntivo presente
   (Erwartung bezieht sich auf jetzt/Zukunft)

spero che  +  congiuntivo passato (abbia/sia + Partizip)
   (Erwartung bezieht sich auf etwas, das schon passiert sein soll)

Gleiches Subjekt  →  di + Infinitiv statt che + congiuntivo
```

Mit diesen Bausteinen kannst du eine Beschwerde formulieren, die höflich, aber
bestimmt klingt — genau der richtige Ton, um eine Entschädigung zu verlangen.
