Das Condizionale presente ist dein Werkzeug für alles, was direkt zu direkt
klingen würde: Bitten, Wünsche, Ratschläge und vorsichtige Aussagen.

## Bildung: gleicher Stamm wie das Futuro, andere Endungen

Die gute Nachricht zuerst: Wenn du das Futuro semplice schon kennst, kennst du
auch den Stamm des Condizionale – es sind exakt dieselben Stämme, auch bei den
unregelmäßigen Verben. Nur die Endungen ändern sich: -ei, -esti, -ebbe, -emmo,
-este, -ebbero.

```
parlare → parler-ei, parler-esti, parler-ebbe,
parler-emmo, parler-este, parler-ebbero
```

## Die gleichen unregelmäßigen Stämme wie beim Futuro

```
essere → sarei, saresti, sarebbe, saremmo, sareste, sarebbero
avere  → avrei, avresti, avrebbe, avremmo, avreste, avrebbero
dovere → dovrei, dovresti, dovrebbe, dovremmo, dovreste, dovrebbero
potere → potrei, potresti, potrebbe, potremmo, potreste, potrebbero
volere → vorrei, vorresti, vorrebbe, vorremmo, vorreste, vorrebbero
```

## Verwendung 1: Höflich bitten

Der klassische Fall ist die Bestellung im Café oder Restaurant. Statt "voglio"
(ich will) benutzt du "vorrei" (ich hätte gern):

```
Voglio un caffè.     → klingt wie ein Befehl
Vorrei un caffè.     → klingt höflich, wie ein Gast
```

## Verwendung 2: Ratschläge geben

Mit **dovresti** (du solltest) gibst du einen sanften Ratschlag, statt mit
**devi** (du musst) einen direkten Befehl zu erteilen:

```
Devi riposare di più.       (Du musst mehr ausruhen. — direkt)
Dovresti riposare di più.   (Du solltest mehr ausruhen. — als Rat)
```

## Verwendung 3: Höflich um etwas bitten (potresti)

Genauso funktioniert **potresti** (könntest du) für höfliche Bitten:

```
Puoi aiutarmi?         (Kannst du mir helfen? — direkt)
Potresti aiutarmi?      (Könntest du mir helfen? — höflicher)
```

Präge dir diese drei Formen – vorrei, dovresti, potresti – als festes Set ein:
Mit ihnen klingst du im Alltagsitalienisch sofort deutlich höflicher und
natürlicher.
