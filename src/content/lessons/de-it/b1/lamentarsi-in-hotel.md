Du kennst schon den Konjunktiv Präsens im Deutschen als höfliche Form ("Wenn Sie
könnten..."). Im Italienischen gibt es dafür den **congiuntivo imperfetto** — und du
brauchst ihn genau dann, wenn du höflich eine Hypothese aufstellst, zum Beispiel bei
einer Beschwerde im Hotel.

## Bildung: das Erkennungszeichen -ss-

Der congiuntivo imperfetto wird regelmäßig so gebildet:

| Person       | -are (parlare) | -ere (credere) | -ire (dormire) |
| -------------- | ----------------- | ----------------- | ----------------- |
| io             | parl**assi**      | cred**essi**      | dorm**issi**      |
| tu             | parl**assi**      | cred**essi**      | dorm**issi**      |
| lui/lei        | parl**asse**      | cred**esse**      | dorm**isse**      |
| noi            | parl**assimo**    | cred**essimo**    | dorm**issimo**    |
| voi            | parl**aste**      | cred**este**      | dorm**iste**      |
| loro           | parl**assero**    | cred**essero**    | dorm**issero**    |

## Die wichtigsten unregelmäßigen Verben

| Verb    | io / tu   | lui/lei  |
| --------- | ----------- | ---------- |
| essere  | fossi     | fosse    |
| avere   | avessi    | avesse   |
| fare    | facessi   | facesse  |
| dare    | dessi     | desse    |
| stare   | stessi    | stesse   |

## Der periodo ipotetico della possibilità

Das Standardmuster für höfliche Hypothesen ist:

```
Se + congiuntivo imperfetto,   condizionale presente
```

Beispiele aus einer Hotelbeschwerde:

```
Se ci fosse un problema, lo direi alla reception.
(Wenn es ein Problem gäbe, würde ich es an der Rezeption sagen.)

Se la doccia funzionasse, sarei più contento.
(Wenn die Dusche funktionieren würde, wäre ich zufriedener.)

Se la camera fosse più silenziosa, dormirei meglio.
(Wenn das Zimmer ruhiger wäre, würde ich besser schlafen.)
```

## Höflichkeit ohne vollständigen Bedingungssatz

Oft reicht schon "Se potessi..." allein, um eine Bitte höflich einzuleiten, bevor die
eigentliche Beschwerde folgt:

```
Se potessi, cambierei la camera.
(Wenn ich könnte, würde ich das Zimmer wechseln.)
```

## Nützliche Sätze für den Hotelalltag

| Italienisch                                            | Deutsch                                          |
| ---------------------------------------------------------- | --------------------------------------------------- |
| Se la connessione wifi funzionasse, lavorerei da qui.  | Wenn das WLAN funktionieren würde, würde ich von hier arbeiten. |
| Se aveste una camera più tranquilla, la vorrei.        | Wenn Sie ein ruhigeres Zimmer hätten, würde ich es gerne nehmen. |

## Kurz zusammengefasst

```
se + congiuntivo imperfetto  +  condizionale presente
     (fossi, avessi, facessi, funzionasse...)   (sarei, vorrei, dormirei...)
```

Diese Struktur ist dein Werkzeug für höfliche, hypothetische Beschwerden — sie klingt
weniger direkt als eine einfache Feststellung mit dem Indikativ und wird in
Servicesituationen sehr geschätzt.
