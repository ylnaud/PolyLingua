In dieser Lektion geht es weniger um neue Grammatik als um praktischen
Wortschatz, den du im Berufsalltag ständig brauchst – vom Bewerbungsgespräch bis
zum Büroalltag.

## Berufe nennen: kein Artikel nötig

Eine seltene Übereinstimmung zwischen Deutsch und Italienisch: Nach "essere"
steht bei Berufsbezeichnungen **kein unbestimmter Artikel**:

```
Sono professore.      (Ich bin Lehrer.)
Lei è ingegnera.       (Sie ist Ingenieurin.)
```

Sobald aber ein Adjektiv dazukommt, brauchst du den Artikel doch:

```
È un bravo professore.   (Er ist ein guter Lehrer.)
```

## Rund ums Büro

| Italienisch                | Deutsch                        |
| --------------------------- | ------------------------------- |
| il collega / la collega    | der/die Kollege/Kollegin       |
| il capo / la capa          | der/die Chef(in)                |
| l'ufficio                  | das Büro                        |
| la riunione                | die Besprechung                 |
| lo stipendio               | das Gehalt                      |

## Bewerbung und Anstellung

| Italienisch               | Deutsch                          |
| --------------------------- | --------------------------------- |
| candidarsi (per un posto) | sich bewerben (auf eine Stelle)  |
| un colloquio di lavoro    | ein Bewerbungsgespräch           |
| assumere                  | einstellen                       |
| licenziare                | entlassen, kündigen              |
| essere disoccupato        | arbeitslos sein                  |
| avere un impiego          | eine Stelle haben                |

**Verwechslungsgefahr:** "assumere" und "licenziare" sind genaue Gegensätze –
merk sie dir am besten als Paar, damit du sie nicht durcheinanderbringst.

## Ein typischer Satz zum Üben

```
Ho un colloquio di lavoro domani. Spero che mi assumano!
(Ich habe morgen ein Bewerbungsgespräch. Ich hoffe, sie stellen mich ein!)
```

Übe, ein paar Sätze über deinen eigenen (echten oder erträumten) Beruf zu bilden
– das ist der schnellste Weg, diesen Wortschatz wirklich zu verinnerlichen.
