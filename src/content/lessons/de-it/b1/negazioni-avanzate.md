Im Deutschen reicht für eine Verneinung meist ein einziges Wort: "Ich sehe **niemanden**",
"Ich habe **nie** Zeit". Im Italienischen ist das anders: Die meisten Verneinungswörter
brauchen **zwei Teile** — ein Sandwich aus "non" vor dem Verb und dem eigentlichen
Verneinungswort danach.

## Die Sandwich-Regel

```
non   +   Verb   +   mai / niente / nessuno / più
 ↑                              ↑
 vor dem Verb              nach dem Verb
```

Beispiele:

| Italienisch                  | Deutsch                          |
| ----------------------------- | --------------------------------- |
| Non capisco **niente**.       | Ich verstehe **nichts**.          |
| Non conosco **nessuno** qui.  | Ich kenne hier **niemanden**.     |
| Non vado **mai** in palestra. | Ich gehe **nie** ins Fitnessstudio. |
| Non fumo **più**.             | Ich rauche **nicht mehr**.        |

## Position in zusammengesetzten Zeiten

In Sätzen mit Hilfsverb + Partizip (wie dem passato prossimo) gibt es zwei Muster:

**"mai" und "più" schieben sich zwischen Hilfsverb und Partizip:**

```
Non ho mai mangiato il sushi.       (Ich habe nie Sushi gegessen.)
Non ho più chiamato quel numero.    (Ich habe diese Nummer nicht mehr angerufen.)
```

**"niente", "nulla" und "nessuno" stehen meist nach dem Partizip:**

```
Non ho visto niente.       (Ich habe nichts gesehen.)
Non ho incontrato nessuno. (Ich habe niemanden getroffen.)
```

## Wenn das Verneinungswort zuerst kommt: "non" verschwindet

Steht "mai", "niente" oder "nessuno" schon **vor** dem Verb (meist als Subjekt), braucht
es kein "non" mehr — das Sandwich hat dann nur noch eine Hälfte:

```
Nessuno lo sa.        (Niemand weiß es.)
Niente è perfetto.    (Nichts ist perfekt.)
Mai avrei pensato una cosa simile.   (Nie hätte ich so etwas gedacht.)
```

## "nessuno" als Adjektiv vor einem Nomen

Vor einem Substantiv verhält sich "nessuno" wie der unbestimmte Artikel "un/uno/una" und
passt sich an:

| Vor dem Nomen                  | Beispiel              | Deutsch              |
| ------------------------------- | ---------------------- | ---------------------- |
| nessun (mask., vor Konsonant/Vokal) | nessun problema     | kein Problem          |
| nessuno (mask., vor s+Konsonant, z, gn...) | nessuno sconto | kein Rabatt            |
| nessuna (fem.)                  | nessuna idea            | keine Idee             |

## Kurz zusammengefasst

```
non + Verb + mai      = nie
non + Verb + niente    = nichts
non + Verb + nessuno   = niemand
non + Verb + più       = nicht mehr

Steht das Verneinungswort vor dem Verb → "non" fällt weg.
```

Merke dir vor allem: Im Italienischen ist eine doppelte Verneinung **kein Fehler**,
sondern die Regel — genau umgekehrt zum Deutschen, wo eine doppelte Verneinung die
Bedeutung ins Positive kippen würde.
