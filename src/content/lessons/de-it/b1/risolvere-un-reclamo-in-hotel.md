Nachdem eine Beschwerde bearbeitet wurde, gibt es im Italienischen zwei verschiedene
Wege, das zu sagen — und der Unterschied ist für dich als Deutschsprachige/n
überraschend leicht zu verstehen, weil dein eigene Sprache genau dieselbe
Unterscheidung kennt.

## Vorgang vs. Zustand: dieselbe Logik wie im Deutschen

| Deutsch                       | Italienisch                    | Bedeutung                              |
| -------------------------------- | ---------------------------------- | ------------------------------------------ |
| Das Problem **wurde** gelöst.    | Il problema **è stato** risolto.   | Vorgang: eine Handlung ist passiert.       |
| Das Problem **ist** gelöst.      | Il problema **è** risolto.        | Zustand: so ist die Lage jetzt, das Ergebnis zählt. |

Im Deutschen unterscheidest du zwischen dem Vorgangspassiv mit "werden" und dem
Zustandspassiv mit "sein". Im Italienischen läuft die gleiche Unterscheidung über die
Zeitform von "essere":

- **è stato + Partizip** (Presente von essere + Partizip von essere selbst + Partizip
  des Hauptverbs) = die passato-prossimo-Form des Passivs → Vorgang.
- **è + Partizip** (nur Presente + Partizip) = Zustandsbeschreibung, fast wie ein
  Adjektiv → Ergebnis.

## Weitere Beispiele aus dem Hotelalltag

```
La camera è stata pulita stamattina.
(Das Zimmer wurde heute Morgen geputzt.) — Vorgang, mit Zeitangabe.

La camera è pulita.
(Das Zimmer ist sauber.) — Zustand, das Ergebnis zählt.

Il reclamo è stato accettato dalla direzione.
(Die Beschwerde wurde von der Geschäftsführung angenommen.) — Vorgang mit Handelndem.

Il reclamo è accettato.
(Die Beschwerde ist akzeptiert.) — Zustand, kein Handelnder genannt.
```

## Ein Handelnder passt eher zum Vorgang

Wenn du sagen willst, WER etwas getan hat, benutzt du fast immer die Vorgangsform mit
"da" (von):

```
Il problema è stato risolto dal direttore.
(Das Problem wurde vom Direktor gelöst.)
```

Beim Zustand ("è risolto") würde ein Handelnder seltsam klingen, weil der Fokus nicht
auf der Handlung, sondern auf dem Ergebnis liegt.

## Kurz zusammengefasst

```
è stato/a + Partizip  (+ da + Handelnder)   =  Vorgang    (wurde gemacht)
è + Partizip                                 =  Zustand    (ist gemacht/fertig)
```

Sobald du bei einer Beschwerde das Ergebnis bestätigen willst — "alles ist jetzt in
Ordnung" —, greifst du zur Zustandsform. Willst du beschreiben, WIE und WANN es gelöst
wurde, brauchst du die Vorgangsform mit "stato/a".
