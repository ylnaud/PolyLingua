Wenn du wiedergibst, was jemand anderes gesagt hat, benutzt das Italienische keine
Anführungszeichen – stattdessen verschieben sich systematisch die Zeitformen. Dieses
Phänomen heißt **concordanza dei tempi**.

## Zwei Sprachen, zwei Strategien für dasselbe Problem

Das Deutsche markiert berichtete Rede in erster Linie durch einen **Moduswechsel**: Aus
"Ich bin müde" wird "Sie sagte, sie sei müde" – der Konjunktiv I signalisiert, dass hier
jemand zitiert wird, während die Zeitform (Präsens) im Grunde stehen bleibt. Das
Italienische geht den entgegengesetzten Weg: Es bleibt im Indikativ, verschiebt aber die
**Zeitform** konsequent um eine Stufe nach hinten. Wer aus dem Deutschen kommt, muss sich
also bewusst umgewöhnen – hier hilft kein Moduswechsel, sondern ein mechanisches
"eine Stufe zurück" bei der Zeitform.

## Die Regel der Rückverschiebung

| Discorso diretto | Discorso indiretto   |
| ----------------- | --------------------- |
| Presente          | Imperfetto            |
| Passato prossimo  | Trapassato prossimo   |
| Futuro            | Condizionale passato  |
| Imperativo        | di + infinito         |

```
Diretto:   "Sono stanca."       →  Indiretto: Ha detto che era stanca.
Diretto:   "Ho finito."          →  Indiretto: Ha detto che aveva finito.
Diretto:   "Verrò."              →  Indiretto: Ha detto che sarebbe venuto.
```

## Auch die Zeitmarker verschieben sich

| Diretto | Indiretto        |
| ------- | ----------------- |
| oggi    | quel giorno       |
| domani  | il giorno dopo    |
| ieri    | il giorno prima   |
| adesso  | in quel momento   |

```
Diretto:    "Parto domani."
Indiretto:  Ha detto che partiva il giorno dopo.
```

## Der Sonderfall Imperativ

Befehle in direkter Rede werden zu "di + Infinitiv":

```
Diretto:      "Chiudi la porta!"
Indiretto:    Mi ha detto di chiudere la porta.
```

## Warum das eine C1-Herausforderung ist

Diese doppelte Transformation – Zeitform UND Zeitmarker gleichzeitig, flüssig und ohne
Nachdenkpause – korrekt anzuwenden, ist genau das, was einen C1-Sprecher von jemandem
unterscheidet, der noch Satz für Satz gedanklich übersetzt. Anders als beim deutschen
Konjunktiv I, den du nur einmal am Verb markierst, verlangt das Italienische, dass du an
zwei Stellen gleichzeitig konsequent bleibst.
