Das futuro anteriore drückt eine Zukunftshandlung aus, die **vor** einer anderen
Zukunftshandlung abgeschlossen ist – und dient außerdem dazu, über die jüngste
Vergangenheit zu spekulieren, ohne dich ganz festzulegen.

## Die Formel

```
avere/essere (futuro semplice)  +  participio passato
```

| Person  | avere (futuro) | essere (futuro) |
| ------- | --------------- | ----------------- |
| io      | avrò            | sarò               |
| tu      | avrai           | sarai              |
| lui/lei | avrà            | sarà                |
| noi     | avremo          | saremo             |
| voi     | avrete          | sarete              |
| loro    | avranno         | saranno             |

## Gebrauch 1: eine Zukunftshandlung vor einer anderen

```
Quando avrò finito, ti chiamerò.
   (Wenn ich fertig bin, rufe ich dich an.)

Quando sarò arrivato, ti scriverò.
   (Wenn ich angekommen bin, schreibe ich dir.)
```

Das ist strukturell genau das, was du aus dem deutschen Futur II kennst ("Bis ich fertig
sein werde, ..."), auch wenn das Deutsche in der Alltagssprache oft lieber zum Präsens
greift ("Wenn ich fertig bin, rufe ich dich an"). Das Italienische dagegen verlangt in
diesem Fall konsequent das futuro anteriore im Nebensatz und das futuro semplice im
Hauptsatz — beide Verben bleiben im Futur, während das Deutsche hier typischerweise ins
Präsens ausweicht.

```
Deutsch (typisch):  Wenn ich fertig bin, rufe ich dich an.        (Präsens + Präsens)
Italienisch:         Quando avrò finito, ti chiamerò.              (futuro anteriore + futuro semplice)
```

## Gebrauch 2: eine Vermutung über die jüngste Vergangenheit

Der zweite Gebrauch ist weniger naheliegend, aber im gesprochenen Italienisch sehr
häufig: eine Vermutung über etwas, das wahrscheinlich schon passiert ist, ausdrücken,
ohne explizit "ich glaube" oder "wahrscheinlich" zu sagen — eine Funktion, die das
deutsche Futur II so direkt nicht abdeckt.

```
Non risponde al telefono. Avrà dimenticato il cellulare a casa.
   (Er geht nicht ans Telefon. Er hat wohl sein Handy zu Hause vergessen.)

Sono le tre e non è ancora arrivato: avrà perso il treno.
   (Es ist drei Uhr und er ist noch nicht angekommen: er hat wohl den Zug verpasst.)
```

Im Deutschen bräuchtest du dafür meist ein Modalwort wie "wohl" oder "wahrscheinlich" –
das Italienische leistet dieselbe Nuance allein durch die Verbform.

## Die zwei Gebrauchsweisen nebeneinander

| Gebrauch                              | Beispiel                                    | Funktion                          |
| --------------------------------------- | ---------------------------------------------- | ------------------------------------ |
| Zukunftshandlung vor einer anderen      | Quando avrò finito, ti chiamerò.              | Abfolge zweier Zukunftshandlungen  |
| Vermutung über die jüngste Vergangenheit | Avrà dimenticato il cellulare.               | Spekulation ohne einleitendes Verb |

## Der Trick, um es schnell zu erkennen

Siehst du "quando" + futuro anteriore, ist es fast immer Gebrauch 1 (Abfolge). Steht das
futuro anteriore allein, als Antwort auf etwas ohne unmittelbare Erklärung, ist es fast
immer Gebrauch 2 (Vermutung).
