Dieser Wortschatz bereitet dich auf das spezifische Register der italienischen
Geschäftswelt vor: Meetings, E-Mails und Verhandlungen mit ihrer typischen Formalität.

## Grundlegender Bürowortschatz

| Italienisch                     | Deutsch                        |
| -------------------------------- | -------------------------------- |
| la parte interessata             | betroffene Partei                |
| la scadenza                      | Frist                             |
| fare il punto della situazione   | eine Bestandsaufnahme machen     |
| dare seguito a                   | weiterverfolgen/nachfassen       |
| licenziare qualcuno              | jemanden entlassen               |
| il fatturato                     | Umsatz                            |

## Feste Formeln für Geschäfts-E-Mails

```
Gentile Sig./Sig.ra,                          (formelle Anrede, mit Nachname)
Le scrivo in merito a...                        (ich schreibe Ihnen bezüglich...)
In attesa di un suo riscontro, porgo distinti saluti. (formeller Abschluss)
```

## Die Verwendung von "Lei"

Anders als im Französischen oder Spanischen bleibt das italienische Geschäftsleben sehr
konsequent beim "Lei" (Sie), selbst unter Kollegen ähnlichen Rangs, bis das "tu"
ausdrücklich angeboten wird. Das ist dir aus dem Deutschen vertraut – auch hier bleibt
das "Sie" im Berufskontext oft lange bestehen –, nur zieht das Italienische diese Regel
im formellen Firmenumfeld noch etwas strikter durch, als Zeichen tief verankerten
beruflichen Respekts.

## Widerspruch in Meetings abschwächen

```
Capisco il suo punto di vista, ma ho una prospettiva diversa.
È un'idea interessante; tuttavia, non sono sicuro che sia fattibile.
```

## Ergebnisse präzise präsentieren

```
Il fatturato è aumentato del 15% rispetto al trimestre scorso.
Siamo in linea per rispettare la scadenza.
Ci sono state alcune difficoltà con la tempistica.
```

## Warum es sich lohnt, das zu beherrschen

Dieses spezifische Register – höflich, formell und mit eigenem Wortschatz – ist genau
das, was man in einem professionellen italienischen Umfeld erwartet. Wer es beherrscht,
zeigt, dass er nicht nur die Sprache, sondern auch die kulturellen Codes der
italienischen Geschäftswelt versteht.
