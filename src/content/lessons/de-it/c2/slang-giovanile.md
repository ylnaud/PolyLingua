Kein Grammatikbuch bereitet dich darauf vor, einer Gruppe zwanzigjähriger Italiener
beim Reden untereinander zuzuhören. Diese Lektion behandelt genau das Register, dem du
auf der Straße, in Serien und in sozialen Medien wirklich begegnest.

## Füllwörter und Ausdrücke der Unsicherheit

```
tipo    → Füllwort, ähnlich wie ein deutsches beiläufiges "so"
          Era, tipo, super interessante.

boh     → "keine Ahnung", mit implizitem Schulterzucken
          — Che ore sono?  — Boh, non lo so.
```

"Tipo" funktioniert fast genau wie manche deutschen Jugendsprache-Füllwörter: Es trägt
keine eigene Bedeutung, sondern verleiht dem Satz nur einen beiläufigen, lässigen Ton.

## Doppelte Verneinung mit positivem Sinn: "mica"

"Mica" ist eine umgangssprachliche Verneinung, die "non" verstärkt — aber in der
Kombination "mica male" ergibt sich überraschend etwas Positives:

```
Non è mica male.  /  È mica male.
   (Gar nicht schlecht → eigentlich ziemlich gut)

Questo film è mica male, mi è piaciuto.
   (Dieser Film ist gar nicht so schlecht, er hat mir gefallen.)
```

## Vokabular für Begeisterung und Unlust

| Ausdruck | Bedeutung |
| --- | --- |
| figo / figa | cool, geil (Adjektiv) |
| una figata | etwas Cooles (Substantiv) |
| che sbatti | kein Bock, was für ein Aufwand |
| che palle | wie nervig (vulgärer, aber sehr gebräuchlich) |

```
Che figata questo concerto!     (Was für ein geiles Konzert!)
Ho troppo sbatti per uscire.    (Ich hab keinen Bock rauszugehen.)
```

## Anglizismen, die längst zum italienischen Alltag gehören

Genau wie das deutsche "chillen" oder "cringe" übernimmt das italienische
Umgangssprachliche Anglizismen ganz natürlich, ohne sie zu übersetzen oder
morphologisch anzupassen:

| Englisch | Verwendung im Italienischen |
| --- | --- |
| weekend | il weekend (das Wochenende) |
| smartphone | lo smartphone |
| selfie | il selfie / farsi un selfie |
| cool | è cool (ist cool, ist angesagt) |

```
Cosa fai questo weekend?        (Was machst du dieses Wochenende?)
Ci facciamo un selfie?          (Machen wir ein Selfie?)
```

## Wann (nicht) dieses Register verwenden

Dieses Vokabular gehört ausschließlich in informelle Gespräche unter Gleichaltrigen —
Freunde, soziale Medien, Textnachrichten. "Boh" oder "che sbatti" in einem
professionellen Kontext zu verwenden, würde denselben Registerbruch erzeugen wie
"keine Ahnung, kein Bock" in einer deutschen Teambesprechung. Es zu erkennen ist der
Schlüssel: Es verstehen, wenn du es hörst, ohne es zwingend selbst in jedem Kontext
verwenden zu müssen.
