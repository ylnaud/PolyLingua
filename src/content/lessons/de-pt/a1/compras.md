Einkaufen gehören zu den praktischsten Situationen im Sprachalltag – ob im
Supermarkt, in der Boutique oder auf dem Markt. Hier lernst du den
Grundwortschatz für **fazer compras** (einkaufen gehen).

## Grundausdrücke

```
fazer compras    → einkaufen gehen
a loja              → das Geschäft
comprar               → kaufen
pagar                   → bezahlen
```

"Fazer compras" heißt wörtlich "Käufe machen" – eine feste Wendung, die du als
Ganzes lernst, ähnlich wie "einkaufen gehen" im Deutschen auch eine feste
Verbindung ist.

## Nach dem Preis fragen

Das ist wohl der praktischste Satz beim Einkaufen überhaupt:

```
Quanto custa?      → Wie viel kostet es?
Quanto custa isto?    → Wie viel kostet das (hier)?
Quanto é?               → Wie viel ist es? (kürzere Variante)
```

Im Deutschen fragst du mit dem Verb "kosten". Portugiesisch kann dasselbe mit
"custar" (kosten) tun, benutzt aber im Alltag oft die noch kürzere Version mit
"ser" (sein): "Quanto é?" – wörtlich "Wie viel ist es?". Beide Varianten sind
korrekt und gebräuchlich.

## Kaufen wollen

```
Eu quero comprar isto.     → Ich möchte das kaufen.
Eu quero este livro.          → Ich möchte dieses Buch.
```

**Querer** (wollen/möchten) + Infinitiv ist die Standardkonstruktion, um
einen Kaufwunsch auszudrücken – strukturell parallel zum deutschen "ich
möchte kaufen".

## An der Kasse

```
a caixa       → die Kasse
o preço          → der Preis
pagar               → bezahlen
```

```
Vou pagar na caixa.       → Ich werde an der Kasse bezahlen.
Qual é o preço?              → Was ist der Preis?
```

## Billig oder teuer

```
barato    → billig
caro        → teuer
```

```
Este vestido é caro.      → Dieses Kleid ist teuer.
A loja tem preços baratos.   → Das Geschäft hat billige Preise.
```

## Zusammenfassung

Die wichtigsten Bausteine zum Einkaufen sind: die Preisfrage (Quanto custa? /
Quanto é?), der Kaufwunsch (Quero comprar...) und das Bezahlen (pagar na
caixa). Mit barato und caro kannst du zusätzlich deine Meinung zum Preis
ausdrücken.
