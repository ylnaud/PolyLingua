Als Deutscher kennst du das Problem: Es gibt keine einzige Regel, die für alle
Substantive im Plural funktioniert – der Mann → die Männer, das Auto → die Autos,
das Kind → die Kinder. Fünf verschiedene Pluralendungen, und man muss sie mit jedem
Wort einzeln lernen. Die gute Nachricht: Portugiesisch ist hier deutlich
systematischer. Eine einzige Grundregel deckt die meisten Fälle ab – und nur eine
Wortgruppe braucht wirklich Auswendiglernen.

## Grundregel: einfach -s anhängen

Endet ein Wort auf einen Vokal (a, e, o, u), hängst du einfach **-s** an:

```
casa → casas           (Haus → Häuser)
livro → livros          (Buch → Bücher)
gato → gatos            (Katze → Katzen)
```

Das funktioniert bei der großen Mehrheit der portugiesischen Substantive – schon
allein damit kommst du im Alltag sehr weit.

## Wörter auf -ão: die einzige echte Hürde

Hier liegt die einzige Stelle, an der Portugiesisch dem Deutschen ähnelt: Es gibt
keine feste Regel, welche der drei Endungen ein Wort auf **-ão** im Plural bekommt.
Genau wie du im Deutschen "der Autor" → "die Autoren" nicht aus der Singularform
ableiten kannst, musst du hier mit jedem Wort einzeln lernen.

### 1. -ão → -ões (die häufigste Variante)

```
coração → corações      (Herz → Herzen)
avião → aviões          (Flugzeug → Flugzeuge)
limão → limões          (Zitrone → Zitronen)
```

### 2. -ão → -ães (einige Wörter)

```
pão → pães              (Brot → Brote)
cão → cães              (Hund → Hunde)
alemão → alemães         (Deutscher → Deutsche)
```

### 3. -ão → -ãos (wenige Wörter)

```
mão → mãos              (Hand → Hände)
irmão → irmãos           (Bruder → Brüder)
cidadão → cidadãos       (Bürger → Bürger, Plural)
```

Praktischer Tipp: Bist du unsicher, welche Endung ein Wort auf -ão hat, **wähle
-ões** – damit liegst du in den meisten Fällen richtig.

## Wörter auf -al, -el, -ol, -ul

Das **-l** am Ende fällt weg und wird durch **-is** ersetzt:

```
animal → animais        (Tier → Tiere)
jornal → jornais        (Zeitung → Zeitungen)
papel → papéis          (Papier → Papiere)
hotel → hotéis          (Hotel → Hotels)
azul → azuis            (blau → blau, Plural)
```

Achtung bei -el: Im Plural bekommt das e einen Akzent: pap**é**is, hot**é**is.

## Wörter auf -r oder -s (betonte Endsilbe)

Hier wird **-es** angehängt:

```
professor → professores  (Lehrer → Lehrer, Plural)
flor → flores            (Blume → Blumen)
país → países            (Land → Länder)
```

## Wörter auf -m

Das End-**m** wird zu **-ns**:

```
homem → homens           (Mann → Männer)
viagem → viagens          (Reise → Reisen)
jardim → jardins           (Garten → Gärten)
```

## Übersichtstabelle

| Endung im Singular | Pluralendung        | Beispiel                 |
| ------------------- | -------------------- | ------------------------- |
| Vokal (a, e, o)      | + s                   | casa → casas               |
| -ão                  | -ões / -ães / -ãos    | coração → corações         |
| -al, -ol, -ul        | -l wird zu -is        | animal → animais           |
| -el                   | -l wird zu -éis       | papel → papéis             |
| -r (betont)           | + es                  | professor → professores    |
| -m                    | -m wird zu -ns        | homem → homens             |

Merke dir vor allem die Grundregel (+s) und die drei -ão-Varianten – der Rest kommt
mit der Zeit fast von selbst, sobald du genug portugiesische Wörter kennst.
