Im Deutschen ist die Verbkonjugation dein bester Freund: die Endung verrät dir fast
immer, welche Person handelt — genau dieses Prinzip funktioniert im Portugiesischen
ähnlich gut, nur mit drei statt einer Endungsklasse.

## Die drei regelmäßigen Klassen

Portugiesische Verben werden nach ihrem Infinitiv-Ende in drei Gruppen eingeteilt —
eine Einteilung, die es im Deutschen (schwach/stark) so nicht gibt:

| Pronomen  | falar (-ar) | comer (-er) | partir (-ir) |
| --------- | ----------- | ----------- | ------------- |
| eu        | falo        | como        | parto         |
| tu        | falas       | comes       | partes        |
| ele/ela   | fala        | come        | parte         |
| nós       | falamos     | comemos     | partimos      |
| eles/elas | falam       | comem       | partem        |

Jede Klasse hat ihre eigenen, aber klar erkennbaren Endungen — genau wie im Deutschen
("ich spiele, du spielst, er spielt") verrät dir die Endung fast immer die Person.

## ser (sein) — komplett unregelmäßig

| Pronomen  | Form  |
| --------- | ----- |
| eu        | sou   |
| tu        | és    |
| ele/ela   | é     |
| nós       | somos |
| eles/elas | são   |

## estar (sein) — auch unregelmäßig

| Pronomen  | Form    |
| --------- | ------- |
| eu        | estou   |
| tu        | estás   |
| ele/ela   | está    |
| nós       | estamos |
| eles/elas | estão   |

## Die zentrale Falle: zwei Wörter für "sein"

Das ist die größte Hürde in dieser Lektion, weil das Deutsche dafür keine Vorlage
bietet:

```
SER:    dauerhaft, wer/was etwas IST     → Sou professor. (Ich bin Lehrer.)
ESTAR:  vorübergehend, ein ZUSTAND       → Estou cansado. (Ich bin müde.)
```

| Deutsch          | Portugiesisch      | Warum                     |
| ----------------- | ------------------- | --------------------------- |
| Ich bin Lehrer.   | Sou professor.       | dauerhafter Beruf (ser)     |
| Ich bin müde.     | Estou cansado.       | vorübergehender Zustand (estar) |
| Sie ist aus Porto. | Ela é do Porto.     | dauerhafte Herkunft (ser)   |
| Sie ist zu Hause.  | Ela está em casa.   | vorübergehender Ort (estar) |

Verwechselst du sie, ändert sich die Bedeutung: "ele é cansado" klingt für Muttersprachler
eher nach "er ist von Natur aus ein müder Typ" statt "er ist gerade müde" — genau
dieser Unterschied fehlt im deutschen "sein" komplett.

## Der praktische Trick

Übe die drei regelmäßigen Endungsklassen laut, bis sie automatisch sitzen — das
Prinzip kennst du schon aus dem Deutschen. Bei ser/estar hilft nur eine
Eselsbrücke: frag dich bei jedem "ich bin ...", ob es sich morgen noch ändern könnte.
Ändert es sich vielleicht (müde, zu Hause, glücklich) → estar. Bleibt es stabil
(Beruf, Herkunft, Persönlichkeit) → ser.
