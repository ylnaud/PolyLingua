Über die eigene Arbeit zu sprechen gehört zu den ersten Themen, die im
Alltagsgespräch aufkommen – "Was machst du beruflich?" ist fast überall eine
der ersten Fragen. Hier lernst du den Grundwortschatz rund um **o trabalho**
(die Arbeit).

## Berufe nennen: ser + Beruf, ohne Artikel

Der wichtigste Unterschied zum Deutschen liegt nicht im Wortschatz, sondern
in der Grammatik: Bei Berufsangaben mit **ser** (sein) lässt Portugiesisch den
unbestimmten Artikel weg – genau wie Deutsch:

```
Sou professor.        → Ich bin Lehrer.
Ela é médica.           → Sie ist Ärztin.
Somos colegas.            → Wir sind Kollegen.
```

Das ist eigentlich eine Parallele zum Deutschen, keine Falle – aber weil in
vielen anderen Kontexten (z. B. "tenho um cão" – ich habe einen Hund) der
Artikel im Portugiesischen sehr wohl steht, neigen Anfänger dazu, ihn hier
fälschlich zu ergänzen.

## Wichtige Berufe

```
o professor / a professora   → der Lehrer / die Lehrerin
o médico / a médica            → der Arzt / die Ärztin
o engenheiro / a engenheira      → der Ingenieur / die Ingenieurin
o enfermeiro / a enfermeira        → der Krankenpfleger / die Krankenschwester
```

Die meisten Berufsbezeichnungen haben eine männliche Form auf -o und eine
weibliche auf -a – ein Muster, das dir aus der Artikellektion schon bekannt
vorkommt.

## Rund ums Büro

```
o escritório     → das Büro
a reunião          → die Besprechung
o colega / a colega  → der Kollege / die Kollegin
o chefe / a chefe      → der Chef / die Chefin
```

Beachte: "colega" und "chefe" haben für beide Geschlechter dieselbe Wortform –
nur der vorangestellte Artikel (o/a) zeigt das Geschlecht an.

## Über die Arbeit sprechen

Das regelmäßige -ar-Verb **trabalhar** (arbeiten) konjugierst du wie jedes
andere -ar-Verb, das du schon kennst:

```
eu trabalho       → ich arbeite
tu trabalhas         → du arbeitest
ele/ela trabalha       → er/sie arbeitet
```

Um zu sagen, *als was* du arbeitest, nutzt du "trabalhar como + Beruf":

```
Trabalho como professor.    → Ich arbeite als Lehrer.
```

Und um zu sagen, *wohin* du zur Arbeit gehst: "ir para + Ort":

```
Vou para o escritório.       → Ich gehe ins Büro.
```

## Zusammenfassung

Merke dir vor allem die Konstruktion ser + Beruf ohne Artikel (sou professor,
é médica) und das Verb trabalhar in seinen Grundformen. Mit den Wörtern
escritório, reunião, colega und chefe kannst du schon einfache Sätze über
deinen Arbeitsalltag bilden.
