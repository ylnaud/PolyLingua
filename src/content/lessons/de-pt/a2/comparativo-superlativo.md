Im Deutschen hängst du fürs Vergleichen einfach eine Endung ans Adjektiv:
schnell/schneller/am schnellsten. Das Portugiesische arbeitet stattdessen mit
zusätzlichen Wörtern - eine analytische statt einer synthetischen Konstruktion.

## Der Komparativ: mais + Adjektiv + que

```
Deutsch:       schnell → schneller           (Endung -er)
Portugiesisch: rápido → mais rápido           (Wort 'mais' davor)
```

Beim Vergleich mit 'als' benutzt du 'que':

```
Ela é mais alta que eu.      Sie ist größer als ich.
Este livro é mais caro que aquele.   Dieses Buch ist teurer als jenes.
```

Merk dir 'mais...que' als festes Paar - genau wie im Deutschen 'mehr...als' bei
Substantiven, aber hier auch bei Adjektiven.

## Der Superlativ: Artikel + mais + Adjektiv + de

Der Superlativ braucht zusätzlich den **bestimmten Artikel** direkt vor 'mais', und
für 'von' benutzt du 'de' statt 'que':

```
Ele é o mais rápido da turma.    Er ist der Schnellste der Klasse.
Este é o mais caro de todos.     Dieser ist der Teuerste von allen.
```

Ein typischer Fehler von Deutschsprachigen: 'que' auch im Superlativ zu benutzen.
Merke dir den Unterschied so: **Komparativ vergleicht zwei Dinge → que** (als);
**Superlativ vergleicht eins mit einer Gruppe → de** (von/aus).

## Unregelmäßige Formen

Genau wie im Deutschen ('gut → besser', nicht 'guter') gibt es im Portugiesischen
Adjektive mit unregelmäßigem Komparativ/Superlativ:

| Adjektiv    | Komparativ | Superlativ    |
| ----------- | ---------- | -------------- |
| bom (gut)   | melhor     | o melhor       |
| mau (schlecht) | pior    | o pior         |
| grande (groß) | maior    | o maior        |
| pequeno (klein) | menor  | o menor        |

Diese vier lohnt es sich auswendig zu lernen - sie kommen sehr häufig vor und folgen
keinem regelmäßigen Muster.

## Gleichheit: tão...quanto

Für 'genauso...wie' benutzt du 'tão + Adjektiv + quanto':

```
Ela é tão alta quanto eu.   Sie ist genauso groß wie ich.
```
