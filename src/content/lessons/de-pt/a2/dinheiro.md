Über Geld zu sprechen gehört zu den nützlichsten Alltagsfertigkeiten überhaupt
— ob im Supermarkt, im Café oder an der Bank. In dieser Lektion lernst du das
Grundvokabular, um Preise zu erfragen und zu bezahlen.

## Nach dem Preis fragen

```
Quanto custa?          (Wie viel kostet das?)
Quanto é?               (Wie viel macht das?)
Quanto custam os sapatos? (Wie viel kosten die Schuhe?)
```

Beide Fragen bedeuten praktisch dasselbe und werden im Alltag oft
gleichbedeutend benutzt.

## Bezahlen

| Portugiesisch    | Deutsch          |
| ------------------ | ------------------ |
| pagar               | bezahlen           |
| em dinheiro         | in bar             |
| com cartão          | mit Karte          |
| o troco             | das Wechselgeld    |

```
Vou pagar em dinheiro.        (Ich zahle in bar)
Posso pagar com cartão?       (Kann ich mit Karte zahlen?)
Aqui está o troco.            (Hier ist Ihr Wechselgeld)
```

## Im Restaurant

Die wichtigste Wendung, um zu zahlen und zu gehen:

```
A conta, por favor.           (Die Rechnung, bitte)
```

## Preise beschreiben

| Portugiesisch | Deutsch |
| -------------- | ------- |
| barato          | billig  |
| caro            | teuer   |
| grátis          | kostenlos |

```
Este restaurante é muito caro.    (Dieses Restaurant ist sehr teuer)
A entrada é grátis.                (Der Eintritt ist kostenlos)
```

## Ein ganzer Dialog

```
— Quanto custa este livro?
— Custa 15 euros.
— Posso pagar com cartão?
— Sim, claro.
```

(— Wie viel kostet dieses Buch? — Es kostet 15 Euro. — Kann ich mit Karte
zahlen? — Ja, natürlich.)

Mit diesem Vokabular kannst du dich im Alltag bei jedem Kauf sicher
verständigen, egal ob im Geschäft, im Café oder im Restaurant.
