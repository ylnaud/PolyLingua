Wie drückst du auf Portugiesisch aus, dass etwas allgemein notwendig ist, ohne
jemand Bestimmten zu meinen? Im Deutschen greifst du zum Pseudo-Subjekt "man": man
muss lernen. Portugiesisch löst das eleganter - ganz ohne Subjekt.

## É preciso + Infinitiv: die Grundform

```
É preciso estudar.       Man muss lernen.
É preciso trabalhar.     Man muss arbeiten.
```

Wörtlich heißt "é preciso" so viel wie "es ist nötig" - aber das "es" ist rein
grammatisch, kein echtes Subjekt wie das deutsche "man". Diese Form benutzt du
immer dann, wenn KEIN konkretes Subjekt genannt wird - die Aussage gilt allgemein,
für jeden.

## É preciso QUE + Subjuntivo: sobald ein Subjekt auftaucht

Sobald du sagen willst, WER etwas tun soll, reicht der Infinitiv nicht mehr - du
brauchst 'que' und danach den Subjuntivo:

```
É preciso estudar.              Man muss lernen. (allgemein, kein Subjekt)
É preciso que ela estude.       Es ist nötig, dass SIE lernt. (konkretes Subjekt)
```

Merkregel: **kein Subjekt → Infinitiv. Konkretes Subjekt → que + Subjuntivo.** Diese
Regel gilt für die meisten unpersönlichen Ausdrücke im Portugiesischen, nicht nur für
'é preciso'.

## É necessário: die formellere Variante

'É necessário' bedeutet dasselbe wie 'é preciso', wirkt aber etwas gehobener -
ähnlich wie im Deutschen "es ist notwendig" formeller klingt als das
umgangssprachliche "man muss":

```
É necessário apresentar um documento.   Es ist notwendig, ein Dokument vorzulegen.
```

Für den Alltag reicht 'é preciso' völlig aus; 'é necessário' begegnet dir eher in
offiziellen Texten, Anleitungen oder Formularen.

## Der Kernunterschied zum deutschen "man"

Der wichtigste Unterschied liegt im Subjekt selbst: Deutsch braucht IMMER ein
Pseudo-Subjekt ("man"), das grammatisch wie eine echte Person behandelt wird
(man muss, man kann, man sollte). Portugiesisch braucht dagegen GAR KEIN Subjekt -
'é preciso' ist eine feste, unveränderliche Wendung, die für sich allein steht.
Das macht sie einfacher zu benutzen, sobald du dich an die Struktur gewöhnt hast:
kein Pronomen zum Konjugieren, kein Genus, kein Numerus - immer 'é preciso'.
