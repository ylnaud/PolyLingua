Freunde treffen, ein Wochenende planen, ein Treffen verabreden — dafür
brauchst du feste Redewendungen, um Vorschläge zu machen und darauf zu
reagieren. Genau die lernst du in dieser Lektion.

## Einen Vorschlag machen

Die einfachste Struktur benutzt **"Vamos...?"** (wörtlich "Gehen wir...?",
im Sinne von "Sollen wir...?"):

```
Vamos ao cinema?          (Sollen wir ins Kino gehen?)
Vamos comer fora?         (Sollen wir auswärts essen?)
Vamos marcar um encontro? (Sollen wir uns verabreden?)
```

## Zustimmen

| Portugiesisch  | Deutsch          |
| ---------------- | ------------------ |
| Boa ideia!        | Gute Idee!         |
| Sim, claro!        | Ja, klar!           |
| Combinado!         | Abgemacht!          |

## Zögern oder ablehnen

| Portugiesisch          | Deutsch                    |
| ------------------------- | ----------------------------- |
| Talvez                     | Vielleicht                     |
| Não sei, vou pensar        | Ich weiß nicht, ich überlege es mir |
| Não posso, tenho outros planos | Ich kann nicht, ich habe andere Pläne |

## Nach Zeit und Ort fragen

```
A que horas te convém?    (Um welche Uhrzeit passt es dir?)
Onde nos encontramos?     (Wo treffen wir uns?)
```

## Einen Plan bestätigen

```
Combinado! Até sábado.    (Abgemacht! Bis Samstag.)
```

## Ein ganzer Dialog

```
— Vamos ao cinema no sábado?
— Boa ideia! A que horas te convém?
— Às 20 horas, pode ser?
— Combinado! Até sábado.
```

(— Sollen wir am Samstag ins Kino gehen? — Gute Idee! Um welche Uhrzeit
passt es dir? — Um 20 Uhr, geht das? — Abgemacht! Bis Samstag.)

Mit diesem Vokabular kannst du Verabredungen auf Portugiesisch ganz natürlich
treffen, egal ob mit Freunden oder Kollegen.
