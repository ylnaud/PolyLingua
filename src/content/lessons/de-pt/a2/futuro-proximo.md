Für die nahe Zukunft benutzt das Portugiesische eine Konstruktion, die dir aus dem
Deutschen bekannt vorkommen wird - nur mit einem anderen Hilfsverb.

## Das Muster: ir + Infinitiv

Im Deutschen bildest du die Zukunft oft periphrastisch mit 'werden' + Infinitiv:

```
Deutsch:       Ich werde   reisen.
                  ↑ Hilfsverb    ↑ Infinitiv
Portugiesisch: Eu vou       viajar.
                  ↑ ir (konjugiert)  ↑ Infinitiv
```

'Ir' bedeutet eigentlich 'gehen', aber in dieser Konstruktion übernimmt es exakt
die grammatische Rolle des deutschen 'werden' - ein konjugiertes Hilfswort, das die
Zukunft signalisiert, gefolgt vom Infinitiv des eigentlichen Verbs.

## Konjugation von ir im Präsens

| Pronomen  | ir    |
| --------- | ----- |
| eu        | vou   |
| tu        | vais  |
| ele/ela   | vai   |
| nós       | vamos |
| eles/elas | vão   |

Beispiele:

```
Eu vou estudar.       Ich werde lernen.
Tu vais viajar.        Du wirst reisen.
Nós vamos comer.       Wir werden essen.
```

## Futuro Próximo vs. einfaches Futur

Das Portugiesische hat auch ein einfaches, synthetisches Futur (falarei - ich
werde sprechen, eine einzige konjugierte Form). Im Alltag wird das Futuro Próximo
(vou falar) aber viel häufiger benutzt - genau wie im Deutschen "ich werde reisen"
im gesprochenen Alltag üblicher ist als eine reine Zukunftsvorhersage. Merke dir:

```
Vou viajar amanhã.     nah, konkret, alltagssprachlich (geplante Reise)
Viajarei um dia.        formeller, entfernter (irgendwann, unbestimmt)
```

## Die Verneinung

Genau wie bei den Modalverben aus einer früheren Lektion steht 'não' direkt vor dem
konjugierten Verb, hier also vor 'ir':

```
Eu não vou viajar.     Ich werde nicht reisen.
Nós não vamos estudar hoje.   Wir werden heute nicht lernen.
```
