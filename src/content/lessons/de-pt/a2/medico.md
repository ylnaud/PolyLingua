Krank zu sein und das im Ausland auf Portugiesisch ausdrücken zu müssen ist
eine der stressigsten Alltagssituationen. Mit dem Vokabular dieser Lektion
kannst du Symptome klar beschreiben und Hilfe bekommen.

## Sagen, dass man krank ist

```
Estou doente.            (Ich bin krank)
Não me sinto bem.        (Ich fühle mich nicht gut)
```

## Schmerzen beschreiben mit "Dói-me"

Das portugiesische Muster für Schmerzen funktioniert anders als im Deutschen:
wörtlich "Es schmerzt mir + Körperteil":

```
Dói-me a cabeça.         (Mir tut der Kopf weh)
Dói-me a garganta.       (Mir tut der Hals weh)
Dói-me a barriga.        (Mir tut der Bauch weh)
```

Der Arzt fragt oft:

```
Onde dói?                (Wo tut es weh?)
```

## Häufige Symptome

| Portugiesisch  | Deutsch      |
| ---------------- | -------------- |
| a febre           | das Fieber     |
| a tosse           | der Husten     |
| a constipação      | die Erkältung  |
| a dor              | der Schmerz    |

```
Tenho febre e tosse.       (Ich habe Fieber und Husten)
Tenho uma constipação.     (Ich habe eine Erkältung)
```

## Beim Arzt und in der Apotheke

| Portugiesisch    | Deutsch        |
| ------------------ | ---------------- |
| o médico            | der Arzt         |
| a farmácia          | die Apotheke     |
| o remédio           | das Medikament   |
| a receita           | das Rezept       |

```
Preciso de um médico.        (Ich brauche einen Arzt)
Onde fica a farmácia?        (Wo ist die Apotheke?)
```

## Ein ganzer Dialog

```
— O que se passa?
— Não me sinto bem. Dói-me a cabeça e tenho febre.
— Vou dar-lhe um remédio. Descanse e beba muita água.
```

(— Was ist los? — Ich fühle mich nicht gut. Mir tut der Kopf weh und ich
habe Fieber. — Ich gebe Ihnen ein Medikament. Ruhen Sie sich aus und trinken
Sie viel Wasser.)

Mit diesem Vokabular kannst du beim Arzt oder in der Apotheke klar
beschreiben, was dir fehlt, und die Antworten verstehen.
