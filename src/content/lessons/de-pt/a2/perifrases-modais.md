Modalverben plus Infinitiv - im Deutschen ('können', 'müssen', 'wollen') kennst du
dieses Muster schon gut. Die gute Nachricht: Im Portugiesischen ist die Wortstellung
sogar einfacher.

## Der Unterschied in der Satzstellung

Im Deutschen bildet das Modalverb mit dem Vollverb eine **Satzklammer**: Das
Modalverb bleibt an Position 2, das Vollverb wandert ganz ans Satzende.

```
Deutsch:       Ich kann  heute Abend leider nicht  kommen.
                  ↑ Position 2                        ↑ Satzende
Portugiesisch: Eu não posso vir hoje à noite.
                       ↑ Modalverb + Infinitiv bleiben zusammen
```

Im Portugiesischen gibt es diese Klammer nicht: Das Modalverb (konjugiert) und der
Infinitiv stehen direkt nebeneinander, egal wie viele weitere Wörter im Satz folgen.
Das macht lange Sätze im Portugiesischen oft übersichtlicher zu bauen als im
Deutschen - du musst dir nicht merken, was noch alles ans Ende muss.

## Die drei wichtigsten Modalverben

| Portugiesisch | Deutsch                | Konjugation (eu / você / nós)  |
| -------------- | ----------------------- | ------------------------------- |
| poder          | können, dürfen          | posso / pode / podemos          |
| dever          | müssen, sollen (Pflicht)| devo / deve / devemos           |
| querer         | wollen, mögen (Wunsch)  | quero / quer / queremos         |

Beispiele:

```
Eu posso ajudar você.       Ich kann dir helfen.
Você deve chegar cedo.      Du musst/solltest früh ankommen.
Nós queremos viajar.        Wir wollen/möchten reisen.
```

## poder vs. dever: Fähigkeit/Erlaubnis vs. Pflicht

Ein häufiger Fehler: 'poder' und 'dever' klingen für Deutschsprachige manchmal
austauschbar, sind es aber nicht. 'Poder' beschreibt, was möglich oder erlaubt ist -
wie 'können/dürfen'. 'Dever' beschreibt eine Verpflichtung oder Empfehlung - näher an
'müssen/sollen'.

```
Você pode entrar.   Du kannst/darfst hereinkommen. (Möglichkeit/Erlaubnis)
Você deve entrar.   Du musst/solltest hereinkommen. (Pflicht/Empfehlung)
```

## Die Verneinung

'Não' steht immer direkt vor dem konjugierten Modalverb - nicht zwischen Modalverb
und Infinitiv, wie man aus dem Deutschen ('kann ... nicht kommen') vielleicht
erwarten würde:

```
Eu não posso vir hoje.   Ich kann heute nicht kommen.
```

Ein Wort, ein fester Platz - das ist mit etwas Übung fast automatisch.
