Präpositionen für Ort und Zeit brauchst du ständig: um Wege zu beschreiben,
Räume zu erklären und Pläne zu organisieren. Auf Portugiesisch funktionieren
sie in vielen Fällen anders als im Deutschen — aber mit ein paar festen
Mustern hast du sie schnell drauf.

## Ortspräpositionen

| Portugiesisch | Deutsch |
| -------------- | ------------ |
| em             | in / an      |
| sobre          | auf / über   |
| sob            | unter        |
| em frente de   | vor / gegenüber von |
| atrás de       | hinter       |
| entre          | zwischen     |
| perto de       | nah bei      |

```
O livro está sobre a mesa.               (Das Buch liegt auf dem Tisch)
O gato está sob a cadeira.               (Die Katze ist unter dem Stuhl)
A farmácia fica entre o banco e o café.  (Die Apotheke liegt zwischen der Bank und dem Café)
```

## Zeitpräpositionen

Für eine genaue Uhrzeit benutzt man **"às"** (Kontraktion aus "a" + "as"):

```
às 8 horas          (um 8 Uhr)
às 10 horas          (um 10 Uhr)
```

Für Monate und Jahre benutzt man **"em"**:

```
em janeiro           (im Januar)
em 2026               (im Jahr 2026)
```

Für die nahe Zukunft benutzt man **"daqui a"**:

```
daqui a três dias      (in drei Tagen)
daqui a uma semana      (in einer Woche)
```

## Ein bekanntes Muster aus dem Deutschen

Portugiesische Kontraktionen wie "às" (a + as), "no" (em + o) oder "da"
(de + a) klingen erst mal exotisch — aber das Deutsche macht genau dasselbe:
"im" ist "in" + "dem", "zum" ist "zu" + "dem", "ins" ist "in" + "das". Der
Unterschied ist nur, dass das Portugiesische diese Verschmelzung viel
konsequenter durchzieht, mit fast jeder Präposition und jedem Artikel.

## Ein ganzer Satz

```
A reunião é às 8 horas, em frente do banco.
(Die Besprechung ist um 8 Uhr, gegenüber der Bank)
```
