Wenn du bereits Erfahrung mit dem deutschen Perfekt hast, wird dich diese Lektion
positiv überraschen: Das Portugiesische macht die Sache einfacher.

## Der große Unterschied zum Deutschen

Im Deutschen bildest du die Alltagsvergangenheit fast immer mit **Hilfsverb + Partizip
II**: haben oder sein + gesprochen/gegessen/gegangen. Das Portugiesische braucht dafür
nur **ein einziges konjugiertes Wort**:

```
Deutsch:       Ich habe gesprochen.   (zwei Wörter: Hilfsverb + Partizip)
Portugiesisch: Eu falei.               (ein Wort, kein Hilfsverb)
```

## Die regelmäßigen Konjugationen

| Pronomen  | falar (-ar)     | comer (-er)     | abrir (-ir)     |
| --------- | --------------- | --------------- | --------------- |
| eu        | falei           | comi            | abri            |
| tu/você   | falaste / falou | comeste / comeu | abriste / abriu |
| ele/ela   | falou           | comeu           | abriu           |
| nós       | falamos         | comemos         | abrimos         |
| eles/elas | falaram         | comeram         | abriram         |

Beachte: Es gibt keine Endung, die extra "haben" oder "sein" markiert - die
Personalendung selbst trägt schon die ganze Bedeutung von Person UND Zeit.

## Vorsicht mit "ter + Partizip"

Portugiesisch besitzt zwar eine Struktur "ter + Partizip" (tenho falado), aber sie
**bedeutet etwas anderes** als das deutsche Perfekt: Statt ein einmaliges,
abgeschlossenes Ereignis zu beschreiben, drückt sie etwas Wiederholtes oder bis jetzt
Andauerndes aus:

```
Eu falei com ela ontem.        (Ich habe gestern mit ihr gesprochen - einmaliges Ereignis)
Eu tenho falado muito com ela. (Ich spreche in letzter Zeit viel mit ihr - wiederholt)
```

Das ist der häufigste Fehler von Deutschsprachigen: Sie übertragen das Muster
"Hilfsverb + Partizip" reflexhaft aus dem Deutschen und landen bei "tenho falado",
wo eigentlich das einfache "falei" gemeint war.

## Unverzichtbare unregelmäßige Verben

| Infinitiv | eu     | ele/ela |
| --------- | ------ | ------- |
| ser/ir    | fui    | foi     |
| estar     | estive | esteve  |
| ter       | tive   | teve    |
| fazer     | fiz    | fez     |

Eine hübsche Besonderheit: "ser" (sein) und "ir" (gehen) teilen sich exakt dieselben
Formen im Pretérito - "fui" kann sowohl "ich war" als auch "ich ging" bedeuten, und
der Kontext klärt immer, welches gemeint ist.
