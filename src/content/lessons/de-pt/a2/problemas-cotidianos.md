Im Alltag geht früher oder später etwas schief: ein Gerät funktioniert nicht,
man verliert etwas oder verläuft sich. In dieser Lektion lernst du das
Vokabular, um solche Situationen auf Portugiesisch zu beschreiben und um
Hilfe zu bitten.

## Etwas verlieren

```
Perdi a carteira.        (Ich habe die Geldbörse verloren)
Perdi as chaves.         (Ich habe die Schlüssel verloren)
Perdi-me.                (Ich habe mich verlaufen)
```

Achtung: **"perder"** (verlieren) und **"perder-se"** (sich verlaufen) sind
zwei verschiedene Verben. Nur das reflexive "-se" macht den Unterschied
zwischen "etwas verlieren" und "sich selbst verlaufen".

## Etwas ist kaputt

| Portugiesisch      | Deutsch                  |
| ------------------- | ------------------------- |
| Está partido        | Es ist kaputt/zerbrochen  |
| Não funciona        | Es funktioniert nicht     |
| Está avariado        | Es ist defekt (Gerät)     |

```
O telemóvel não funciona.       (Das Handy funktioniert nicht)
A torneira está avariada.       (Der Wasserhahn ist defekt)
```

## Um Hilfe bitten

```
Preciso de ajuda.               (Ich brauche Hilfe)
Pode ajudar-me, por favor?       (Können Sie mir bitte helfen?)
Chamei a polícia.               (Ich habe die Polizei gerufen)
```

## Weitere häufige Probleme

| Portugiesisch        | Deutsch               |

| A porta está trancada  | Die Tür ist verschlossen |

## Ein ganzer Dialog

```
— Desculpe, preciso de ajuda. Perdi-me e o telemóvel não funciona.
— Não se preocupe, eu ajudo. Para onde precisa de ir?
```

(— Entschuldigung, ich brauche Hilfe. Ich habe mich verlaufen und das Handy
funktioniert nicht. — Keine Sorge, ich helfe Ihnen. Wohin müssen Sie?)

Mit diesem Vokabular kannst du in schwierigen Alltagssituationen klar
kommunizieren, was passiert ist und was du brauchst.
