Das Prinzip hinter direkten und indirekten Objektpronomen kennst du aus dem
Deutschen genau: Akkusativ (direktes Objekt, "wen/was?") und Dativ (indirektes
Objekt, "wem?"). Portugiesisch macht denselben Unterschied - nur die Position im
Satz ist komplizierter als im Deutschen.

## Direkte Objektpronomen = dein Akkusativ

Wenn du fragst "wen/was sehe ich?", ist die Antwort direktes Objekt - Akkusativ im
Deutschen, 'o/a/os/as' im Portugiesischen:

| Person             | Pronomen |
| ------------------ | -------- |
| ihn (männlich)      | o        |
| sie (weiblich)      | a        |
| sie (männlich Pl.)  | os       |
| sie (weiblich Pl.)  | as       |

```
Eu vejo Maria.  →  Eu vejo-a.     Ich sehe Maria. → Ich sehe sie.
```

## Indirekte Objektpronomen = dein Dativ

Wenn du fragst "wem gebe ich das?", ist die Antwort indirektes Objekt - Dativ im
Deutschen, 'lhe/lhes' im Portugiesischen. Anders als bei 'o/a' unterscheidet 'lhe'
NICHT nach Geschlecht - es bedeutet sowohl "ihm" als auch "ihr":

```
Eu dou o livro a João.   →   Eu dou-lhe o livro.
Ich gebe das Buch an João. → Ich gebe ihm das Buch.
```

## Die Wortstellung: der eigentlich knifflige Teil

Im Deutschen ist die Position von Pronomen relativ locker - "ich sehe sie" klingt
einfach. Im europäischen Portugiesischen wird das Pronomen in einem normalen
Aussagesatz meist **mit Bindestrich ans Verb angehängt** (Ênklise):

```
Eu vejo-a todos os dias.   Ich sehe sie jeden Tag.
Eu dou-lhe o livro.        Ich gebe ihm das Buch.
```

Aber bei Verneinung, Fragewörtern und bestimmten Konjunktionen rutscht das Pronomen
VOR das Verb (Próklise):

```
Eu não a vejo.        Ich sehe sie nicht. (não → Próklise)
Quando lhe dou o livro...   Wenn ich ihm das Buch gebe... (quando → Próklise)
```

Diese Regeln (Próklise vs. Ênklise) sind ein eigenes Kapitel für sich - für A2
reicht es, das Grundmuster "normaler Satz → Bindestrich danach, Verneinung/Fragewort
→ davor" zu erkennen.

## Wenn beide zusammenkommen: lhe + o = lho

Eine hübsche Besonderheit ohne echte deutsche Entsprechung: Kombinierst du
indirektes und direktes Pronomen, verschmelzen sie:

```
Eu dou-lhe o livro.  →  Eu dou-lho.
Ich gebe ihm das Buch. → Ich gebe es ihm.
```

Im Deutschen bleiben "ihm" und "es" getrennt - im Portugiesischen wird daraus ein
einziges verschmolzenes Wort.
