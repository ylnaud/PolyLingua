Sich in einer portugiesischen Stadt zurechtzufinden ist eine der praktischsten
Fähigkeiten, die du lernen kannst. In dieser Lektion lernst du die wichtigsten
Verkehrsmittel und wie du nach dem Weg fragst — und ihn verstehst, wenn dir
jemand antwortet.

## Verkehrsmittel

| Portugiesisch | Deutsch |
| -------------- | ------------ |
| o comboio      | der Zug      |
| o autocarro    | der Bus      |
| o metro        | die U-Bahn   |
| o táxi         | das Taxi     |
| o carro        | das Auto     |
| a bicicleta    | das Fahrrad  |

Wichtig: Im europäischen Portugiesisch heißt der Bus **"autocarro"**, nicht
"ônibus" (Brasilien), und der Zug heißt **"comboio"**, nicht "trem". Diese
Lektion folgt durchgehend dem europäischen Portugiesisch.

```
Vou de comboio para o Porto.     (Ich fahre mit dem Zug nach Porto)
Apanho o autocarro às 8 horas.   (Ich nehme den Bus um 8 Uhr)
```

## Orte des öffentlichen Verkehrs

| Portugiesisch      | Deutsch          |
| ------------------- | ---------------- |
| a estação           | der Bahnhof      |
| a paragem           | die Haltestelle  |
| o aeroporto         | der Flughafen    |

## Nach dem Weg fragen

Die Standardfrage lautet **"Onde fica...?"** (Wo befindet sich...?):

```
Onde fica a estação de comboios?   (Wo ist der Bahnhof?)
Onde fica a paragem mais próxima?  (Wo ist die nächste Haltestelle?)
```

## Richtungsangaben verstehen

| Portugiesisch      | Deutsch          |
| ------------------- | ---------------- |
| à esquerda          | links            |
| à direita           | rechts           |
| sempre em frente    | immer geradeaus  |
| vire...             | biege ab...      |
| siga...             | folge / geh...   |

```
Vire à esquerda na primeira rua.        (Biege links in der ersten Straße ab)
Siga sempre em frente até ao semáforo.  (Geh immer geradeaus bis zur Ampel)
```

## Ein ganzer Dialog

```
— Onde fica a estação?
— Vire à direita e siga sempre em frente. Fica perto do banco.
```

(— Wo ist der Bahnhof? — Biege rechts ab und geh immer geradeaus.
Er liegt in der Nähe der Bank.)

Mit diesem Vokabular kannst du dich in fast jeder portugiesischen Stadt
zurechtfinden, egal ob du mit dem Zug ankommst oder jemanden nach dem Weg
fragen musst.
