Diese Lektion ist ein Geschenk: Du brauchst keine neue Formenwelt zu lernen,
sondern kombinierst zwei Dinge, die du schon kennst.

## Die Bildung: Infinitiv-Stamm + Imperfeito-ähnliche Endungen

```
Condicional = Infinitiv-Stamm (wie beim Futuro Simples) + Endungen (-ia, -ias, -ia, -íamos, -íeis, -iam)
```

Da du die unregelmäßigen Futuro-Stämme aus Lektion 3 schon kennst (far-,
dir-, trar-...), musst du hier nur noch die neuen, dem Imperfeito ähnlichen
Endungen anhängen. Nicht zufällig heißt diese Zeit offiziell **"Futuro do
Pretérito"**: eine Zukunft, betrachtet aus der Vergangenheit heraus.

| Person | Endung | fazer (Stamm: far-) |
| ------ | ------ | -------------------- |
| eu     | -ia    | faria                |
| tu     | -ias   | farias               |
| ele/ela | -ia   | faria                |
| nós    | -íamos | faríamos             |
| eles/elas | -iam | fariam               |

**Achtung, Verwechslungsgefahr:** "farei" (Futuro Simples, Endung -ei)
bedeutet "ich werde machen". "faria" (Condicional, Endung -ia) bedeutet "ich
würde machen". Der Unterschied liegt nur in der Endung - aber er ist
entscheidend.

## Drei Hauptfunktionen

**1. Höflichkeit** - genau wie im Deutschen "ich hätte gern" statt "ich
will":

```
Gostaria de um café, por favor.
```

**2. Ratschlag** mit "no teu/seu lugar" (an deiner/Ihrer Stelle):

```
No teu lugar, eu sairia.
```

**3. Hypothese** in Se-Sätzen vom Typ 2 (Gegenwart/Zukunft, wenig
wahrscheinlich):

```
Se + Imperfeito do Conjuntivo,   Condicional
Se eu tivesse tempo,              viajaria.
```

## Vergleich mit dem deutschen Konjunktiv II

Das Condicional entspricht ziemlich genau dem deutschen Konjunktiv II
("würde" + Infinitiv, oder käme/hätte/wäre):

```
Deutsch:        Wenn ich Zeit hätte, würde ich reisen.
Portugiesisch:  Se eu tivesse tempo, viajaria.
```

Die Struktur ist parallel: Der Se-Satz (Bedingung) steht im Imperfeito do
Conjuntivo, genau wie der deutsche wenn-Satz im Konjunktiv II (hätte) steht
- nur dass das Portugiesische diesen Kontrast grammatikalisch klar
kennzeichnet, mit zwei eigenständigen, formal verwandten Verbformen
(Imperfeito do Conjuntivo im Nebensatz, Condicional im Hauptsatz).
