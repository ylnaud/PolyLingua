Diese Lektion enthält vielleicht die tückischste Falle für Deutschsprachige
im gesamten Portugiesisch-Kurs: eine Zeitform, die es im Deutschen einfach
nicht gibt, und die dein Sprachgefühl deshalb systematisch überlistet.

## Die deutsche Gewohnheit, die dich in die Irre führt

Im Deutschen benutzt du bei zeitlichen Nebensätzen mit Zukunftsbezug ganz
selbstverständlich das Präsens:

```
Wenn ich ANKOMME, rufe ich dich an.   (Präsens, obwohl Zukunft gemeint ist)
```

Portugiesisch erlaubt das nicht. Sobald "quando" (oder "assim que") sich auf
ein zukünftiges Ereignis bezieht, brauchst du eine eigene grammatische Form:
das **Futuro do Conjuntivo**.

```
Quando eu chegar, ligo-te.
(NICHT: Quando eu chego, ligo-te.)
```

## Die Bildung des Futuro do Conjuntivo

Der Ausgangspunkt ist überraschend: die 3. Person Plural des **Pretérito
Perfeito**. Du schneidest das "-am" ab und hängst die Endungen -, -es, -,
-mos, -des, -em an:

| Verb | Pretérito Perfeito (eles) | Futuro do Conjuntivo (eu) |
| ---- | -------------------------- | -------------------------- |
| chegar | chegaram | chegar |
| comer  | comeram  | comer  |
| partir | partiram | partir |

Bei regelmäßigen Verben sieht die "eu"-Form dadurch zufällig genauso aus wie
der Infinitiv – aber Vorsicht, das ist nur eine oberflächliche Ähnlichkeit,
keine Regel. Bei unregelmäßigen Verben wird der Unterschied deutlich:

```
ter    → tiveram → tiver, tiveres, tiver, tivermos, tiverdes, tiverem
fazer  → fizeram → fizer, fizeres, fizer, fizermos, fizerdes, fizerem
ser/ir → foram   → for, fores, for, formos, fordes, forem
```

## Drei Konjunktionen im Vergleich

| Konjunktion | Bedeutung | Bei Zukunftsbezug |
| ----------- | --------- | ------------------ |
| quando      | wenn / als | + Futuro do Conjuntivo |
| assim que   | sobald    | + Futuro do Conjuntivo |
| enquanto    | während   | + Indicativo (Gleichzeitigkeit, keine Zukunftsform nötig) |

```
Assim que chegar, ligo-te.        (sobald, Zukunft)
Enquanto eu estudo, ele dorme.    (während, Gleichzeitigkeit, ganz normaler Indicativo)
```

## Eine kurze Randbemerkung: "antes que"

Achte darauf, im europäischen Portugiesisch **"antes que"** (nicht "antes de
que") zu sagen, wenn Haupt- und Nebensatz unterschiedliche Subjekte haben -
gefolgt vom Subjuntivo:

```
Fala comigo antes que eu saia.   (bevor ich gehe, anderes Subjekt)
Fala comigo antes de saíres.     (bevor du gehst, gleiches Subjekt → Infinitiv)
```

Die Faustregel für diese ganze Lektion: Sobald eine zeitliche Konjunktion
auf ein zukünftiges Ereignis zeigt, ist dein deutsches Präsens-Reflex genau
das falsche Signal - such stattdessen das Futuro do Conjuntivo.
