Im Deutschen benutzt du meist nur "seit" für andauernde Zeit und "für"/"lang" für
abgeschlossene Zeitspannen. Das Portugiesische unterscheidet feiner — mit drei
Wörtern statt zwei.

## Die drei Kästchen

```
há + Dauer         →  Handlung dauert bis JETZT an (wie "seit" + Zeitspanne, Presente)
desde + Zeitpunkt   →  nennt den STARTPUNKT (wie "seit" + Datum/Ereignis)
durante + Dauer     →  abgeschlossene Zeitspanne, oft in der Vergangenheit (wie "... lang")
```

## há: Dauer bis jetzt

"há" + Zeitspanne beschreibt, WIE LANGE eine noch andauernde Handlung schon läuft. Das
Verb steht im Presente, genau wie im Deutschen bei "seit":

```
Moro em Lisboa há três anos.
(Ich wohne seit drei Jahren in Lissabon. — wohne noch immer dort)

Estou à espera há vinte minutos.
(Ich warte seit zwanzig Minuten.)
```

## desde: der Startpunkt

"desde" nennt nicht die Dauer, sondern den konkreten **Zeitpunkt**, an dem etwas
begonnen hat — ein Datum, ein Ereignis, ein "seit dem Moment, als...":

```
O elevador não funciona desde ontem.
(Der Aufzug funktioniert seit gestern nicht.)

Estou insatisfeito desde que cheguei.
(Ich bin unzufrieden, seit ich angekommen bin.)
```

"há" und "desde" lassen sich oft kombinieren, wenn man beides ausdrücken will: "Moro
aqui desde 2020, ou seja, há seis anos."

## durante: abgeschlossene Dauer

"durante" beschreibt eine Zeitspanne unabhängig davon, ob sie bis jetzt andauert — oft
bei einer Handlung, die schon **vorbei** ist:

```
Fiquei sem água quente durante toda a noite.
(Ich war die ganze Nacht ohne warmes Wasser. — jetzt vorbei)

Morei em Lisboa durante três anos.
(Ich habe drei Jahre lang in Lissabon gewohnt. — nicht mehr aktuell)
```

## Achtung: há kann auch "vor" bedeuten

Ohne Dauerbezug, bei einer klar abgeschlossenen Handlung, entspricht "há" dem
deutschen "vor":

```
Cheguei há duas horas.
(Ich bin vor zwei Stunden angekommen.)
```

## Kurz zusammengefasst

```
há + Dauer        →  seit + Zeitspanne, Handlung dauert an (Presente)
desde + Zeitpunkt  →  seit + Datum/Ereignis, Startpunkt
durante + Dauer     →  ... lang, abgeschlossene Zeitspanne
há + Zeitpunkt      →  vor (bei abgeschlossener Handlung)
```

Sobald du dir diese drei Kästchen einprägst, klingen deine Zeitangaben im
Portugiesischen präziser als eine reine Übersetzung von "seit" oder "für" es je
könnte.
