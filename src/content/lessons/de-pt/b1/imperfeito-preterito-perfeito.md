Du kennst das Pretérito Perfeito Simples bereits (eu falei, comi, abri). Jetzt
lernst du seinen Gegenspieler kennen: das **Pretérito Imperfeito**. Und hier
liegt eine Falle für Deutschsprachige, die du unbedingt kennen solltest.

## Der Denkfehler, den fast jeder Deutschsprachige macht

Im Deutschen ist die Wahl zwischen Präteritum ("ich sprach") und Perfekt
("ich habe gesprochen") fast egal – eine Stilfrage, keine Bedeutungsfrage:
schriftlich bevorzugt man das Präteritum, mündlich das Perfekt, aber beide
Sätze sagen dasselbe.

Im Portugiesischen ist das **komplett anders**. Imperfeito und Perfeito
transportieren unterschiedliche Bedeutungen:

```
Eu falava com ela.   (Imperfeito) → ich sprach [gewöhnlich/gerade] mit ihr
Eu falei com ela.    (Perfeito)   → ich sprach [einmal, abgeschlossen] mit ihr
```

Wenn du das eine mit dem anderen verwechselst, sagst du buchstäblich etwas
anderes, als du meinst – kein Stilfehler, sondern ein Bedeutungsfehler.

## Die Grundregel: Gewohnheit vs. Einzelereignis

| Signalwort | Bedeutung | Zeit |
| ---------- | --------- | ---- |
| todos os dias, sempre, normalmente | Gewohnheit, Wiederholung | **Imperfeito** |
| ontem, uma vez, de repente | einmaliges, abgeschlossenes Ereignis | **Perfeito** |

```
Quando era criança, brincava no parque todos os dias.  (Gewohnheit)
Ontem brinquei no parque com o meu irmão.               (einmal, gestern)
```

## Die regelmäßigen Imperfeito-Endungen

| Pronomen | falar (-ar) | comer (-er) | abrir (-ir) |
| -------- | ----------- | ----------- | ----------- |
| eu       | falava      | comia       | abria       |
| tu       | falavas     | comias      | abrias      |
| ele/ela  | falava      | comia       | abria       |
| nós      | falávamos   | comíamos    | abríamos    |
| eles/elas | falavam    | comiam      | abriam      |

Nur drei Verben sind im Imperfeito unregelmäßig: **ser** (era, eras, era,
éramos, éreis, eram), **ter** (tinha...) und **pôr** (punha...).

## Das klassische Muster: Hintergrund + Unterbrechung

Der häufigste und nützlichste Anwendungsfall kombiniert beide Zeiten in
einem Satz: Das Imperfeito beschreibt eine Handlung, die gerade im Gange
war (Hintergrund), das Perfeito ein plötzliches Ereignis, das sie
unterbricht:

```
Eu estava a dormir      quando      o telefone tocou.
(Hintergrund, Imperfeito)            (Unterbrechung, Perfeito)
```

Präge dir dieses Muster gut ein – es ist eines der nützlichsten im ganzen
Portugiesischen, weil es fast jede erzählte Geschichte strukturiert.
