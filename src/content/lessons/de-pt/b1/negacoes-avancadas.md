Im Deutschen gilt: zwei Verneinungen ergeben eine Bejahung ("Ich sehe nicht niemanden"
klingt falsch oder ironisch). Im Portugiesischen ist es umgekehrt — die doppelte
Verneinung ist die **normale, korrekte** Form.

## Die Grundregel: Position entscheidet

```
Verneinungswort NACH dem Verb  →  não + Verb + Verneinungswort  (Pflicht: não)
Verneinungswort VOR dem Verb   →  Verneinungswort + Verb          (kein não)
```

Beispiele:

```
Não vejo ninguém.        (Ich sehe niemanden.)
Ninguém vem.             (Niemand kommt.)

Não como nada.           (Ich esse nichts.)
Nada aconteceu.          (Nichts ist passiert.)
```

Für dich als Deutschsprachige/n ist das gewöhnungsbedürftig: "Não vejo ninguém" hat
wörtlich zwei Verneinungen ("nicht sehe niemand"), ist aber grammatisch Pflicht — kein
Stilfehler.

## Die wichtigsten Verneinungswörter

| Portugiesisch    | Deutsch          | Beispiel                                  |
| ------------------- | ------------------- | ---------------------------------------------- |
| nunca              | nie, niemals        | Nunca tive este problema.                      |
| nada                | nichts               | Não há nada no minibar.                        |
| ninguém             | niemand              | Ninguém respondeu ao telefone.                 |
| nenhum / nenhuma    | kein / keine         | Não há nenhuma toalha limpa.                   |
| tampouco            | auch nicht           | O ar condicionado não funciona, e a luz tampouco. |

## nenhum/nenhuma: wie ein Adjektiv

Anders als "ninguém" oder "nada" (unveränderlich) passt sich **nenhum/nenhuma** wie
"kein/keine" im Deutschen an Genus und Numerus des Substantivs an:

```
nenhum quarto      (kein Zimmer, maskulin)
nenhuma toalha      (kein Handtuch, feminin)
nenhuns problemas    (keine Probleme, seltener, meist "nenhum problema")
```

## tampouco: das "auch nicht"

"tampouco" hängt eine zweite Verneinung an eine schon negative Aussage an — genau wie
das deutsche "auch nicht":

```
O quarto não tem vista, e a casa de banho tampouco.
(Das Zimmer hat keinen Blick, und das Badezimmer auch nicht.)
```

Alternativ hörst du auch "nem... também": "A casa de banho também não tem janela."

## Kurz zusammengefasst

```
Verneinungswort nach dem Verb  →  não + Verb + nunca/nada/ninguém/nenhum
Verneinungswort vor dem Verb   →  Verneinungswort + Verb, kein não
nenhum/nenhuma                 →  passt sich an Genus/Numerus an, wie "kein"
tampouco                       →  hängt eine zweite Verneinung an ("auch nicht")
```

Sobald du diese Position-vor-oder-nach-dem-Verb-Regel verinnerlicht hast, klingen deine
portugiesischen Verneinungen sofort natürlich — auch wenn sich "doppelt verneint" für
dein deutsches Sprachgefühl erst einmal falsch anfühlt.
