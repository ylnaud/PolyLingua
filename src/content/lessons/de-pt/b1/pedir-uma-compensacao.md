Wenn du eine Entschädigung verlangst, drückst du meist eine **Erwartung** oder eine
**Hoffnung** aus, keine feste Tatsache. Genau dafür braucht das Portugiesische den
conjuntivo.

## Die Grundregel

```
Verb der Erwartung/Hoffnung/Wertung  +  que  +  anderes Subjekt  +  conjuntivo
```

Typische Auslöser: **espero que** (ich hoffe, dass), **quero que** (ich möchte, dass),
**gostaria que** (ich würde gerne, dass), **é justo que** (es ist richtig, dass).

```
Espero que o hotel me reembolse a noite.
(Ich erwarte, dass das Hotel mir die Nacht erstattet.)

Quero que resolvam este problema hoje.
(Ich möchte, dass Sie dieses Problem heute lösen.)

É justo que eu receba uma compensação.
(Es ist gerecht, dass ich eine Entschädigung erhalte.)
```

## Presente do conjuntivo: schnelle Übersicht

| Person   | -ar (reembolsar) | -er (receber) | -ir (resolver → dieselbe Logik) |
| ---------- | -------------------- | ----------------- | ------------------------------------ |
| eu       | reembols**e**        | receb**a**         | resolv**a**                          |
| tu       | reembols**es**       | receb**as**        | resolv**as**                         |
| ele/ela  | reembols**e**        | receb**a**         | resolv**a**                          |
| nós      | reembols**emos**     | receb**amos**      | resolv**amos**                       |
| vós      | reembols**eis**      | receb**ais**       | resolv**ais**                        |
| eles     | reembols**em**       | receb**am**        | resolv**am**                         |

## Wenn das Subjekt gleich bleibt: der Infinitiv

Haben Haupt- und Nebensatz dasselbe Subjekt, vermeidest du "que + conjuntivo" und
benutzt stattdessen den Infinitiv:

```
Espero receber um reembolso.
(Ich hoffe, eine Rückerstattung zu erhalten. — nicht: Espero que eu receba...)
```

## Pretérito perfeito do conjuntivo: wenn die Handlung schon abgeschlossen sein soll

Manchmal bezieht sich deine Erwartung auf etwas, das **vorher** schon passiert sein
soll. Dafür brauchst du den pretérito perfeito do conjuntivo: ter im presente do
conjuntivo + Partizip.

```
Espero que o hotel já tenha recebido a minha reclamação.
(Ich hoffe, dass das Hotel meine Beschwerde schon erhalten hat.)
```

## Kurz zusammengefasst

```
espero que / quero que / é justo que  +  presente do conjuntivo
   (Erwartung bezieht sich auf jetzt/Zukunft)

espero que  +  pretérito perfeito do conjuntivo (tenha + Partizip)
   (Erwartung bezieht sich auf etwas, das schon passiert sein soll)

Gleiches Subjekt  →  Infinitiv statt que + conjuntivo
```

Mit diesen Bausteinen kannst du eine Beschwerde formulieren, die höflich, aber
bestimmt klingt — genau der richtige Ton, um eine Entschädigung zu verlangen.
