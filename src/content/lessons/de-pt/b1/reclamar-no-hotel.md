Du kennst schon den Konjunktiv II im Deutschen als höfliche Form ("Wenn Sie könnten...").
Im europäischen Portugiesisch gibt es dafür den **pretérito imperfeito do conjuntivo** —
und du brauchst ihn genau dann, wenn du höflich eine Hypothese aufstellst, zum Beispiel
bei einer Beschwerde im Hotel.

## Bildung: das Erkennungszeichen -sse-

Der pretérito imperfeito do conjuntivo wird regelmäßig aus der 3. Person Plural des
Pretérito Perfeito Simples gebildet (Endung -ram entfernen, -sse-Endungen anhängen):

| Person       | -ar (falar) | -er (comer) | -ir (partir) |
| -------------- | -------------- | -------------- | -------------- |
| eu             | fal**asse**    | com**esse**    | part**isse**   |
| tu             | fal**asses**   | com**esses**   | part**isses**  |
| ele/ela        | fal**asse**    | com**esse**    | part**isse**   |
| nós            | fal**ássemos** | com**êssemos**  | part**íssemos** |
| vós            | fal**ásseis**  | com**êsseis**   | part**ísseis**  |
| eles/elas      | fal**assem**   | com**essem**    | part**issem**   |

## Die wichtigsten unregelmäßigen Verben

| Verb    | eu / ele    |
| --------- | -------------- |
| ser     | fosse         |
| estar   | estivesse     |
| ter     | tivesse       |
| haver   | houvesse      |
| poder   | pudesse       |
| fazer   | fizesse       |

## Das höfliche Hypothesen-Muster

Das Standardmuster für höfliche Hypothesen ist:

```
Se + pretérito imperfeito do conjuntivo,   condicional (oder Imperfeito do Indicativo)
```

Beispiele aus einer Hotelbeschwerde:

```
Se houvesse um problema, eu dizia na receção.
(Wenn es ein Problem gäbe, würde ich es an der Rezeption sagen.)

Se o chuveiro funcionasse, eu ficaria mais satisfeito.
(Wenn die Dusche funktionieren würde, wäre ich zufriedener.)

Se o quarto fosse mais silencioso, eu dormia melhor.
(Wenn das Zimmer ruhiger wäre, würde ich besser schlafen.)
```

**Wichtig für das europäische Portugiesisch:** In der gesprochenen Alltagssprache
ersetzt oft der Imperfeito do Indicativo (dizia, dormia) den Condicional (diria,
dormiria) im Hauptsatz — beide Formen sind verbreitet.

## Höflichkeit ohne vollständigen Bedingungssatz

Oft reicht schon "Se pudesse..." allein, um eine Bitte höflich einzuleiten, bevor die
eigentliche Beschwerde folgt:

```
Se pudesse, mudava de quarto.
(Wenn ich könnte, würde ich das Zimmer wechseln.)
```

## Nützliche Sätze für den Hotelalltag

| Portugiesisch                                            | Deutsch                                                          |
| ------------------------------------------------------------ | ---------------------------------------------------------------------- |
| Se o wifi funcionasse, eu trabalhava daqui.               | Wenn das WLAN funktionieren würde, würde ich von hier aus arbeiten.    |
| Se tivessem um quarto mais tranquilo, eu gostava.         | Wenn Sie ein ruhigeres Zimmer hätten, würde ich es gerne nehmen.       |

## Kurz zusammengefasst

```
se + pretérito imperfeito do conjuntivo  +  condicional / imperfeito do indicativo
     (fosse, tivesse, pudesse, funcionasse...)   (ficaria/ficava, diria/dizia...)
```

Diese Struktur ist dein Werkzeug für höfliche, hypothetische Beschwerden — sie klingt
weniger direkt als eine einfache Feststellung im Indikativ und wird in
Servicesituationen sehr geschätzt.
