Nachdem eine Beschwerde bearbeitet wurde, gibt es im Portugiesischen mehrere Wege, das
zu sagen — und die Logik dahinter ist für dich als Deutschsprachige/n überraschend
leicht zu verstehen, weil deine eigene Sprache eine ganz ähnliche Unterscheidung kennt.

## Vorgang vs. Zustand: fast dieselbe Logik wie im Deutschen

| Deutsch                       | Portugiesisch                        | Bedeutung                                    |
| -------------------------------- | ----------------------------------------- | -------------------------------------------------- |
| Das Problem **wurde** gelöst.    | O problema **foi** resolvido.             | Vorgang: eine Handlung ist passiert (Passiv mit ser). |
| Das Problem **ist** gelöst.      | O problema **está** resolvido.            | Zustand: so ist die Lage jetzt (mit estar).         |

Im Deutschen unterscheidest du zwischen dem Vorgangspassiv mit "werden" und dem
Zustandspassiv mit "sein". Im Portugiesischen läuft eine sehr ähnliche Unterscheidung
über zwei verschiedene Hilfsverben:

- **ser + Partizip** = Passiv, das eine Handlung/einen Vorgang beschreibt, oft mit
  einem Handelnden ("pelo técnico") → wie das deutsche werden-Passiv.
- **estar + Partizip** = Zustandsbeschreibung, fast wie ein Adjektiv → wie das
  deutsche sein-Passiv.

## Eine dritte Option: die einfache Handlung ohne Passiv

Neben dem Passiv gibt es auch die einfache, aktive Handlung im **pretérito perfeito
simples** — die direkteste Art, ein abgeschlossenes Ereignis zu benennen:

```
O técnico resolveu o problema.
(Der Techniker hat das Problem gelöst. — aktiv, Subjekt = o técnico)
```

## Weitere Beispiele aus dem Hotelalltag

```
O quarto foi limpo esta manhã.
(Das Zimmer wurde heute Morgen geputzt.) — Vorgang, mit Zeitangabe.

O quarto está limpo.
(Das Zimmer ist sauber.) — Zustand, das Ergebnis zählt.

A reclamação foi aceite pela direção.
(Die Beschwerde wurde von der Geschäftsführung angenommen.) — Vorgang mit Handelndem.

A reclamação está aceite.
(Die Beschwerde ist akzeptiert.) — Zustand, kein Handelnder genannt.
```

## Ein Handelnder passt eher zum Vorgang

Wenn du sagen willst, WER etwas getan hat, benutzt du fast immer die Vorgangsform mit
"por" (von):

```
O problema foi resolvido pelo diretor.
(Das Problem wurde vom Direktor gelöst.)
```

Beim Zustand ("está resolvido") würde ein Handelnder seltsam klingen, weil der Fokus
nicht auf der Handlung, sondern auf dem Ergebnis liegt.

## Kurz zusammengefasst

```
foi + Partizip  (+ por + Handelnder)   =  Vorgang    (wurde gemacht)
está + Partizip                         =  Zustand    (ist gemacht/fertig)
resolveu (aktiv, pretérito perfeito simples)  =  direkte Handlung mit Subjekt
```

Sobald du bei einer Beschwerde das Ergebnis bestätigen willst — "alles ist jetzt in
Ordnung" —, greifst du zur Zustandsform mit "estar". Willst du beschreiben, WIE und
WANN es gelöst wurde, brauchst du die Vorgangsform mit "ser" oder die einfache aktive
Vergangenheit.
