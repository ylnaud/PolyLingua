In dieser Lektion geht es weniger um neue Grammatik als um praktischen
Wortschatz, den du im Berufsalltag ständig brauchst - vom Bewerbungsgespräch
bis zum Büroalltag.

## Berufe nennen: kein Artikel nötig

Eine seltene Übereinstimmung zwischen Deutsch und Portugiesisch: Nach "ser"
steht bei Berufsbezeichnungen **kein unbestimmter Artikel**:

```
Sou professor.       (Ich bin Lehrer.)
Ela é engenheira.    (Sie ist Ingenieurin.)
```

Sobald aber ein Adjektiv dazukommt, brauchst du den Artikel doch:

```
É um bom professor.   (Er ist ein guter Lehrer.)
```

## Rund ums Büro

| Portugiesisch | Deutsch |
| -------------- | ------- |
| o colega / a colega | der/die Kollege/Kollegin |
| o chefe / a chefe   | der/die Chef(in)          |
| o escritório         | das Büro                  |
| a reunião            | die Besprechung           |
| o salário            | das Gehalt                |

## Bewerbung und Anstellung

| Portugiesisch | Deutsch |
| -------------- | ------- |
| candidatar-se (para um cargo) | sich bewerben (auf eine Stelle) |
| uma entrevista de emprego     | ein Bewerbungsgespräch |
| contratar                     | einstellen |
| despedir                      | entlassen, kündigen |
| estar desempregado            | arbeitslos sein |
| ter um emprego                | eine Stelle haben |

**Verwechslungsgefahr:** "contratar" und "despedir" sind genaue
Gegensätze - merk sie dir am besten als Paar, damit du sie nicht
durcheinanderbringst.

## Ein typischer Satz zum Üben

```
Tenho uma entrevista de emprego amanhã. Espero que me contratem!
(Ich habe morgen ein Bewerbungsgespräch. Ich hoffe, sie stellen mich ein!)
```

Übe, ein paar Sätze über deinen eigenen (echten oder erträumten) Beruf zu
bilden - das ist der schnellste Weg, diesen Wortschatz wirklich zu
verinnerlichen.
