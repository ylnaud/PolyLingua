Kontrast und Konzession auszudrücken gehört zu den Werkzeugen, die einen Text auf
B2-Niveau heben. Das Portugiesische unterscheidet dabei — ähnlich wie das Deutsche
zwischen "obwohl" und "trotzdem" — klar zwischen Nebensatz-Konnektoren und
Satzverbindern.

## no entanto / contudo: der Satzverbinder

**no entanto** und **contudo** verbinden zwei vollständige, eigenständige Sätze —
genau wie das deutsche "jedoch":

```
Estudei muito. No entanto, não passei no exame.
(Ich habe viel gelernt. Jedoch habe ich die Prüfung nicht bestanden.)
```

Wichtig: Anders als im Deutschen ("TROTZDEM ging er nicht") verlangt das Portugiesische
nach diesem Konnektor **keine Inversion**. Die Wortstellung bleibt normal
Subjekt-Verb.

## apesar de: vor Infinitiv oder Substantiv

**apesar de** funktioniert wie eine Präposition und steht vor einem Infinitiv oder
einem Substantiv, niemals vor einem konjugierten Verb:

```
Apesar de estar cansado, vou trabalhar.       (+ Infinitiv)
Apesar do cansaço, vou trabalhar.              (+ Substantiv, mit Artikelverschmelzung do)
```

## embora: vor konjugiertem Verb, immer mit Subjuntivo

Willst du einen vollständigen Nebensatz mit einem konjugierten Verb bilden, brauchst
du **embora** — und das verlangt zwingend den Subjuntivo, selbst wenn der Inhalt eine
reale, unbestreitbare Tatsache ist:

```
Embora esteja a chover, vou sair.
(Obwohl es regnet, gehe ich raus.)
```

Das ist eine Eigenheit, die das Deutsche nicht kennt: "obwohl" verlangt im Deutschen
keinen speziellen Modus, nur Verbendstellung. Das Portugiesische koppelt "embora"
dagegen fest an den Subjuntivo — unabhängig davon, wie sicher die Tatsache ist.

## Übersicht

| Portugiesisch | Deutsch                          | Was folgt danach                |
| --------------- | ---------------------------------- | ---------------------------------- |
| no entanto / contudo | jedoch (Satzverbinder)        | vollständiger Satz, keine Inversion |
| apesar de        | trotz / obwohl                    | Infinitiv oder Substantiv           |
| embora            | obwohl (Nebensatz)                | konjugiertes Verb im Subjuntivo     |
| mas                | aber (einfach)                    | vollständiger Satz                  |

Wer diese vier Bausteine sauber trennt, klingt auf Portugiesisch deutlich
differenzierter als mit dem alltäglichen "mas" allein — genau der Sprung, den du auf
B2-Niveau machen willst.
