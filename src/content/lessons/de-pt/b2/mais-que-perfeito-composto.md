Diese Zeitform ist eine Verschnaufpause: Das portugiesische Pretérito mais-que-perfeito
composto funktioniert fast identisch zum deutschen Plusquamperfekt, das du längst
beherrschst.

## Die Bildung

```
ter (Imperfeito)  +  particípio passado
```

| Person             | ter (Imperfeito) | + particípio  |
| -------------------- | ------------------ | -------------- |
| eu                    | tinha               | falado         |
| tu                     | tinhas              | falado         |
| ele/ela/você           | tinha               | falado         |
| nós                    | tínhamos            | falado         |
| eles/elas/vocês        | tinham              | falado         |

Vergleiche mit dem Deutschen:

```
Deutsch:        ich  hatte     gesprochen
Portugiesisch:   eu   tinha     falado
```

Dieselbe Struktur: Hilfsverb in der Vergangenheit + Partizip. Anders als bei "ser" im
Passiv bleibt das Partizip hier **unveränderlich** — keine Kongruenz mit dem
Subjekt.

## Wozu braucht man die Vorvergangenheit?

Wie im Deutschen markiert diese Zeitform, dass eine Handlung bereits VOR einem
anderen Vergangenheitspunkt abgeschlossen war:

```
Quando cheguei, ela já tinha saído.
(Als ich ankam, war sie schon gegangen.)
```

Zwei Vergangenheitshandlungen, klar geordnet:
1. Sie ging weg → Mais-que-perfeito composto (tinha saído) — die frühere Handlung
2. Ich kam an → Pretérito perfeito simples (cheguei) — die spätere Handlung

## Praktisches Muster

```
Quando + Pretérito perfeito simples,  já  +  Mais-que-perfeito composto

Quando cheguei,  já  tínhamos jantado.
(Als ich ankam,  hatten wir  schon zu Abend gegessen.)
```

## Die gesprochene Alternative: das synthetische Mais-que-perfeito

Nur zur Orientierung: Portugiesisch besitzt zusätzlich eine einwortige,
literarisch-formelle Form (fizera, falara), die in der gesprochenen Sprache praktisch
verschwunden ist. Auf B2-Niveau reicht die zusammengesetzte Form mit ter völlig aus —
sie ist die im Alltag und in fast jedem geschriebenen Text verwendete Standardform,
genau wie das deutsche "hatte gesprochen" gegenüber selten gewordenen literarischen
Alternativen.
