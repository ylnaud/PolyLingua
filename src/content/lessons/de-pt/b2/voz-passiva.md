Du beherrschst das deutsche werden-Passiv längst: "Das Haus wird gebaut", "der Brief
wurde geschrieben". Das Portugiesische braucht dafür kein eigenes Passiv-Verb — es
verwendet einfach **ser**, dasselbe ser, das du schon aus "sou professor" kennst.

## Die Formel

```
ser (konjugiert)  +  particípio passado (kongruent mit dem Subjekt)
```

| Zeit               | Beispiel                                              |
| ------------------- | ------------------------------------------------------ |
| Presente             | A casa é construída. (Das Haus wird gebaut.)          |
| Pretérito perfeito   | A casa foi construída. (Das Haus wurde gebaut.)        |
| Futuro               | A casa será construída. (Das Haus wird gebaut werden.) |

Funktional entspricht das exakt deiner deutschen werden-Konstruktion. Der Unterschied
ist rein formal: Statt eines eigenen Passiv-Hilfsverbs recycelt Portugiesisch ser.

## Ativa → Passiva umformen

1. Das direkte Objekt im Aktivsatz wird zum Subjekt im Passivsatz.
2. Das Verb wird zu "ser + particípio passado".
3. Der Handelnde (falls genannt) wird mit "por" eingeführt — wie das deutsche "von".

```
Ativa:    Camões    escreveu       este livro.
Passiva:  Este livro    foi escrito    por Camões.
```

## Die Kongruenz: der eigentliche Unterschied zum Deutschen

Im deutschen Passiv bleibt das Partizip immer unverändert: "wird gebaut", "wird
gebaut" — egal ob Subjekt maskulin, feminin, Singular oder Plural ist. Im
Portugiesischen verhält sich das Partizip dagegen wie ein Adjektiv und **kongruiert
immer** mit dem Subjekt, weil das Hilfsverb ja ser ist:

```
O livro é lido.          (maskulin Singular)
A carta é lida.          (feminin Singular)
Os livros são lidos.     (maskulin Plural)
As cartas são lidas.     (feminin Plural)
```

## ser vs. estar + particípio: Vorgang vs. Zustand

Ein Punkt, der Deutschsprachigen oft entgeht: Portugiesisch unterscheidet zwischen dem
**Vorgang** (ser + particípio) und dem **Zustand als Ergebnis** (estar + particípio):

```
A porta é fechada às 22h.   (Der Vorgang: Die Tür wird um 22 Uhr geschlossen.)
A porta está fechada.       (Der Zustand: Die Tür ist [gerade] geschlossen.)
```

Das Deutsche drückt beides oft gleich aus ("die Tür ist geschlossen" kann beides
meinen), das Portugiesische zwingt dich zur Entscheidung.

## Wann benutzt man die Voz passiva?

Genau wie im Deutschen: bei Nachrichten, Prozessbeschreibungen, Anleitungen, oder wenn
der Handelnde unbekannt oder unwichtig ist. "A ponte foi construída em 1930" klingt in
einem informativen Kontext deutlich natürlicher, als einen unnötigen Aktiv-Satz zu
erzwingen.
