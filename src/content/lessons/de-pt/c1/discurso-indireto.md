Wenn du fremde Aussagen wiedergibst, greift dein deutsches Sprachgefühl automatisch zum
Konjunktiv I: "Er sagte, er sei müde." Portugiesisch braucht diesen Modus-Wechsel nicht
— es löst dasselbe Problem mit einer Zeitverschiebung im Indikativ. Das ist der zentrale
Kontrast dieser Lektion.

## Zwei Sprachen, zwei Strategien

| | Deutsch | Portugiesisch |
| --- | -------- | --------------- |
| Strategie | Moduswechsel (Indikativ → Konjunktiv I) | Zeitverschiebung (presente → pretérito imperfeito usw.) |
| Beispiel | Er sagte, er **sei** müde. | Disse que **estava** cansado. |
| Modus bleibt | nein, wechselt | ja, bleibt Indikativ |

Das bedeutet konkret: Wenn du portugiesische indirekte Rede bildest, brauchst du keinen
neuen Modus zu lernen — du musst stattdessen die **concordância dos tempos verbais**
(Zeitenfolge) beherrschen, ein Konzept, das dem lateinischen consecutio temporum ähnelt
und im Deutschen praktisch nicht existiert.

## Die Verschiebungstabelle

| Direta (direkte Rede) | Indireta (indirekte Rede) |
| ----------------------- | ---------------------------- |
| presente (estou) | pretérito imperfeito (estava) |
| pretérito perfeito (fui) | mais-que-perfeito (tinha ido / fora) |
| futuro (irei) | condicional (iria) |
| futuro próximo (vou sair) | ia + Infinitiv (ia sair) |
| imperativo (Vai!) | para + Infinitiv (Disse para ir.) |

## Auch die Pronomen und Adverbien rutschen

Genau wie im Deutschen ("morgen" → "am nächsten Tag") verändern sich Zeit- und
Ortsangaben, wenn sie aus der Perspektive eines späteren Zeitpunkts wiedergegeben
werden:

| Direta | Indireta |
| -------- | ---------- |
| hoje | naquele dia |
| amanhã | no dia seguinte |
| ontem | no dia anterior |
| aqui | ali / lá |
| este | aquele |

## Die C1-Nuance: das mais-que-perfeito simples als Alternative

In formellerem Schriftportugiesisch ersetzt die synthetische Form "fora" oft die
periphrastische "tinha ido" — "Disse que fora ao médico" statt "Disse que tinha ido ao
médico". Beide sind korrekt, aber "fora" gehört zu einem literarischeren Register, das
du in der nächsten Lektionseinheit (mais-que-perfeito literário) vertiefst.

## Praktischer Trick für Deutschsprachige

Wann immer du merkst, dass du reflexartig nach einem Konjunktiv suchst, um portugiesische
indirekte Rede zu markieren — stopp. Frag dich stattdessen: "Welche Zeit muss ich nach
hinten verschieben?" Das ist der eigentliche Mechanismus.
