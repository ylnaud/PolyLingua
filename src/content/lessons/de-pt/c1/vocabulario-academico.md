Akademisches Portugiesisch folgt vielen Prinzipien, die dir aus dem deutschen
Wissenschaftsstil vertraut sind: Distanz zum Subjekt, Nominalisierung, feste
Konnektoren für logische Verknüpfungen. Der Unterschied liegt vor allem im konkreten
Wortschatz — das Prinzip dahinter kennst du bereits.

## Nominalisierung: dein deutscher Reflex hilft hier direkt

| Verb (neutral) | Nominalisierung (akademisch) |
| ---------------- | ------------------------------- |
| analisar | a análise |
| realizar | a realização |
| demonstrar | a demonstração |
| concluir | a conclusão |
| investigar | a investigação |

Statt "Nós analisámos os dados" (Wir analysierten die Daten) schreibt man akademisch
"Procedeu-se à análise dos dados" (Es wurde zur Analyse der Daten geschritten) — exakt
das Muster, das du aus deutschen Hausarbeiten kennst ("Es erfolgte die Analyse der
Daten").

## Konnektoren nach Funktion

| Funktion | Portugiesisch | Deutsch |
| --------- | ---------------- | --------- |
| Schlussfolgerung | portanto, por conseguinte | folglich, daher |
| Gegensatz | no entanto, contudo | jedoch, dennoch |
| Hinzufügung | além disso, ademais | darüber hinaus |
| Umformulierung | ou seja, isto é | das heißt |
| Zusammenfassung | em suma, em síntese | zusammenfassend |
| Kontextsetzung | no âmbito de | im Rahmen von |

## Formelle Verben statt alltäglicher Alternativen

| Alltäglich | Akademisch | Bedeutung |
| ------------ | ------------- | ----------- |
| mostrar | evidenciar, demonstrar | zeigen/nachweisen |
| dizer | afirmar, salientar | sagen/betonen |
| pensar | considerar | denken/erwägen |
| ver | constatar, verificar | feststellen |

## Das Passiv als Register-Marker

Genau wie im deutschen Wissenschaftsstil ("die Probanden wurden befragt" statt "wir
befragten die Probanden") rückt das portugiesische akademische Passiv das handelnde
Subjekt in den Hintergrund: "Os participantes foram entrevistados" statt "Nós
entrevistámos os participantes". Diese Depersonalisierung signalisiert Objektivität —
ein zentrales Stilmerkmal, das du direkt aus deiner Muttersprache übertragen kannst.

## Die C1-Nuance: die unpersönliche "procede-se a"-Konstruktion

Eine typisch portugiesische Wendung ohne direkte deutsche Eins-zu-eins-Entsprechung
ist "procede-se a" (man schreitet zu / es erfolgt): "Procede-se, de seguida, à
apresentação dos resultados" (Im Folgenden erfolgt die Präsentation der Ergebnisse).
Diese Konstruktion ist im akademischen und behördlichen Portugiesisch extrem häufig
und lohnt sich, aktiv einzuüben.
