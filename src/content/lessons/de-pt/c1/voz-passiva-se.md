Für dieses Thema lohnt es sich, dein deutsches "man" statt des echten Passivs als
Denkbrücke zu nehmen — die Parallele ist überraschend präzise.

## Die Grundstruktur

```
[Verb (3. Person)] + -se + [Nomen]
Vende-se        casa.
Vendem-se       casas.
```

"Se" steht direkt vor oder nach dem konjugierten Verb (je nach Satzstellung) und
signalisiert: Es gibt kein konkretes, genanntes Subjekt — die Handlung "passiert
einfach", ausgeführt von niemandem Bestimmtem. Genau das leistet auch "man" im
Deutschen.

## Die Numerus-Falle: das, was "man" nie tut

Der wichtigste Unterschied zur deutschen man-Konstruktion: Das portugiesische Verb
**kongruiert mit dem folgenden Nomen**, weil dieses Nomen grammatisch als Subjekt der
Konstruktion fungiert:

| Portugiesisch | Wörtliche Struktur | Deutsch |
| --------------- | --------------------- | --------- |
| Vende-se casa. | [casa = Subjekt, Singular] | Man verkauft ein Haus. |
| Vendem-se casas. | [casas = Subjekt, Plural] | Man verkauft Häuser. |
| Aluga-se apartamento. | Singular | Man vermietet eine Wohnung. |
| Alugam-se apartamentos. | Plural | Man vermietet Wohnungen. |

Diese Kongruenzregel — Verb passt sich dem nachgestellten Nomen an — hat im
deutschen "man" **keine Entsprechung**: "man verkauft" bleibt immer gleich, egal ob
ein oder mehrere Häuser gemeint sind.

## Typische Kontexte im Alltag

| Formel | Bedeutung | Wo man sie sieht |
| -------- | ----------- | ------------------- |
| Vende-se | zu verkaufen | Immobilienschilder |
| Aluga-se | zu vermieten | Immobilienschilder |
| Precisa-se de | gesucht wird | Stellenanzeigen |
| Fala-se português | man spricht Portugiesisch | Schilder, Tourismus |

## Abgrenzung: passiva sintética vs. echtes Passiv (ser + Partizip)

Portugiesisch hat zusätzlich ein echtes Passiv nach deutschem Muster: "A casa foi
vendida" (Das Haus wurde verkauft) — hier wird das ursprüngliche Objekt (casa) zum
grammatischen Subjekt, mit ser + Partizip, genau wie im Deutschen. Die passiva
sintética mit "se" ist die **unpersönlichere, alltagssprachlichere** Alternative,
besonders wenn kein spezifisches Objekt im Fokus steht, sondern eine allgemeine
Aussage getroffen wird.

## Die C1-Nuance

In formelleren Registern wird "se" manchmal auch mit einem indirekten
Reflexivitäts-Sinn kombiniert, der Verwirrung stiften kann: "Aqui não se fala
inglês" kann sowohl "Man spricht hier kein Englisch" als auch (seltener, kontextabhängig)
reflexiv gelesen werden. In der Praxis löst der Kontext diese Mehrdeutigkeit fast
immer eindeutig auf.
