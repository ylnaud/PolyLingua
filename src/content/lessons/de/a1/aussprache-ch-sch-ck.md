Acá hay tres combinaciones que se parecen al escribirlas y suenan muy distinto. La
única complicada es `ch`, y tiene una regla clara.

## sch — la fácil

`sch` suena siempre **«sh»**, como el «shh» de pedir silencio:

```
Schule   «SHÚU-le»   la escuela
Tisch    «TISH»      la mesa
Tasche   «TÁ-she»    el bolso
```

## ck — también fácil

`ck` es simplemente una **k fuerte**. La c no agrega nada:

```
Jacke    «YÁ-ke»     la chaqueta
lecker   «LÉ-ka»     rico
Rücken   «RÜ-ken»    la espalda
```

## ch — dos sonidos, y la vocal anterior decide

Esta es la única que hay que pensar. **Mirá la letra que viene antes:**

```
después de a, o, u   →   j fuerte (como la j española)
después de e, i      →   j suave, casi «sh», hecha adelante
```

```
Woche    «VÓ-je»     la semana        (después de o → fuerte)
Buch     «BUUJ»      el libro         (después de u → fuerte)
Nacht    «NAJT»      la noche         (después de a → fuerte)

Licht    «LIJT»      la luz           (después de i → suave)
mich     «MIJ»       me               (después de i → suave)
echt     «EJT»       de verdad        (después de e → suave)
```

Para la suave, poné la lengua como para decir «i» y soplá: sale sola. Si te sale la j
de «jamón», estás haciendo la fuerte.

**Bonus:** la terminación `-ig` se lee con esa misma ch suave — `lustig` = «LÚS-tij»,
no «LÚS-tig».

## De paso: la j alemana

Aparece en `Jacke`, así que conviene aclararlo: la `j` alemana suena como la **y
española**, nunca como la j de «jamón».

```
ja      «YA»       sí
Jacke   «YÁ-ke»    la chaqueta
Jahr    «YAAR»     el año
```

## El truco para practicar

Decí seguido el par **`Buch` / `Licht`** — «BUUJ» / «LIJT». Uno es de garganta, el otro
de adelante. Cuando sientas dónde se te mueve la lengua en cada uno, ya no vas a tener
que pensar la regla.
