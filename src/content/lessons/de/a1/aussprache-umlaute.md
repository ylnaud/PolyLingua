En alemán, los dos puntitos de arriba (`¨`) se llaman **Umlaut** y no son un adorno:
cambian el sonido y, muchas veces, la palabra entera.

```
schon   =  ya            schön   =  bonito
```

## ä — la más fácil

`ä` suena como una **«e» abierta**, muy parecida a la e del español:

```
Käse     «KÉ-se»      el queso
Bär      «BEEA»       el oso
Mädchen  «MÉD-jen»    la niña
```

## ö y ü — las que no existen en español

Estas dos no las tenés en tu idioma, así que no intentes sacarlas de oído: **sacalas de
la posición de los labios**.

```
ö  →  poné los labios como para decir «o», y decí «e»
ü  →  poné los labios como para decir «u», y decí «i»
```

```
Öl        «ÖL»        el aceite
schön     «SHÖN»      bonito
Tür       «TÜA»       la puerta
Prüfung   «PRÜ-fung»  el examen
```

Poné la mano en los labios mientras lo hacés: si los labios se te estiran, no está
saliendo. Tienen que quedar redondeados todo el tiempo.

## Una trampa: «äu» no es «ä»

Cuando la `ä` viene con una `u` al lado, el sonido cambia por completo y se lee **«oi»**:

```
Mäuse    «MOI-se»    los ratones
Häuser   «HÓI-sa»    las casas
Bäume    «BÓI-me»    los árboles
```

Es el mismo sonido que `eu` (lo vemos en la próxima lección). Y fijate que aparece
mucho en **plurales**: `Haus → Häuser`, `Baum → Bäume`, `Maus → Mäuse`.

## El truco para practicar

Decí en voz alta el par `schon / schön` varias veces seguidas, exagerando los labios en
la segunda. Cuando escuches clarita la diferencia entre las dos, ya tenés el sonido —
después es solo repetirlo en otras palabras.
