Una compra entera, de principio a fin, se resuelve con cuatro momentos. Aprendé una
frase para cada uno y ya no necesitás improvisar.

## 1. Pedir o buscar

```
Ich möchte einen Kaffee.     Quisiera un café.
Ich suche Milch.             Busco leche.
Wo finde ich das Brot?       ¿Dónde encuentro el pan?
```

`möchte` es la forma **cortés** de pedir. Decir `ich will` suena brusco, casi exigente —
usá `möchte` siempre que estés pidiendo algo.

## 2. Preguntar el precio

```
Was kostet das?          ¿Cuánto cuesta esto?
Das ist zu teuer.        Es demasiado caro.
```

## 3. Decidir

```
Ich nehme das.           Me llevo esto.
```

## 4. Pagar

```
Ich zahle mit Karte.     Pago con tarjeta.
Ich zahle bar.           Pago en efectivo.
Danke, das ist alles.    Gracias, eso es todo.
```

## El truco para practicar

Antes de ir al supermercado, decí en voz alta las cuatro frases en orden, como si ya
estuvieras ahí. Son siempre las mismas: lo único que cambia es el producto. Después de
unas cuantas veces las vas a soltar sin pensarlas.
