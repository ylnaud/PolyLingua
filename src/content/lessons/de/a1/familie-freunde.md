Ya tenés la lista de parentescos en la lección de vocabulario de la familia. Acá vamos a
lo otro: **las frases con las que realmente hablás de tu gente**.

## Cuántos sos

La cantidad siempre va con `haben`:

```
Ich habe zwei Brüder.          Tengo dos hermanos.
Ich habe eine Schwester.       Tengo una hermana.
Ich habe zwei Kinder.          Tengo dos hijos.
Ich habe keine Geschwister.    No tengo hermanos.
```

Fijate en la última: `Geschwister` es un sustantivo, así que se niega con **`keine`**,
nunca con `nicht`.

## Cómo se llaman y qué hacen

```
Meine Mutter heißt Ana.        Mi madre se llama Ana.
Mein Vater arbeitet viel.      Mi padre trabaja mucho.
Meine Familie wohnt in Spanien. Mi familia vive en España.
```

## El detalle que evita malentendidos

```
mein Freund          →  suele entenderse como MI NOVIO
ein Freund von mir   →  un amigo mío, sin ambigüedad
```

Lo mismo con `meine Freundin` (mi novia) vs. `eine Freundin von mir` (una amiga mía).
Si estás presentando a alguien, la segunda forma es la segura:

```
Das ist ein Freund von mir.    Este es un amigo mío.
Wir sind gute Freunde.         Somos buenos amigos.
```

## El truco para practicar

Presentá a tres personas reales de tu vida en una frase cada una: quién es, cómo se
llama y algo que hace. Tres frases, siempre el mismo molde. Después probá contestando
`Hast du Geschwister?` en voz alta, sin pensarlo.
