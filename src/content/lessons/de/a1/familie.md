Presentar a tu familia es una de las primeras conversaciones reales que vas a tener en
alemán. Aquí tienes el vocabulario esencial.

## La familia nuclear

| Alemán | Español |
| --- | --- |
| die Familie | la familia |
| der Vater / die Mutter | el padre / la madre |
| die Eltern | los padres |
| der Sohn / die Tochter | el hijo / la hija |
| der Bruder / die Schwester | el hermano / la hermana |
| die Geschwister | los hermanos (colectivo) |

## La familia extendida

| Alemán | Español |
| --- | --- |
| die Großmutter / der Großvater | la abuela / el abuelo |
| die Tante / der Onkel | la tía / el tío |
| die Cousine / der Cousin | la prima / el primo |

## Hablar de tu familia

```
Ich habe zwei Geschwister.        (Tengo dos hermanos)
Meine Mutter heißt Ana.            (Mi madre se llama Ana)
Mein Bruder ist 20 Jahre alt.      (Mi hermano tiene 20 años)
```

## El truco de las parejas

Aprende cada palabra junto a su contraparte de género: Vater/Mutter, Bruder/Schwester,
Sohn/Tochter. Ese emparejamiento hace que memorices el doble de vocabulario sin doble
esfuerzo, y refuerza el patrón der/die según el sexo de la persona.
