Los números son vocabulario de supervivencia: precios, horas, edades, direcciones. En
alemán tienen una lógica particular que vale la pena entender desde el principio.

## Del 0 al 20 (memorizar de una vez)

| 0-10 | 11-20 |
| --- | --- |
| null, eins, zwei, drei, vier, fünf | elf, zwölf, dreizehn, vierzehn |
| sechs, sieben, acht, neun, zehn | fünfzehn... neunzehn, zwanzig |

## Las decenas

| Número | Palabra |
| --- | --- |
| 20 | zwanzig |
| 30 | dreißig |
| 40 | vierzig |
| 50 | fünfzig |
| 60 | sechzig |
| 70 | siebzig |
| 80 | achtzig |
| 90 | neunzig |

## El patrón invertido (21-99)

```
[unidad] + und + [decena]

21 = einundzwanzig       (uno-y-veinte)
47 = siebenundvierzig     (siete-y-cuarenta)
99 = neunundneunzig       (nueve-y-noventa)
```

## Los números grandes

```
100 = hundert       200 = zweihundert       1000 = tausend
```

## El truco para practicar

Di en voz alta los precios que veas en cualquier tienda o app en alemán, o cuenta hacia
atrás desde 20. La repetición activa fija el patrón invertido mucho más rápido que solo
leerlo.
