Ya viste las Wechselpräpositionen, que cambian de caso según haya movimiento o no. Estas
preposiciones son más simples en un sentido: **siempre** rigen el mismo caso, sin
excepción, así que no hay que pensar en movimiento ni en nada más — solo memorizar a
qué grupo pertenece cada una.

## Grupo Akkusativ (siempre)

| Preposición | Significado |
| --- | --- |
| für | para |
| durch | a través de |
| gegen | contra |
| ohne | sin |
| um | alrededor de / a las (hora) |

```
Das Geschenk ist für dich.        Wir gehen durch den Park.
Ich bin gegen diese Idee.         Der Film beginnt um 20 Uhr.
```

## Grupo Dativ (siempre)

| Preposición | Significado |
| --- | --- |
| aus | de / desde (origen) |
| bei | en casa de / junto a |
| mit | con |
| nach | después de / hacia |
| seit | desde (tiempo) |
| von | de (posesión/origen) |
| zu | hacia / a |

```
Ich komme aus Spanien.        Ich wohne bei meiner Schwester.
Wir fahren mit dem Bus.       Seit einem Jahr lerne ich Deutsch.
```

Muchos profesores enseñan este grupo con una rima que se repite hasta memorizarla:

> **Aus, bei, mit, nach, seit, von, zu — immer nur den Dativ du!**
> ("Aus, bei, mit, nach, seit, von, zu — ¡siempre solo el Dativ tú [usas]!")

## Contracciones frecuentes

Cuando la preposición se combina con un artículo Dativ muy usado, el alemán suele
contraerlos en una sola palabra:

```
zu + dem  → zum      (zum Bahnhof)
zu + der  → zur       (zur Arbeit)
bei + dem → beim      (beim Arzt)
von + dem → vom       (vom Bahnhof)
```

## El truco para practicar

Agrupá las 12 preposiciones en dos columnas físicas (Akkusativ / Dativ) y repetí la rima
del grupo Dativ en voz alta unas cuantas veces seguidas. Como son solo dos grupos
cerrados — nada cambia nunca — memorizarlos de una vez te ahorra tener que dudar cada
vez que arms una frase.
