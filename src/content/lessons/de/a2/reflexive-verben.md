Algunos verbos alemanes necesitan siempre un pronombre que "regresa" la acción al
sujeto — como si el verbo mirara al espejo.

## Los pronombres reflexivos

| Pronombre | Reflexivo |
| --- | --- |
| ich | mich |
| du | dich |
| er/sie/es | sich |
| wir | uns |
| ihr | euch |
| sie/Sie | sich |

## Verbos reflexivos comunes

```
sich freuen (alegrarse)     → Ich freue mich.
sich waschen (lavarse)       → Du wäschst dich.
sich erinnern an (acordarse) → Er erinnert sich an sie.
sich beeilen (apurarse)      → Wir beeilen uns.
```

## El truco para no olvidar el pronombre

En español muchas veces omites el reflexivo ("me alegro" ya lleva el "me" incorporado en
la conjugación mental), pero en alemán el pronombre es una palabra separada
**obligatoria** — nunca la olvides, incluso si suena redundante.

```
✅ Ich freue mich auf die Ferien.
❌ Ich freue auf die Ferien.  (falta "mich")
```
