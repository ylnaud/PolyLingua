Ya sea para hablar de tu trabajo actual, escribir una solicitud o prepararte para una
entrevista, este vocabulario es esencial en el nivel B1.

## El proceso de búsqueda de empleo

| Alemán | Español |
| --- | --- |
| die Bewerbung | la solicitud/postulación |
| der Lebenslauf | el currículum |
| das Vorstellungsgespräch | la entrevista de trabajo |
| der Vertrag | el contrato |
| das Gehalt | el salario |

## En la oficina

| Alemán | Español |
| --- | --- |
| der Chef / die Chefin | el jefe / la jefa |
| der Kollege / die Kollegin | el colega |
| die Besprechung | la reunión |
| das Büro | la oficina |
| die Firma | la empresa |

## Frases útiles para hablar de tu trabajo

```
Ich arbeite als Lehrer/Lehrerin.       (Trabajo como profesor/a)
Ich habe ein Vorstellungsgespräch.     (Tengo una entrevista de trabajo)
Meine Kollegin heißt Anna.              (Mi colega se llama Anna)
```

## El patrón -in para profesiones femeninas

```
der Lehrer → die Lehrerin        der Arzt → die Ärztin
der Ingenieur → die Ingenieurin   der Student → die Studentin
```

Aprende cada profesión en su pareja masculino/femenino desde el principio — el patrón
se vuelve predecible muy rápido y duplicas tu vocabulario útil sin esfuerzo extra.
