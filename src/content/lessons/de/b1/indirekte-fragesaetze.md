Las preguntas indirectas son una forma más cortés y natural de preguntar algo,
especialmente en contextos formales — y siguen la misma lógica de "verbo al final" que
ya conoces de las oraciones subordinadas.

## Dos caminos según el tipo de pregunta

**Preguntas de sí/no** → se introduce con "ob"

```
Directa:    Kommt sie heute?
Indirecta:  Ich weiß nicht, ob sie heute kommt.
```

**Preguntas con W-Wort** → se reutiliza la misma palabra interrogativa

```
Directa:    Wo wohnst du?
Indirecta:  Ich möchte wissen, wo du wohnst.
```

## La regla que nunca cambia: verbo al final

```
Ich frage mich,    ob    sie    heute    kommt.
Können Sie mir sagen,    wann    der Zug    ankommt?
```

## Frases introductorias útiles

```
Ich weiß nicht, ob...          (No sé si...)
Ich frage mich, ob/wann/wo...  (Me pregunto si/cuándo/dónde...)
Können Sie mir sagen, ob...    (¿Podría decirme si...?)
Ich möchte wissen, was...      (Quisiera saber qué...)
```

## Por qué vale la pena dominarlas

Preguntar de forma directa a un desconocido ("Ist der Zug pünktlich?") puede sonar
brusco en ciertos contextos formales. Envolver la pregunta en una estructura indirecta
("Können Sie mir sagen, ob der Zug pünktlich ist?") suaviza el tono — un recurso que
usan constantemente los hablantes educados de alemán.
