El alemán tiene una relación curiosa con el futuro: aunque existe una forma gramatical
formal, el presente hace la mayor parte del trabajo en la conversación diaria.

## Futur I: la fórmula

```
werden (conjugado)  +  infinitivo (al final)

Ich werde    nach Berlin    fahren.
```

## Cuándo se usa realmente

| Uso | Ejemplo | ¿Común? |
| --- | --- | --- |
| Futuro con presente + marcador de tiempo | Ich fahre morgen nach Berlin. | Muy común |
| Futur I para plan/promesa formal | Ich werde das Problem lösen. | Común en contextos formales |
| Futur I para SUPOSICIÓN sobre el presente | Er wird jetzt zu Hause sein. | Muy común, sorprendente |

## El uso que sorprende a los estudiantes

```
Sie wird wohl krank sein.
(Probablemente está enferma — no "ella estará enferma" en el futuro)
```

Este uso especulativo del Futur I sobre el PRESENTE es extremadamente común y a menudo
se pasa por alto en los libros de texto básicos.

## Futur II: lo que ya habrá pasado

```
werden  +  participio  +  haben/sein (al final)

Bis morgen werde ich die Arbeit    beendet haben.
(Para mañana, habré terminado el trabajo)
```

También puede expresar una suposición sobre el pasado: "Er wird die Nachricht schon
gelesen haben" (probablemente ya leyó el mensaje).

## El resumen práctico

Para hablar de planes concretos, usa presente + marcador temporal (más natural). Para
sonar formal, prometer algo solemnemente, o especular sobre el presente/pasado, usa
Futur I/II — son herramientas de matiz, no solo de tiempo verbal.
