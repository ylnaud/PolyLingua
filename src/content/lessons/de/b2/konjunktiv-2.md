El Konjunktiv II es tu herramienta para hablar de mundos hipotéticos, deseos y — muy
importante en alemán — para sonar cortés al pedir algo.

## La fórmula universal: würde + infinitivo

```
würde (conjugado)  +  infinitivo (al final)

Ich würde    gerne nach Japan reisen.
```

| Pronombre | würde |
| --- | --- |
| ich | würde |
| du | würdest |
| er/sie/es | würde |
| wir | würden |
| ihr | würdet |
| sie/Sie | würden |

## Las formas propias que suenan más naturales

Un puñado de verbos tienen su propia forma de Konjunktiv II, más corta y preferida por
los hablantes nativos:

| Verbo | Konjunktiv II |
| --- | --- |
| sein | wäre |
| haben | hätte |
| können | könnte |
| müssen | müsste |
| dürfen | dürfte |

```
Ich wäre froh.        (en vez de "ich würde froh sein")
Ich hätte gern Kaffee. (en vez de "ich würde Kaffee haben")
```

## Los tres usos que debes dominar

1. **Condicionales irreales**: Wenn ich Zeit hätte, würde ich reisen. (Si tuviera tiempo,
   viajaría)
2. **Deseos**: Ich wünschte, ich könnte fliegen. (Ojalá pudiera volar)
3. **Cortesía**: Könnten Sie mir bitte helfen? (¿Podría ayudarme, por favor?) — mucho más
   educado que "Können Sie mir helfen?"

## El detalle que suena a hablante avanzado

Usar "könnten Sie" en vez de "können Sie" para pedir algo es el equivalente alemán de
pasar de "¿puedes ayudarme?" a "¿podrías ayudarme?" en español — el mismo matiz de
cortesía, marcado gramaticalmente con el Konjunktiv II.
