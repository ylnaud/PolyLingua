En español decimos "se vende la casa" sin decir quién la vende. El alemán hace lo mismo con
el **Passiv**, y una vez que dominas la fórmula, puedes aplicarla a cualquier tiempo verbal.

## La fórmula base

```
werden (conjugado)  +  participio (al final)
```

| Tiempo | Ejemplo |
| --- | --- |
| Presente | Das Haus wird gebaut. (La casa está siendo construida) |
| Pasado (Präteritum) | Das Haus wurde gebaut. (La casa fue construida) |
| Perfekt | Das Haus ist gebaut worden. |

## Transformar activa → pasiva en 3 pasos

1. El objeto directo (acusativo) de la activa se convierte en el sujeto (nominativo)
2. El verbo se transforma en "werden + participio"
3. Si quieres mencionar al agente, usa "von + dativo"

```
Activa:  Der Koch    kocht      die Suppe.
Pasiva:  Die Suppe   wird       (vom Koch) gekocht.
```

## ¿Cuándo usarla?

El Passiv es perfecto cuando el **qué pasó** importa más que el **quién lo hizo**: noticias,
instrucciones, procesos científicos o simplemente cuando no sabes (o no te importa) quién
hizo la acción.
