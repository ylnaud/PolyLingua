Este vocabulario te permite dar el salto de conversaciones cotidianas a discusiones
sobre economía, política y sociedad — el tipo de tema que domina las noticias.

## Economía

| Alemán | Español |
| --- | --- |
| die Wirtschaft | la economía |
| der Markt | el mercado |
| das Angebot | la oferta |
| die Nachfrage | la demanda |
| die Inflation | la inflación |
| die Arbeitslosigkeit | el desempleo |
| die Steuer | el impuesto |

## Sociedad

| Alemán | Español |
| --- | --- |
| die Gesellschaft | la sociedad |
| die Regierung | el gobierno |
| die Entwicklung | el desarrollo |
| die Gleichberechtigung | la igualdad de derechos |
| die Integration | la integración |

## Por qué puedes adivinar el género de casi todo esto

Fíjate en los patrones que ya conoces de la lección de der/die/das:

```
-keit → die Arbeitslosigkeit, die Möglichkeit
-ung → die Regierung, die Entwicklung
-schaft → die Gesellschaft, die Wirtschaft
```

Estas terminaciones son femeninas con 95-98% de certeza — el vocabulario abstracto de
nivel B2 confirma una y otra vez las reglas que aprendiste desde el primer día.

## Frase útil para debatir

```
Meiner Meinung nach ist die Arbeitslosigkeit das größte Problem.
(En mi opinión, el desempleo es el mayor problema)
```
