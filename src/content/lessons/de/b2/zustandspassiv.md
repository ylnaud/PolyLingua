Ya conoces el Passiv con "werden". Ahora descubres que existe una segunda forma, con
"sein", que cambia el matiz de proceso a resultado.

## La diferencia clave

| Tipo | Auxiliar | Enfoque | Ejemplo |
| --- | --- | --- | --- |
| Vorgangspassiv | werden | El proceso, la acción en marcha | Die Tür wird geöffnet. |
| Zustandspassiv | sein | El resultado, el estado final | Die Tür ist geöffnet. |

## Comparación directa

```
Vorgangspassiv:   Der Brief wird geschrieben.    (Se está escribiendo la carta — proceso)
Zustandspassiv:    Der Brief ist geschrieben.     (La carta ya está escrita — resultado)
```

## Cuándo usar cada uno

- **Vorgangspassiv**: cuando te importa el proceso, quién lo está haciendo o cuándo
  ocurre la acción.
- **Zustandspassiv**: cuando solo te importa el estado actual, sin importar el proceso
  que lo produjo.

```
Um 9 Uhr wird das Geschäft geöffnet.   (A las 9, se abre la tienda — el evento)
Ab 9 Uhr ist das Geschäft geöffnet.     (Desde las 9, la tienda está abierta — el estado)
```

## El truco para no confundirlos

Pregúntate: "¿estoy describiendo algo que está OCURRIENDO, o algo que YA TERMINÓ y
ahora es un hecho?" Proceso → werden. Resultado/estado → sein. Esta distinción es sutil
pero muy usada en alemán cotidiano y escrito.
