Este vocabulario te permite leer y escribir en el registro que domina tesis, artículos
científicos y ensayos universitarios en alemán.

## Vocabulario esencial

| Alemán | Español |
| --- | --- |
| die Hypothese | la hipótesis |
| die Untersuchung | la investigación |
| das Ergebnis | el resultado |
| die Schlussfolgerung | la conclusión |
| die Quelle | la fuente |
| der Beweis | la prueba |
| die Annahme | la suposición |

## Fórmulas fijas para citar y argumentar

```
Laut der Studie...                    (Según el estudio...)
Wie X zeigt/argumentiert...            (Como X muestra/argumenta...)
Es lässt sich feststellen, dass...    (Se puede constatar que...)
Zusammenfassend lässt sich sagen...    (En resumen, se puede decir...)
```

## Verbos académicos clave

| Alemán | Español |
| --- | --- |
| untersuchen | investigar |
| feststellen | constatar |
| belegen | comprobar/documentar |
| widerlegen | refutar |
| begründen | fundamentar |

## El truco: aprende bloques, no palabras sueltas

En vez de memorizar "laut" y "Studie" por separado, memoriza "laut der Studie" como una
unidad completa lista para usar. Estas fórmulas fijas son las que realmente aparecen
una y otra vez en textos académicos reales, y dominarlas te ahorra construir cada frase
desde cero.
