Este es uno de los superpoderes más rentables del alemán avanzado: reconocer patrones
de formación de palabras te permite deducir el significado de vocabulario que nunca
estudiaste explícitamente.

## Los prefijos y sufijos más productivos

| Afijo | Significado | Ejemplo |
| --- | --- | --- |
| un- | negación | möglich → unmöglich |
| -los | sin | Hoffnung → hoffnungslos |
| -bar | que se puede | lesen → lesbar |
| -heit / -keit | convierte adjetivo en sustantivo abstracto | frei → Freiheit |
| -ung | convierte verbo en sustantivo de acción | bewegen → Bewegung |
| ver- | cambio de estado (a menudo negativo) | schwinden → verschwinden |

## Encadenando afijos: el verdadero poder

Una vez que reconoces los patrones, puedes deducir palabras compuestas complejas:

```
un + vergess + lich = unvergesslich
(negación) + (olvidar, raíz) + (-lich, adjetivo) = "inolvidable"
```

## Practica con palabras nuevas

Aplica el patrón a palabras que nunca viste:

```
trinkbar = ? (trinken + bar)          → "que se puede beber, potable"
Sauberkeit = ? (sauber + keit)         → "limpieza" (sustantivo abstracto de "limpio")
```

## Por qué esto es tu herramienta más rentable en C1

En lugar de memorizar vocabulario palabra por palabra, reconocer estos patrones te
permite leer un texto denso y deducir el significado de palabras desconocidas sobre la
marcha — exactamente la habilidad que necesitas para leer periódicos, ensayos o
literatura sin diccionario a mano todo el tiempo.
