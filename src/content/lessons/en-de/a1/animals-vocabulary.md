Animal vocabulary is a fun place to practice the noun plural patterns you already
learned, since these words cover all five patterns in one small set. This lesson gives
you the most common animals — pets, farm animals, and general wildlife.

## Pets

| German | Plural | English |
| -------- | -------- | -------- |
| der Hund | die Hunde | dog |
| die Katze | die Katzen | cat |
| der Vogel | die Vögel | bird |
| der Fisch | die Fische | fish |
| das Kaninchen | die Kaninchen | rabbit |

Notice **der Vogel → die Vögel** uses the no-ending-plus-umlaut pattern you saw earlier
with der Vater → die Väter — a good reminder that this pattern is not limited to family
words.

## Farm animals

| German | Plural | English |
| -------- | -------- | -------- |
| die Kuh | die Kühe | cow |
| das Pferd | die Pferde | horse |
| das Schwein | die Schweine | pig |
| das Schaf | die Schafe | sheep |
| das Huhn | die Hühner | chicken |

## The general word: das Tier

Just as English has "animal" as a category word, German has **das Tier** (plural: die
Tiere). Use it the same way:

- Ich mag Tiere. — I like animals.
- Welches Tier magst du? — Which animal do you like?

## Talking about pets with haben

Combine this vocabulary with haben (which you already know) to say what pets you have:

```
Ich habe einen Hund.    I have a dog.   (der Hund → einen, masculine direct object)
Ich habe eine Katze.     I have a cat.   (die Katze → eine, feminine direct object)
Ich habe ein Pferd.      I have a horse. (das Pferd → ein, neuter direct object)
```

## Sample sentences

- Der Hund spielt im Garten. — The dog plays in the garden.
- Die Katze schläft den ganzen Tag. — The cat sleeps all day.
- Wir haben drei Hühner. — We have three chickens.
- Das Pferd ist sehr schnell. — The horse is very fast.

Try naming any pets you have (or would like to have) using "Ich habe..." — it is an easy
way to combine this lesson's vocabulary with grammar you already learned.
