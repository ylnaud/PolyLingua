Family vocabulary is one of the most useful — and easiest — vocabulary sets to learn
in German, because it also doubles as free practice for der/die/das gender.

## The core family

| German         | English      |
| -------------- | ------------- |
| die Familie    | the family    |
| die Eltern     | the parents   |
| der Vater      | the father    |
| die Mutter     | the mother    |
| die Geschwister| the siblings  |
| der Bruder     | the brother   |
| die Schwester  | the sister    |
| der Sohn       | the son       |
| die Tochter    | the daughter  |
| die Kinder     | the children  |

## A gift for practicing der/die

Unlike objects — where der Tisch (table) has no logical reason to be masculine — family
words are one place where grammatical gender and real-world (biological) gender line up
perfectly. Every male relative takes **der**, every female relative takes **die**:

- der Vater, der Bruder, der Sohn, der Onkel, der Großvater, der Cousin (all der)
- die Mutter, die Schwester, die Tochter, die Tante, die Großmutter, die Cousine (all die)

This makes family vocabulary an easy, low-stress place to build confidence with
articles before tackling objects, where the gender is far less predictable.

## Grandparents, aunts, uncles, cousins

| German                  | English              |
| ------------------------ | --------------------- |
| der Großvater / Opa      | grandfather / grandpa |
| die Großmutter / Oma     | grandmother / grandma |
| die Großeltern           | the grandparents       |
| der Onkel                | the uncle              |
| die Tante                | the aunt               |
| der Cousin / die Cousine | male cousin / female cousin |

Note the compound structure: "groß" (big/grand) + Vater/Mutter/Eltern builds
"grandfather / grandmother / grandparents" — a pattern you'll see repeated across many
German compound words.

## Talking about your own family

To describe your family, combine these words with the possessive **mein** (my,
masculine/neuter) or **meine** (my, feminine/plural):

> Mein Vater heißt Klaus. Meine Mutter heißt Petra. Ich habe eine Schwester und zwei
> Brüder. Meine Geschwister heißen Lisa, Max und Tim.
>
> (My father is named Klaus. My mother is named Petra. I have one sister and two
> brothers. My siblings are named Lisa, Max, and Tim.)

## Plural forms worth noting

A few family words shift more than just their article in the plural:

```
der Bruder   →  die Brüder    (brother → brothers)
die Schwester → die Schwestern (sister → sisters)
das Kind     →  die Kinder    (child → children)
```

Learning these plurals alongside the singular now will save you from having to
memorize them separately later, when you start describing bigger groups of people.
