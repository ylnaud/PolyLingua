German has four diphthongs (two vowel sounds glued into one) that appear constantly:
**ei, ie, eu,** and **au**. The good news is that each one maps onto a sound you
already make in English — you just need to learn which spelling goes with which sound,
because German spelling is far more consistent than English spelling once you know the
rules.

## ei and ie — easy to mix up, easy to tell apart

These two look almost identical on the page, which is exactly why English speakers
confuse them. Here is the trick that fixes it permanently:

> **Say the alphabet name of the SECOND letter.**

```
ei  →  second letter is "i"  →  the letter i says "eye"   →  ei sounds like "eye"
ie  →  second letter is "e"  →  the letter e says "ee"    →  ie sounds like "ee"
```

Examples:

```
ei     mein   "mine"        rhymes with "fine"
       heißt  "is called"   the ei sounds like "eye"
ie     wie    "how"         rhymes with "see"
       Sie    "you" (formal) rhymes with "see"
```

This is not a minor detail — mixing them up changes real words. Getting comfortable
with "ei = eye" and "ie = ee" now will save you from misreading hundreds of words later.

## eu — the "oy" sound

"eu" is pronounced like the **"oy" in "boy"**. It is the same sound you met as "äu" in
the umlaut lesson — German just spells it two different ways depending on the word.

```
neu      "noy"        new
heute    "HOY-tuh"     today
Deutsch  "DOYTCH"      German (the language)
```

## au — the "ow" sound

"au" is pronounced like the **"ow" in "how"** or "cow".

```
Haus     "house" (almost exactly the English word)   house
blau     "BLOW" (rhymes with "how", not "slow")       blue
auch     "OWKH"                                        also/too
```

## Quick reference table

| Spelling | Sounds like (English) | Example      |
| -------- | ---------------------- | ------------ |
| ei       | eye (as in "time")     | Wein (wine)  |
| ie       | ee (as in "see")       | wie (how)    |
| eu       | oy (as in "boy")       | neu (new)    |
| au       | ow (as in "cow")       | Haus (house) |

## How to practice

Read this pair of questions out loud, exaggerating each vowel:

```
Wie heißt du?  →  "vee HYST doo?"   (How are you called? / What's your name?)
```

Notice "wie" uses the "ee" sound and "heißt" uses the "eye" sound, right next to each
other. If you can say that sentence cleanly, you have all four diphthongs from this
lesson under control — the rest is just recognizing them in new words.
