This lesson closes out the pronunciation basics with three separate patterns that all
trip up English speakers in different ways: a **silent h**, the very common **-er**
ending, and the letters **v, z,** and **s**, which do not sound the way an English eye
expects.

## Silent h — a length marker, not a sound

When h appears right after a vowel, you do not pronounce the h itself. Instead, it is
a signal: **the vowel before it is long**.

```
Sohn      "zohn"        son     (long o, not "sonn")
Uhr       "oor"          clock / watch / o'clock  (long u, not "oohr" with a real h)
gehen     "GAY-en"      to go   (long e, the h is silent)
```

Contrast this with a short vowel with no h: "Sonne" (sun) has a short o, because there
is no h after it.

## The -er ending — a soft "uh"

German words ending in unstressed **-er** are extremely common (Vater, Mutter, Bruder,
Lehrer...) and English speakers tend to pronounce that ending too strongly, the way an
American would say "her". In German, it softens into a light, short **"uh"** sound —
closer to how a British speaker says the unstressed ending of "better".

```
Vater     "FAH-tuh"      father
Mutter    "MOOT-uh"      mother
Bruder    "BROO-duh"     brother
```

## v — usually an English "f"

This one surprises almost everyone: German **v** is normally pronounced like an
English **f**, not like an English v.

```
Vater     "FAH-ter"     father   (starts with an F sound!)
viel      "feel"         a lot / much
```

The exception is loanwords from other languages, where v keeps its "v" sound:

```
Vase      "VAH-zeh"      vase (borrowed word, real v sound)
```

## z — always "ts"

German **z** is never the buzzing sound of English z. It is always pronounced
**"ts"** — the exact sound you learned for "tz" in the last lesson.

```
Zeit      "tsyte"        time
Zimmer    "TSIM-er"      room
```

## s — depends on its position

German **s** changes sound depending on where it sits in the word:

- **At the start of a word, before a vowel** → voiced, like an English **z**.
- **At the end of a word, or before a consonant** → unvoiced, like a plain English
  **s**.

```
sagen     "ZAH-gen"      to say     (voiced z-sound, word-initial + vowel)
sehen     "ZAY-en"       to see      (voiced z-sound)
das       "dass"          the/that   (unvoiced s-sound, word-final)
Haus      "house"         house      (unvoiced s-sound)
```

## Quick reference table

| Letter                          | Sounds like              | Example         |
| -------------------------------- | ------------------------- | ---------------- |
| silent h (after a vowel)         | nothing — lengthens vowel | Sohn, Uhr        |
| -er (unstressed ending)          | soft "uh"                 | Vater, Mutter    |
| v (native German words)          | English f                  | Vater            |
| v (loanwords)                    | English v                  | Vase             |
| z                                 | "ts"                       | Zeit             |
| s (start of word, before vowel)  | English z                  | sagen            |
| s (end of word)                  | English s                  | das, Haus        |

## How to practice

Say this sentence slowly, applying every rule from the last five lessons:

```
Mein Vater sagt es jetzt.   →   "myne FAH-tuh zahkt es yetst."
```

If that sentence comes out smoothly, you have covered every core sound pattern in
German pronunciation — the rest of this course builds vocabulary and grammar on top of
sounds you can already produce correctly.
