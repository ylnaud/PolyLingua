Four more spelling patterns change how you should read a German word out loud: **st**,
**sp**, **pf**, **tz**, and the special letter **ß**. Unlike the umlauts and
diphthongs, a couple of these depend on *where* the letters sit in the word — so pay
attention to position, not just spelling.

## st and sp at the start of a word: "sht" and "shp"

This is the single most useful pronunciation rule for a beginner, because it affects
extremely common words. When **st** or **sp** appears at the **start of a word or word
part**, it is pronounced **"sht"** and **"shp"** — the s picks up a "sh" sound.

```
Stadt      "SHTAT"        city
Student    "SHTU-dent"    student
sprechen   "SHPREKH-en"   to speak
Sport      "SHPORT"       sport
```

## st and sp elsewhere: plain "st" and "sp"

This rule is specifically about the **start** of a word or word part. In the middle or
at the end, st and sp are pronounced just like they look, close to English:

```
Fenster    "FEN-ster"    window   (st is not at the start, so it stays "st")
Wurst      "voorst"       sausage  (same — normal "st" sound)
```

## pf — both letters, blended tight

English almost never puts p and f next to each other at the start of a word (think of
"cupful" said quickly — that blend is close). In German, **pf** is a normal consonant
cluster: both sounds are pronounced, sliding into each other very quickly.

```
Apfel      "AP-fel"     apple
Pferd      "PFERT"       horse
Kopf       "KOPF"        head
```

## tz — a hard "ts"

**tz** is pronounced like the "ts" at the end of the English word "cats" — a quick,
hard blend, never a soft "z" sound.

```
jetzt      "yetst"       now
Platz      "plats"       place / square
Katze      "KAT-tseh"    cat
```

## ß — the sharp-s letter

**ß** (called "eszett" or "scharfes S") is unique to German. It is not a "z" sound at
all — it is a plain, sharp, unvoiced **s**, exactly like the "ss" in the English word
"hiss". You will mostly see it after long vowels and diphthongs, where a double "ss"
would otherwise appear.

```
Straße     "SHTRAH-suh"    street
groß       "grohs"          big / tall
Fuß        "foos"           foot
```

## Quick reference table

| Spelling                 | Sounds like              | Example         |
| ------------------------- | ------------------------- | --------------- |
| st / sp (word-initial)    | sht / shp                 | Stadt, sprechen |
| st / sp (elsewhere)       | plain st / sp              | Fenster         |
| pf                         | p blended into f           | Apfel           |
| tz                         | ts (as in "cats")          | jetzt           |
| ß                          | sharp s (as in "hiss")     | Straße          |

## How to practice

Say this sentence slowly, applying every rule from this lesson:

```
Ich spreche jetzt Deutsch.   →   "ish SHPREKH-uh yetst DOYTCH"
```

That single sentence packs in the shp-sound, the tz-sound, and the ch-sound from the
last lesson. If you can say it smoothly, you have covered the trickiest consonant
patterns in German.
