Getting around a new city is one of the first practical challenges you will face, and a
small set of phrases covers most of what you need — both to ask for directions and to
talk about how you are traveling.

## Asking for directions

The core question is:

- **Wie komme ich zu...?** — How do I get to...?

The word after "zu" contracts depending on the noun's gender:

```
Wie komme ich zum Bahnhof?   (zu + dem → zum, masculine: der Bahnhof)
Wie komme ich zur Post?       (zu + der → zur, feminine: die Post)
```

At this level, it is enough to recognize both contractions and default to **zum** for
masculine/neuter places and **zur** for feminine ones.

## Understanding the answer: direction words

| German | English |
| -------- | ------- |
| links | left |
| rechts | right |
| geradeaus | straight ahead |
| zurück | back |
| an der Ampel | at the traffic light |
| an der Ecke | at the corner |

A typical set of directions might sound like:

- Gehen Sie geradeaus, dann links. — Go straight ahead, then left.
- An der Ampel rechts. — At the traffic light, right.

## Modes of transport

| German | English |
| -------- | ------- |
| der Bus | the bus |
| der Zug | the train |
| die U-Bahn | the subway/metro |
| das Auto | the car |
| das Fahrrad | the bicycle |
| zu Fuß | on foot |

To say how you are traveling, German uses **fahren** (to travel/drive) with "mit dem/der":

```
Ich fahre mit dem Bus.    I go by bus.
Ich fahre mit der U-Bahn.  I go by subway. (die U-Bahn is feminine → mit der)
Ich gehe zu Fuß.            I go on foot. (uses gehen, not fahren)
```

## Places you will ask about

| German | English |
| -------- | ------- |
| der Bahnhof | train station |
| die Haltestelle | bus/tram stop |
| der Flughafen | airport |
| der Parkplatz | parking lot |

## Sample exchange

```
A: Entschuldigung, wie komme ich zum Bahnhof?   Excuse me, how do I get to the train station?
B: Gehen Sie geradeaus und dann rechts.           Go straight ahead and then right.
A: Ist das weit von hier?                           Is that far from here?
B: Nein, nur fünf Minuten zu Fuß.                    No, only five minutes on foot.
```

Practice asking "Wie komme ich zu...?" with different places from this lesson and
earlier ones (der Supermarkt, das Restaurant) to build real flexibility.
