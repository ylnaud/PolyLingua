By now you know that Akkusativ marks a direct object — the thing being acted on
directly. **Dativ** marks a different role: the person (or thing) something is being
done *to* or *for* — the indirect object. Many German sentences use both at once.

## The two-question test

The fastest way to find the right case is to ask the matching question about the
sentence:

```
Wen oder was?  →  Akkusativ (direct object)
Wem?           →  Dativ (indirect object)
```

**Ich gebe meinem Bruder ein Buch.** — Wem gebe ich das Buch? *meinem Bruder* (Dativ).
Was gebe ich? *ein Buch* (Akkusativ).

## How the articles change

| Case      | masculine (der) | feminine (die) | neuter (das) | plural (die) |
| --------- | ---------------- | ---------------- | -------------- | -------------- |
| Nominativ | der               | die               | das             | die             |
| Akkusativ | den               | die               | das             | die             |
| Dativ     | dem               | der               | dem             | den (+n)        |

Note the plural Dativ takes both a changed article (den) **and** an -n added to the
noun itself when it does not already end in -n: den Kindern, den Frauen.

The indefinite article follows the same pattern:

```
ein  →  einen (Akkusativ, masc.)  →  einem (Dativ, masc./neut.)  →  einer (Dativ, fem.)
```

## Verbs that take both a Dativ and an Akkusativ object

A small group of common verbs describe giving, showing, or sending something to
someone — and they take a person in the Dativ plus a thing in the Akkusativ:

```
geben (to give)       Ich gebe meinem Bruder ein Buch.
zeigen (to show)      Ich zeige dir das Foto.
schenken (to gift)    Wir schenken ihr Blumen.
schicken (to send)    Sie schickt mir eine E-Mail.
erklären (to explain) Er erklärt uns die Regel.
```

## Word order with two objects

When both objects are full nouns, Dativ usually comes first, then Akkusativ:

```
Ich gebe meinem Bruder ein Buch.
   (Dativ: meinem Bruder)   (Akkusativ: ein Buch)
```

But if the Akkusativ object is a **pronoun** (es, ihn, sie), it jumps in front of a
Dativ noun object instead:

```
Ich gebe es meinem Bruder.   (not: Ich gebe meinem Bruder es.)
```

## Verbs that are dative-only

A handful of very common verbs never take an Akkusativ object at all — the person
affected is always in the Dativ, even though English treats it as a direct object:

```
helfen (to help)      Ich helfe dir.        (not: Ich helfe dich.)
danken (to thank)     Ich danke Ihnen.
gefallen (to please)  Das Buch gefällt mir.  (literally: the book pleases me)
gehören (to belong to) Das Auto gehört meinem Vater.
```

These verbs are worth memorizing as a set, since the English translation gives no clue
that German treats them differently.
