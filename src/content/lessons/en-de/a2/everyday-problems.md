These are the phrases that get you out of a jam: when something breaks, when you
didn't understand, or when you messed up.

## When something isn't working

```
Das funktioniert nicht.           It doesn't work.
Meine Waschmaschine ist kaputt.   My washing machine is broken.
Ich habe ein Problem.             I have a problem.
```

`kaputt` is an **adjective**, so it always goes with `sein`: `ist kaputt`, never _"hat
kaputt"_.

## When you don't understand (the most important phrases of all)

```
Ich verstehe nicht.                      I don't understand.
Können Sie das bitte wiederholen?        Can you repeat that, please?
Können Sie bitte langsamer sprechen?     Can you speak more slowly, please?
Wie sagt man das auf Deutsch?            How do you say this in German?
```

These four are worth more than a hundred vocabulary words. Asking someone to repeat
themselves is what lets you **keep following** a conversation instead of nodding along
without understanding anything.

Notice the structure with `können`: the conjugated verb goes second and the infinitive
goes **at the end**.

```
Können   Sie das bitte   wiederholen?
```

## Asking for help: helfen always takes mir/dir/ihm

```
Können Sie mir helfen?      Can you help me?
```

It's `mir`, not `mich`, because `helfen` always takes the "to whom" form (**Dativ**:
mir, dir, ihm) — just like `danken` and `gefallen`, which you've already seen.

## Apologizing

```
Ich habe meinen Schlüssel verloren.   I lost my key.
Ich habe mich verspätet.              I'm running late.
Es tut mir leid.                      I'm sorry.
— Kein Problem.                       No problem.
```

## How to practice

Memorize **`Können Sie das bitte wiederholen?`** first, until it comes out
automatically, before any other phrase in this lesson. It's the one that will help you
most in a real conversation, because it's the one that keeps the conversation from
breaking down.
