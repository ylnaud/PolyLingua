A lot of German verbs describe an action that bounces back onto the person doing it —
"to wash oneself," "to get dressed," "to hurry." These are **reflexive verbs**, and in
German they are marked with the little word **sich**, which changes form depending on
who the subject is.

## The reflexive pronouns

Good news: you already know most of these from the accusative pronouns you learned
earlier. Only one form is new.

| Subject     | Reflexive pronoun | Notes                     |
| ----------- | ------------------ | -------------------------- |
| ich         | mich                | same as accusative "me"    |
| du          | dich                | same as accusative "you"   |
| er/sie/es   | **sich**            | new form — not "ihn/sie/es" |
| wir         | uns                 | same as accusative "us"    |
| ihr         | euch                | same as accusative "you"   |
| sie (they)  | **sich**            | same word as er/sie/es      |
| Sie (formal)| **sich**            | same word again             |

Only **sich** is genuinely new — and it single-handedly covers third person singular,
third person plural, and the formal "you."

## Reflexive verbs in action

```
Ich freue mich auf die Ferien.     (I am looking forward to the holidays.)
Du wäschst dich.                    (You wash yourself.)
Er zieht sich an.                   (He gets dressed.)
Wir setzen uns.                     (We sit down.)
Ihr beeilt euch.                    (You all hurry.)
Sie interessieren sich für Musik.   (They are interested in music.)
```

Notice the reflexive pronoun sits right after the conjugated verb, in the same slot
where a direct object pronoun would normally go.

## When the reflexive pronoun becomes dative

Most reflexive verbs use the accusative pronoun (mich, dich, sich, uns, euch, sich).
But if the sentence already has its own direct object in the accusative, the
reflexive pronoun shifts to the **dative** form instead — because the accusative slot
is already taken:

```
Ich putze mir die Zähne.     (I brush my teeth. — "die Zähne" is the direct object, so "mir" is dative)
Ich kaufe mir ein Buch.      (I am buying myself a book.)
```

The dative reflexive pronouns are: **mir, dir, sich, uns, euch, sich** — identical to
the accusative set except for the first and second person singular (mich → mir, dich
→ dir).

## Common reflexive verbs to learn first

```
sich freuen (auf/über)   to be happy, to look forward to / to be happy about
sich interessieren für   to be interested in
sich erinnern an         to remember
sich waschen             to wash oneself
sich anziehen            to get dressed
sich setzen              to sit down
sich beeilen             to hurry
sich fühlen              to feel (a certain way)
```

## A small but useful nuance: auf vs. über

"Sich freuen auf" and "sich freuen über" both mean "to be happy about," but they point
in different directions in time:

```
Ich freue mich auf die Ferien.       (looking forward to something still coming)
Ich freue mich über das Geschenk.    (happy about something that already happened)
```

## Word order in questions

The reflexive pronoun stays in its usual position even when the verb moves to the
front of a question:

```
Freust du dich auf die Party?     (Are you looking forward to the party?)
```
