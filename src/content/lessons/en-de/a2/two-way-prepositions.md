Nine German prepositions are called **Wechselpräpositionen** ("switching
prepositions") because they can take either Dativ or Akkusativ — and unlike the
prepositions you have already learned, the case here depends entirely on **meaning**,
not on the preposition itself.

## The nine two-way prepositions

```
an        at, on (vertical surface)
auf       on (horizontal surface)
hinter    behind
in        in, into
neben     next to
über      over, above
unter     under
vor       in front of
zwischen  between
```

## The rule: Wo? vs. Wohin?

Ask yourself which question the sentence is answering:

```
Wo?     (where is it — a fixed location, no movement)   →   Dativ
Wohin?  (where is it going — movement toward a place)    →   Akkusativ
```

Compare these two sentences with the exact same preposition:

```
Die Katze liegt auf dem Tisch.     (Wo? — location — Dativ)
Die Katze springt auf den Tisch.   (Wohin? — movement — Akkusativ)
```

Same preposition, same noun, different case — because the *meaning* changed from "is
located" to "moves toward."

## State verbs vs. movement verbs

A useful shortcut: certain verbs almost always signal one side or the other.

| State verbs (→ Dativ) | Movement verbs (→ Akkusativ) |
| ----------------------- | ------------------------------ |
| sein (to be)             | gehen (to go)                  |
| liegen (to lie/be located) | legen (to lay/put down)      |
| stehen (to stand)        | stellen (to stand/place)      |
| sitzen (to sit)          | setzen (to sit down/place)    |
| hängen (hanging, state)  | hängen (to hang something up) |

```
Der Stuhl steht neben dem Tisch.     (Dativ — the chair is standing there)
Ich stelle den Stuhl neben den Tisch. (Akkusativ — I am placing the chair there)
```

## Common contractions

Some two-way prepositions merge with the article that follows, especially in the
Dativ and with **in**/**an**/**auf**:

```
in dem  →  im       Ich bin im Haus.
in das  →  ins       Ich gehe ins Haus.
an dem  →  am        Ich sitze am Tisch.
an das  →  ans        Ich gehe ans Fenster.
auf das →  aufs       Ich lege es aufs Bett.
```

## More examples

```
Das Bild hängt an der Wand.        (Dativ — the picture is hanging on the wall)
Ich hänge das Bild an die Wand.    (Akkusativ — I am hanging the picture on the wall)
Er sitzt zwischen seinen Freunden.  (Dativ — he is sitting between his friends)
Er setzt sich zwischen seine Freunde. (Akkusativ — he sits down between his friends)
```

Once you have the Wo?/Wohin? question and the state-vs-movement verb pattern down,
these nine prepositions stop being nine separate problems and become one single rule
applied nine times.
