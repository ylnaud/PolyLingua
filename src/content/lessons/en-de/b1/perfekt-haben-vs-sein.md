You already know how to form the Perfekt with **haben** + past participle. Now it is
time for the other half: when does German use **sein** instead? Let's follow a hotel
complaint from the first message to the resolution to see both in action.

## The core test: movement/change of state + no direct object

A verb takes **sein** in the Perfekt when BOTH of these are true:

1. It describes movement from one place to another, OR a change of state
2. It has **no direct object** (nothing you can "do it to")

```
Ich bin ins neue Zimmer gezogen.     (movement, no direct object → sein)
Ich bin heute früh aufgewacht.        (change of state, no direct object → sein)
```

Everything else — which is most verbs — defaults to **haben**, including virtually
all reflexive and transitive verbs (verbs with a direct object):

```
Der Manager hat sich entschuldigt.      (reflexive, has "sich" as object → haben)
Wir haben das Problem besprochen.        (transitive, "das Problem" is the object → haben)
```

## Following the complaint: haben in action

The complaint itself and its resolution mostly use haben, because these actions have
a direct object or are reflexive:

```
Ich habe mich beim Empfang beschwert.
(I complained at the front desk.)

Der Manager hat sich entschuldigt.
(The manager apologized.)

Wir haben das Problem besprochen.
(We discussed the problem.)
```

## Following the complaint: sein in action

The physical movement parts of the story use sein instead:

```
Ich bin ins neue Zimmer gezogen.
(I moved into the new room.)

Ich bin heute Morgen früh aufgewacht — wegen des Lärms.
(I woke up early this morning — because of the noise.)
```

## The exceptions: bleiben and sein itself

A small handful of verbs take sein even though they don't describe movement:
**bleiben** (to stay) and **sein** (to be) itself. Think of them as "state" verbs that
German groups with the movement verbs by long tradition rather than strict logic:

```
Der Gast ist zufrieden geblieben.
(The guest stayed/remained satisfied.)

Es ist ein guter Aufenthalt gewesen.
(It was/turned out to be a good stay.)
```

## Quick reference

| Use sein when...                 | Use haben when...                |
| ---------------------------------- | ----------------------------------- |
| movement between locations (gehen, fahren, ziehen) | the verb has a direct object (besprechen) |
| change of state (aufwachen, sterben, werden)          | the verb is reflexive (sich entschuldigen, sich beschweren) |
| the exceptions: bleiben, sein         | almost everything else               |

With this test in hand, you can now build a complete, natural-sounding Perfekt story
— complaint, apology, resolution — mixing both helpers correctly every time.
