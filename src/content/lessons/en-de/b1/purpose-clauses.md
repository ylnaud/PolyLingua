By now you can connect ideas with weil, dass, obwohl and wenn. This lesson adds one
more connector job: expressing **purpose** — "in order to" and "so that". German
splits this into two different constructions, and picking the right one comes down to
a single question.

## The one question that decides everything

**Is the subject the same in both halves of the sentence?**

- **Yes** → use **um...zu** + infinitive (no second subject, no conjugated verb)
- **No** → use **damit** + a full subordinate clause (its own subject, verb at the end)

```
Ich lerne Deutsch, um in Berlin zu arbeiten.     (ich...ich → um...zu)
Ich spreche langsam, damit meine Oma mich versteht.  (ich...meine Oma → damit)
```

## um...zu: same subject, infinitive only

The pattern is: **um** + [rest of the clause] + **zu** + infinitive, at the very end.

```
Ich arbeite viel, um meine Familie zu unterstützen.
(I work a lot in order to support my family.)
```

Notice there is no second "ich" and no conjugated verb inside the um...zu part — just
"zu" glued directly onto the infinitive. With separable-prefix verbs, "zu" slides
between the prefix and the stem: **einladen** → **einzuladen**.

```
Ich rufe an, um dich einzuladen.
(I am calling in order to invite you.)
```

## damit: different subjects, full clause

When the person doing the purpose-action is NOT the same as the main subject, um...zu
is grammatically impossible — you need **damit**, which works exactly like weil, dass
and obwohl: it is a subordinating conjunction, so the conjugated verb goes to the end.

```
Ich schicke dir das Buch, damit du es lesen kannst.
(I am sending you the book so that you can read it.)
```

## Quick comparison

| Construction | Subject rule       | Verb form               |
| ------------ | ------------------- | ------------------------ |
| um...zu      | same subject         | infinitive + zu, at the end |
| damit        | different subjects  | conjugated verb, at the end |

A helpful trap to watch for: **damit** can technically be used even when the subject
is the same, but native speakers strongly prefer um...zu whenever possible — it is
shorter and considered more natural style. Save damit for when the subjects genuinely
differ.
