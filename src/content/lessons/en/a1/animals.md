Los animales son uno de los primeros temas de vocabulario que se aprenden en cualquier
idioma — y en inglés, sirven para practicar "to be" y "have got" al mismo tiempo.

## Animales domésticos

| Inglés | Español |
| ------ | ------- |
| dog    | perro   |
| cat    | gato    |
| fish   | pez     |
| bird   | pájaro  |

## Animales de granja y salvajes

| Inglés   | Español  |
| -------- | -------- |
| cow      | vaca     |
| horse    | caballo  |
| lion     | león     |
| elephant | elefante |

## Describir animales con "to be"

```
The dog is big.
(El perro es grande)

The cat is small.
(El gato es pequeño)

Lions are wild animals.
(Los leones son animales salvajes)
```

## Hablar de mascotas con "have got"

"have got" significa "tener" — se usa mucho en inglés británico para hablar de
posesiones y mascotas:

```
I have got a cat.
(Tengo un gato)

I have got a dog and a fish.
(Tengo un perro y un pez)
```

También puedes decir simplemente "I have a cat" — ambas formas son correctas y
significan lo mismo.

## El truco para practicar

Describe a tus propias mascotas (o las que te gustaría tener) usando "to be" para sus
características ("The dog is friendly") y "have got" para decir que las tienes ("I
have got a dog").
