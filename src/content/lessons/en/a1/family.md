Hablar de tu familia es una de las primeras conversaciones naturales en cualquier
idioma. En inglés, además, no hay géneros gramaticales que complicar.

## La familia nuclear

| Inglés | Español |
| --- | --- |
| family | familia |
| father / mother | padre / madre |
| parents | padres |
| son / daughter | hijo / hija |
| brother / sister | hermano / hermana |
| siblings | hermanos (colectivo) |

## La familia extendida

| Inglés | Español |
| --- | --- |
| grandmother / grandfather | abuela / abuelo |
| grandparents | abuelos (colectivo) |
| aunt / uncle | tía / tío |
| cousin | primo/a (misma palabra para ambos) |

## Hablar de tu familia

```
I have two siblings: a brother and a sister.
(Tengo dos hermanos: un hermano y una hermana)

My mother's name is Ana.
(Mi madre se llama Ana)

My brother is 20 years old.
(Mi hermano tiene 20 años)
```

## Una palabra que sirve para ambos géneros

"cousin" (primo/prima) es igual para hombre y mujer — si necesitas aclarar el género,
añades "male cousin" o "female cousin", aunque rara vez es necesario en conversación
normal.

## El truco para practicar

Describe tu propio árbol genealógico en voz alta usando estas palabras — es una forma
natural de fijar el vocabulario mientras hablas de algo que ya conoces bien.
