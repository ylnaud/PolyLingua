Describir tu casa es una de las conversaciones más básicas y útiles en inglés — y con
"there is/there are" puedes hacerlo desde el primer día.

## Las habitaciones de la casa

| Inglés      | Español         |
| ----------- | ---------------- |
| kitchen     | cocina           |
| bedroom     | dormitorio       |
| bathroom    | baño             |
| living room | sala de estar    |
| garden      | jardín           |

## Muebles básicos

| Inglés | Español |
| ------ | ------- |
| bed    | cama    |
| table  | mesa    |
| chair  | silla   |
| sofa   | sofá    |

## "There is" vs. "There are"

Para describir qué hay en un lugar, usa "there is" (singular) o "there are" (plural):

```
There is a table in the kitchen.
(Hay una mesa en la cocina)

There are two chairs in the living room.
(Hay dos sillas en la sala de estar)

There is a bed in the bedroom.
(Hay una cama en el dormitorio)
```

## La regla clave

- Un solo objeto → **there is** + a/an + sustantivo singular
- Varios objetos → **there are** + número/some + sustantivo plural

```
There is a sofa in the living room.   (singular)
There are three chairs in the kitchen. (plural)
```

## El truco para practicar

Camina mentalmente por tu propia casa habitación por habitación y describe qué hay en
cada una usando "there is"/"there are" — es la forma más rápida de fijar tanto el
vocabulario como la estructura.
