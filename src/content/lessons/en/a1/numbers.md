Los números son vocabulario de supervivencia inmediata: precios, horas, edades,
direcciones. Aquí está la base completa del 0 al 100.

## Del 0 al 20

| 0-10                               | 11-20                              |
| ---------------------------------- | ---------------------------------- |
| zero, one, two, three, four        | eleven, twelve, thirteen, fourteen |
| five, six, seven, eight, nine, ten | fifteen... nineteen, twenty        |

## Las decenas (¡ojo con "forty"!)

| Número | Palabra           |
| ------ | ----------------- |
| 20     | twenty            |
| 30     | thirty            |
| 40     | forty (¡sin "u"!) |
| 50     | fifty             |
| 60     | sixty             |
| 70     | seventy           |
| 80     | eighty            |
| 90     | ninety            |

## El patrón del 21 al 99

```
[decena]-[unidad]

21 = twenty-one       47 = forty-seven       99 = ninety-nine
```

Mismo orden que en español, con un guión entre las dos palabras.

## Los números grandes

```
100 = one hundred (o solo "a hundred")
1,000 = one thousand
```

## El truco para practicar

Practica diciendo precios en voz alta cada vez que veas un número en inglés — apps,
recibos, precios de tiendas. La repetición activa fija mucho más rápido que solo
memorizar la lista.
