Describir tu rutina diaria es una de las conversaciones más naturales en Simple
Present — el tiempo perfecto para practicar este vocabulario.

## Los verbos de rutina esenciales

| Inglés | Español |
| --- | --- |
| wake up | despertarse |
| get up | levantarse (de la cama) |
| get dressed | vestirse |
| have breakfast/lunch/dinner | desayunar/almorzar/cenar |
| go to work/school | ir al trabajo/escuela |
| go to bed | irse a la cama |

## Expresiones de frecuencia

| Inglés | Español |
| --- | --- |
| always | siempre |
| usually | usualmente |
| often | a menudo |
| sometimes | a veces |
| rarely | rara vez |
| never | nunca |
| every day | todos los días |

## Construyendo una rutina completa

```
I usually wake up at 7am. I get up and get dressed quickly.
I have breakfast at 7:30, and then I go to work.
I never skip breakfast — it's my favorite meal.
```

## Dónde van las expresiones de frecuencia

Las palabras de frecuencia (always, usually, often, sometimes, never) van **antes** del
verbo principal, pero **después** de "to be":

```
I always have breakfast.        (antes del verbo)
I am always tired in the morning. (después de "am")
```

## El truco para practicar

Narra tu propia rutina diaria en voz alta usando Simple Present + estas expresiones de
frecuencia — es una de las formas más naturales de fijar vocabulario y gramática al
mismo tiempo.
