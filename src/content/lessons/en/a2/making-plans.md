Emma termina su día con un mensaje de un amigo: quedaron para el fin de
semana. Estas son las frases para proponer, aceptar y cancelar planes en
inglés.

## 1. Proponer

```
Are you free on Saturday?              ¿Estás libre el sábado?
Do you want to go to the cinema?        ¿Querés ir al cine?
```

## 2. Aceptar o rechazar

```
I'm in!                          ¡Me apunto!
Sounds good then.                 Suena bien entonces.
Unfortunately, I can't.           Lamentablemente no puedo.
```

## 3. Acordar

```
What time should we meet?         ¿A qué hora deberíamos encontrarnos?
Eight o'clock, in front of the cinema.   A las ocho frente al cine.
```

## 4. Cancelar

```
Unfortunately, I can't make it.    Lamentablemente no puedo ir.
See you tomorrow.                   Nos vemos mañana.
```

## Una frase completa

```
Are you free on Saturday? Do you want to go to the cinema? — I'm in! What time should we meet?
(¿Estás libre el sábado? ¿Querés ir al cine? — ¡Me apunto! ¿A qué hora deberíamos encontrarnos?)
```

## El truco para practicar

Ensayá el intercambio completo en voz alta, haciendo los dos papeles: uno
propone, el otro acepta con "I'm in!" y acuerdan la hora. Como hizo Emma
para quedar con su amigo.
