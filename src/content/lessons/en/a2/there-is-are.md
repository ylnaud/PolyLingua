"There is/are" es tu herramienta para describir qué existe o qué hay en un lugar —
mucho más común de lo que su traducción literal sugiere.

## La fórmula básica

| Singular | Plural |
| --- | --- |
| There is a cat. | There are two cats. |
| There isn't a cat. | There aren't any cats. |
| Is there a cat? | Are there any cats? |

## some vs. any: la regla clave

| Contexto | Palabra | Ejemplo |
| --- | --- | --- |
| Afirmación positiva | some | There are some books. |
| Negación | any | There aren't any books. |
| Pregunta | any | Are there any books? |

## Una excepción cortés

En preguntas que ofrecen algo (más que preguntar información), se usa "some" incluso en
pregunta:

```
Would you like some coffee?    (¿Quieres café? — es una oferta, no una pregunta neutra)
```

## Practicando la estructura completa

```
There is a park near my house.        (Hay un parque cerca de mi casa)
There aren't any restaurants here.     (No hay restaurantes aquí)
Are there any shops nearby?            (¿Hay tiendas cerca?)
```

## El truco para no confundir "there" con "their"

"There is/are" (hay) no tiene relación con "their" (su/de ellos) ni con "they're" (ellos
son/están) — suenan igual pero se escriben distinto y significan cosas completamente
diferentes. Presta atención especial al escribir.
