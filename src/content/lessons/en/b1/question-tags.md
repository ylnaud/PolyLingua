Los question tags son esas pequeñas preguntas al final de una frase que buscan
confirmación — extremadamente comunes en conversación real, y con una lógica de espejo
muy precisa.

## La regla del espejo

```
Afirmativa + tag negativo
Negativa + tag afirmativo

You're tired,       aren't you?
You aren't tired,    are you?
```

## Cómo elegir el auxiliar del tag

| Verbo principal | Auxiliar del tag |
| --- | --- |
| to be (is/are/was/were) | mismo verbo | She is nice, isn't she? |
| Verbo modal (can/will/should) | mismo modal | You can swim, can't you? |
| Verbo normal (presente) | do/does | You like tea, don't you? |
| Verbo normal (pasado) | did | They left, didn't they? |

## Un caso especial: "I am"

```
I am right, aren't I?      (no "amn't I", que no se usa)
```

## Cómo suena en conversación real

```
It's cold today, isn't it?
You don't smoke, do you?
She can drive, can't she?
```

## El truco para dominarlo rápido

Practica transformando frases simples que ya conoces en question tags — el patrón de
"espejo opuesto" se automatiza sorprendentemente rápido una vez que lo practicas en voz
alta varias veces. Es una de las estructuras que más suena a hablante nativo cuando se
usa con fluidez.
