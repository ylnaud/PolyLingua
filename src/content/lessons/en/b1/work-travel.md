Este vocabulario te prepara para dos de las situaciones más comunes en las que
necesitarás inglés con fluidez: el trabajo y los viajes.

## Vocabulario de trabajo

| Inglés | Español |
| --- | --- |
| job interview | entrevista de trabajo |
| resume/CV | currículum |
| deadline | fecha límite |
| meeting | reunión |
| colleague | colega |
| salary | salario |
| to apply for a job | postular a un trabajo |

## Vocabulario de viajes

| Inglés | Español |
| --- | --- |
| flight | vuelo |
| to check in | registrarse/facturar |
| boarding pass | tarjeta de embarque |
| luggage | equipaje |
| customs | aduana |

## Frases útiles para el trabajo

```
I have a job interview tomorrow.
I'm looking forward to meeting you.
Could we schedule a meeting for next week?
```

## Frases útiles para viajar

```
I'd like to check in, please.
Where is the boarding gate?
Is breakfast included in the accommodation?
```

## La trampa de "looking forward to"

Recuerda: después de "look forward to", "to" es una preposición (no parte de un
infinitivo), así que siempre necesita gerundio:

```
✅ I'm looking forward to seeing you.
❌ I'm looking forward to see you.
```

Es una de las estructuras que más delata a un hablante intermedio versus uno más
avanzado — vale la pena memorizarla bien.
