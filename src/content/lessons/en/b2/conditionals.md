Los condicionales conectan una condición con su consecuencia — pero el inglés distingue
claramente entre "esto podría pasar de verdad" y "esto es pura fantasía".

## First Conditional: lo realista

Se usa para situaciones futuras genuinamente posibles.

```
If + Present Simple,   will + infinitivo
If it rains,            I will stay home.
```

Ejemplo de uso real: "If you study, you will pass." — es una condición que realmente
podría cumplirse.

## Second Conditional: lo hipotético / imaginario

Se usa para situaciones irreales, imaginarias, o muy poco probables en el presente/futuro.

```
If + Past Simple,   would + infinitivo
If I won the lottery,   I would buy a house.
```

Ojo: el verbo está en pasado, ¡pero NO estamos hablando del pasado! Es solo la forma
gramatical que marca "esto es imaginario".

## El caso especial: "If I were you..."

Con el verbo "be" en Second Conditional, usamos **"were"** para todas las personas
(incluso "I" y "he/she/it"), aunque suene raro:

```
If I were you, I would apologize.     (Yo que tú, me disculparía)
If she were taller, she would play basketball.
```

## Compáralos lado a lado

| | Probabilidad | Estructura | Ejemplo |
| --- | --- | --- | --- |
| First | Realista | if + presente, will + infinitivo | If I have time, I'll call you. |
| Second | Imaginario | if + pasado, would + infinitivo | If I had time, I would call you. |

La diferencia de significado es enorme: la primera dice "probablemente tendré tiempo", la
segunda dice "no tengo tiempo, pero imagino qué pasaría si lo tuviera".
