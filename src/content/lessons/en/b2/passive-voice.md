En inglés, la voz pasiva se usa muchísimo más que en español, especialmente en contextos
formales: noticias, ciencia, negocios. Dominarla es clave para sonar profesional por
escrito.

## La fórmula base

```
be (conjugado)  +  past participle
```

| Tiempo | Ejemplo |
| --- | --- |
| Presente | The report is written every month. |
| Pasado | The report was written last week. |
| Presente perfecto | The report has been written. |
| Futuro | The report will be written. |

## Transformar activa → pasiva

1. El objeto de la activa se convierte en sujeto de la pasiva
2. El verbo se transforma en "be + participio"
3. El agente (si se menciona) se introduce con "by"

```
Activa:   Shakespeare    wrote      this play.
Pasiva:   This play      was written   by Shakespeare.
```

## Cuándo usarla (y por qué el inglés la prefiere)

- El agente es desconocido: My phone was stolen.
- El agente no importa: The bridge was built in 1930.
- Registro formal/científico: The results were analyzed carefully.
- Para sonar objetivo en noticias: The decision was announced yesterday.

## El matiz que suena a nivel avanzado

En inglés de negocios y académico, usar la voz pasiva para evitar señalar culpables
directamente es una estrategia de estilo muy común: "Mistakes were made" suena mucho más
diplomático que "I made mistakes" o "You made mistakes". Reconocer este uso estratégico
—no solo gramatical— es lo que distingue un inglés escrito pulido de uno básico.
