Este condicional te permite reflexionar sobre un pasado que ya no se puede cambiar —
el terreno del "si hubiera hecho las cosas diferente..."

## La fórmula

```
If + Past Perfect,   would have + participio

If I had studied,     I would have passed the exam.
```

## El detalle clave: describe lo OPUESTO a la realidad

```
If she had left earlier, she wouldn't have missed the train.
```

Esto significa: en la realidad, ella NO salió temprano, Y SÍ perdió el tren. El Third
Conditional siempre describe un escenario alternativo, contrario a lo que realmente
pasó.

## Comparando los tres condicionales

| | Tiempo | Estructura | Ejemplo |
| --- | --- | --- | --- |
| First | Futuro real | if + presente, will | If it rains, I'll stay home. |
| Second | Presente imaginario | if + pasado, would | If I had time, I would travel. |
| Third | Pasado alternativo | if + past perfect, would have | If I had known, I would have helped. |

## Variaciones con "might have" y "could have"

```
If I had studied more, I might have passed.     (posibilidad, no certeza)
If you had asked, I could have helped.            (capacidad en el pasado alternativo)
```

## El uso más natural: expresar arrepentimiento

```
If I had known you were coming, I would have cleaned the house!
(Si hubiera sabido que venías, ¡habría limpiado la casa!)
```

Esta estructura es exactamente lo que necesitas para lamentarte, reflexionar sobre
decisiones pasadas, o imaginar cómo las cosas podrían haber sido diferentes — una
herramienta emocional tanto como gramatical.
