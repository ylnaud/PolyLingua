Este es uno de los rasgos más sutiles de un inglés verdaderamente fluido: evitar
repetir información que ya quedó clara, usando atajos gramaticales precisos.

## "so" y "not" para sustituir ideas completas

```
"Will it rain?" "I think so."           (= I think it will rain)
"Will it rain?" "I hope not."           (= I hope it won't rain)
"Is she coming?" "I believe so."        (= I believe she is coming)
```

## "do so" para sustituir una acción completa

```
He asked me to leave, and I did so immediately.
(= I left immediately — evita repetir "leave")
```

## "neither/so + auxiliar" para acuerdo

```
"I don't like coffee." "Neither do I."      (yo tampoco)
"I love this song." "So do I."               (a mí también)
"I can't swim." "Neither can I."             (yo tampoco — nota el auxiliar "can")
```

El auxiliar debe concordar con el verbo original: do/does/did, am/is/are, can, have,
etc.

## "one/ones" para sustituir sustantivos contables

```
I need a new phone. Mine is old, so I want a new one.
These shoes are nice, but I prefer the black ones.
```

## Elipsis: simplemente omitir lo obvio

```
She can speak French, and he can [speak French] too.
(la parte entre corchetes se omite naturalmente, se entiende por contexto)
```

## Por qué esto es el nivel C1 real

Cualquier estudiante puede repetir información completa cada vez. Un hablante C1 confía
en que su oyente puede reconstruir lo omitido — esa economía de lenguaje, sin perder
claridad, es exactamente lo que hace que el inglés suene natural y fluido en vez de
mecánicamente correcto.
