El neutro es el género que **no existe en español**, y por eso el que más cuesta al
principio. La buena noticia: tiene la regla más segura de todo el idioma.

## DAS por terminación

| Terminación / categoría            | Certeza          | Ejemplos                                   |
| ---------------------------------- | ---------------- | ------------------------------------------ |
| -chen, -lein (diminutivos)         | **100%**         | das Mädchen, das Brötchen, das Tischlein   |
| -ing (préstamos ingleses)          | 95%              | das Marketing, das Recycling               |
| -um                                | 90%              | das Zentrum, das Publikum                  |
| -nis                               | 90%              | das Ergebnis, das Erlebnis                 |
| -ment                              | 85%              | das Dokument, das Instrument               |
| Infinitivos usados como sustantivo | tendencia fuerte | das Leben (de leben), das Lesen (de lesen) |
| Palabras internacionales           | tendencia fuerte | das Hotel, das Telefon, das Handy          |

## La regla del 100%: -chen y -lein

Son las dos terminaciones de **diminutivo** —el equivalente a nuestro _-ito_— y no
fallan nunca:

```
der Tisch  →  das Tischlein   (la mesita)
die Brot   →  das Brötchen    (el panecillo)
```

Y acá está la clave de la palabra que confunde a todo el mundo: **das Mädchen** es «la
niña» con artículo neutro porque es el diminutivo de _Magd_. La terminación **gana** al
significado. Cuando una palabra tiene una terminación con regla propia, esa regla manda,
aunque hable de una persona.

## Infinitivos convertidos en sustantivo

Cualquier verbo alemán se puede volver un sustantivo: se escribe con mayúscula y lleva
`das`. Es una fábrica de vocabulario gratis:

```
essen (comer)   →  das Essen   (la comida)
lesen (leer)    →  das Lesen   (la lectura)
leben (vivir)   →  das Leben   (la vida)
```
