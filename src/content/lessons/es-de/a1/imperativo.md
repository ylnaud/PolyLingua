El imperativo sirve para dar órdenes, hacer pedidos o dar instrucciones. Tiene tres
formas según a quién le hablás: du (informal singular), ihr (informal plural) y Sie
(formal).

## Du — la forma más común

Se toma el infinitivo, se saca el `-en` final, y **no** se usa el pronombre:

```
gehen → Geh!        kommen → Komm!        warten → Warte! (se agrega -e tras d/t)
```

Si el verbo cambia la vocal en presente (e→i o e→ie), ese cambio se mantiene en el
imperativo, pero **sin** la `-st` final:

```
sprechen (du sprichst) → Sprich!        lesen (du liest) → Lies!
```

## Ihr — igual que la conjugación normal

Simplemente se usa la forma de "ihr" del presente, sin el pronombre:

```
ihr kommt → Kommt!        ihr helft → Helft!        ihr arbeitet → Arbeitet!
```

## Sie — infinitivo + Sie (orden invertido)

La forma más fácil de recordar: siempre es el infinitivo seguido de "Sie", justo al
revés de una frase normal:

```
Kommen Sie!        Helfen Sie mir!        Seien Sie leise! (sein es irregular)
```

## El caso especial de "sein"

`sein` no sigue el patrón regular en ninguna de sus formas:

| Persona | Imperativo |
| ------- | ---------- |
| du      | Sei!       |
| ihr     | Seid!      |
| Sie     | Seien Sie! |

## El truco para practicar

Elegí 5 verbos que ya conozcas (`kommen`, `gehen`, `warten`, `helfen`, `sein`) y armá el
imperativo para du, ihr y Sie de cada uno, en voz alta. Como el imperativo se usa
constantemente en la vida diaria alemana — mucho más que en español — cuanto antes lo
automatices, antes vas a sonar natural.
