Antes de aprender ninguna regla de gramática, puedes empezar a hablar alemán hoy
mismo con un puñado de frases fijas. Son bloques que se memorizan enteros — como
letras de canciones — y te van a servir en cualquier primera conversación.

## Saludar

| Alemán       | Español                     | Cuándo usarlo                              |
| ------------ | --------------------------- | ------------------------------------------ |
| Hallo        | Hola                        | A cualquier hora, casi cualquier situación |
| Guten Morgen | Buenos días                 | Por la mañana                              |
| Guten Tag    | Buenos días / buenas tardes | Del mediodía hasta el atardecer            |
| Guten Abend  | Buenas noches (al llegar)   | Al anochecer                               |

## Despedirse

| Alemán          | Español                          | Registro |
| --------------- | -------------------------------- | -------- |
| Tschüss         | Adiós, chao                      | Informal |
| Auf Wiedersehen | Adiós                            | Formal   |
| Gute Nacht      | Buenas noches (al irse a dormir) | —        |

## Presentarte: las 3 preguntas esenciales

Con estas tres preguntas y sus respuestas puedes sostener toda una primera
conversación:

```
Wie heißt du?         →  Ich heiße Ana.
(¿Cómo te llamas?)        (Me llamo Ana.)

Woher kommst du?      →  Ich komme aus Spanien.
(¿De dónde eres?)         (Soy de España — sin artículo delante del país.)

Wie alt bist du?       →  Ich bin 25 Jahre alt.
(¿Cuántos años tienes?)    (Tengo 25 años.)
```

## Bitte y Danke: las palabras mágicas

- **Bitte** — significa tanto "por favor" como "de nada", según el contexto.
- **Danke** — gracias. También puedes decir "Danke schön" (muchas gracias) para
  sonar un poco más cálido.
- **Entschuldigung** — perdón / disculpe, útil para pedir algo o llamar la
  atención de alguien educadamente.

## du vs. Sie: el tratamiento formal

El alemán distingue entre dos formas de decir "tú":

- **du** — informal, para amigos, familia, niños y compañeros de tu edad.
- **Sie** — formal (siempre con mayúscula, aunque esté en medio de la frase),
  para desconocidos, en el trabajo, o con personas mayores.

```
du:   Wie heißt du?       Woher kommst du?
Sie:  Wie heißen Sie?     Woher kommen Sie?
```

Si tienes dudas sobre cuál usar, empieza con "Sie" — es más seguro pasar de
formal a informal que al revés.

## El truco para memorizarlas

No traduzcas palabra por palabra: repite cada frase completa en voz alta varias
veces, como si fuera una canción corta. "Ich heiße... Ich komme aus..." — cuando
la frase entera te sale sin pensar, ya la aprendiste de verdad.
