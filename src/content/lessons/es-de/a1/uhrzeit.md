Decir la hora en alemán tiene dos sistemas paralelos: uno para hablar con amigos y otro
para todo lo oficial. Ambos son igual de importantes.

## El sistema oficial (24 horas): el más fácil

```
[hora] Uhr [minutos]

14:30 = vierzehn Uhr dreißig
09:05 = neun Uhr fünf
```

Se usa en trenes, aeropuertos, televisión, citas médicas — cualquier contexto formal.

## El sistema coloquial: el que sorprende

| Hora | Expresión coloquial          |
| ---- | ---------------------------- |
| 3:00 | drei Uhr                     |
| 3:15 | viertel nach drei            |
| 3:30 | halb vier (¡no "halb drei"!) |
| 3:45 | viertel vor vier             |

## La trampa de "halb"

Este es el punto que más confunde: "halb vier" no significa "las tres y media" en el
sentido de "mitad de las tres" — significa "camino hacia las cuatro, a mitad de
camino". Es decir, **apunta a la hora siguiente**, no a la actual.

```
2:30 = halb drei     (mitad de camino hacia las 3)
3:30 = halb vier      (mitad de camino hacia las 4)
```

## Preguntar la hora

```
Wie spät ist es?          (¿Qué hora es?)
Wie viel Uhr ist es?      (¿Qué hora es? — alternativa)
Es ist ... Uhr.            (Son las...)
```

Con práctica, cambiar mentalmente entre ambos sistemas se vuelve automático — solo
recuerda que "halb" siempre mira hacia adelante.
