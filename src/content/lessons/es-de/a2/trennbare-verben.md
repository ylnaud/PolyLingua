Este es uno de los rasgos más distintivos del alemán: verbos que, en presente, se
"parten" en dos pedazos dentro de la frase.

## El patrón básico

```
aufstehen (levantarse) → ich stehe auf

Ich    stehe    um 7 Uhr    auf.
(verbo conjugado, 2ª posición)    (prefijo, al final)
```

## Los prefijos separables más comunes

| Prefijo | Ejemplo     | Significado         |
| ------- | ----------- | ------------------- |
| auf-    | aufstehen   | levantarse          |
| an-     | anrufen     | llamar por teléfono |
| ein-    | einkaufen   | hacer compras       |
| aus-    | ausgehen    | salir               |
| mit-    | mitkommen   | venir con alguien   |
| vor-    | vorbereiten | preparar            |

## Cuándo SE separa y cuándo NO

| Se separa                          | No se separa                                       |
| ---------------------------------- | -------------------------------------------------- |
| Presente simple: Ich rufe dich an. | Con modal + infinitivo: Ich muss dich anrufen.     |
| Imperativo: Ruf mich an!           | Infinitivo con "zu": Ich versuche, dich anzurufen. |

## Los prefijos que NUNCA se separan

Ojo: existe otro grupo de prefijos (be-, ver-, ent-, er-, ge-, zer-) que se comportan
completamente distinto — **nunca se separan**, sin importar el contexto:

```
verstehen → ich verstehe (nunca "ich stehe ver")
```

## El truco para reconocerlos

Cuando veas un verbo en el diccionario con el prefijo pegado (aufstehen), sabrás que se
va a separar en frases normales. Practica formando frases simples con los 6 prefijos de
la tabla hasta que el "salto al final" se sienta automático.
