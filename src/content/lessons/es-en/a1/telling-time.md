Decir la hora en inglés tiene su propia lógica — una vez que la entiendes, es
completamente predecible.

## La forma directa (la más simple)

```
[hora]:[minutos]

3:15 = three fifteen
9:05 = nine oh five (el "oh" se dice para el cero)
```

## La forma coloquial: past y to

| Minutos               | Expresión                     |
| --------------------- | ----------------------------- |
| :15                   | a quarter past [hora]         |
| :30                   | half past [hora]              |
| :45                   | a quarter to [hora siguiente] |
| :05, :10, :20, :25... | [minutos] past/to [hora]      |

```
3:15 = a quarter past three
3:30 = half past three
3:45 = a quarter to four      (¡mira hacia la próxima hora!)
3:20 = twenty past three
```

## La lógica de "past" vs. "to"

- **past** (después de) → cuando aún no llegaste a la mitad de la hora (:01 a :30)
- **to** (antes de) → cuando ya pasaste la mitad, mirando hacia la próxima hora (:31 a
  :59)

```
3:10 = ten past three         (todavía "después" de las 3)
3:50 = ten to four             (ya "antes" de las 4)
```

## Preguntar la hora

```
What time is it?              (¿Qué hora es?)
Do you have the time?          (¿Tienes hora? — más informal)
It's half past three.          (Son las tres y media)
```

Con práctica, elegir entre "past" y "to" se vuelve automático — solo recuerda que el
punto de quiebre es la media hora.
