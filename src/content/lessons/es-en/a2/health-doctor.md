Saber describir cómo te sientes es esencial cuando viajas o simplemente te enfermas en
un entorno de habla inglesa. Aquí tienes el vocabulario básico para ir al médico.

## Partes del cuerpo comunes

| Inglés  | Español  |
| ------- | -------- |
| head    | cabeza   |
| throat  | garganta |
| stomach | estómago |
| arm     | brazo    |
| leg     | pierna   |

## Síntomas básicos

| Inglés      | Español           |
| ----------- | ----------------- |
| headache    | dolor de cabeza   |
| fever       | fiebre            |
| cough       | tos               |
| sore throat | dolor de garganta |

## Frases para el médico

```
I have a headache.
(Tengo dolor de cabeza)

My throat hurts.
(Me duele la garganta)

I have a fever and a cough.
(Tengo fiebre y tos)
```

## Lo que puede decirte el médico

```
You should take this medicine.
(Deberías tomar esta medicina)

You should rest and drink water.
(Deberías descansar y tomar agua)
```

## "have" vs. "hurt": dos formas de describir dolor

Puedes usar "I have a headache" (tengo dolor de cabeza) o "My head hurts" (me duele la
cabeza) — ambas son correctas y muy comunes:

```
I have a stomachache.  =  My stomach hurts.
(Tengo dolor de estómago / Me duele el estómago)
```

## El truco para practicar

La próxima vez que te sientas mal (o simplemente imagines un síntoma), practica
describirlo en voz alta con "I have a..." y "My... hurts" — así memorizas ambas
estructuras a la vez.
