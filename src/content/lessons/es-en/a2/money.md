Emma cierra la semana pensando en sus gastos: está ahorrando para un
viaje, así que estas son las frases del dinero que más usa.

## La pregunta que hay que hacer primero

```
Can I pay by card?           ¿Puedo pagar con tarjeta?
— Cash only, please.          Solo efectivo, por favor.
```

Conviene preguntarlo **antes** de pedir, no después.

## Sacar plata

```
I need to withdraw some cash.      Necesito sacar dinero.
Where's an ATM?                     ¿Dónde hay un cajero automático?
I don't have any cash on me.        No tengo efectivo encima.
```

"Cash" es efectivo — no confundirlo con "caja" ("box").

## Ahorro y gastos

```
I'm saving up for a trip.          Estoy ahorrando para un viaje.
How much do I owe you?              ¿Cuánto te debo?
```

## Una frase completa

```
I need to withdraw some cash because I'm saving up for a trip.
(Necesito sacar dinero porque estoy ahorrando para un viaje)
```

## El truco para practicar

Memorizá primero **"Can I pay by card?"** — es la que más vas a usar, como
Emma antes de cualquier compra. Después sumale "I'm saving up for ...", que
sirve para contar cualquier meta de ahorro.
