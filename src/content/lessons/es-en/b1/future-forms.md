En inglés hay tres formas principales de hablar del futuro, y elegir la correcta depende
de CUÁNTA certeza o planificación hay detrás de lo que decís.

## Las 3 formas y cuándo usarlas

| Forma                 | Se usa para                                 | Ejemplo                             |
| ---------------------- | -------------------------------------------- | ------------------------------------ |
| will                   | decisiones espontáneas, predicciones sin evidencia | I think it will rain tomorrow. |
| going to               | planes/intenciones ya decididas, predicciones con evidencia | Look at those clouds, it's going to rain. |
| present continuous     | planes/citas ya organizadas (hora y lugar)   | I'm meeting her at 6pm.             |

## Will: decisión en el momento + predicción de opinión

Usás "will" cuando decidís algo AHORA MISMO, mientras hablás, sin haberlo planeado
antes:

```
A: The phone is ringing.
B: I'll get it!    (decisión espontánea, recién ahora)
```

También usás "will" para predicciones basadas en opinión, sin evidencia concreta
delante tuyo — típicamente con "I think", "I guess", "probably":

```
I think it will rain tomorrow.   (opinión, no ves nada ahora)
```

## Going to: plan ya decidido + predicción con evidencia

Usás "going to" cuando el plan YA estaba decidido antes de hablar, aunque no tenga
hora ni lugar exactos todavía:

```
I'm going to look for a new job.   (ya lo decidiste, es una intención)
```

También usás "going to" para predicciones cuando hay evidencia VISIBLE en el momento:

```
Look at those clouds, it's going to rain.   (ves las nubes ahora mismo)
```

## Present continuous: citas ya organizadas

Usás el present continuous cuando el plan ya tiene hora y/o lugar fijados — es una
cita concreta, no solo una intención:

```
I'm meeting her at 6pm.       (hora y lugar acordados)
We're having dinner with them on Friday.
```

## El truco práctico

Preguntate: ¿tengo hora y lugar? → present continuous. ¿Solo tengo la intención, sin
detalles? → going to. ¿Estoy decidiendo ahora mismo o dando mi opinión? → will.

```
I will call you.          (decisión espontánea)
I'm going to call you.    (ya lo tenía pensado)
I'm calling you at 5pm.   (cita fijada, hora exacta)
```
