"So" y "such" sirven para intensificar — dar más fuerza a lo que decís — pero se usan
en lugares distintos de la frase, y confundirlos es un error muy común en B1.

## La regla base

| Estructura                     | Ejemplo                |
| ------------------------------- | ------------------------ |
| so + adjetivo                   | I'm so tired.           |
| so + adverbio                   | She runs so quickly.    |
| such + a/an + sustantivo (+ adj.) | It was such a good idea. |
| such + sustantivo plural (+ adj.) | They are such nice people. |

## So: va antes de un adjetivo o adverbio SOLO

Cuando la palabra que sigue es solo un adjetivo o un adverbio — sin ningún sustantivo
después — usás "so":

```
I'm so tired.            (adjetivo solo)
She runs so quickly.     (adverbio solo)
This coffee is so hot.   (adjetivo solo)
```

## Such: va antes de un sustantivo (aunque tenga adjetivo delante)

Cuando después viene un sustantivo — con o sin adjetivo intercalado — usás "such". Si
el sustantivo es contable singular, agregá "a"/"an":

```
It was such a good idea.     (a + sustantivo con adjetivo)
They are such nice people.   (sustantivo plural con adjetivo)
It was such a mess.          (a + sustantivo, sin adjetivo)
```

## El truco práctico

Mirá la palabra que sigue inmediatamente después del hueco:

```
so + [adjetivo/adverbio, nada más] → so tired, so quickly
such + [sustantivo, con o sin adjetivo] → such a good idea, such nice people
```

Si dudás, preguntate: "¿la frase termina en un sustantivo?" Si la respuesta es sí,
por más que haya un adjetivo pegado delante ("good idea", "nice people"), la palabra
que manda es el sustantivo — y ahí va "such".

## Un error típico

```
❌ It was so good idea.       (falta el sustantivo, "idea" necesita "such a")
✅ It was such a good idea.

❌ I'm such tired.             ("tired" es adjetivo solo, necesita "so")
✅ I'm so tired.
```
