En inglés académico y formal, hay una preferencia marcada por convertir verbos y
adjetivos en sustantivos abstractos. Este proceso se llama **nominalización**, y es uno
de los rasgos que más distingue un texto académico de uno conversacional.

## La transformación básica: verbo/adjetivo → sustantivo

```
Verbo:        They analyzed the data.
Nominalizado: The analysis of the data revealed a pattern.

Adjetivo:     People are becoming aware of the issue.
Nominalizado: Public awareness of the issue is growing.
```

## Sufijos comunes de nominalización

| Sufijo | Verbo/adjetivo → sustantivo    |
| ------ | -------------------------------- |
| -tion  | decide → decision                |
| -sis   | analyze → analysis                |
| -ness  | aware → awareness                 |
| -ance  | perform → performance             |
| -ery   | discover → discovery              |
| -ment  | develop → development             |

## Por qué el inglés académico la prefiere

1. **Objetividad**: "The analysis revealed..." suena más impersonal que "We analyzed and found...", quita el foco de QUIÉN hizo la acción.
2. **Densidad de información**: permite empaquetar una acción entera en un sustantivo, dejando espacio para modificadores: "a careful, systematic analysis of the data".
3. **Registro formal**: papers, informes y ensayos académicos usan sustantivos abstractos como bloque estructural central de cada oración.

```
Conversacional:  We decided to change the policy because we became aware of the problem.
Académico:       The decision to change the policy followed growing awareness of the problem.
```

## El truco práctico

Cuando escribas en registro formal o académico, busca el verbo o adjetivo principal de
tu frase y pregúntate: ¿existe una forma nominal (-tion, -sis, -ness, -ment)? Si la hay,
úsala como sujeto u objeto de la oración — el verbo principal se vuelve algo más neutro
como "reveal", "show" o "lead to", y el sustantivo abstracto carga el peso del
significado.
