Comer en un restaurante frances es una experiencia cultural, y saber las frases
correctas te permite disfrutarla sin estres. Las frases son siempre las mismas:
lo unico que cambia es lo que pides.

## 1. Llegar y sentarse

```
Bonjour! Une table pour deux, s'il vous plait.
Buenos dias! Una mesa para dos, por favor.
```

Si reservaste:

```
J'ai une reservation au nom de Garcia.
Tengo una reserva a nombre de Garcia.
```

## 2. Pedir la carta

```
La carte, s'il vous plait.     La carta, por favor.
```

Diferencia importante: en Francia, **la carte** es la carta completa con todos
los platos. **Le menu** (o **la formule**) es un menu fijo con precio cerrado,
normalmente con tres opciones: entree (entrada), plat (plato principal) y
dessert (postre).

## 3. Preguntar y pedir

```
Qu'est-ce que vous recommandez?     Que recomienda?
Je voudrais le plat du jour.         Quisiera el plato del dia.
Je voudrais un steak, s'il vous plait.  Quisiera un bistec, por favor.
```

Si pides carne, el camarero preguntara **"Quelle cuisson?"** (que punto de
coccion):

| Frances   | Espanol           |
| --------- | ----------------- |
| saignant  | poco hecho / rojo |
| a point   | al punto / medio  |
| bien cuit | muy hecho         |

## 4. Bebidas

```
Une carafe d'eau, s'il vous plait.    Una jarra de agua, por favor.
Un verre de vin rouge, s'il vous plait.  Una copa de vino tinto, por favor.
```

Truco cultural: en Francia, el agua del grifo es potable y gratis en los
restaurantes. Pide **"une carafe d'eau"** y no te cobraran. Si pides "de l'eau"
sin especificar, pueden traerte agua embotellada (de pago).

## 5. Durante la comida

```
C'est delicieux!           Esta delicioso!
Encore un peu de pain?     Un poco mas de pan?
```

El pan en los restaurantes franceses normalmente es gratis y se repone.

## 6. Pedir la cuenta

```
L'addition, s'il vous plait.       La cuenta, por favor.
```

El camarero **no te traera la cuenta** hasta que la pidas -- es una cuestion
de cortesia: no quieren apurarte.

## La propina

El servicio esta incluido en el precio en Francia (es obligatorio por ley). No
necesitas dejar propina, pero dejar uno o dos euros es un gesto amable si el
servicio fue bueno. No se espera el 15-20% como en otros paises.
