El plural en frances se parece al espanol en lo basico (anadir una marca al
final de la palabra), pero tiene reglas propias y una diferencia clave: **la -s
del plural no se pronuncia**. Donde el espanol dice "gato" vs "gatos" y se oye
la diferencia, el frances dice "chat" y "chats" exactamente igual. La pista
esta en el articulo.

## Regla general: anadir -s (muda)

La mayoria de los sustantivos simplemente anaden una **-s** que no se pronuncia:

| Singular            | Plural     |
| ------------------- | ---------- |
| le livre (el libro) | les livres |
| la table (la mesa)  | les tables |
| le chat (el gato)   | les chats  |

El articulo definido siempre cambia a **les** en plural, sin importar el genero.

## Palabras en -eau / -au: plural en -eaux / -aux

Las palabras que terminan en **-eau** o **-au** hacen el plural anadiendo una
**-x** en lugar de una -s:

```
le chateau   ->   les chateaux
le bureau    ->   les bureaux
le gateau    ->   les gateaux
le noyau     ->   les noyaux
```

## Palabras en -al: plural en -aux

La terminacion **-al** cambia a **-aux**:

```
le journal   ->   les journaux
l'animal     ->   les animaux
le cheval    ->   les chevaux
```

Excepciones que mantienen -als: le festival -> les festivals, le carnaval -> les carnavals.

## Palabras en -s, -x, -z: no cambian

Si el singular ya termina en **-s**, **-x** o **-z**, el plural no anade nada:

```
le bras      ->   les bras    (el brazo / los brazos)
la voix      ->   les voix    (la voz / las voces)
le nez       ->   les nez     (la nariz / las narices)
```

## Plurales irregulares que debes memorizar

Algunos plurales no siguen ninguna regla:

| Singular | Plural    | Significado       |
| -------- | --------- | ----------------- |
| l'oeil   | les yeux  | el ojo / los ojos |
| monsieur | messieurs | senor / senores   |
| madame   | mesdames  | senora / senoras  |

## El truco: escucha el articulo

Ya que la -s final es muda, la forma de saber si algo es singular o plural en
el frances hablado es el articulo:

```
le chat  /lə ʃa/    vs    les chats  /le ʃa/
```

"Le" y "les" suenan diferente: ahi esta tu pista.
