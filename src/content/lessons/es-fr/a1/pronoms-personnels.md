Los pronombres personales sujeto son las primeras palabras que necesitas para
construir cualquier frase en frances. Si vienes del espanol, la buena noticia
es que el sistema es parecido: hay formas para yo, tu, el/ella, nosotros,
ustedes, ellos/ellas. Las diferencias estan en los detalles.

## La lista completa

| Persona                     | Frances                | Espanol             |
| --------------------------- | ---------------------- | ------------------- |
| 1a singular                 | je (j' antes de vocal) | yo                  |
| 2a singular informal        | tu                     | tu                  |
| 3a singular masculino       | il                     | el                  |
| 3a singular femenino        | elle                   | ella                |
| 3a singular impersonal      | on                     | uno / se / nosotros |
| 1a plural                   | nous                   | nosotros/as         |
| 2a plural / formal singular | vous                   | ustedes / usted     |
| 3a plural masculino/mixto   | ils                    | ellos               |
| 3a plural femenino          | elles                  | ellas               |

## "Tu" vs "vous": la diferencia que importa

En espanol tienes "tu" y "usted". En frances es igual, pero con una diferencia
importante: **vous** es tanto la forma de respeto (usted) como el plural
(ustedes/vosotros).

Usa **tu** con:

- amigos, familia, ninos, personas de tu edad en contextos informales

Usa **vous** con:

- desconocidos, personas mayores, en contextos profesionales, o simplemente
  cuando no tienes confianza con alguien

Si alguien te dice "On se tutoie?" te esta proponiendo pasar al "tu" -- es una
senal de confianza.

## El misterioso "on"

"On" es el pronombre que mas sorprende a los hispanohablantes. Oficialmente es
impersonal (como "uno" o "se" en espanol):

```
On parle francais ici.       Aqui se habla frances.
```

Pero en la vida real, los franceses lo usan como **sinonimo informal de
"nous"**:

```
On y va!                 Vamos!
On mange ensemble?       Comemos juntos?
```

Gramaticalmente, "on" se conjuga como la tercera persona del singular (como
"il/elle"), aunque signifique "nosotros":

```
On parle (no "on parlons")
```

## "Je" se convierte en "j'" antes de vocal

Cuando la palabra siguiente empieza por vocal o "h" muda, "je" pierde la "e"
y se pega con un apostrofo:

```
Je suis   (yo soy)
J'aime    (yo amo)     -- no "je aime"
J'habite  (yo vivo)    -- no "je habite"
```

## "Il" e "ils" vs "elle" y "elles"

El frances distingue el genero tambien en los pronombres plurales:

- **ils** = grupo masculino o mixto (basta un hombre en el grupo)
- **elles** = grupo exclusivamente femenino

```
Marie et Sophie? Elles sont francaises.
Pierre et Marie? Ils sont francais.
```
