Léa abre los ojos, mira el reloj y arranca su día: en esta lección la vas a
acompañar por su jornada de trabajo en francés, con el vocabulario que
necesitás para contar en qué trabajás vos también.

## La pregunta que te van a hacer

```
Qu'est-ce que tu fais dans la vie?     (¿A qué te dedicas?)
```

Fijate que el verbo es **"faire"** (hacer), no "travailler" — literalmente
"¿qué haces en la vida?".

## Las respuestas siguen siempre el mismo molde

```
Je travaille dans un bureau.       (Trabajo en una oficina)
Je travaille dans un magasin.      (Trabajo en una tienda)
Léa travaille dans un magasin.      (Léa trabaja en una tienda)
```

## El horario: de ... à ...

```
Je travaille de neuf heures à dix-sept heures.   (Trabajo de nueve a cinco)
Je fais une pause à onze heures.                  (Me tomo un descanso a las once)
J'ai une réunion à trois heures.                   (Tengo una reunión a las tres)
```

## Vocabulario de la oficina

| Francés         | Español              |
| ---------------- | --------------------- |
| le travail       | el trabajo             |
| le bureau        | la oficina              |
| le patron        | el jefe                  |
| la réunion       | la reunión                |
| faire une pause  | tomarse un descanso       |

## Una frase completa

```
Je travaille dans un bureau, de neuf heures à dix-sept heures, et je fais une pause à onze heures.
(Trabajo en una oficina, de nueve a cinco, y me tomo un descanso a las once)
```

## El truco para practicar

Contá tu propio día de trabajo en tres frases: dónde trabajás, tu horario y
cuándo hacés una pausa. Usá siempre la misma estructura y cambiá solo los
datos — así como hizo Léa para contarte el suyo.
