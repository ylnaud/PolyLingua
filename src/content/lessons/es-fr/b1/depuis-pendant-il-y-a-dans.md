Estas cuatro expresiones traducen al español palabras que se solapan ("hace",
"desde hace", "durante", "en"), pero en francés cada una tiene un uso muy preciso.
Confundirlas es uno de los errores más comunes de los hispanohablantes en este nivel.

## depuis: desde un punto que sigue vivo

"Depuis" señala el inicio de una acción que **continúa en el presente**. Se usa con
verbo en presente (aunque la acción haya empezado hace tiempo):

```
J'habite ici depuis 2020.
(Empecé a vivir aquí en 2020 y todavía vivo aquí.)
```

"Depuis" también funciona con una duración, no solo con una fecha:

```
J'apprends le français depuis trois ans.
(Empecé hace tres años y sigo aprendiendo.)
```

## pendant: duración cerrada, con principio y fin

"Pendant" mide cuánto duró (o durará) algo, sin importar si es pasado, presente o
futuro — lo importante es que tiene un final marcado:

```
J'ai voyagé pendant deux mois.
(El viaje empezó y terminó: duró dos meses completos.)
```

La diferencia con "depuis" es clave: "depuis" describe algo que sigue pasando ahora;
"pendant" describe un bloque de tiempo cerrado, ya sea en el pasado o proyectado.

## il y a: hace X tiempo (mirando hacia atrás)

"Il y a" + una cantidad de tiempo ubica un punto en el pasado, visto desde el
presente. Equivale exactamente al "hace" español:

```
Il y a trois ans, je vivais à Paris.
(Hace tres años, vivía en París.)
```

Cuidado: esta misma expresión "il y a" también significa "hay" (Il y a un problème =
Hay un problema). Cuando va seguida de una cantidad de tiempo, siempre significa
"hace".

## dans: en/dentro de (mirando hacia adelante)

"Dans" + tiempo señala un momento futuro, algo que todavía no ha ocurrido:

```
Je pars dans une heure.
(Me voy dentro de una hora — todavía no me he ido.)
```

## Los cuatro juntos, de un vistazo

| Expresión | Dirección                    | Ejemplo                       |
| --------- | ----------------------------- | ------------------------------ |
| depuis    | pasado → presente (continúa)  | J'habite ici depuis 2020.      |
| pendant   | duración cerrada (cualquiera) | J'ai voyagé pendant deux mois. |
| il y a    | presente → pasado (hace)      | Il y a trois ans...            |
| dans      | presente → futuro (en/dentro) | Je pars dans une heure.        |

El truco para no confundirlas: pregúntate si la acción **sigue pasando ahora**
(depuis), si **ya terminó o tiene un final marcado** (pendant), si estás **mirando
hacia atrás** (il y a) o **hacia adelante** (dans).
