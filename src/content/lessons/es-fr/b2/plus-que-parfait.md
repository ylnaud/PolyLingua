El plus-que-parfait cuenta lo que **ya había pasado** antes de otro momento del pasado
— exactamente como el pluscuamperfecto español ("había llegado", "habíamos comido").

## La fórmula

```
avoir/être (imparfait)  +  participe passé
```

| Verbo   | Auxiliar en imparfait | Plus-que-parfait  |
| ------- | ---------------------- | ------------------ |
| finir   | avait                   | il avait fini      |
| partir  | était                   | elle était partie  |
| manger  | avait                   | j'avais mangé      |
| arriver | étaient                 | ils étaient arrivés |

El auxiliar que usa cada verbo (avoir o être) es **el mismo** que usa en passé composé
— solo cambia la conjugación de ese auxiliar, de présent a imparfait.

## Por qué existe: dos pasados, uno antes del otro

Cuando una historia tiene dos acciones pasadas y una ocurrió **antes** que la otra, el
francés necesita marcar esa diferencia — igual que el español:

```
Quand je suis arrivé,  il était déjà parti.
(acción 1: llegué)     (acción 2, ANTERIOR: ya se había ido)
```

Si dijeras "il est parti" (passé composé) en vez de "il était parti", sonaría como si
las dos acciones fueran simultáneas o el orden se perdiera — la frase pierde precisión
temporal.

## Comparación español-francés

| Español                          | Francés                                |
| --------------------------------- | ---------------------------------------- |
| Cuando llegué, ya había comido.  | Quand je suis arrivé, j'avais déjà mangé. |
| Se había despertado antes que yo. | Elle s'était réveillée avant moi.       |
| Habíamos terminado el trabajo.    | Nous avions fini le travail.            |

La correspondencia es casi uno a uno: si en español necesitás "había + participio",
en francés casi seguro necesitás "avait/était + participe passé".

## El truco práctico

Preguntate: de las dos acciones pasadas de mi frase, ¿cuál pasó primero? Esa va en
plus-que-parfait. La que pasó después (o el punto de referencia) va en passé composé o
imparfait normal. Ese orden mental — "¿cuál fue antes?" — es la clave de todo el tiempo.
