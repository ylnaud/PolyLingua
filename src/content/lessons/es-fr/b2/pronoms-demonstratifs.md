Los pronombres demostrativos evitan repetir un sustantivo que ya mencionaste — igual
que en español decimos "el de Marie" en vez de "el libro de Marie".

## Las cuatro formas

| Género/número      | Pronombre |
| ------------------ | --------- |
| Masculino singular | celui     |
| Femenino singular  | celle     |
| Masculino plural   | ceux      |
| Femenino plural    | celles    |

El pronombre concuerda con el sustantivo que reemplaza — no con lo que viene después.

## La regla de oro: nunca van solos

A diferencia de "este/esta" en español, "celui/celle/ceux/celles" **siempre** necesitan
algo más después. Hay tres construcciones posibles:

### 1. Con -ci / -là (para señalar)

```
Je préfère celui-ci.   (Prefiero este.)
Je préfère celui-là.   (Prefiero ese/aquel.)
```

### 2. Con "de" (para indicar posesión)

```
celui de Marie          (el de Marie)
celle de mon frère       (la de mi hermano)
ceux de mes parents      (los de mis padres)
```

### 3. Con "qui" o "que" (para describir con una cláusula)

```
celui qui est rouge      (el que es rojo — sujeto)
celle que tu as achetée   (la que compraste — objeto)
```

## Ejemplo completo

```
J'ai deux stylos: celui-ci écrit bien, mais celui-là ne marche plus.
(Tengo dos bolígrafos: este escribe bien, pero ese ya no funciona.)

Ce ne sont pas mes clés, ce sont celles de Marie.
(No son mis llaves, son las de Marie.)
```

## El truco práctico

Antes de elegir la forma, identificá el género y número del sustantivo que estás
reemplazando (no el verbo ni lo que sigue). Después, elegí cómo lo vas a completar:
¿señalás algo (-ci/-là)? ¿marcás posesión (de)? ¿lo describís con una cláusula (qui/que)?
Esa secuencia de dos pasos resuelve el 100% de los casos.
