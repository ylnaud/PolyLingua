Este vocabulario te prepara para el registro específico del mundo corporativo
francófono: reuniones, correos y negociaciones, con su característica formalidad.

## Vocabulario esencial de oficina

| Francés               | Español                     |
| --------------------- | --------------------------- |
| la partie prenante    | parte interesada            |
| l'échéance            | fecha límite                |
| faire le point        | hacer un balance/evaluación |
| assurer le suivi      | dar seguimiento             |
| licencier quelqu'un   | despedir a alguien          |
| le chiffre d'affaires | los ingresos/facturación    |

## Fórmulas fijas para correos de negocios

```
Madame, Monsieur,                              (apertura muy formal, sin nombre)
Je me permets de vous contacter au sujet de... (me permito contactarle sobre...)
Je vous prie d'agréer mes salutations distinguées. (cierre muy formal)
```

## Suavizar el desacuerdo en reuniones

```
Je comprends votre point de vue, mais j'ai une perspective différente.
C'est une idée intéressante; cependant, je ne suis pas sûr que ce soit faisable.
```

## Presentar resultados con precisión

```
Le chiffre d'affaires a augmenté de 15% par rapport au trimestre dernier.
Nous sommes en bonne voie pour respecter l'échéance.
Il y a eu quelques difficultés avec le calendrier.
```

## Por qué vale la pena dominarlo

El francés de negocios es notablemente más formal y ceremonioso que su equivalente
inglés o incluso el español — dominar este registro específico te distingue como
alguien que entiende no solo el idioma, sino los códigos culturales del mundo
profesional francófono.
