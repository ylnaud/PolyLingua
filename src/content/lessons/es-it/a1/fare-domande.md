Hacer preguntas en italiano es sorprendentemente simple — de los cinco idiomas del
curso, es el que menos reglas nuevas exige.

## La regla de oro: solo cambia la entonación

```
Afirmación:   Tu parli italiano.
Pregunta:      Parli italiano?      (misma estructura, solo entonación/signo)
```

No necesitas invertir el sujeto, ni añadir auxiliares como "do" (inglés) o "est-ce
que" (francés) — el italiano confía completamente en la entonación, igual que el
español.

## Las palabras interrogativas esenciales

| Palabra   | Significado | Ejemplo                |
| --------- | ----------- | ---------------------- |
| Chi?      | ¿Quién?     | Chi sei?               |
| Cosa/Che? | ¿Qué?       | Cosa fai?              |
| Dove?     | ¿Dónde?     | Dove abiti?            |
| Quando?   | ¿Cuándo?    | Quando arrivi?         |
| Perché?   | ¿Por qué?   | Perché studi italiano? |
| Come?     | ¿Cómo?      | Come stai?             |
| Quanto?   | ¿Cuánto?    | Quanto costa?          |

## El orden con palabra interrogativa

```
[palabra interrogativa] + verbo + resto?

Dove    abiti?
Come    stai?
```

## Preguntas de sí/no: solo entonación

```
Hai fame?          (¿Tienes hambre?)
Vieni con noi?       (¿Vienes con nosotros?)
```

## El truco práctico

Como hispanohablante, este tema es de los más intuitivos del curso: la lógica de
"solo cambiar la entonación" ya es exactamente lo que haces en español. Enfoca tu
energía en memorizar el vocabulario de las palabras interrogativas, que es lo único
realmente nuevo aquí.
