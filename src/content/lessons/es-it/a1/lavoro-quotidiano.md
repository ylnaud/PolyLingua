Giulia abre los ojos, mira el reloj y arranca su día: en esta lección la vas
a acompañar por su jornada de trabajo en italiano, con el vocabulario que
necesitás para contar en qué trabajás vos también.

## La pregunta que te van a hacer

```
Che lavoro fai?          (¿A qué te dedicas?)
```

Fijate que el verbo es **"fare"** (hacer), no "lavorare" — literalmente
"¿qué trabajo haces?".

## Las respuestas siguen siempre el mismo molde

```
Lavoro in ufficio.        (Trabajo en una oficina)
Lavoro in un negozio.     (Trabajo en una tienda)
Giulia lavora in un negozio.  (Giulia trabaja en una tienda)
```

## El horario: dalle ... alle ...

```
Lavoro dalle nove alle sei.       (Trabajo de nueve a seis)
Faccio una pausa alle undici.     (Me tomo un descanso a las once)
Ho una riunione alle tre.          (Tengo una reunión a las tres)
```

## Vocabulario de la oficina

| Italiano       | Español             |
| -------------- | ------------------- |
| il lavoro      | el trabajo          |
| l'ufficio      | la oficina          |
| il capo        | el jefe             |
| la riunione    | la reunión          |
| fare una pausa | tomarse un descanso |

## Una frase completa

```
Lavoro in ufficio, dalle nove alle sei, e faccio una pausa alle undici.
(Trabajo en una oficina, de nueve a seis, y me tomo un descanso a las once)
```

## El truco para practicar

Contá tu propio día de trabajo en tres frases: dónde trabajás, tu horario y
cuándo hacés una pausa. Usá siempre la misma estructura y cambiá solo los
datos — así como hizo Giulia para contarte el suyo.
