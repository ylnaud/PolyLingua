Decir la hora en italiano te resultará muy familiar si vienes del español — la lógica
es prácticamente idéntica.

## La fórmula base

```
Sono le [hora].          (para todas las horas excepto la una)
È l'una.                   (excepción: la una, en singular)

Sono le due.               (Son las dos)
Sono le sette.               (Son las siete)
```

## Cuartos y medias

| Expresión      | Significado            |
| -------------- | ---------------------- |
| e un quarto    | y cuarto (+15 min)     |
| e mezza        | y media (+30 min)      |
| meno un quarto | menos cuarto (-15 min) |

```
3:15 = le tre e un quarto
3:30 = le tre e mezza
3:45 = le quattro meno un quarto
```

## Casos especiales

```
È mezzogiorno.        (es mediodía)
È mezzanotte.           (es medianoche)
```

## El sistema de 24 horas (formal)

Para horarios oficiales (trenes, citas), el italiano usa el sistema de 24 horas:

```
15:30 = le quindici e trenta         (3:30pm formal)
```

## Preguntar y responder

```
Che ora è?                    (¿Qué hora es?)
Sono le due e mezza.            (Son las dos y media)
A che ora...?                    (¿A qué hora...?)
```

Gracias al parecido estructural con el español (singular para "la una", plural para el
resto), este tema es de los más intuitivos del curso.
