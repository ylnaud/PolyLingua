A diferencia del español, donde añades una "-s" o "-es" al final, el italiano cambia
directamente la vocal final para formar el plural. Es un sistema diferente pero muy
regular: con tres reglas cubres el 90% de los casos.

## Las tres reglas base del plural

### 1. Palabras en -o (masculinas) → -i

| Singular   | Plural    | Español    |
| ---------- | --------- | ---------- |
| il libro   | i libri   | los libros |
| il ragazzo | i ragazzi | los chicos |
| il tavolo  | i tavoli  | las mesas  |

### 2. Palabras en -a (femeninas) → -e

| Singular   | Plural     | Español        |
| ---------- | ---------- | -------------- |
| la casa    | le case    | las casas      |
| la ragazza | le ragazze | las chicas     |
| la penna   | le penne   | los bolígrafos |

### 3. Palabras en -e (masculinas o femeninas) → -i

| Singular    | Plural       | Español         |
| ----------- | ------------ | --------------- |
| il pane     | i pani       | los panes       |
| la notte    | le notti     | las noches      |
| lo studente | gli studenti | los estudiantes |

## Los artículos también cambian en plural

No olvides que al pasar al plural, el artículo también se transforma:

| Singular   | Plural |
| ---------- | ------ |
| il         | i      |
| lo         | gli    |
| la         | le     |
| l' (masc.) | gli    |
| l' (fem.)  | le     |

## Casos especiales: palabras en -ca y -ga

Cuando una palabra femenina termina en **-ca** o **-ga**, el plural añade una **h** para
mantener el sonido duro de la consonante:

```
amica   →   amiche     (no "amice", que sonaría "amiche" con c suave)
bottega →   botteghe   (no "bottege")
```

Lo mismo pasa con las masculinas en **-co** y **-go**, aunque aquí hay más variación:

```
amico   →   amici      (la c se suaviza — excepción frecuente)
lago    →   laghi      (se conserva el sonido duro con h)
```

## Plurales irregulares que hay que memorizar

Algunos plurales no siguen ninguna regla:

| Singular   | Plural     | Español     |
| ---------- | ---------- | ----------- |
| l'uomo     | gli uomini | los hombres |
| il dito    | le dita    | los dedos   |
| il braccio | le braccia | los brazos  |
| l'uovo     | le uova    | los huevos  |

Estos plurales irregulares son pocos pero frecuentes. Muchos vienen del neutro latino y
cambian de género en plural (masculino singular → femenino plural).

## Palabras invariables

Algunas palabras no cambian en plural:

- Palabras terminadas en **consonante** (de origen extranjero): _il bar → i bar_, _il
  film → i film_
- Palabras terminadas en **vocal acentuada**: _la città → le città_, _il caffè → i caffè_
- Abreviaciones: _la foto → le foto_, _la moto → le moto_

## Resumen rápido

```
-o  →  -i    (libro → libri)
-a  →  -e    (casa → case)
-e  →  -i    (notte → notti)
-ca →  -che  (amica → amiche)
-ga →  -ghe  (bottega → botteghe)
```

Con estas reglas ya puedes formar correctamente el plural de la gran mayoría de
sustantivos italianos que encuentres.
