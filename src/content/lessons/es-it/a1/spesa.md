Giulia pasa por el mercado antes de volver a casa: acompañala en una compra
entera, resuelta con cuatro momentos fijos.

## 1. Pedir con cortesía

```
Vorrei un caffè.       Quisiera un café.
Vorrei del pane.        Quisiera pan.
```

"Vorrei" (en vez de "voglio") es la forma cortés de pedir — igual que
"quisiera" en español frente a "quiero".

## 2. Preguntar el precio

```
Quanto costa?          ¿Cuánto cuesta?
È troppo caro.          Es demasiado caro.
```

## 3. Decidir

```
Lo prendo.              Me lo llevo.
```

## 4. Pagar

```
Posso pagare con la carta?   ¿Puedo pagar con tarjeta?
Pago in contanti.             Pago en efectivo.
Grazie, è tutto.               Gracias, eso es todo.
```

## Una frase completa

```
Vorrei del pane, quanto costa? — Ah, è economico. Lo prendo. Posso pagare con la carta?
(Quisiera pan, ¿cuánto cuesta? — Ah, está barato. Me lo llevo. ¿Puedo pagar con tarjeta?)
```

## El truco para practicar

Antes de ir a comprar, decí en voz alta las cuatro frases en orden, como
hizo Giulia en el mercado. Son siempre las mismas: lo único que cambia es
el producto.
