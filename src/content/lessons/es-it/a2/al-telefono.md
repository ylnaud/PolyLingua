Giulia termina su pausa y tiene que hacer una llamada antes de volver al
trabajo: acompañala por una conversación telefónica típica en italiano,
donde casi todo es guion fijo.

## Atender y presentarte

```
Pronto?                  (¿Hola?)
Sono Giulia.              (Habla Giulia)
```

Para presentarte por teléfono se usa **"sono"** + tu nombre, la misma
fórmula que en persona, pero siempre después de "Pronto?".

## Pedir por alguien

```
Posso parlare con Marco?         (¿Puedo hablar con Marco?)
— Un momento, per favore.         (Un momento, por favor)
— Non c'è al momento.             (No está en este momento)
```

## Si no está

```
Posso lasciare un messaggio?      (¿Puedo dejar un mensaje?)
Richiamo più tardi.                (Llamo más tarde)
```

"Il messaggio" es el mensaje que le dejás a alguien — palabra clave de toda
esta lección.

## Cuando te equivocás de número

```
Scusi, ho sbagliato numero.       (Perdón, me equivoqué de número)
```

## Despedirse

```
Grazie, arrivederci!              (Gracias, ¡hasta luego!)
```

## El truco para practicar

Ensayá la llamada completa de Giulia en voz alta: atendés, te presentás,
pedís por alguien, te dicen que no está, dejás el mensaje y te despedís.
Seis frases seguidas, siempre las mismas — cuando te salgan sin pensar, el
teléfono deja de dar miedo.
