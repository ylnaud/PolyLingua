Comparar en italiano tiene una ventaja especial: además del comparativo normal, tienes
el "superlativo absoluto" con -issimo, un recurso muy expresivo que el español comparte
parcialmente.

## Las estructuras comparativas

| Estructura     | Significado  | Ejemplo                        |
| -------------- | ------------ | ------------------------------ |
| più... di      | más... que   | È più alto di me.              |
| meno... di     | menos... que | È meno timida di lui.          |
| (così)... come | tan... como  | È bello come te lo immaginavi. |

## El superlativo relativo: "el más..."

```
il/la più + adjetivo + di

È il ristorante più caro della città.
(Es el restaurante más caro de la ciudad)
```

## El superlativo absoluto: la joya italiana

```
adjetivo + -issimo/-issima

bello → bellissimo         (muy bonito/bellísimo)
buono → buonissimo           (buenísimo)
```

Este sufijo intensifica el adjetivo sin necesitar "molto" (muy) — una sola palabra
comunica la intensidad máxima.

## Los irregulares que hay que memorizar

| Positivo        | Comparativo | Superlativo relativo |
| --------------- | ----------- | -------------------- |
| buono (bueno)   | migliore    | il migliore          |
| cattivo (malo)  | peggiore    | il peggiore          |
| grande (grande) | maggiore    | il maggiore          |

## Practicando la estructura completa

```
Roma è bella, ma Firenze è bellissima!
Questo libro è più interessante di quello, ma non è il migliore che abbia letto.
```

## El truco práctico

Usa "più/meno...di" para comparar dos cosas específicas, "il/la più...di" para el
extremo de un grupo, y el sufijo -issimo cuando quieras intensificar algo sin comparar
con nada en particular — simplemente "muchísimo" de esa cualidad.
