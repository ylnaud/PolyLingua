Giulia termina su día con un mensaje de un amigo: quedaron para el fin de
semana. Estas son las frases para proponer, aceptar y cancelar planes en
italiano.

## 1. Proponer

```
Sei libero sabato?           ¿Estás libre el sábado?
Andiamo al cinema?            ¿Vamos al cine?
```

## 2. Aceptar o rechazar

```
Ci sto!                       ¡Me apunto!
D'accordo allora.              De acuerdo entonces.
Purtroppo non posso.           Lamentablemente no puedo.
```

"Ci sto!" es la forma italiana informal de aceptar un plan con
entusiasmo — literalmente "estoy ahí".

## 3. Acordar

```
A che ora ci vediamo?         ¿A qué hora nos vemos?
Alle otto davanti al cinema.   A las ocho frente al cine.
```

## 4. Cancelar

```
Purtroppo non posso venire.    Lamentablemente no puedo ir.
Ci vediamo domani.              Nos vemos mañana.
```

## Una frase completa

```
Sei libero sabato? Andiamo al cinema? — Ci sto! A che ora ci vediamo?
(¿Estás libre el sábado? ¿Vamos al cine? — ¡Me apunto! ¿A qué hora nos vemos?)
```

## El truco para practicar

Ensayá el intercambio completo en voz alta, haciendo los dos papeles: uno
propone, el otro acepta con "Ci sto!" y acuerdan la hora. Como hizo Giulia
para quedar con su amigo.
