Giulia termina la semana y le toca hacer un repaso: qué hizo ayer y qué
tiene planeado para mañana. No necesitás tiempos verbales nuevos — con el
passato prossimo y el presente que ya conocés alcanza.

## El pasado: passato prossimo

```
Cosa hai fatto ieri?            ¿Qué hiciste ayer?
Ho lavorato molto.               Trabajé mucho.
Ho incontrato un amico.          Me encontré con un amigo.
Ieri ho mangiato molto.          Ayer comí mucho.
```

## Negar en pasado

```
Non ho fatto niente.             No hice nada.
```

## El futuro: alcanza con el presente

Para hablar de mañana no hace falta un tiempo especial. Usás el
**presente** y agregás cuándo:

```
Domani lavoro.                   Mañana trabajo.
La settimana prossima sono libero.  La semana que viene estoy libre.
```

## Una frase completa

```
Ieri ho lavorato molto, ma domani sono libero.
(Ayer trabajé mucho, pero mañana estoy libre)
```

## El truco para practicar

Todas las noches, contá tu día en dos frases con passato prossimo y lo de
mañana en una frase en presente — como hizo Giulia para cerrar su semana.
Tres frases por día, siempre con la misma estructura.
