Estas preposiciones te permiten ubicar cosas en el espacio y hablar de cuándo pasan las
cosas — dos usos distintos de las mismas palabras clave que conviene aprender juntos.

## Preposiciones de lugar

| Italiano     | Español         |
| ------------ | --------------- |
| a            | en/a            |
| in           | en/dentro de    |
| su           | sobre/encima de |
| sotto        | debajo de       |
| davanti a    | delante de      |
| dietro       | detrás de       |
| tra / fra    | entre           |

```
Il gatto è sotto il tavolo.               (El gato está debajo de la mesa)
Il libro è tra il tavolo e la sedia.      (El libro está entre la mesa y la silla)
```

## Preposiciones de tiempo

Las mismas palabras "a", "in" y "tra/fra" también funcionan para hablar de tiempo, pero
con reglas distintas según lo que sigue:

| Uso                        | Ejemplo         | Significado           |
| --------------------------- | --------------- | ---------------------- |
| a + hora                   | alle 8          | a las 8                |
| in + mes/estación          | in gennaio      | en enero               |
| in + mes/estación          | in estate       | en verano              |
| tra/fra + tiempo futuro    | tra tre giorni  | dentro de tres días     |

```
Ci vediamo alle 8.        (Nos vemos a las 8)
Parto in gennaio.         (Me voy en enero)
Ci vediamo tra tre giorni. (Nos vemos dentro de tres días)
```

## El truco para no confundir "a" e "in"

"A" se usa con horas y ciudades ("a Roma"); "in" se usa con meses, estaciones y países
("in Italia", "in gennaio"). Si dudas entre las dos, piensa si lo que sigue es un punto
específico en el tiempo (a) o un período más amplio (in).
