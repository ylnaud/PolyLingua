Moverte por una ciudad italiana y entender indicaciones es una de las habilidades más
prácticas que puedes desarrollar — aquí tienes el vocabulario esencial de transporte y
direcciones.

## Medios de transporte

| Italiano  | Español    |
| --------- | ---------- |
| l'autobus | el autobús |
| il treno  | el tren    |
| il taxi   | el taxi    |
| la metro  | el metro   |

```
Prendo l'autobus per andare in centro.  (Tomo el autobús para ir al centro)
```

## Direcciones básicas

| Italiano          | Español              |
| ----------------- | -------------------- |
| girare a sinistra | girar a la izquierda |
| girare a destra   | girar a la derecha   |
| dritto            | todo recto           |
| accanto a         | al lado de           |
| di fronte a       | enfrente de          |
| vicino a          | cerca de             |

## Pedir y dar indicaciones

```
Come arrivo alla stazione?          (¿Cómo llego a la estación?)
Giri a sinistra all'angolo.         (Gire a la izquierda en la esquina)
Vai dritto e poi a destra.          (Sigue recto y luego a la derecha)
```

"Come arrivo a...?" es la pregunta estándar para pedir indicaciones sobre cómo llegar a
un lugar. La respuesta suele combinar "dritto" (recto) con "a sinistra/a destra"
(izquierda/derecha) para armar el recorrido completo.

## El truco para no confundir "dritto"

"Dritto" se parece a "derecho" en español, pero significa "todo recto" — si alguien te
dice "vai dritto", no gires, sigue caminando en línea recta. Para "a la derecha" usa
siempre "a destra".
