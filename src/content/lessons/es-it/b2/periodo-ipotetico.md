El "periodo ipotetico" es la estructura con "se" (si) que usás para condiciones. En
italiano hay tres tipos según cuán real o hipotética sea la condición — acá vemos los
dos primeros.

## Tipo 1: della realtà

Se cumple siempre que se da la condición — es casi una regla, no una hipótesis:

```
se + indicativo presente,  indicativo presente / imperativo

Se piove, resto a casa.        (Si llueve, me quedo en casa.)
Se studi, impari.               (Si estudias, aprendes.)
Se hai fame, mangia qualcosa.  (Si tienes hambre, come algo.)
```

Ambas partes usan indicativo — nada de subjuntivo ni condicional. Es la misma lógica
del español "si + presente, presente": una condición y su consecuencia habitual.

## Tipo 2: della possibilità

Describe algo hipotético, posible pero no seguro — imaginás un escenario presente o
futuro distinto del real:

```
se + congiuntivo imperfetto,  condizionale presente

Se avessi tempo, verrei alla festa.
   (Si tuviera tiempo, vendría a la fiesta — pero probablemente no lo tengo.)

Se fossi ricco, viaggerei sempre.
   (Si fuera rico, viajaría siempre — pero no lo soy.)
```

| Verbo (congiuntivo imperfetto) | io      | Ejemplo             |
| ------------------------------ | ------- | ------------------- |
| avere                          | avessi  | Se avessi soldi...  |
| essere                         | fossi   | Se fossi ricco...   |
| potere                         | potessi | Se potessi, verrei. |

## Comparando los dos tipos

| Tipo              | Fórmula                                             | Ejemplo                  |
| ----------------- | --------------------------------------------------- | ------------------------ |
| Della realtà      | se + indicativo presente + indicativo/imperativo    | Se piove, resto a casa.  |
| Della possibilità | se + congiuntivo imperfetto + condizionale presente | Se avessi tempo, verrei. |

## El próximo paso: el tercer tipo

Todavía queda un tercer tipo — el "periodo ipotetico dell'irrealtà" — para hablar de
condiciones pasadas que ya no se pueden cambiar ("si hubiera sabido, habría venido").
Ese usa el congiuntivo trapassato, un tema que retomamos en el nivel C1 como
continuación directa de esta misma estructura.
