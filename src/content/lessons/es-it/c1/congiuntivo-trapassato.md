En B2 viste dos tipos de periodo ipotetico: della realtà (se piove, resto a casa) y
della possibilità (se avessi tempo, verrei). Ahora llega el tercer tipo, **dell'irrealtà**,
para condiciones pasadas que ya no tienen vuelta atrás.

## La fórmula del congiuntivo trapassato

```
avere/essere (congiuntivo imperfetto)  +  participio passato
```

| Verbo   | avere      | essere    |
| ------- | ---------- | --------- |
| io      | avessi     | fossi     |
| tu      | avessi     | fossi     |
| lui/lei | avesse     | fosse     |
| noi     | avessimo   | fossimo   |
| voi     | aveste     | foste     |
| loro    | avessero   | fossero   |

```
avessi saputo   (hubiera sabido)
fossi arrivato   (hubiera llegado)
```

## El tercer tipo de periodo ipotetico: dell'irrealtà

```
se + congiuntivo trapassato,   condizionale passato

Se avessi saputo, sarei venuto.
   (Si hubiera sabido, habría venido.)
```

La diferencia con della possibilità (B2) es clave: acá la condición ya pasó y **ya no
se puede cambiar**. No es "quizás pase" — es "ya no pasó, y no hay nada que hacer".

## Comparando los tres tipos, uno al lado del otro

| Tipo               | Fórmula                                              | Ejemplo                              |
| ------------------- | ------------------------------------------------------ | --------------------------------------- |
| Della realtà        | se + indicativo presente + indicativo/imperativo       | Se piove, resto a casa.              |
| Della possibilità   | se + congiuntivo imperfetto + condizionale presente     | Se avessi tempo, verrei.             |
| Dell'irrealtà       | se + congiuntivo trapassato + condizionale passato       | Se avessi saputo, sarei venuto.      |

## Qué significa realmente

```
Se avessi saputo, sarei venuto.
```

En la realidad: NO supo a tiempo, y por eso NO vino. Es exactamente el mismo mecanismo
del español "si hubiera sabido, habría venido" — describe un pasado alternativo que
nunca ocurrió.

## Más ejemplos

```
Se fossi partito prima, non avrei perso il treno.
   (Si hubiera partido antes, no habría perdido el tren.)

Se avessimo studiato di più, avremmo superato l'esame.
   (Si hubiéramos estudiado más, habríamos aprobado el examen.)
```

## El truco para no perderte

Preguntate: ¿la condición ya pasó y ya no se puede cambiar? Si la respuesta es sí,
necesitás congiuntivo trapassato + condizionale passato — el "combo del arrepentimiento"
que cierra el periodo ipotetico.
