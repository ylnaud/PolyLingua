El futuro anteriore expresa una acción futura que **se completa antes** que otra
acción futura — y también sirve para especular sobre el pasado reciente sin
comprometerte del todo.

## La fórmula

```
avere/essere (futuro semplice)  +  participio passato
```

| Persona | avere (futuro) | essere (futuro) |
| ------- | -------------- | --------------- |
| io      | avrò           | sarò            |
| tu      | avrai          | sarai           |
| lui/lei | avrà           | sarà            |
| noi     | avremo         | saremo          |
| voi     | avrete         | sarete          |
| loro    | avranno        | saranno         |

## Uso 1: una acción futura anterior a otra

```
Quando avrò finito, ti chiamerò.
   (Cuando haya terminado, te llamaré.)

Quando sarò arrivato, ti scriverò.
   (Cuando haya llegado, te escribiré.)
```

Fijate el patrón: en español usás "cuando haya + participio", en italiano es "quando

- futuro anteriore" — el italiano usa futuro en las dos partes, mientras el español
  mezcla subjuntivo con futuro. Es un punto donde muchos hispanohablantes se equivocan
  por calcar la estructura española.

```
Español:   Cuando haya terminado, te llamaré.        (subjuntivo + futuro)
Italiano:  Quando avrò finito, ti chiamerò.           (futuro anteriore + futuro semplice)
```

## Uso 2: suponer sobre el pasado reciente

El segundo uso es menos intuitivo pero muy frecuente en italiano hablado: expresar una
conjetura sobre algo que probablemente ya ocurrió, sin decir explícitamente "creo que"
o "seguramente".

```
Non risponde al telefono. Avrà dimenticato il cellulare a casa.
   (No contesta el teléfono. Se habrá olvidado el celular en casa.)

Sono le tre e non è ancora arrivato: avrà perso il treno.
   (Son las tres y todavía no llegó: se habrá perdido el tren.)
```

Es exactamente el mismo mecanismo del español "se habrá olvidado" — una suposición
elegante, sin necesidad de un verbo introductorio como "creo" o "supongo".

## Los dos usos, uno al lado del otro

| Uso                                 | Ejemplo                          | Función                            |
| ----------------------------------- | -------------------------------- | ---------------------------------- |
| Acción futura anterior a otra       | Quando avrò finito, ti chiamerò. | Secuencia de dos acciones futuras  |
| Suposición sobre el pasado reciente | Avrà dimenticato il cellulare.   | Conjetura, sin verbo introductorio |

## El truco para reconocerlo rápido

Si ves "quando" + futuro anteriore, casi siempre es el Uso 1 (secuencia). Si el
futuro anteriore aparece solo, como respuesta a algo que no tiene explicación
inmediata, casi siempre es el Uso 2 (suposición).
