## La nominalización: el sello del italiano formal

Convertir verbos en sustantivos abstractos es la técnica más característica del estilo
formale:

| Verbo (registro neutro) | Sustantivo (registro formal) |
| ----------------------- | ---------------------------- |
| decidere                | la decisione                 |
| analizzare              | l'analisi                    |
| aumentare               | l'aumento                    |
| attuare                 | l'attuazione                 |

```
Neutro:    Il governo ha deciso di aumentare le tasse.
Formale:   La decisione del governo di aumentare le tasse ha suscitato dibattiti.
```

## Conectores formales vs. cotidianos

| Cotidiano | Formale                          |
| --------- | -------------------------------- |
| però      | tuttavia / nondimeno             |
| perché    | poiché / giacché                 |
| anche se  | sebbene / benché                 |
| molto     | notevolmente / considerevolmente |

## Vocabulario elevado

| Cotidiano | Formale                  |
| --------- | ------------------------ |
| mostrare  | dimostrare / evidenziare |
| aiutare   | contribuire a            |
| dire      | affermare / sostenere    |

## Cuándo usarlo (y cuándo evitarlo)

El estilo formale es perfecto para ensayos, informes, discursos y textos periodísticos
serios. Usarlo en una conversación casual con amigos sonaría tan extraño como hablar en
tono de discurso oficial en una charla de café — el verdadero dominio del C2 está en
saber **cuándo** activar este registro, no solo en saber usarlo.
