Marina pasa por el mercado antes de volver a casa: acompañala en una compra
entera, resuelta con cuatro momentos fijos.

## 1. Pedir con cortesía

```
Eu queria um café.       Quisiera un café.
Eu queria pão.            Quisiera pan.
```

"Queria" (en vez de "quero") es la forma cortés de pedir — igual que
"quisiera" en español frente a "quiero".

## 2. Preguntar el precio

```
Quanto custa isso?        ¿Cuánto cuesta esto?
Está muito caro.          Está muy caro.
```

## 3. Decidir

```
Eu levo isso.             Me llevo esto.
```

## 4. Pagar

```
Posso pagar com cartão?   ¿Puedo pagar con tarjeta?
Eu pago em dinheiro.      Pago en efectivo.
Obrigada, é só isso.      Gracias, eso es todo.
```

## Una frase completa

```
Eu queria pão, quanto custa? — Ah, está barato. Eu levo. Posso pagar com cartão?
(Quisiera pan, ¿cuánto cuesta? — Ah, está barato. Me lo llevo. ¿Puedo pagar con tarjeta?)
```

## El truco para practicar

Antes de ir a comprar, decí en voz alta las cuatro frases en orden, como hizo
Marina en el mercado. Son siempre las mismas: lo único que cambia es el
producto.
