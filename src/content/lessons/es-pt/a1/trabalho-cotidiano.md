Marina abre los ojos, mira el reloj y arranca su día: en esta lección la vas a
acompañar por su jornada de trabajo en portugués, con el vocabulario que
necesitás para contar en qué trabajás vos también.

## La pregunta que te van a hacer

```
O que você faz?          (¿A qué te dedicas?)
```

Y las respuestas siguen siempre el mismo molde:

```
Eu trabalho numa loja.        (Trabajo en una tienda)
Eu trabalho num escritório.   (Trabajo en una oficina)
Eu trabalho de casa.          (Trabajo desde casa)
```

## El horario: das ... às ...

```
Eu trabalho das nove às seis.     (Trabajo de nueve a seis)
Meu expediente começa às nove.    (Mi horario empieza a las nueve)
```

"Expediente" es la palabra clave acá — y un falso amigo importante: no es un
documento, es tu horario de trabajo.

## El descanso de Marina

```
Marina faz uma pausa às onze.     (Marina se toma un descanso a las once)
Ela tem uma reunião às três.      (Ella tiene una reunión a las tres)
```

## Una frase completa

```
Eu trabalho num escritório, das nove às seis, e faço uma pausa ao meio-dia.
(Trabajo en una oficina, de nueve a seis, y me tomo un descanso al mediodía)
```

## El truco para practicar

Contá tu propio día de trabajo en tres frases: dónde trabajás, tu horario y
cuándo hacés una pausa. Usá siempre la misma estructura y cambiá solo los
datos — así como hizo Marina para contarte el suyo.
