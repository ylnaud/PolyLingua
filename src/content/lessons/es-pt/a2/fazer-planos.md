Marina termina su día con un mensaje de un amigo: quedaron para el fin de
semana. Estas son las frases para proponer, aceptar y cancelar planes en
portugués.

## 1. Proponer

```
Você tem tempo no sábado?      ¿Tenés tiempo el sábado?
Vamos ao cinema?                ¿Vamos al cine?
```

## 2. Aceptar o rechazar

```
Eu topo!                        ¡Me apunto!
Combinado então.                 Trato hecho entonces.
Infelizmente não posso.          Lamentablemente no puedo.
```

"Topar" es la palabra clave en portugués brasileño para aceptar un plan
con entusiasmo — mucho más natural que un simple "sim".

## 3. Acordar

```
A que horas nos encontramos?    ¿A qué hora nos encontramos?
Às oito na frente do cinema.     A las ocho frente al cine.
```

## 4. Cancelar

```
Infelizmente não posso ir.       Lamentablemente no puedo ir.
Nos vemos amanhã.                 Nos vemos mañana.
```

## Una frase completa

```
Você tem tempo no sábado? Vamos ao cinema? — Eu topo! A que horas nos encontramos?
(¿Tenés tiempo el sábado? ¿Vamos al cine? — ¡Me apunto! ¿A qué hora nos encontramos?)
```

## El truco para practicar

Ensayá el intercambio completo en voz alta, haciendo los dos papeles: uno
propone, el otro acepta con "Eu topo!" y acuerdan la hora. Como hizo
Marina para quedar con su amigo.
