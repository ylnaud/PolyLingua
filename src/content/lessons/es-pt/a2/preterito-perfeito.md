Si vienes de estudiar alemán, francés o italiano en PolyLingua, esta lección te va a dar
una sorpresa agradable: el portugués simplifica las cosas.

## La gran diferencia con los otros idiomas

Alemán, francés e italiano forman su pasado cotidiano con **auxiliar + participio**
(Perfekt, passé composé, passato prossimo). El portugués, como el español, usa una
**sola palabra conjugada**:

```
Español:     Yo hablé.
Portugués:   Eu falei.        (una sola palabra, sin auxiliar)

Francés:     J'ai parlé.      (dos palabras: auxiliar + participio)
```

## Las conjugaciones regulares

| Pronombre | falar (-ar)     | comer (-er)     | abrir (-ir)     |
| --------- | --------------- | --------------- | --------------- |
| eu        | falei           | comi            | abri            |
| tu/você   | falaste / falou | comeste / comeu | abriste / abriu |
| ele/ela   | falou           | comeu           | abriu           |
| nós       | falamos         | comemos         | abrimos         |
| eles/elas | falaram         | comeram         | abriram         |

## El cuidado con "ter + particípio"

El portugués SÍ tiene una estructura "ter + participio" (tenho falado), pero **no
significa lo mismo que en otros idiomas**: en vez de describir un evento puntual del
pasado, describe algo repetitivo o continuo hasta ahora:

```
Eu falei com ela ontem.        (Hablé con ella ayer — evento puntual → pretérito simples)
Eu tenho falado muito com ela. (He estado hablando mucho con ella — repetitivo)
```

Este es el error más común de quien viene de estudiar francés o alemán primero: no
"inventes" un auxiliar donde el portugués usa la forma simple.

## Verbos irregulares imprescindibles

| Infinitivo | eu     | ele/ela |
| ---------- | ------ | ------- |
| ser/ir     | fui    | foi     |
| estar      | estive | esteve  |
| ter        | tive   | teve    |
| fazer      | fiz    | fez     |

Nota la curiosidad: "ser" e "ir" comparten exactamente las mismas formas en pretérito
—"fui" puede significar "fui" (de ir) o "fui" (de ser)— y el contexto siempre aclara
cuál es.
