Más allá de "não", el portugués tiene varias herramientas para negar con precisión y
matiz — muy útiles en un nivel B1 para sonar más natural.

## "Nem": ni / tampoco

```
Eu não bebo, nem fumo.       (No bebo, ni fumo)
Nem eu sei a resposta.         (Ni yo sé la respuesta)
```

## "Nem... nem...": ni... ni...

```
Ela não gosta nem de café nem de chá.
(A ella no le gusta ni el café ni el té)
```

## "Nem sequer": ni siquiera

```
Nem sequer tentei consertar.       (Ni siquiera intenté arreglarlo)
```

## "Tampouco": tampoco

```
Eu não fui à festa, e ela tampouco.
(Yo no fui a la fiesta, y ella tampoco)
```

## "De jeito nenhum" / "de forma alguma": de ninguna manera

```
Você vai desistir? De jeito nenhum!
(¿Vas a rendirte? ¡De ninguna manera!)
```

## Combinando varias estructuras

```
Nem sequer me convidaram, e eu tampouco teria ido.
(Ni siquiera me invitaron, y yo tampoco habría ido)
```

## Un consejo práctico

Estas estructuras aparecen constantemente en conversación real y en textos — dominarlas
te permite pasar de negaciones básicas y repetitivas a un portugués con matices reales.
