El pretérito mais-que-perfeito composto es el pluscuamperfecto de todos los días en
portugués: la forma que vas a escuchar y usar constantemente para hablar de "lo que ya
había pasado" antes de otra cosa en el pasado.

## Cómo se forma

```
imperfeito de TER (tinha)  +  particípio del verbo principal
```

| Pessoa          | tinha + particípio |
| --------------- | ------------------- |
| eu              | tinha saído         |
| tu              | tinhas saído        |
| ele/ela/você    | tinha saído         |
| nós             | tínhamos saído      |
| vós             | tínheis saído       |
| eles/elas/vocês | tinham saído        |

## El participio NO concuerda

Esta es la trampa más común para quien ya conoce la voz pasiva de portugués (donde el
participio sí concuerda con el sujeto, como en "a carta foi escrita"). En los tiempos
compuestos con "ter", el participio se queda **siempre invariable**, en masculino
singular:

```
Ela tinha saído.      (NO "tinha saída")
Eles tinham chegado.  (NO "tinham chegados")
```

## Para qué sirve: dos acciones pasadas, una antes que la otra

```
Quando cheguei, ele já tinha saído.
(Cuando llegué, él ya había salido — primero salió él, después llegué yo)

Ela já tinha comido quando o telefone tocou.
(Ella ya había comido cuando sonó el teléfono)
```

El adverbio "já" (ya) aparece constantemente junto a este tiempo, reforzando la idea de
que la acción ya estaba completa antes de la otra.

## No lo confundas con el mais-que-perfeito literario (nivel C1)

Este mismo significado también existe en una forma simple de una sola palabra, muy
propia de la literatura: "ele saíra" en vez de "ele tinha saído". Esa forma literaria
casi no aparece en el habla — en portugués cotidiano, casi el cien por ciento de las
veces vas a usar **esta** forma compuesta con "tinha", no la simple.

## Truco práctico

Si podés decir "ya había [verbo]" en español, casi seguro necesitás "tinha +
particípio" en portugués — sin preocuparte por concordancia de género o número en el
participio.
