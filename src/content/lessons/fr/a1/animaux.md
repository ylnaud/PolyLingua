Hablar de animales es uno de los primeros temas divertidos en cualquier idioma —
mascotas en casa, animales de granja y animales salvajes que ves en el zoo o en
documentales. Aquí tienes el vocabulario básico junto con "être" y "avoir" para
describirlos.

## Mascotas comunes

| Francés     | Español  |
| ----------- | -------- |
| le chien    | el perro |
| le chat     | el gato  |
| le poisson  | el pez   |
| l'oiseau    | el pájaro |

## Animales de granja y salvajes

| Francés      | Español    |
| ------------ | ---------- |
| la vache     | la vaca    |
| le cheval    | el caballo |
| le lion      | el león    |
| l'éléphant   | el elefante |

## Describir animales con "être" y "avoir"

```
J'ai un chat.                (Tengo un gato)
Le chien est grand.          (El perro es grande)
Le lion est fort.            (El león es fuerte)
```

"Avoir" (tener) se usa para decir qué animal tienes, y "être" (ser/estar) para
describir cómo es.

## El truco del artículo

Aprende cada animal siempre junto a su artículo (le/la/l') desde el principio: le
chien, la vache, l'oiseau. Así memorizas el género al mismo tiempo que la palabra, en
vez de tener que adivinarlo después.
