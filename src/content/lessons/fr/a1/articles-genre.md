Si hablas español, ya entiendes el concepto de género gramatical — la ventaja es enorme.
El reto está en que las palabras francesas no siempre "heredan" el mismo género que sus
equivalentes en español.

## Los artículos definidos

| Género                 | Singular | Ejemplo                 |
| ---------------------- | -------- | ----------------------- |
| Masculino              | le       | le livre (el libro)     |
| Femenino               | la       | la table (la mesa)      |
| Antes de vocal (ambos) | l'       | l'ami (el amigo)        |
| Plural (ambos géneros) | les      | les livres / les tables |

## Los artículos indefinidos

| Género    | Singular | Plural |
| --------- | -------- | ------ |
| Masculino | un       | des    |
| Femenino  | une      | des    |

Nota algo curioso: en plural, el francés **no distingue género** en el artículo
indefinido — "des" sirve para ambos.

## Patrones que sí ayudan

| Terminación       | Género casi siempre | Ejemplo                  |
| ----------------- | ------------------- | ------------------------ |
| -tion, -sion      | femenino            | la nation, la télévision |
| -ment             | masculino           | le gouvernement          |
| -eau              | masculino           | le bureau, le château    |
| -e (muchos casos) | femenino            | la chaise, la porte      |

## La trampa de traducir del español

No confíes en tu intuición de hispanohablante: "le lait" (la leche), "le soleil" (el
sol), "la voiture" (el carro/coche) — algunos coinciden, otros no. La única forma segura
es aprender cada sustantivo **con su artículo pegado**, como si fueran una sola palabra.
