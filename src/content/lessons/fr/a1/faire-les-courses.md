Comprar en Francia se resuelve con un punado de frases que siempre se repiten.
Aprendelas como bloques y podras entrar a cualquier tienda o supermercado sin
improvisar.

## 1. Pedir o buscar un producto

```
Je voudrais une baguette, s'il vous plait.   Quisiera una baguette, por favor.
Je cherche du pain.                           Busco pan.
Vous avez des tomates?                        Tiene tomates?
```

**Je voudrais** es la forma cortes de pedir, equivalente a "quisiera" en
espanol. Evita "je veux" (quiero), que suena demasiado directo.

## 2. Preguntar el precio

```
Combien ca coute?       Cuanto cuesta?
C'est combien?          Cuanto es? (mas informal)
```

Si el precio te parece alto:

```
C'est trop cher.        Es demasiado caro.
```

## 3. Decidir

```
Je prends ca.           Me llevo esto.
Je prends celui-la.     Me llevo ese.
```

## 4. Pagar

```
Je paie par carte.      Pago con tarjeta.
Je paie en especes.     Pago en efectivo.
Un sac, s'il vous plait.  Una bolsa, por favor.
Merci, c'est tout.      Gracias, eso es todo.
```

## Las tiendas especializadas

En Francia, muchas personas todavia compran en tiendas especializadas ademas
del supermercado:

| Tienda | Que vende |
| --- | --- |
| la boulangerie | pan y baguettes |
| la patisserie | pasteles y dulces |
| la boucherie | carne |
| la fromagerie | quesos |
| le marche | mercado al aire libre |
| le supermarche | supermercado |

## El protocolo en una tienda pequena

1. Al entrar: **"Bonjour!"**
2. El vendedor pregunta: "Qu'est-ce que je vous sers?" (Que le sirvo?)
3. Tu pides: **"Je voudrais..., s'il vous plait"**
4. El vendedor pregunta si quieres algo mas: "Et avec ceci?" (Y con esto?)
5. Si no: **"Merci, c'est tout"**
6. Pagas y al salir: **"Merci, au revoir!"**
