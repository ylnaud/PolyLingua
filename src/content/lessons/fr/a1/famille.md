Presentar a tu familia es una de las primeras conversaciones reales en francés. Aquí
tienes el vocabulario esencial, con sus artículos.

## La familia nuclear

| Francés | Español |
| --- | --- |
| la famille | la familia |
| le père / la mère | el padre / la madre |
| les parents | los padres |
| le fils / la fille | el hijo / la hija |
| le frère / la sœur | el hermano / la hermana |

## La familia extendida

| Francés | Español |
| --- | --- |
| la grand-mère / le grand-père | la abuela / el abuelo |
| la tante / l'oncle | la tía / el tío |
| le cousin / la cousine | el primo / la prima |

## Hablar de tu familia

```
J'ai deux frères et une sœur.       (Tengo dos hermanos y una hermana)
Ma mère s'appelle Anne.               (Mi madre se llama Anne)
Mon frère a vingt ans.                 (Mi hermano tiene veinte años)
```

## Un detalle: "l'enfant" y el género oculto

"enfant" (niño/a) usa "l'" por la vocal inicial, sin revelar el género — para
especificar, necesitas contexto o un adjetivo: "un enfant" (un niño) vs. "une enfant"
(una niña), aunque en la práctica muchos hablantes usan el masculino de forma genérica.

## El truco de las parejas

Aprende cada palabra junto a su contraparte de género: père/mère, frère/sœur,
fils/fille. Ese emparejamiento duplica tu vocabulario útil con el mismo esfuerzo, y
refuerza el patrón le/la que ya conoces de tu primera lección.
