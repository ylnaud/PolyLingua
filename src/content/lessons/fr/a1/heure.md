Decir la hora en francés combina un vocabulario específico con la estructura "il est"
(son las...).

## La fórmula base

```
Il est [hora] heure(s).

Il est une heure.        (es la una)
Il est trois heures.      (son las tres)
```

## Cuartos y medias

| Expresión | Significado |
| --- | --- |
| et quart | y cuarto (+15 min) |
| et demie | y media (+30 min) |
| moins le quart | menos cuarto (-15 min) |

```
3:15 = trois heures et quart
3:30 = trois heures et demie
3:45 = quatre heures moins le quart
```

## El sistema de 24 horas (formal)

Para horarios oficiales (trenes, citas, televisión), el francés usa el sistema de 24
horas sin "et quart/demie":

```
15h30 = quinze heures trente        (3:30pm formal)
9h15 = neuf heures quinze            (9:15am formal)
```

## Casos especiales

```
Il est midi.        (es mediodía)
Il est minuit.        (es medianoche)
Il est midi et demi.  (mediodía y media — sin "e" en "demi")
```

## Preguntar y responder

```
Quelle heure est-il?          (¿Qué hora es?)
Il est deux heures.            (Son las dos)
À quelle heure...?              (¿A qué hora...?)
```

Con práctica, alternar entre el sistema coloquial (et quart/moins le quart) y el
formal de 24 horas se vuelve automático — igual que en español al distinguir "las 3 y
cuarto" de "las 15:15".
