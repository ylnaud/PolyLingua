El imperativo sirve para dar ordenes, instrucciones, consejos o invitaciones.
En frances, como en espanol, se conjuga en tres personas: tu, nous y vous --
sin necesidad de escribir el pronombre.

## Como se forma

Se toma la conjugacion del presente de indicativo y se quita el pronombre:

| Persona | Presente | Imperativo |
| --- | --- | --- |
| tu | tu finis | Finis! |
| nous | nous finissons | Finissons! |
| vous | vous finissez | Finissez! |

## La regla especial de los verbos en -er

Para los verbos del primer grupo (terminados en -er), la forma "tu" **pierde la
-s** final:

```
tu parles    ->    Parle!     (no "Parles!")
tu manges    ->    Mange!     (no "Manges!")
tu regardes  ->    Regarde!   (no "Regardes!")
```

Esta regla solo afecta a la forma "tu" de los verbos en -er. Los verbos del
segundo (-ir) y tercer grupo mantienen la -s:

```
tu finis     ->    Finis!     (con -s, normal)
tu ecris     ->    Ecris!     (con -s, normal)
```

## Imperativos irregulares

Tres verbos muy comunes tienen imperativos completamente irregulares:

### Etre (ser/estar)

| Persona | Imperativo |
| --- | --- |
| tu | sois |
| nous | soyons |
| vous | soyez |

```
Sois sage!          Se bueno!
Soyons patients!    Seamos pacientes!
Soyez les bienvenus!  Sean bienvenidos!
```

### Avoir (tener/haber)

| Persona | Imperativo |
| --- | --- |
| tu | aie |
| nous | ayons |
| vous | ayez |

```
Aie confiance!       Ten confianza!
Ayons du courage!    Tengamos valor!
N'ayez pas peur!     No tengan miedo!
```

### Savoir (saber)

| Persona | Imperativo |
| --- | --- |
| tu | sache |
| nous | sachons |
| vous | sachez |

```
Sache que je suis la.    Sabe que estoy aqui.
Sachez que c'est interdit.  Sepan que esta prohibido.
```

## El imperativo negativo

Para la forma negativa, se envuelve el verbo entre "ne" y "pas":

```
Ne parle pas!           No hables!
Ne mangeons pas ici!    No comamos aqui!
N'ayez pas peur!        No tengan miedo!
```

## Usos cotidianos

El imperativo no solo sirve para dar ordenes. Tambien se usa para:

- **Invitaciones**: Mangeons ensemble! (Comamos juntos!)
- **Consejos**: Fais attention! (Ten cuidado!)
- **Instrucciones**: Tournez a droite. (Gire a la derecha.)
- **Animo**: Sois courageux! (Se valiente!)
