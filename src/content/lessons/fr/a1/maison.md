Describir tu casa es una de las conversaciones más comunes al conocer gente nueva o
alquilar un piso. Aquí tienes el vocabulario esencial de las habitaciones y los
muebles, junto con la fórmula "il y a" para describirlas.

## Las habitaciones

| Francés          | Español      |
| ----------------- | ------------ |
| la cuisine         | la cocina    |
| la chambre         | el dormitorio |
| la salle de bains  | el baño      |
| le salon           | el salón     |

## Los muebles básicos

| Francés     | Español    |
| ----------- | ---------- |
| le lit      | la cama    |
| la table    | la mesa    |
| la chaise   | la silla   |
| le canapé   | el sofá    |

## "Il y a": la fórmula para describir

"Il y a" significa "hay" y es invariable: se usa igual para una cosa o para varias,
en singular o en plural.

```
Il y a une table dans la cuisine.        (Hay una mesa en la cocina)
Il y a un lit dans la chambre.           (Hay una cama en el dormitorio)
Il y a une chaise dans le salon.         (Hay una silla en el salón)
```

## El truco de "il y a"

A diferencia de otros verbos franceses, "il y a" nunca cambia de forma —
ni con el número de cosas, ni con el género. Aprendida una vez, sirve para describir
cualquier habitación de la casa con solo cambiar el sustantivo y el lugar.
