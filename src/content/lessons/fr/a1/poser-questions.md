El francés ofrece tres caminos para hacer la misma pregunta, cada uno apropiado para
un contexto distinto — una flexibilidad que vale la pena dominar desde el principio.

## Las tres formas, de informal a formal

| Forma | Estructura | Ejemplo |
| --- | --- | --- |
| Entonación (informal) | Frase normal + ? | Tu parles français? |
| Est-ce que (neutral) | Est-ce que + frase normal? | Est-ce que tu parles français? |
| Inversión (formal) | Verbo-sujeto? | Parles-tu français? |

## Entonación: la más simple

Solo toma la frase afirmativa y sube el tono de voz al final (por escrito, añade "?"):

```
Tu es fatigué.    →    Tu es fatigué?
```

## Est-ce que: la más versátil

Añade "est-ce que" al principio, sin cambiar nada más:

```
Tu aimes le café.    →    Est-ce que tu aimes le café?
```

Con palabras interrogativas:

```
Où est-ce que tu habites?      (¿Dónde vives?)
Pourquoi est-ce que tu pars?    (¿Por qué te vas?)
```

## Inversión: la más formal

Invierte el verbo y el pronombre, unidos por un guión:

```
Tu parles français.    →    Parles-tu français?
Vous habitez ici.       →    Habitez-vous ici?
```

Con "il/elle" y un verbo terminado en vocal, se añade "-t-" para facilitar la
pronunciación:

```
Il parle.    →    Parle-t-il?
```

## El truco para elegir

En conversación cotidiana con amigos, la entonación o "est-ce que" son perfectamente
naturales. Reserva la inversión para contextos más formales o escritos — como cuando
eliges "¿podrías...?" en vez de "¿puedes...?" en español.
