Las vocales nasales son probablemente el sonido mas "frances" que existe -- y el
que mas cuesta a los hispanohablantes porque en espanol no tenemos nada
parecido. La buena noticia: son solo cuatro sonidos, y con un truco mecanico se
aprenden rapido.

## Que es una vocal nasal

Es una vocal que se pronuncia dejando salir parte del aire por la nariz, en
lugar de solo por la boca. Cuando ves "an", "on", "in" o "un" en frances, la
letra "n" (o "m") NO se pronuncia como consonante: solo indica que la vocal
anterior es nasal.

```
bon    = /bɔ̃/    (NO se dice "bonn" con n espanola)
pain   = /pɛ̃/    (NO se dice "pa-in" como dos silabas)
```

## Las cuatro nasales

### 1. /ɑ̃/ -- escrito: an, am, en, em

Suena como una "a" profunda que vibra en la nariz.

```
enfant      nino/a
restaurant  restaurante
chambre     habitacion
```

Nota: "an" y "en" suenan **igual** en frances moderno.

### 2. /ɔ̃/ -- escrito: on, om

Suena como una "o" redondeada y nasal.

```
bonjour     buenos dias
maison      casa
nom         nombre
```

### 3. /ɛ̃/ -- escrito: in, im, ain, aim, ein, ien

Suena como una "e" abierta y nasal.

```
vin         vino
pain        pan
jardin      jardin
bien        bien
```

### 4. /œ̃/ -- escrito: un, um

Suena como una mezcla entre /ɔ̃/ y /ɛ̃/, con labios redondeados. Muchos
franceses modernos ya la pronuncian igual que /ɛ̃/, asi que si no la distingues,
no pasa nada.

```
un          uno
lundi       lunes
brun        marron
```

## El truco para practicar

Tapa tu nariz con los dedos y di "ba". Ahora suelta la nariz y di "bon" sin
cerrar los labios para la "n": el aire debe salir por la nariz al final. Si
sientes vibracion en la nariz, lo estas haciendo bien.

## Cuando NO es nasal

Si despues de la "n" o "m" viene una vocal o otra "n/m", el sonido NO es nasal:

```
bonne  = /bɔn/   (la n se pronuncia porque le sigue una e)
animal = /a.ni.mal/  (la n se pronuncia porque le sigue una vocal)
```
