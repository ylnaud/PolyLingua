Léa cierra la semana pensando en sus gastos: está ahorrando para un viaje,
así que estas son las frases del dinero que más usa.

## La pregunta que hay que hacer primero

```
Je peux payer par carte?               ¿Puedo pagar con tarjeta?
— Seulement en liquide, s'il vous plaît. Solo efectivo, por favor.
```

Conviene preguntarlo **antes** de pedir, no después.

## Sacar plata

```
Je dois retirer de l'argent.       Necesito sacar dinero.
Où est un distributeur?             ¿Dónde hay un cajero automático?
Je n'ai pas de liquide sur moi.     No tengo efectivo encima.
```

"Liquide" es efectivo en francés — no confundirlo con "líquido" en el
sentido literal.

## Ahorro y gastos

```
J'économise pour un voyage.        Estoy ahorrando para un viaje.
Combien je te dois?                 ¿Cuánto te debo?
```

## Una frase completa

```
Je dois retirer de l'argent parce que j'économise pour un voyage.
(Necesito sacar dinero porque estoy ahorrando para un viaje)
```

## El truco para practicar

Memorizá primero **"Je peux payer par carte?"** — es la que más vas a usar,
como Léa antes de cualquier compra. Después sumale "J'économise pour ...",
que sirve para contar cualquier meta de ahorro.
