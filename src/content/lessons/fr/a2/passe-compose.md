Cuando un francés cuenta qué hizo ayer, casi siempre usa el **passé composé**. Si has
visto el Perfekt alemán o el Perfect inglés, la estructura te resultará familiar.

## La fórmula: dos ingredientes

```
avoir o être (conjugado)  +  participe passé
```

```
J'ai    mangé    une pizza hier.
(aux)   (participio)
```

## ¿avoir o être?

- **avoir** → la gran mayoría de los verbos (el "por defecto")
- **être** → un grupo cerrado de ~14 verbos de movimiento/cambio de estado: aller, venir,
  partir, arriver, entrer, sortir, monter, descendre, naître, mourir, retourner, rester,
  tomber, passer (y sus derivados)

## El detalle que solo pasa con "être"

Cuando el auxiliar es "être", el participio **concuerda en género y número** con el
sujeto, como si fuera un adjetivo:

```
Il est allé.        (masculino singular)
Elle est allée.     (femenino singular — nota la 'e')
Ils sont allés.     (masculino plural — nota la 's')
Elles sont allées.  (femenino plural — 'e' + 's')
```

Con "avoir", en cambio, el participio normalmente **no cambia**: J'ai mangé (yo, sea
hombre o mujer, dice siempre "mangé").

## Formar el participio pasado

| Grupo | Regla | Ejemplo |
| --- | --- | --- |
| Verbos en -er | raíz + é | parler → parlé |
| Verbos en -ir (regulares) | raíz + i | finir → fini |
| Verbos en -re (regulares) | raíz + u | vendre → vendu |
| Irregulares | memorizar caso por caso | avoir → eu, être → été, faire → fait |
