Ubicar objetos y momentos en el espacio y en el tiempo es esencial para construir
frases completas en francés. Aquí tienes las preposiciones de lugar y de tiempo más
usadas, con ejemplos claros.

## Preposiciones de lugar

| Francés   | Español      |
| --------- | ------------ |
| à         | en / a       |
| dans      | dentro de    |
| sur       | encima de    |
| sous      | debajo de    |
| devant    | delante de   |
| derrière  | detrás de    |
| entre     | entre        |

```
Le chat est sous la table.        (El gato está debajo de la mesa)
Le livre est sur la table.        (El libro está encima de la mesa)
La voiture est devant la maison.  (El coche está delante de la casa)
Le jardin est derrière la maison. (El jardín está detrás de la casa)
```

## Preposiciones de tiempo puntual

Para el tiempo, "à", "en" y "dans" no son intercambiables: cada una marca un tipo de
momento distinto.

| Uso                    | Preposición | Ejemplo             |
| ----------------------- | ----------- | -------------------- |
| Hora exacta              | à           | à 8 heures            |
| Mes o año                | en          | en janvier, en 2026   |
| Tiempo futuro (dentro de) | dans        | dans trois jours       |

```
Le cours commence à 8 heures.       (El curso empieza a las 8 horas)
Mon anniversaire est en janvier.    (Mi cumpleaños es en enero)
Nous partons dans trois jours.      (Nos vamos dentro de tres días)
```

## El truco para no confundirlas

Piensa en tres preguntas: ¿a qué hora exacta? → "à". ¿En qué mes o año? → "en".
¿Cuánto falta para que pase? → "dans". Con esas tres preguntas cubres casi todos los
usos de tiempo puntual en francés.
