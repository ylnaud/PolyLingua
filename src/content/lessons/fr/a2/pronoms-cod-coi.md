Estos pronombres te permiten evitar repetir un sustantivo una y otra vez — la clave
está en identificar si el verbo francés usa una preposición oculta antes del objeto.

## COD (objeto directo): sin preposición

| Pronombre | Reemplaza |
| --- | --- |
| le | objeto masculino singular |
| la | objeto femenino singular |
| les | objeto plural (ambos géneros) |

```
Je vois le film.    →    Je le vois.       (lo veo)
Je vois Marie.        →    Je la vois.        (la veo)
```

## COI (objeto indirecto): con "à" oculta

| Pronombre | Reemplaza |
| --- | --- |
| lui | a él/ella (singular) |
| leur | a ellos/ellas (plural) |

```
Je parle à Marc.    →    Je lui parle.       (le hablo — a él)
Je parle à mes amis.  →    Je leur parle.       (les hablo — a ellos)
```

## Cómo saber si un verbo pide COD o COI

Piensa en el verbo en francés: si necesitas "à" antes de la persona, es COI. Si no, es
COD.

| Verbo | Tipo | Ejemplo |
| --- | --- | --- |
| voir (ver) | COD | Je le vois. |
| aimer (amar) | COD | Je l'aime. |
| parler à (hablar a) | COI | Je lui parle. |
| téléphoner à (llamar a) | COI | Je lui téléphone. |

## Posición: antes del verbo conjugado

```
Je le vois.              (presente simple)
Je ne le vois pas.        (negación rodea al pronombre + verbo)
Je l'ai vu.                 (passé composé: antes del auxiliar)
```

## El truco práctico

Antes de elegir el pronombre, pregúntate: "¿este verbo en francés necesita 'à' antes
de la persona?" Si sí → lui/leur (COI). Si no → le/la/les (COD). Memorizar los verbos
más comunes con su preposición (o sin ella) es la base de este tema.
