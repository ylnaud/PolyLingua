El Conditionnel présent es tu herramienta para sonar cortés, dar consejos suaves y
construir oraciones condicionales hipotéticas.

## La fórmula: raíz del futuro + terminaciones del imparfait

```
raíz del futuro  +  -ais, -ais, -ait, -ions, -iez, -aient

parler → je parlerais, tu parlerais, il parlerait...
```

Como ya conoces ambas piezas por separado (futuro simple e imparfait), esta
conjugación es más fácil de lo que parece.

## Los tres usos principales

### 1. Cortesía

```
Je voudrais un café.          (Quisiera un café — en vez de "je veux")
Pourriez-vous m'aider?         (¿Podría ayudarme?)
```

### 2. Consejos suaves

```
Tu devrais dormir plus.        (Deberías dormir más)
À ta place, je partirais.      (Yo que tú, me iría)
```

### 3. Condicionales hipotéticos (con "si" + imparfait)

```
Si j'avais de l'argent, je voyagerais.
(Si tuviera dinero, viajaría)
```

## Los irregulares (mismas raíces que el futuro)

| Infinitivo | Raíz | Conditionnel |
| --- | --- | --- |
| être | ser- | je serais |
| avoir | aur- | j'aurais |
| aller | ir- | j'irais |
| faire | fer- | je ferais |

## Comparando registro

```
Direct (brusco):     Je veux un café.
Poli (Conditionnel): Je voudrais un café.
```

## El truco práctico

Usa el Conditionnel cada vez que quieras suavizar una petición, un consejo o una
opinión — es exactamente el mismo instinto que en español te lleva de "quiero" a
"quisiera", o de "debes" a "deberías".
