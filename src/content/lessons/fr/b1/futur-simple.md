El futur simple es el futuro "formal" del francés — el que aparece en promesas
solemnes, planes a largo plazo y contextos escritos.

## La fórmula: infinitivo + terminación

```
infinitivo (raíz)  +  -ai/-as/-a/-ons/-ez/-ont

parler → je parlerai, tu parleras, il parlera...
finir → je finirai, tu finiras...
```

## Las terminaciones completas

| Pronombre | Terminación | parler |
| --- | --- | --- |
| je | -ai | parlerai |
| tu | -as | parleras |
| il/elle | -a | parlera |
| nous | -ons | parlerons |
| vous | -ez | parlerez |
| ils/elles | -ont | parleront |

## Verbos en -re: pierden la "e" final

```
vendre → je vendrai      (no "vendreai")
```

## Los irregulares imprescindibles

| Infinitivo | Raíz del futuro |
| --- | --- |
| être | ser- (je serai) |
| avoir | aur- (j'aurai) |
| aller | ir- (j'irai) |
| faire | fer- (je ferai) |
| voir | verr- (je verrai) |

## Futur simple vs. futur proche

```
Futur proche (cotidiano):   Je vais partir demain.
Futur simple (formal/lejano): Un jour, je partirai vivre à l'étranger.
```

## Un uso especial: después de "quand"

A diferencia del español (donde usas presente), el francés usa futur simple después de
"quand" cuando la acción es futura:

```
Quand tu arriveras, appelle-moi.
(Cuando llegues, llámame — no "quand tu arrives")
```
