Este es, para muchos hispanohablantes, el reto número uno del francés intermedio: elegir
entre dos pasados que en español a veces se traducen igual, pero que en francés marcan
matices muy distintos.

## La imagen mental: foto fija vs. película

```
Il pleuvait     quand    je suis sorti.
(foto de fondo)          (acción puntual, película)
```

El imparfait describe **cómo eran las cosas**; el passé composé cuenta **qué pasó**.

## Cuándo usar el imparfait

| Uso | Ejemplo |
| --- | --- |
| Descripciones (clima, apariencia, estado) | Il faisait beau. Elle était fatiguée. |
| Hábitos/repetición sin límite claro | Je jouais au foot tous les samedis. |
| Fondo de una acción | Je lisais quand tu as appelé. |

## Cuándo usar el passé composé

| Uso | Ejemplo |
| --- | --- |
| Eventos puntuales y completados | Hier, j'ai visité le musée. |
| Una serie de acciones concretas | Je me suis levé, j'ai mangé, je suis parti. |
| Algo que interrumpe el fondo | Le téléphone a sonné pendant que je dormais. |

## Cómo se forman (repaso rápido)

**Imparfait**: raíz de "nous" en presente + terminaciones -ais, -ais, -ait, -ions, -iez,
-aient (je parlais, tu parlais, il parlait...)

**Passé composé**: ya lo conoces — avoir/être + participe passé.

## El truco final

Si puedes reemplazar el verbo por "estaba + gerundio" en español ("estaba lloviendo",
"estaba jugando"), casi siempre es imparfait. Si describe un evento con inicio y fin
claros ("llegué", "llamé", "terminé"), es passé composé.
