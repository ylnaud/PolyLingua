Ya dominas "ne...pas". Ahora conoces al resto de la familia — todas siguen la misma
estructura de sándwich alrededor del verbo.

## La familia completa de negaciones

| Negación | Significado | Ejemplo |
| --- | --- | --- |
| ne...pas | no | Je ne mange pas. |
| ne...jamais | nunca | Je ne mange jamais de viande. |
| ne...rien | nada | Je ne vois rien. |
| ne...personne | nadie | Je ne vois personne. |
| ne...plus | ya no | Je ne fume plus. |
| ne...que | solo (restricción) | Je n'ai qu'un frère. |

## Todas siguen el mismo sándwich

```
sujeto + ne + verbo + [jamais/rien/plus...] + resto

Je    ne    mange    jamais    de viande.
```

## El caso especial de "personne" y "rien" como sujeto

Cuando "personne" o "rien" son el SUJETO de la frase, el orden cambia:

```
Personne ne vient.        (Nadie viene)
Rien n'est parfait.        (Nada es perfecto)
```

## Combinando negaciones

```
Je ne dis plus jamais rien à personne.
(Ya nunca le digo nada a nadie — combinación de varias negaciones)
```

## El detalle de "de" después de la negación

Después de una negación, los artículos indefinidos (un/une/des) y partitivos
(du/de la) casi siempre se convierten en "de":

```
J'ai des amis.       →    Je n'ai pas d'amis.
Je mange du pain.     →    Je ne mange jamais de pain.
```

## El truco para dominarlas rápido

Todas comparten la misma estructura de "ne...X" que ya automatizaste con "pas" —
solo necesitas memorizar el vocabulario nuevo (jamais, rien, personne, plus) y aplicarlo
al molde que ya conoces.
