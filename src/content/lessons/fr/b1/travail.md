Ya sea para hablar de tu trabajo actual, escribir una candidatura o prepararte para
una entrevista, este vocabulario es esencial en francés profesional.

## El proceso de búsqueda de empleo

| Francés                  | Español                  |
| ------------------------ | ------------------------ |
| la candidature           | la postulación           |
| le CV (curriculum vitae) | el currículum            |
| l'entretien d'embauche   | la entrevista de trabajo |
| le contrat               | el contrato              |
| le salaire               | el salario               |

## En la oficina

| Francés                 | Español           |
| ----------------------- | ----------------- |
| le patron / la patronne | el jefe / la jefa |
| le/la collègue          | el/la colega      |
| la réunion              | la reunión        |
| le bureau               | la oficina        |
| l'entreprise            | la empresa        |

## Frases útiles para hablar de tu trabajo

```
Je travaille comme professeur.          (Trabajo como profesor)
J'ai un entretien d'embauche demain.     (Tengo una entrevista mañana)
Ma collègue s'appelle Sophie.             (Mi colega se llama Sophie)
```

## El patrón femenino de las profesiones (con irregularidades)

```
un directeur → une directrice          un acteur → une actrice
un vendeur → une vendeuse                un boulanger → une boulangère
```

A diferencia del patrón simple "-in" del alemán, el francés tiene varias terminaciones
posibles (-trice, -euse, -ère) según la palabra — apréndelas en parejas desde el
principio para evitar errores comunes.
