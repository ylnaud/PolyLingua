## "le temps" vs. "le climat": el error clásico

```
le temps = el tiempo de HOY/esta semana (a corto plazo)
le climat = el patrón climático de una región (a largo plazo)

Il fait beau aujourd'hui. (le temps)
Cette région a un climat tropical. (le climat)
```

## Frases útiles para debatir

```
À mon avis, le changement climatique est le plus grand défi de notre génération.
Il faut investir davantage dans les énergies renouvelables.
Le développement durable devrait être une priorité pour chaque entreprise.
```
