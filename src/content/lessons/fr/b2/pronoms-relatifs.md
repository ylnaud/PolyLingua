Los pronombres relativos son la herramienta que separa el francés de principiante ("J'ai
un ami. Il habite à Paris.") del francés fluido ("J'ai un ami qui habite à Paris.").

## La lógica: identifica la función primero

Antes de elegir el pronombre, pregúntate qué función cumplía la palabra que vas a
reemplazar en la segunda frase.

| Pronombre | Reemplaza | Ejemplo |
| --- | --- | --- |
| qui | el sujeto | La femme qui parle est ma sœur. |
| que | el objeto directo | Le film que j'ai vu était super. |
| dont | algo con "de" | Le livre dont je parle est génial. |
| où | lugar o tiempo | La ville où j'habite est belle. |

## qui vs. que: el error más común

Ambos suenan parecido, pero cumplen roles opuestos:

```
qui + verbo    (qui es el SUJETO del verbo que sigue)
que + sujeto + verbo    (que es el OBJETO, siempre seguido de otro sujeto)
```

```
L'homme qui parle...        (el hombre HABLA → sujeto → qui)
L'homme que je vois...      (YO veo al hombre → objeto → que)
```

## "dont": el pronombre que reemplaza "de + algo"

Cualquier verbo o expresión que use "de" (parler de, avoir besoin de, être content de)
activa "dont" en vez de "que":

```
J'ai besoin de ce stylo. → C'est le stylo dont j'ai besoin.
```

## Combinándolos en una frase natural

```
Voici la maison    où    j'ai grandi,    dont    je parle souvent,    et    qui    me manque.
(la casa donde crecí, de la que hablo seguido, y que extraño)
```

Cuantos más pronombres relativos domines, menos frases cortas y entrecortadas tendrás —
justo el salto de calidad que define el nivel B2.
