Cuando cuentas lo que alguien más dijo, el francés no usa comillas — cambia
sistemáticamente los tiempos verbales, un fenómeno llamado **concordance des temps**.

## La regla del retroceso (igual lógica que el "backshift" inglés)

| Discurso directo | Discurso indirecto |
| --- | --- |
| Présent | Imparfait |
| Passé composé | Plus-que-parfait |
| Futur simple | Conditionnel présent |
| Impératif | de + infinitif |

```
Direct:    "Je suis fatiguée."      →  Indirect: Elle a dit qu'elle était fatiguée.
Direct:    "J'ai fini."              →  Indirect: Il a dit qu'il avait fini.
Direct:    "Je viendrai."            →  Indirect: Elle a dit qu'elle viendrait.
```

## Los marcadores de tiempo también cambian

| Directo | Indirecto |
| --- | --- |
| aujourd'hui | ce jour-là |
| demain | le lendemain |
| hier | la veille |
| maintenant | à ce moment-là |

```
Direct:    "Je pars demain."
Indirect:  Il a dit qu'il partait le lendemain.
```

## El caso especial del imperativo

Las órdenes en discurso directo se transforman en "de + infinitif":

```
Direct:    "Ferme la porte!"
Indirect:  Elle m'a dit de fermer la porte.
```

## Por qué es un reto de nivel C1

Aplicar correctamente esta doble transformación —tiempo verbal Y marcadores
temporales— de forma simultánea y fluida, sin pausar a pensar, es exactamente el tipo de
automatismo que separa a un hablante C1 de uno que todavía traduce mentalmente frase por
frase.
