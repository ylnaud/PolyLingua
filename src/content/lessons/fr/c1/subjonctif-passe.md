Ya dominas el Subjonctif présent. Ahora aprendes su versión de pasado — necesaria
cuando la acción que provoca duda, emoción o deseo ya ocurrió antes del momento en que
hablas.

## La fórmula: la misma lógica del passé composé

```
avoir/être (en Subjonctif présent) + participe passé

que j'aie fini          que je sois parti(e)
```

## Comparando présent vs. passé

```
Subjonctif présent:  Je doute qu'il vienne.        (duda sobre algo futuro/simultáneo)
Subjonctif passé:      Je doute qu'il soit venu.      (duda sobre algo ya pasado)
```

## Ejemplos completos

```
Je suis content que tu aies réussi ton examen.
(Estoy contento de que hayas aprobado tu examen)

Il est possible qu'elle soit déjà partie.
(Es posible que ya se haya ido)

Je ne pense pas qu'il ait compris.
(No creo que haya entendido)
```

## El truco para elegir entre présent y passé

Pregúntate: "¿la acción subordinada ocurre AL MISMO TIEMPO/DESPUÉS del sentimiento
principal, o ya ocurrió ANTES?" Si ya pasó, necesitas Subjonctif passé.

```
Je suis triste qu'il parte.      (se va ahora/pronto → présent)
Je suis triste qu'il soit parti.  (ya se fue → passé)
```

## Por qué es un reto de nivel C1

No se trata de aprender gramática nueva —ya conoces todas las piezas por separado—
sino de reconocer instantáneamente CUÁNDO ocurrió la acción subordinada respecto a la
principal, y elegir la forma correcta sin pausar a pensarlo.
