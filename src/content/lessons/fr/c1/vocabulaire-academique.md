Este vocabulario te permite leer y escribir en el registro que domina disertaciones,
artículos científicos y ensayos universitarios en francés.

| --- | --- |

| la recherche | la investigación |

| la source | la fuente |
| la preuve | la prueba |
| l'analyse | el análisis |

## Fórmulas fijas para citar y argumentar

```
Selon l'étude...                       (Según el estudio...)
Comme X le montre/argumente...          (Como X muestra/argumenta...)
Il convient de souligner que...         (Conviene subrayar que...)
En conclusion, on peut affirmer que...   (En conclusión, se puede afirmar que...)
```

## La estructura clásica francesa: thèse, antithèse, synthèse

A diferencia de otras tradiciones académicas, el ensayo francés clásico sigue un
formato muy codificado:

1. **Thèse**: presentar una idea o argumento
2. **Antithèse**: presentar el contraargumento
3. **Synthèse**: sintetizar ambas perspectivas en una conclusión matizada

## El truco: aprende bloques, no palabras sueltas

En vez de memorizar "selon" y "l'étude" por separado, memoriza "selon l'étude" como
una unidad completa lista para usar. Estas fórmulas fijas son las que realmente
aparecen una y otra vez en textos académicos reales.
