Los números italianos son, de los cinco idiomas de PolyLingua, los más fáciles de
aprender para un hispanohablante — la similitud con el español es notable.

## Del 0 al 20

| 0-10 | 11-20 |
| --- | --- |
| zero, uno, due, tre, quattro | undici, dodici, tredici, quattordici |
| cinque, sei, sette, otto, nove, dieci | quindici... diciannove, venti |

## Las decenas

| Número | Palabra |
| --- | --- |
| 20 | venti |
| 30 | trenta |
| 40 | quaranta |
| 50 | cinquanta |
| 60 | sessanta |
| 70 | settanta |
| 80 | ottanta |
| 90 | novanta |

## El patrón de fusión (21-99)

A diferencia del español (con guión: veintiuno) o el francés (con guión: vingt-et-un),
el italiano fusiona todo en una sola palabra:

```
21 = ventuno         35 = trentacinque         99 = novantanove
```

## La regla de elisión con uno/otto

Cuando la decena termina en vocal y se combina con "uno" u "otto" (que empiezan con
vocal), la decena pierde su vocal final:

```
venti + uno = ventuno       (no "ventiuno")
trenta + otto = trentotto    (no "trentaotto")
```

## Los números grandes

```
100 = cento          200 = duecento          1000 = mille
```

## El truco para practicar

Gracias al parecido con el español, este vocabulario se memoriza rápido — practica
diciendo precios y horarios en voz alta para automatizar el patrón de fusión de las
decenas.
