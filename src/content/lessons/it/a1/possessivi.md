El italiano añade un paso extra a los posesivos que el español no tiene: combinar el
artículo definido con el adjetivo posesivo.

## La fórmula general

```
artículo + posesivo + sustantivo

il mio libro         (mi libro)
la mia casa            (mi casa)
i miei libri            (mis libros)
```

## Tabla completa (con "mio")

| Género/número | Forma |
| --- | --- |
| masculino singular | il mio libro |
| femenino singular | la mia casa |
| masculino plural | i miei libri |
| femenino plural | le mie case |

## La gran excepción: familiares en singular

Con un familiar singular (sin adjetivo adicional), el artículo **desaparece**:

```
mia madre            (no "la mia madre")
mio padre              (no "il mio padre")
tuo fratello            (no "il tuo fratello")
```

Pero en plural, o si añades un adjetivo, el artículo vuelve:

```
i miei fratelli          (mis hermanos — plural, sí lleva artículo)
la mia cara madre         (mi querida madre — con adjetivo, sí lleva artículo)
```

## Tabla de posesivos (masculino singular, como referencia)

| Poseedor | Posesivo |
| --- | --- |
| io | il mio |
| tu | il tuo |
| lui/lei | il suo |
| noi | il nostro |
| voi | il vostro |
| loro | il loro |

## El truco práctico

Memoriza la regla como dos pasos: primero, el italiano SIEMPRE combina artículo +
posesivo (a diferencia del español); segundo, esa regla tiene una única excepción común:
familiares en singular sin adjetivo adicional.
