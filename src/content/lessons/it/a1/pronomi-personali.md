Los pronombres personales sujeto en italiano son muy parecidos al sistema español, con
una ventaja extra: muchas veces ni siquiera necesitas usarlos.

## La tabla completa de pronombres

| Italiano | Español        | Ejemplo                |
| -------- | -------------- | ---------------------- |
| io       | yo             | Io parlo italiano.     |
| tu       | tú             | Tu parli bene.         |
| lui      | él             | Lui mangia la pasta.   |
| lei      | ella           | Lei legge un libro.    |
| Lei      | usted (formal) | Lei parla inglese?     |
| noi      | nosotros/as    | Noi studiamo italiano. |
| voi      | vosotros/as    | Voi parlate spagnolo?  |
| loro     | ellos/ellas    | Loro vivono a Roma.    |

## El italiano es "pro-drop": puedes omitir el pronombre

Esta es una de las ventajas más grandes del italiano para un hispanohablante. Igual que
en español puedes decir "hablo italiano" sin decir "yo", en italiano funciona exactamente
igual:

```
Io parlo italiano.   →   Parlo italiano.     (ambas correctas)
Noi mangiamo pasta.  →   Mangiamo pasta.     (ambas correctas)
```

La terminación del verbo ya indica quién realiza la acción, así que el pronombre solo se
usa cuando quieres **enfatizar** o **contrastar**:

```
Io parlo italiano, tu parli francese.
(YO hablo italiano, TÚ hablas francés — énfasis contrastivo)
```

## Él, ella... y usted: lui, lei, Lei

Aquí hay un detalle importante que no tiene equivalente directo en español:

- **lui** = él (masculino, informal)
- **lei** = ella (femenino, informal)
- **Lei** = usted (formal, con mayúscula)

La forma de cortesía **Lei** se conjuga exactamente igual que **lei** (tercera persona
singular), pero se escribe con mayúscula en textos formales. En la lengua hablada, el
contexto deja claro si es "ella" o "usted":

```
Lei parla italiano?     (¿Usted habla italiano? — formal)
Lei parla italiano.     (Ella habla italiano. — informal)
```

## Voi: segunda persona del plural

En italiano moderno, **voi** sirve tanto para el plural informal ("vosotros") como, en
algunas regiones del sur, para el plural formal. En la mayoría de contextos urbanos y
escritos, el formal plural se expresa con **Loro** (aunque suena muy elevado) o
simplemente con **voi**.

## Cuándo SÍ usar el pronombre

Aunque el italiano permite omitirlo, hay situaciones donde conviene usarlo:

1. **Para enfatizar**: _Io studio, tu giochi._ (Yo estudio, tú juegas.)
2. **Para evitar ambigüedad**: _Lui mangia, lei legge._ (Él come, ella lee.)
3. **Al presentarse**: _Io sono Marco._ (Yo soy Marco.)
4. **Después de "anche" (también)**: _Anche io parlo italiano._ (Yo también hablo italiano.)

Con esta base, ya puedes identificar quién hace qué en cualquier frase italiana — y
sabes que no necesitas repetir el pronombre en cada oración.
