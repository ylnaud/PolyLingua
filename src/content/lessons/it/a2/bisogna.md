Estas expresiones impersonales son extremadamente comunes en italiano cotidiano —
perfectas para dar consejos y hablar de necesidades sin señalar a nadie en particular.

## bisogna: la obligación general

```
bisogna + infinitivo         (obligación general, sin sujeto específico)

Bisogna mangiare per vivere.      (Hay que comer para vivir)
Bisogna essere pazienti.            (Hay que ser paciente)
```

## bisogna che + congiuntivo: con sujeto específico

Cuando quieres señalar A QUIÉN le corresponde la obligación, necesitas "che" + sujeto +
congiuntivo:

```
Bisogna che tu parta adesso.
(Tienes que irte ahora — nota el congiuntivo "parta")
```

## ci vuole / ci vogliono: lo que se necesita

```
Ci vuole tempo.               (Se necesita tiempo — singular)
Ci vogliono due ore.            (Se necesitan dos horas — plural)
```

La forma cambia según si lo que se necesita es singular o plural.

## Otras expresiones impersonales útiles

| Expresión | Significado |
| --- | --- |
| è importante | es importante |
| è necessario | es necesario |
| è possibile | es posible |
| è meglio | es mejor |

```
È importante dormire bene.
È meglio partire presto.
```

## El truco práctico

"Bisogna" es tu herramienta para dar consejos generales sin sonar demasiado directo
("devi...") — mucho más natural y frecuente en italiano cotidiano para hablar de
necesidades o recomendaciones generales.
