El italiano cotidiano tiene dos formas naturales de hablar del futuro cercano, sin
recurrir al futuro formal que verás más adelante.

## El presente para planes cercanos

```
Domani parto per Roma.        (Mañana salgo para Roma)
Stasera vediamo un film.        (Esta noche vemos una película)
```

Igual que en español ("mañana salgo para Roma" en vez de "mañana saldré"), el
italiano prefiere el presente + marcador de tiempo para planes ya decididos.

## "stare per": lo que está a punto de pasar AHORA

```
stare (conjugado) + per + infinitivo

Sto per partire.        (Estoy a punto de partir/salir)
Il film sta per iniziare. (La película está a punto de empezar)
```

## Comparando los dos futuros cercanos

| Estructura | Uso | Ejemplo |
| --- | --- | --- |
| Presente + marcador | Plan futuro con fecha | Parto domani. |
| stare per + infinitivo | Algo inminente, ahora mismo | Sto per partire. |

## Conjugación de "stare" (repaso)

| Pronombre | stare |
| --- | --- |
| io | sto |
| tu | stai |
| lui/lei | sta |
| noi | stiamo |
| voi | state |
| loro | stanno |

## El truco práctico

Para planes con fecha específica, usa presente. Para algo que está a punto de pasar en
este instante (el tren que ya casi llega, la película que va a empezar ya), usa "stare
per" — la distinción es de inmediatez, no solo de tiempo gramatical.
