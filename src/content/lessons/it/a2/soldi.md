Giulia cierra la semana pensando en sus gastos: está ahorrando para un
viaje, así que estas son las frases del dinero que más usa.

## La pregunta que hay que hacer primero

```
Posso pagare con la carta?       ¿Puedo pagar con tarjeta?
— Solo contanti, per favore.      Solo efectivo, por favor.
```

Conviene preguntarlo **antes** de pedir, no después.

## Sacar plata

```
Devo prelevare dei soldi.         Necesito sacar dinero.
Dov'è un bancomat?                 ¿Dónde hay un cajero automático?
Non ho contanti con me.            No tengo efectivo encima.
```

"Contanti" viene de "contare" (contar) — la plata que literalmente se
cuenta, a diferencia de pagar con tarjeta.

## Ahorro y gastos

```
Sto risparmiando per un viaggio.   Estoy ahorrando para un viaje.
Quanto ti devo?                     ¿Cuánto te debo?
```

## Una frase completa

```
Devo prelevare dei soldi perché sto risparmiando per un viaggio.
(Necesito sacar dinero porque estoy ahorrando para un viaje)
```

## El truco para practicar

Memorizá primero **"Posso pagare con la carta?"** — es la que más vas a
usar, como Giulia antes de cualquier compra. Después sumale "Sto
risparmiando per ...", que sirve para contar cualquier meta de ahorro.
