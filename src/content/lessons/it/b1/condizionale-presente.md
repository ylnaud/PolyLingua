El condizionale presente es tu herramienta para sonar cortés, dar consejos suaves y
construir oraciones condicionales hipotéticas.

## La fórmula: raíz del futuro + terminaciones propias

```
raíz del futuro  +  -ei, -esti, -ebbe, -emmo, -este, -ebbero

parlare → parlerei, parleresti, parlerebbe...
```

Como ya conoces la raíz del futuro, solo necesitas memorizar este nuevo set de
terminaciones.

## Los tres usos principales

### 1. Cortesía

```
Vorrei un caffè.          (Quisiera un café — en vez de "voglio")
Potrebbe aiutarmi?          (¿Podría ayudarme?)
```

### 2. Consejos suaves

```
Dovresti dormire di più.    (Deberías dormir más)
Al posto tuo, partirei.       (Yo que tú, me iría)
```

### 3. Condicionales hipotéticos (con "se" + congiuntivo imperfetto)

```
Se avessi soldi, viaggerei.
(Si tuviera dinero, viajaría)
```

## Los irregulares (mismas raíces que el futuro)

| Infinitivo | Raíz | Condizionale |
| --- | --- | --- |
| essere | sar- | sarei |
| avere | avr- | avrei |
| andare | andr- | andrei |
| fare | far- | farei |

## Comparando registro

```
Diretto (brusco):     Voglio un caffè.
Educato (Condizionale): Vorrei un caffè.
```

## El truco práctico

Usa el condizionale cada vez que quieras suavizar una petición, un consejo o una
opinión — exactamente el mismo instinto que en español te lleva de "quiero" a
"quisiera", o de "debes" a "deberías".
