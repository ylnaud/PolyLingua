El futuro semplice es el futuro "formal" del italiano — el que aparece en promesas,
predicciones y contextos escritos.

## La fórmula: infinitivo (modificado) + terminación

```
infinitivo → raíz del futuro + -ò/-ai/-à/-emo/-ete/-anno

parlare → parlerò, parlerai, parlerà...   (¡nota el cambio a "er"!)
vendere → venderò, venderai...
finire → finirò, finirai...
```

## Las terminaciones completas

| Pronombre | Terminación | parlare |
| --- | --- | --- |
| io | -ò | parlerò |
| tu | -ai | parlerai |
| lui/lei | -à | parlerà |
| noi | -emo | parleremo |
| voi | -ete | parlerete |
| loro | -anno | parleranno |

## La trampa ortográfica de los verbos en -are

```
parlare → parlerò        (la 'a' cambia a 'e')
```

Solo los verbos en -are hacen este cambio de vocal; los verbos en -ere y -ire
mantienen su vocal original.

## Los irregulares imprescindibles

| Infinitivo | Raíz del futuro |
| --- | --- |
| essere | sar- (io sarò) |
| avere | avr- (io avrò) |
| andare | andr- (io andrò) |
| fare | far- (io farò) |
| potere | potr- (io potrò) |

## Un uso especial: la probabilidad

El futuro italiano también expresa una suposición sobre el presente, igual que en
alemán o francés:

```
Sarà tardi, ormai.
(Ya debe ser tarde — no "será tarde" en el futuro literal, sino una suposición ahora)
```

## El truco práctico

Para planes cercanos, sigue prefiriendo el presente que ya conoces. Reserva el futuro
semplice para promesas formales, predicciones a futuro lejano, o —como en la mayoría de
los idiomas del curso— para expresar suposiciones sobre el presente.
