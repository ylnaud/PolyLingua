Este es, para muchos hispanohablantes, el reto número uno del italiano intermedio:
elegir entre dos pasados que en español a veces se traducen igual, pero que en italiano
marcan matices muy distintos.

## La imagen mental: foto fija vs. película

```
Pioveva      quando    sono uscito.
(foto de fondo)         (acción puntual, película)
```

El imperfetto describe **cómo eran las cosas**; el passato prossimo cuenta **qué pasó**.

## Cuándo usar el imperfetto

| Uso | Ejemplo |
| --- | --- |
| Descripciones (clima, apariencia, estado) | Faceva bello. Era stanca. |
| Hábitos/repetición sin límite claro | Giocavo a calcio ogni sabato. |
| Fondo de una acción | Leggevo quando hai chiamato. |

## Cuándo usar el passato prossimo

| Uso | Ejemplo |
| --- | --- |
| Eventos puntuales y completados | Ieri, ho visitato il museo. |
| Una serie de acciones concretas | Mi sono alzato, ho mangiato, sono uscito. |
| Algo que interrumpe el fondo | Il telefono ha squillato mentre dormivo. |

## Cómo se forma el imperfetto (repaso rápido)

Raíz del infinitivo + terminaciones -avo/-evo/-ivo según el grupo (-are/-ere/-ire):

```
parlare → parlavo, parlavi, parlava, parlavamo, parlavate, parlavano
```

## El truco final

Si puedes reemplazar el verbo por "estaba + gerundio" en español ("estaba lloviendo",
"estaba jugando"), casi siempre es imperfetto. Si describe un evento con inicio y fin
claros ("llegué", "llamé", "terminé"), es passato prossimo.
