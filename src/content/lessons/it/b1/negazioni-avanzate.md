Ya dominas "non" solo. Ahora conoces al resto de la familia de negaciones — todas
requieren 'non' antes del verbo, incluso cuando en español no dirías "no".

## La familia completa de negaciones

| Negación | Significado | Ejemplo |
| --- | --- | --- |
| non... mai | nunca | Non mangio mai carne. |
| non... niente/nulla | nada | Non vedo niente. |
| non... nessuno | nadie | Non vedo nessuno. |
| non... più | ya no | Non fumo più. |
| non... ancora | todavía no | Non ho ancora finito. |

## El detalle clave: "non" siempre es obligatorio

A diferencia del español, donde puedes decir "nunca como carne" (sin "no"), el
italiano SIEMPRE necesita ambas partes:

```
Español:    Nunca como carne.                (sin "no")
Italiano:    Non mangio mai carne.              (con "non" obligatorio)
```

## Cuando la palabra negativa va ANTES del verbo (como sujeto)

Si "nessuno" o "niente" son el SUJETO de la frase, "non" desaparece:

```
Nessuno viene.        (Nadie viene — sin "non")
Niente è perfetto.      (Nada es perfecto — sin "non")
```

Pero si van DESPUÉS del verbo (como objeto), "non" es obligatorio antes del verbo:

```
Non vedo nessuno.      (No veo a nadie — "non" antes, "nessuno" después)
```

## Combinando negaciones

```
Non dico mai più niente a nessuno.
(Ya nunca le digo nada a nadie — combinación de varias negaciones)
```

## El truco para dominarlas rápido

Todas comparten la misma estructura "non...X" que ya automatizaste — solo necesitas
memorizar el vocabulario nuevo (mai, niente, nessuno, più) y recordar que "non" nunca se
omite cuando la palabra negativa va después del verbo.
