El gerundio italiano cumple dos funciones importantes: describir simultaneidad y
formar la construcción progresiva, muy parecida al inglés.

## Formación del gerundio

```
-are → -ando          -ere/-ire → -endo

parlare → parlando         vendere → vendendo         dormire → dormendo
```

## Uso 1: simultaneidad (mismo sujeto)

```
Ascolto musica lavorando.
(Escucho música mientras trabajo)
```

## Uso 2: la forma progresiva con "stare"

```
stare (conjugado) + gerundio

Sto mangiando.        (Estoy comiendo — ahora mismo)
Stava piovendo.         (Estaba lloviendo)
```

Esta forma progresiva es más específica que el presente simple: "mangio" (como, en
general) vs. "sto mangiando" (estoy comiendo, en este preciso momento) — una distinción
que el francés o el alemán no marcan gramaticalmente con la misma claridad.

## Uso 3: medio o manera

```
Ho imparato l'italiano guardando film.
(Aprendí italiano viendo películas — el MEDIO por el cual lo logré)
```

## Los irregulares imprescindibles

```
fare → facendo         dire → dicendo         bere → bevendo
```

## El truco práctico

Cuando quieras ser específico sobre algo que está pasando EN ESTE MOMENTO (no en
general), usa "stare + gerundio" en vez del presente simple — es la forma más natural
de replicar el matiz del "estoy haciendo" en italiano cotidiano.
