Ya dominas el Congiuntivo presente. Ahora aprendes su versión de pasado — necesaria
cuando la acción que provoca duda, emoción o deseo ya ocurrió antes del momento en que
hablas.

## La fórmula: la misma lógica del passato prossimo

```
avere/essere (en Congiuntivo presente) + participio passato

che io abbia finito          che io sia partito/a
```

## Comparando presente vs. passato

```
Congiuntivo presente:  Dubito che venga.        (duda sobre algo futuro/simultáneo)
Congiuntivo passato:      Dubito che sia venuto.    (duda sobre algo ya pasado)
```

## Ejemplos completos

```
Sono contento che tu abbia superato l'esame.
(Estoy contento de que hayas aprobado tu examen)

È possibile che sia già partita.
(Es posible que ya se haya ido)

Non penso che abbia capito.
(No creo que haya entendido)
```

## El truco para elegir entre presente y passato

Pregúntate: "¿la acción subordinada ocurre AL MISMO TIEMPO/DESPUÉS del sentimiento
principal, o ya ocurrió ANTES?" Si ya pasó, necesitas Congiuntivo passato.

```
Sono triste che parta.      (se va ahora/pronto → presente)
Sono triste che sia partito. (ya se fue → passato)
```

## Por qué es un reto de nivel C1

No se trata de aprender gramática nueva —ya conoces todas las piezas por separado—
sino de reconocer instantáneamente CUÁNDO ocurrió la acción subordinada respecto a la
principal, y elegir la forma correcta sin pausar a pensarlo.
