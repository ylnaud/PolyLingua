Cuando cuentas lo que alguien más dijo, el italiano no usa comillas — cambia
sistemáticamente los tiempos verbales, un fenómeno llamado **concordanza dei tempi**.

## La regla del retroceso

| Discurso diretto | Discorso indiretto |
| --- | --- |
| Presente | Imperfetto |
| Passato prossimo | Trapassato prossimo |
| Futuro | Condizionale passato |
| Imperativo | di + infinito |

```
Diretto:      "Sono stanca."        →  Indiretto: Ha detto che era stanca.
Diretto:      "Ho finito."           →  Indiretto: Ha detto che aveva finito.
Diretto:      "Verrò."               →  Indiretto: Ha detto che sarebbe venuto.
```

## Los marcadores de tiempo también cambian

| Diretto | Indiretto |
| --- | --- |
| oggi | quel giorno |
| domani | il giorno dopo |
| ieri | il giorno prima |
| adesso | in quel momento |

```
Diretto:    "Parto domani."
Indiretto:  Ha detto che partiva il giorno dopo.
```

## El caso especial del imperativo

Las órdenes en discurso directo se transforman en "di + infinito":

```
Diretto:      "Chiudi la porta!"
Indiretto:    Mi ha detto di chiudere la porta.
```

## Por qué es un reto de nivel C1

Aplicar correctamente esta doble transformación —tiempo verbal Y marcadores
temporales— de forma simultánea y fluida, sin pausar a pensar, es exactamente el tipo de
automatismo que separa a un hablante C1 de uno que todavía traduce mentalmente frase por
frase.
