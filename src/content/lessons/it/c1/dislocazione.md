La dislocazione (o frase scissa) es la herramienta italiana para poner el foco
exactamente donde tú decides — el equivalente exacto de las cleft sentences inglesas o
la mise en relief francesa.

## La estructura básica

```
È + [elemento enfatizado] + che + resto

Normal:  Marco ha chiamato.
Cleft:    È Marco che ha chiamato.     (énfasis en QUIÉN)
```

## "che" hace casi todo el trabajo

A diferencia del francés (qui/que), el italiano simplifica usando "che" tanto para
sujeto como para objeto en esta estructura:

```
Sujeto:    È Marco che ha chiamato.
Objeto:     È questo libro che amo.
```

## Enfatizando distintos elementos de la misma frase

```
Base:      Paolo ha comprato quella macchina ieri.

È Paolo che ha comprato quella macchina ieri.       (énfasis en QUIÉN)
È quella macchina che Paolo ha comprato ieri.         (énfasis en QUÉ)
È ieri che Paolo ha comprato quella macchina.           (énfasis en CUÁNDO)
```

## "Quello che" / "Ciò che": énfasis con contenido completo

Para enfatizar toda una idea (no solo un elemento), se usa "quello che/ciò che + è":

```
Quello che mi interessa è la musica.
(Lo que me interesa es la música)

Ciò che voglio è tempo libero.
(Lo que quiero es tiempo libre)
```

## Cuándo usarla

- Para corregir un malentendido: "Non sono io che ho detto questo."
- Para contrastar: "Non sono i soldi che contano, è l'esperienza."
- Para dar énfasis dramático en un discurso o texto persuasivo.

## Por qué es un reto de nivel C1

Dominar la dislocazione requiere entender no solo la gramática, sino el efecto
retórico que produce — la diferencia entre transmitir información y dirigir
deliberadamente la atención de quien te escucha.
