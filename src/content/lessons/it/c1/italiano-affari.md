## Fórmulas fijas para correos de negocios

```
Gentile Sig./Sig.ra,                          (apertura formal, con apellido)
Le scrivo in merito a...                        (le escribo con respecto a...)
In attesa di un suo riscontro, porgo distinti saluti. (cierre formal)
```

## El uso del "Lei" formal

A diferencia del francés o español, el italiano corporativo mantiene el "Lei" (usted)
de forma muy consistente, incluso entre colegas de similar nivel, hasta que se ofrece
explícitamente pasar al "tu" — una señal de respeto profesional muy arraigada.

## Suavizar el desacuerdo en reuniones

```
Capisco il suo punto di vista, ma ho una prospettiva diversa.
È un'idea interessante; tuttavia, non sono sicuro che sia fattibile.
```

## Presentar resultados con precisión

```
Il fatturato è aumentato del 15% rispetto al trimestre scorso.
Siamo in linea per rispettare la scadenza.
Ci sono state alcune difficoltà con la tempistica.
```

## Por qué vale la pena dominarlo

Este registro específico —cortés, formal y con vocabulario propio— es exactamente lo
que se espera en un entorno profesional italiano, y dominarlo te distingue como alguien
que entiende no solo el idioma, sino los códigos culturales del mundo corporativo
italiano.
