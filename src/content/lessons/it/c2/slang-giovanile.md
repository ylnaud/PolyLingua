Ningún libro de gramática te prepara para escuchar a un grupo de veinteañeros
italianos hablando entre ellos. Esta lección cubre el registro que sí vas a encontrar
en la calle, en series, y en redes sociales.

## Muletillas y expresiones de incertidumbre

```
tipo    → "tipo", muletilla de relleno, igual que en español juvenil
          Era, tipo, super interessante.

boh     → "ni idea", con encogimiento de hombros implícito
          — Che ore sono?  — Boh, non lo so.
```

"Tipo" funciona exactamente como en el español juvenil rioplatense o mexicano: no
aporta significado, solo rellena y da un tono casual a la frase.

## Doble negación con sentido positivo: "mica"

"Mica" es una negación coloquial que refuerza "non", pero en la combinación "mica
male" produce un resultado sorprendentemente positivo:

```
Non è mica male.  /  È mica male.
   (No está nada mal → está bastante bien)

Questo film è mica male, mi è piaciuto.
   (Esta película no está nada mal, me gustó.)
```

## Vocabulario de aprobación y desgana

| Expresión      | Significado                          |
| --------------- | --------------------------------------- |
| figo / figa     | genial, copado (adjetivo)              |
| una figata      | algo genial (sustantivo)               |
| che sbatti      | qué pereza, qué esfuerzo                |
| che palle       | qué fastidio (más vulgar, muy común)   |

```
Che figata questo concerto!     (¡Qué genialidad este concierto!)
Ho troppo sbatti per uscire.    (Tengo demasiada pereza para salir.)
```

## Anglicismos que ya son parte del italiano cotidiano

El italiano informal incorpora anglicismos con total naturalidad, sin traducirlos ni
adaptarlos morfológicamente:

| Inglés     | Uso en italiano                       |
| ----------- | --------------------------------------- |
| weekend     | il weekend (el fin de semana)          |
| smartphone  | lo smartphone                           |
| selfie      | il selfie / farsi un selfie             |
| cool        | è cool (es genial, está de moda)       |

```
Cosa fai questo weekend?        (¿Qué haces este fin de semana?)
Ci facciamo un selfie?          (¿Nos sacamos una selfie?)
```

## Cuándo (no) usar este registro

Este vocabulario pertenece exclusivamente a conversaciones informales entre pares —
amigos, redes sociales, mensajes de texto. Usar "boh" o "che sbatti" en un contexto
profesional produciría el mismo choque de registro que decir "ni idea, qué paja" en
una reunión de trabajo en español. Reconocerlo es la clave: entenderlo cuando lo
escuchás, sin necesariamente tener que usarlo vos mismo en cualquier contexto.
