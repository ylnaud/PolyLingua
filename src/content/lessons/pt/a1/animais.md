Los nombres de los animales son de los primeros vocabularios útiles, ya sea
para hablar de mascotas o para leer cuentos infantiles en portugués.

## Animales domésticos

| Portugués   | Español   |
| ----------- | --------- |
| o cachorro  | el perro  |
| o gato      | el gato   |
| o peixe     | el pez    |
| o pássaro   | el pájaro |

## Animales de granja y salvajes

| Portugués   | Español    |
| ----------- | ---------- |
| a vaca      | la vaca    |
| o cavalo    | el caballo |
| o leão      | el león    |
| o elefante  | el elefante |

## Describir animales con ser y ter

Para hablar de animales usamos "ser" (describir características) y "ter"
(decir qué mascotas tenemos).

```
O cachorro é grande.            (El perro es grande)
O gato é pequeno.                (El gato es pequeño)
Eu tenho um gato.                (Yo tengo un gato)
Eu tenho dois cachorros.         (Yo tengo dos perros)
```

## Nota sobre Brasil y Portugal

```
o cachorro (BR, uso general)     o cão (PT, uso general)
```

En Brasil "cachorro" es la palabra estándar para perro; en Portugal se
prefiere "cão", aunque "cachorro" también se entiende como cría de perro.
