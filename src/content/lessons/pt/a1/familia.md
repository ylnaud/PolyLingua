El vocabulario de familia es fundamental desde el primer día — y el portugués tiene
algunas trampas específicas para hispanohablantes.

## Los términos básicos

| Portugués | Español |
| --- | --- |
| o pai | el padre |
| a mãe | la madre |
| os pais | los padres (ambos) |
| o irmão | el hermano |
| a irmã | la hermana |
| o filho | el hijo |
| a filha | la hija |

## Abuelos y nietos: cuidado con el acento

```
o avô    (abuelo, o cerrada)          a avó    (abuela, o abierta)
o neto   (nieto)                        a neta   (nieta)
```

## Tíos y primos

```
o tio / a tia         (tío / tía)
o primo / a prima      (primo / prima)
o sobrinho / a sobrinha  (sobrino / sobrina)
```

## El falso amigo más importante

```
os pais = los padres (papá y mamá)     ≠     os países = los países
```

Este es uno de los errores más comunes entre hispanohablantes principiantes — presta
atención especial a esta pareja de palabras.

## Cómo hablar de tu familia

```
Eu tenho dois irmãos e uma irmã.       (Tengo dos hermanos y una hermana)
Meus avós moram no Porto.               (Mis abuelos viven en Porto)
```
