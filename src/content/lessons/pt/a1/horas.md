Preguntar y decir la hora es una de las primeras habilidades verdaderamente prácticas
que necesitas en cualquier idioma.

## La pregunta

```
Que horas são?   (¿Qué hora es?)
```

## Ser: singular para la una, plural para el resto

```
É uma hora.        (Es la una)
São duas horas.     (Son las dos)
São dez horas.      (Son las diez)
```

## Los minutos

| Expresión                    | Significado  |
| ---------------------------- | ------------ |
| e meia                       | y media      |
| e quinze                     | y cuarto     |
| menos um quarto / para as... | menos cuarto |
| em ponto                     | en punto     |

```
São três e meia.               (Son las tres y media)
São quatro e quinze.            (Son las cuatro y quince)
É uma hora em ponto.            (Es la una en punto)
```

## Mañana, tarde y noche

```
da manhã   (de la mañana)
da tarde   (de la tarde)
da noite   (de la noche)

São nove da manhã.       São três da tarde.       São dez da noite.
```

## Un dato práctico

En contextos formales (horarios de trenes, aeropuertos), tanto en Brasil como en
Portugal se suele usar el formato de 24 horas: "às quinze horas" (a las 15:00) en vez
de "às três da tarde".
