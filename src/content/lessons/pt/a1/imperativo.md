El imperativo es la forma verbal que usas para dar órdenes, instrucciones, consejos o hacer
pedidos. En portugués brasileño tiene una particularidad que lo hace más fácil de lo que
parece.

## El imperativo brasileño: simplificado

En el portugués de Brasil, el imperativo cotidiano usa la conjugación de **"você"**, que
viene del presente de subjuntivo. Esto significa que hay una sola forma principal que
aprender, no dos como en español (tú vs. usted).

### Verbos regulares: imperativo afirmativo

| Infinitivo     | Presente (você) | Imperativo |
| -------------- | --------------- | ---------- |
| falar (hablar) | fala            | **fale**   |
| comer (comer)  | come            | **coma**   |
| abrir (abrir)  | abre            | **abra**   |

La regla para el imperativo formal (y el más usado en escritura) es tomar la raíz del
presente de indicativo de "eu" y cambiar la vocal temática:

```
-ar → -e      falar → eu falo → fal- → fale
-er → -a      comer → eu como → com- → coma
-ir → -a      abrir → eu abro → abr- → abra
```

### La versión coloquial

En la conversación informal, muchos brasileños usan directamente la forma del presente de
indicativo de "você" como imperativo:

```
Fala mais devagar!       (¡Habla más despacio!)
Come logo!               (¡Come ya!)
Abre a porta!            (¡Abre la puerta!)
```

Ambas formas (la formal del subjuntivo y la coloquial del indicativo) se usan y se
entienden perfectamente.

## Imperativo negativo: não + subjuntivo

Para el imperativo negativo, **siempre** se usa la forma del subjuntivo, incluso en el
habla coloquial:

```
Não fale assim!          (¡No hables así!)
Não coma isso!           (¡No comas eso!)
Não abra a janela!       (¡No abras la ventana!)
```

## El imperativo para "vocês" (ustedes)

Para dirigirse a varias personas, se usa la tercera persona plural del presente de
subjuntivo:

```
Falem mais baixo!        (¡Hablen más bajo!)
Comam tudo!              (¡Coman todo!)
Abram os livros!         (¡Abran los libros!)
```

## Imperativos irregulares importantes

Algunos verbos muy usados tienen imperativos irregulares:

```
ser    → seja (sea)           / sejam (sean)
estar  → esteja (esté)        / estejam (estén)
ir     → vá (ve/vaya)         / vão (vayan)
vir    → venha (ven/venga)    / venham (vengan)
fazer  → faça (haz/haga)      / façam (hagan)
dar    → dê (da/dé)           / deem (den)
ter    → tenha (ten/tenga)    / tenham (tengan)
```

```
(Hablen más bajo, los niños están durmiendo.)
```

## Consejo práctico

Si vienes del español, recuerda: en Brasil no existe el "tú" con su conjugación propia
para el imperativo. Todo pasa por la conjugación de "você", lo cual reduce a la mitad la
cantidad de formas que necesitas memorizar.
