Los números son la base práctica de cualquier idioma — los necesitas desde el primer día
para precios, horas, direcciones y edades.

## Del 0 al 10

| Número | Portugués |
| --- | --- |
| 0 | zero |
| 1 | um |
| 2 | dois |
| 3 | três |
| 4 | quatro |
| 5 | cinco |
| 6 | seis |
| 7 | sete |
| 8 | oito |
| 9 | nove |
| 10 | dez |

## Las decenas y el conector "e"

```
30  trinta        60  sessenta        90  noventa
40  quarenta      70  setenta         100 cem
50  cinquenta     80  oitenta

21 = vinte e um       47 = quarenta e sete       99 = noventa e nove
```

## Cuidado con "cem" vs. "cento"

```
100 = cem              (forma aislada)
102 = cento e dois      (en compuestos, reaparece la "o")
200 = duzentos
```

## Un consejo práctico

Practica los números en contexto real desde el primer día: precios en una tienda, tu
edad, un número de teléfono. La memorización aislada de una lista se olvida rápido; usarlos
te los graba de verdad.
