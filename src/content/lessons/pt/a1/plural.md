Formar el plural en portugués es bastante parecido al español en los casos simples, pero
tiene reglas propias que conviene aprender desde el principio.

## Regla general: añadir -s

Si la palabra termina en vocal (a, e, o, u), simplemente añade **-s** — igual que en
español:

```
casa → casas           (casa → casas)
livro → livros          (libro → libros)
gato → gatos           (gato → gatos)
```

## Palabras terminadas en -ão: el triple plural

Esta es la parte más particular del portugués. Las palabras en **-ão** pueden formar el
plural de tres maneras:

### 1. -ão → -ões (la mayoría)

```
coração → corações      (corazón → corazones)
avião → aviões          (avión → aviones)
limão → limões          (limón → limones)
opinião → opiniões      (opinión → opiniones)
```

### 2. -ão → -ães (algunas)

```
pão → pães             (pan → panes)
cão → cães             (perro → perros)
capitão → capitães      (capitán → capitanes)
alemão → alemães        (alemán → alemanes)
```

### 3. -ão → -ãos (pocas)

```
mão → mãos             (mano → manos)
irmão → irmãos          (hermano → hermanos)
cidadão → cidadãos      (ciudadano → ciudadanos)
```

No hay una regla infalible para saber cuál de los tres usar. El consejo práctico: **si no
estás seguro, usa -ões** — cubre la mayoría de los casos.

## Palabras terminadas en -al, -el, -ol, -ul

Se elimina la **-l** y se añade **-is**:

```
animal → animais        (animal → animales)
jornal → jornais        (periódico → periódicos)
papel → papéis          (papel → papeles)
hotel → hotéis          (hotel → hoteles)
azul → azuis            (azul → azules)
```

Fíjate en que las terminadas en **-el** llevan acento en la **é** del plural: pap**é**is,
hot**é**is.

## Palabras terminadas en -r o -s (oxítonas)

Se añade **-es**:

```
professor → professores  (profesor → profesores)
flor → flores            (flor → flores)
país → países            (país → países)
```

## Palabras terminadas en -m

La **-m** final se convierte en **-ns**:

```
homem → homens          (hombre → hombres)
viagem → viagens        (viaje → viajes)
jardim → jardins         (jardín → jardines)
```

## Resumen rápido

| Terminación     | Plural             | Ejemplo                 |
| --------------- | ------------------ | ----------------------- |
| vocal (a, e, o) | + s                | casa → casas            |
| -ão             | -ões / -ães / -ãos | coração → corações      |
| -al, -ol, -ul   | -l → -is           | animal → animais        |
| -el             | -l → -éis          | papel → papéis          |
| -r (oxítona)    | + es               | professor → professores |
| -m              | -m → -ns           | homem → homens          |
