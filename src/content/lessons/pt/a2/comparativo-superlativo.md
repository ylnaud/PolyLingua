Comparar es una función comunicativa esencial — y el portugués tiene su propia lógica,
muy cercana al español pero con matices propios.

## Comparativo de superioridad: mais... do que

```
Ela é mais alta do que eu.        (Ella es más alta que yo)
Este livro é mais interessante do que aquele.  (Este libro es más interesante que aquel)
```

## Comparativo de inferioridad: menos... do que

```
Este carro é menos caro do que o outro.  (Este coche es menos caro que el otro)
```

## Comparativo de igualdad: tão... quanto/como

```
Ela é tão inteligente quanto o irmão.   (Ella es tan inteligente como su hermano)
```

## Las formas irregulares

| Adjetivo | Comparativo |
| --- | --- |
| bom (bueno) | melhor |
| mau (malo) | pior |
| grande (grande) | maior |
| pequeno (pequeño) | menor |

```
Este café é melhor do que aquele.       (Este café es mejor que aquel)
```

## El superlativo relativo

```
o/a mais + adjetivo + de

Ela é a mais rápida da equipe.       (Ella es la más rápida del equipo)
```

## El superlativo absoluto (-íssimo)

```
lindo → lindíssimo (bellísimo)
fácil → facílimo (facilísimo, forma irregular)

Este exercício é facílimo!    (¡Este ejercicio es facilísimo!)
```
