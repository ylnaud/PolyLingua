Marina cierra la semana pensando en sus gastos: está ahorrando para un viaje,
así que estas son las frases del dinero que más usa.

## La pregunta que hay que hacer primero

```
Posso pagar com cartão?       ¿Puedo pagar con tarjeta?
— Só dinheiro, por favor.      Solo efectivo, por favor.
```

Igual que en muchos países, conviene preguntarlo **antes** de pedir, no
después.

## Sacar plata

```
Eu preciso sacar dinheiro.        Necesito sacar dinero.
Onde tem um caixa eletrônico?     ¿Dónde hay un cajero automático?
Não tenho dinheiro comigo.        No tengo dinero encima.
```

"Caixa eletrônico" es la palabra brasileña; en Portugal es "caixa
multibanco" — dos nombres para lo mismo.

## Ahorro y gastos

```
Eu estou economizando para uma viagem.    Estoy ahorrando para un viaje.
Quanto eu te devo?                         ¿Cuánto te debo?
```

## Una frase completa

```
Eu preciso sacar dinheiro porque estou economizando para uma viagem.
(Necesito sacar dinero porque estoy ahorrando para un viaje)
```

## El truco para practicar

Memorizá primero **"Posso pagar com cartão?"** — es la que más vas a usar,
como Marina antes de cualquier compra. Después sumale "Eu estou
economizando para ...", que sirve para contar cualquier meta de ahorro.
