Las expresiones impersonales te permiten hablar de reglas generales y necesidades sin
señalar un sujeto específico — muy útiles en instrucciones, consejos y normas.

## La estructura básica

```
É preciso + infinitivo

É preciso estudar todos os dias.       (Hay que estudiar todos los días)
É preciso ter cuidado aqui.             (Hay que tener cuidado aquí)
```

## Con sujeto específico: é preciso que + subjuntivo

```
É preciso que você chegue cedo.        (Es necesario que llegues temprano)
É preciso que todos participem.         (Es necesario que todos participen)
```

## Otras expresiones impersonales similares

| Portugués | Español |
| --- | --- |
| é necessário | es necesario |
| é importante | es importante |
| é possível | es posible |
| é proibido | está prohibido |

```
É proibido fumar aqui.       (Está prohibido fumar aquí)
É importante descansar bem.   (Es importante descansar bien)
```

## Diferencia clave con "tem que" / "precisa"

```
Impersonal:    É preciso estudar.          (regla general, sin sujeto)
Personal:       Você precisa estudar.        (dirigido directamente a ti)
```

Ambas son correctas — la elección depende de si quieres sonar general o directo.
