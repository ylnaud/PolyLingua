Marina termina la semana y le toca hacer un repaso: qué hizo ayer y qué
tiene planeado para mañana. No necesitás tiempos verbales nuevos — con el
pretérito perfecto y el presente que ya conocés alcanza.

## El pasado: pretérito perfecto

```
O que você fez ontem?           ¿Qué hiciste ayer?
Eu trabalhei muito.              Trabajé mucho.
Eu encontrei um amigo.           Me encontré con un amigo.
Ontem eu comi muito.             Ayer comí mucho.
```

## Negar en pasado

```
Eu não fiz nada.                 No hice nada.
```

## El futuro: alcanza con el presente

Para hablar de mañana no hace falta un tiempo especial. Usás el
**presente** y agregás cuándo:

```
Amanhã eu trabalho.              Mañana trabajo.
Semana que vem eu estou de folga.  La semana que viene tengo libre.
```

## Una frase completa

```
Ontem eu trabalhei muito, mas amanhã eu estou de folga.
(Ayer trabajé mucho, pero mañana tengo el día libre)
```

## El truco para practicar

Todas las noches, contá tu día en dos frases con pretérito perfecto y lo de
mañana en una frase en presente — como hizo Marina para cerrar su semana.
Tres frases por día, siempre con la misma estructura.
