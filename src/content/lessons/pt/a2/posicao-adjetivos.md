La posición del adjetivo en portugués sigue una lógica muy parecida al español — y el
mismo tipo de matiz de significado según dónde lo coloques.

## La posición por defecto: después del sustantivo

```
um livro interessante        (un libro interesante)
uma cidade bonita             (una ciudad bonita)
```

## Adjetivos comunes que suelen ir antes

```
um bom amigo         (un buen amigo)
uma pequena casa       (una pequeña casa)
um grande problema      (un gran problema)
```

## Cuando la posición cambia el significado

| Antes (sentido figurado) | Después (sentido literal) |
| --- | --- |
| um grande homem (un gran hombre, admirable) | um homem grande (un hombre grande, de tamaño) |
| um velho amigo (un viejo amigo, de mucho tiempo) | um amigo velho (un amigo anciano, de edad) |
| uma simples pergunta (una simple/mera pregunta) | uma pergunta simples (una pregunta fácil) |

## Ejemplo comparativo

```
Ele é um grande escritor.       (Es un gran escritor — admiración)
Ele é um homem grande.           (Es un hombre grande — tamaño físico)
```

## Un consejo práctico

Cuando dudes, la posición después del sustantivo es siempre segura y neutral. La
posición antes del sustantivo, con matiz figurado, se aprende mejor con exposición a
textos y conversación real que con reglas memorizadas.
