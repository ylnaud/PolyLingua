Las preposiciones de lugar y de tiempo son esenciales para dar direcciones,
describir espacios y organizar planes en portugués.

## Preposiciones de lugar

| Portugués      | Español      |
| -------------- | ------------ |
| em             | en           |
| sobre          | sobre / encima de |
| sob            | debajo de    |
| em frente de   | delante de   |
| atrás de       | detrás de    |
| entre          | entre        |
| perto de       | cerca de     |

```
O livro está sobre a mesa.        (El libro está sobre la mesa)
O gato está sob a cadeira.        (El gato está debajo de la silla)
A farmácia fica entre o banco e o café.  (La farmacia está entre el banco y el café)
```

## Preposiciones de tiempo

Para dar una hora exacta se usa "às" (contracción de "a" + "as"):

```
às 8 horas          (a las 8 horas)
às 10 horas          (a las 10 horas)
```

Para meses y años se usa "em":

```
em janeiro           (en enero)
em 2026               (en 2026)
```

Para hablar de algo en el futuro cercano se usa "daqui a":

```
daqui a três dias      (dentro de tres días)
daqui a uma semana      (dentro de una semana)
```

## Una frase completa

```
A reunião é às 8 horas, em frente do banco.
(La reunión es a las 8 horas, delante del banco)
```
