El condicional portugués sirve para hipótesis, cortesía y para reportar lo que alguien
dijo que haría — funciones muy parecidas al condicional español.

## La formación regular

```
Infinitivo + ia, ias, ia, íamos, íeis, iam

falar → falaria, falarias, falaria, falaríamos, falaríeis, falariam
comer → comeria, comerias, comeria, comeríamos, comeríeis, comeriam
```

## Los mismos tres irregulares del futuro simple

```
fazer → faria       dizer → diria       trazer → traria
```

## Uso 1: hipótesis

```
Se eu tivesse tempo, eu viajaria mais.
(Si tuviera tiempo, viajaría más)
```

## Uso 2: cortesía

```
Eu gostaria de um café.        (Me gustaría un café)
Você poderia me ajudar?          (¿Podrías ayudarme?)
```

## Uso 3: reportar un futuro desde el pasado (futuro do pretérito literal)

```
Ele disse que viria à festa.       (Dijo que vendría a la fiesta)
Ela prometeu que ligaria.           (Ella prometió que llamaría)
```

## Una nota práctica sobre "queria" vs. "quereria"

```
Habla real:    Eu queria um café, por favor.       (imperfecto, tono cortés)
Formal/raro:    Eu quereria um café, por favor.       (condicional literal, poco usado)
```

En la práctica, el imperfecto ("queria", "gostava") a menudo reemplaza al condicional
para pedidos corteses en el habla cotidiana.
