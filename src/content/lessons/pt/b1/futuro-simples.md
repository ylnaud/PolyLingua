El futuro simple morfológico es el registro más formal para hablar del futuro en
portugués — el que verás en textos escritos, discursos y noticias.

## La formación: infinitivo + terminaciones

```
Infinitivo completo + terminación

falar → falarei, falarás, falará, falaremos, falareis, falarão
comer → comerei, comerás, comerá, comeremos, comereis, comerão
partir → partirei, partirás, partirá, partiremos, partireis, partirão
```

## Los tres verbos irregulares clave

| Verbo | Raíz irregular | Ejemplo |
| --- | --- | --- |
| fazer | far- | farei, farás, fará... |
| dizer | dir- | direi, dirás, dirá... |
| trazer | trar- | trarei, trarás, trará... |

## Cuándo se usa (registro formal/escrito)

```
O governo anunciará novas medidas amanhã.       (El gobierno anunciará nuevas medidas mañana)
Este projeto mudará o futuro da cidade.           (Este proyecto cambiará el futuro de la ciudad)
```

## Futuro próximo vs. futuro simple

```
Habla cotidiana:    Vou falar com ela.
Registro formal:      Falarei com ela.
```

## La curiosa mesóclise

```
Dar-lhe-ei o livro amanhã.       (Le daré el libro mañana)
```

Esta estructura, con el pronombre insertado dentro del propio verbo, es gramaticalmente
correcta pero suena muy formal/arcaica — casi nunca se usa en el habla real, ni siquiera
en Portugal.
