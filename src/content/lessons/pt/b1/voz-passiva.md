En portugués, la voz activa pone el foco en quién hace la acción ("O chef prepara a refeição"). La voz pasiva pone el foco en quién o qué la recibe: "A refeição é preparada."

## Cómo se forma

```
sujeito + SER (conjugado) + particípio (+ por + agente)
```

"Ser" lleva el tiempo verbal, y el participio **concuerda en género y número con el sujeto**, como un adjetivo:

| Tiempo               | Activa                          | Pasiva                                     |
| ---------------------- | -------------------------------- | --------------------------------------------- |
| Presente               | O chef prepara a refeição.       | A refeição **é preparada** pelo chef.         |
| Presente (masc.)       | O chef prepara o prato.          | O prato **é preparado** pelo chef.            |
| Pretérito perfeito     | Camões escreveu este poema.      | Este poema **foi escrito** por Camões.        |
| Futuro                 | Vão convidar todos os alunos.    | Todos os alunos **serão convidados**.         |

## Cómo pasar de activa a pasiva

1. El objeto directo de la activa se convierte en el sujeto de la pasiva.
2. "Ser" toma el tiempo del verbo original.
3. El verbo principal pasa a participio, concordando con el nuevo sujeto.
4. El sujeto original se vuelve agente opcional con "por" (contraído: pelo/pela).

```
Eles constroem casas. → As casas são construídas (por eles).
```

## "Por" y sus formas contraídas

"Por" se contrae con el artículo del agente: por + o → **pelo**, por + a → **pela**, por + os → **pelos**, por + as → **pelas**. "A refeição é preparada **pelo** chef", "As casas são construídas **pelos** pedreiros."

## El truco práctico

Antes de conjugar el participio, preguntate: ¿el sujeto de mi frase pasiva es masculino o femenino, singular o plural? El participio siempre lo sigue — como cuando usás un adjetivo común.
