El condicional compuesto expresa lo que habría pasado bajo una condición que, en
realidad, no se cumplió — el terreno del arrepentimiento y la especulación sobre el
pasado.

## La formación

```
teria / terias / teria / teríamos / teríeis / teriam + participio

teria falado         (habría hablado)
teria feito           (habría hecho)
teria ido              (habría ido)
```

## La estructura condicional completa (irreal del pasado)

```
Se + pluscuamperfeito do subjuntivo, + condicional composto

Se eu tivesse estudado, teria passado no exame.
(Si hubiera estudiado, habría aprobado el examen)
```

## Más ejemplos

```
Se ela tivesse me avisado, eu não teria chegado atrasado.
(Si ella me hubiera avisado, no habría llegado tarde)

Se nós tivéssemos mais tempo, teríamos visitado o museu.
(Si hubiéramos tenido más tiempo, habríamos visitado el museo)
```

## El matiz de arrepentimiento

Esta estructura casi siempre implica que la condición NO se cumplió en la realidad — es
terreno del "hubiera sido diferente si...".

```
Eu teria ajudado, se você tivesse pedido.
(Habría ayudado, si me lo hubieras pedido — implícito: no me lo pediste)
```

## Un consejo práctico

Reconoce el par completo (pluscuamperfecto do subjuntivo + condicional composto) como
una unidad — casi siempre aparecen juntos en esta estructura de hipótesis pasada
irreal.
