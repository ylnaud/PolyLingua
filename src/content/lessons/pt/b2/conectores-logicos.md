Los conectores lógicos son las bisagras que permiten construir argumentos elaborados,
esenciales para redacción académica, debates y textos formales.

## Conectores de contraste

| Portugués | Español |
| --- | --- |
| no entanto | sin embargo |
| contudo | no obstante |
| por outro lado | por otro lado |
| mas | pero |

```
Ele estudou muito; no entanto, não passou no exame.
(Estudió mucho; sin embargo, no aprobó el examen)
```

## Conectores de concesión

| Portugués | Español |
| --- | --- |
| apesar de | a pesar de |
| embora | aunque |
| mesmo que | aunque / incluso si |
| ainda que | aunque (más formal) |

```
Apesar da chuva, saímos para caminhar.
(A pesar de la lluvia, salimos a caminar)

Embora ele seja jovem, tem muita experiência.
(Aunque él es joven, tiene mucha experiencia — nota: "embora" pide subjuntivo)
```

## Conectores de adición

| Portugués | Español |
| --- | --- |
| além disso | además |
| também | también |
| não só... mas também | no solo... sino también |

```
O projeto é caro. Além disso, vai demorar meses.
(El proyecto es caro. Además, va a tardar meses)
```

## Construyendo un párrafo argumentativo

```
Muitos acreditam que a tecnologia só traz benefícios. No entanto, também gera novos
desafios. Apesar disso, é inegável que facilitou muitos aspectos da vida moderna.
Além disso, continua evoluindo rapidamente.
```

## Un consejo práctico

Domina primero un conector de cada categoría (no entanto para contraste, apesar de
para concesión, além disso para adición) — con esos tres ya puedes construir
argumentos con estructura clara.
