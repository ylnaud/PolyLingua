El gerundio portugués tiene el mismo uso básico que en español, pero con una diferencia
regional muy marcada que vale la pena conocer desde ya.

## La formación

```
infinitivo - r + ndo

falar → falando       (hablando)
comer → comendo        (comiendo)
partir → partindo       (partiendo)
```

## Uso 1: acción en progreso (con "estar")

```
Brasil:      Eu estou estudando português.
Portugal:    Eu estou a estudar português.
```

Ambas significan exactamente "Estoy estudiando portugués" — pero la construcción es
completamente distinta según el país.

## Uso 2: acción simultánea

```
Ela saiu correndo.       (Ella salió corriendo)
Ele fala rindo.            (Él habla riendo)
```

## Uso 3: modo o manera

```
Aprendi português conversando com nativos.
(Aprendí portugués conversando con nativos)
```

## La tabla de referencia rápida

| Contexto | Brasil | Portugal |
| --- | --- | --- |
| Acción en curso | estou fazendo | estou a fazer |
| Ir haciendo algo | vou fazendo | vou fazendo (igual) |

## Un consejo práctico

Si tu meta principal es el portugués brasileño, practica el gerundio con "estar" desde
el inicio — es la construcción que escucharás constantemente. Si tu meta es Portugal,
acostúmbrate a "estar a + infinitivo" como forma por defecto.
