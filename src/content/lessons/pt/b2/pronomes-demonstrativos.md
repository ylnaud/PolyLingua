En español usamos "este/ese/aquel" casi por instinto, pero en portugués la elección
importa más de lo que parece: cada uno de estos tres pronombres marca una distancia
distinta respecto a quien habla y a quien escucha.

## Las tres zonas de distancia

| Pronombre | Distancia                                 | Ejemplo                              |
| --------- | ------------------------------------------ | -------------------------------------- |
| este      | cerca de quien habla                       | Este livro aqui é meu.                |
| esse      | cerca de quien escucha / ya mencionado     | Esse livro aí, de quem é?             |
| aquele    | lejos de ambos                             | Aquele livro ali, na estante, é raro. |

## Género y número: concuerdan como adjetivos

| Distancia | Masc. sing. | Fem. sing. | Masc. pl. | Fem. pl. |
| --------- | ----------- | ---------- | --------- | -------- |
| este      | este        | esta       | estes     | estas    |
| esse      | esse        | essa       | esses     | essas    |
| aquele    | aquele      | aquela     | aqueles   | aquelas  |

## Las formas neutras: isto, isso, aquilo

Cuando señalás algo sin nombrarlo (sin saber su género, o sin querer especificarlo),
usás la forma neutra correspondiente:

```
O que é isto?     (¿Qué es esto? — algo cerca de mí)
O que é isso?     (¿Qué es eso? — algo cerca de vos)
O que é aquilo?   (¿Qué es aquello? — algo lejos de ambos)
```

## El uso conversacional de "esse"

Además de marcar cercanía al oyente, "esse" tiene un uso muy frecuente para retomar
algo que ya se mencionó en la conversación, sin importar la distancia física:

```
— Comprei um carro novo.
— Esse carro é automático?
(ese carro que acabás de mencionar, no uno que esté físicamente cerca)
```

## Las contracciones con preposiciones

Estos pronombres se contraen con "em", "de" y "por", algo que vas a ver todo el tiempo
en textos y conversación:

```
em + este → neste       de + esse → desse       em + aquele → naquele
```

## Truco práctico

Pensá en tu propia mano (este), la mano de tu interlocutor (esse) y el horizonte
(aquele) — esa imagen mental resuelve el 90% de los casos.
