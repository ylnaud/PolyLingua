Cuando el posesivo reemplaza completamente al sustantivo, funciona como un pronombre
independiente — y el artículo se vuelve casi obligatorio.

## La estructura: artículo + posesivo (sin sustantivo)

```
Meu carro é azul. O seu é vermelho.
(Mi coche es azul. El tuyo/suyo es rojo.)

Esta é a minha casa. Aquela é a sua.
(Esta es mi casa. Aquella es la tuya/suya.)
```

## Tabla completa como pronombre independiente

| Poseedor | Masculino | Femenino |
| --- | --- | --- |
| eu | o meu | a minha |
| tu | o teu | a tua |
| você/ele/ela | o seu | a sua |
| nós | o nosso | a nossa |

## Comparaciones con posesivos

```
A casa dela é maior do que a minha.
(La casa de ella es más grande que la mía)

Meus pais são mais velhos do que os seus.
(Mis padres son mayores que los tuyos/suyos)
```

## Aclarando la ambigüedad de "seu/sua"

```
O carro é o seu (dela).       (El coche es el suyo — de ella)
```

## Una expresión idiomática común

```
Cada um na sua.       (Cada uno a lo suyo)
```

Un uso fijo e idiomático del posesivo independiente, muy común en conversación
cotidiana en ambos países.
