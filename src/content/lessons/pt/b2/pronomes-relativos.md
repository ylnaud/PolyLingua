Los pronombres relativos son la herramienta que separa el portugués de principiante
("Tenho um amigo. Ele mora em Lisboa.") del portugués fluido ("Tenho um amigo que mora em
Lisboa.").

## "que": el pronombre que hace casi todo el trabajo

Al igual que en italiano, "que" funciona para sujeto y objeto directo, personas y cosas:

| Función | Ejemplo |
| --- | --- |
| Sujeto | A mulher que fala é minha irmã. |
| Objeto directo | O filme que eu vi era ótimo. |

## "quem": solo para personas, después de preposición

```
A pessoa com quem eu falei...    (la persona con quien hablé)
O amigo a quem escrevi...         (el amigo a quien escribí)
```

## "cujo/cuja/cujos/cujas": el pronombre posesivo que sorprende

Este es el verdadero reto: "cujo" significa "cuyo", pero **concuerda con lo que sigue**,
no con el poseedor:

```
o autor cujo LIVRO ganhou um prêmio     (livro es masculino → cujo)
a autora cuja HISTÓRIA emocionou todos   (história es femenino → cuja)
```

## "onde": lugar

```
A cidade onde eu nasci é linda.    (la ciudad donde nací es bonita)
```

## Combinándolos en una frase natural

```
Esta é a casa    onde    cresci,    cujo    jardim    eu adorava,    e    que    sinto falta.
(esta es la casa donde crecí, cuyo jardín adoraba, y que extraño)
```

Cuantos más pronombres relativos domines con soltura —especialmente el traicionero
"cujo"—, menos frases cortas y entrecortadas tendrás: justo el salto de calidad que
define el nivel B2.
