Igual que en español, el portugués usa la voz pasiva cuando el **qué pasó** importa más
que el **quién lo hizo** — y la lógica te va a resultar muy familiar.

## La fórmula base

```
ser (conjugado)  +  particípio (concordando con el sujeto)
```

| Tiempo | Ejemplo |
| --- | --- |
| Presente | A casa é construída. (La casa es construida) |
| Pretérito | A casa foi construída. (La casa fue construida) |
| Futuro | A casa será construída. (La casa será construida) |

## Transformar activa → pasiva

1. El objeto directo de la activa se convierte en sujeto de la pasiva
2. El verbo se transforma en "ser + particípio"
3. El agente (si se menciona) se introduce con "por"

```
Ativa:    Machado de Assis    escreveu    este livro.
Passiva:  Este livro          foi escrito    por Machado de Assis.
```

## La concordancia: siempre presente

Como en la voz pasiva el auxiliar siempre es "ser", el participio **siempre concuerda**
en género y número con el sujeto:

```
O livro é lido.              (masculino singular)
A carta é lida.              (femenino singular)
Os livros são lidos.         (masculino plural)
As cartas são lidas.         (femenino plural)
```

## Una alternativa muy portuguesa: la voz pasiva con "se"

El portugués usa con mucha frecuencia una pasiva más informal con el pronombre "se",
especialmente cuando no importa quién hizo la acción:

```
Vende-se casas.          (Se venden casas — más natural que "Casas são vendidas")
Fala-se português aqui.  (Se habla portugués aquí)
```

Esta forma con "se" es, en el portugués cotidiano, incluso más común que la pasiva
formal con "ser" — vale la pena reconocerla y usarla.
