El pretérito imperfeito do subjuntivo es la puerta de entrada a las hipótesis
elaboradas y a un registro más elegante y preciso del portugués.

## La formación: un atajo universal

```
3ª persona plural del pretérito perfeito, quitar "-am", añadir terminaciones

falaram → falasse, falasses, falasse, falássemos, falásseis, falassem
fizeram → fizesse, fizesses, fizesse, fizéssemos, fizésseis, fizessem
foram → fosse, fosses, fosse, fôssemos, fôsseis, fossem
```

Este atajo funciona incluso para los verbos más irregulares del idioma.

## Uso 1: condicionales hipotéticas irreales

```
Se eu tivesse mais tempo, viajaria pelo mundo.
(Si tuviera más tiempo, viajaría por el mundo)

Se ela soubesse a verdade, ficaria chateada.
(Si ella supiera la verdad, se molestaría)
```

## Uso 2: deseos poco probables

```
Quem me dera que fosse mais fácil.
(Ojalá fuera más fácil)
```

## Uso 3: cortesía elevada

```
Se você pudesse me ajudar, eu agradeceria muito.
(Si pudiera ayudarme, se lo agradecería mucho)
```

## Comparación con el futuro do subjuntivo

```
Futuro (posible/probable):    Se eu tiver dinheiro, viajarei.
Imperfeito (hipotético/irreal):  Se eu tivesse dinheiro, viajaria.
```

La diferencia clave: el futuro do subjuntivo trata la condición como realista/posible;
el imperfeito la trata como hipotética o contraria a la realidad actual.

## Un consejo práctico

Memoriza primero el patrón de derivación (3ª plural del perfeito → quitar "-am" →
añadir terminaciones) — una vez internalizado, puedes generar el imperfeito do
subjuntivo de cualquier verbo, sin importar cuán irregular sea.
