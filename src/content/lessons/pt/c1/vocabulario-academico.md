El registro académico portugués sigue convenciones muy específicas de vocabulario y
estructura — esenciales si planeas estudiar o publicar en portugués.

## Fórmulas de introducción

```
O presente trabalho tem como objetivo...     (El presente trabajo tiene como objetivo...)
Este estudo busca analisar...                  (Este estudio busca analizar...)
Conforme apresentado a seguir...                (Según se presenta a continuación...)
```

## La preferencia por la voz pasiva

```
Voz activa (menos formal):    Analisamos os dados coletados.
Voz pasiva (más académica):    Os dados coletados foram analisados.
```

## Construcciones nominalizadas

```
Verbal (más directo):    Concluímos que o método funciona.
Nominal (más formal):     A conclusão é de que o método é eficaz.
```

## Fórmulas de conclusión

```
Conclui-se, portanto, que...     (Se concluye, por lo tanto, que...)
Os resultados indicam que...       (Los resultados indican que...)
```

## Un consejo práctico

Lee artículos académicos reales en portugués (disponibles gratis en repositorios como
SciELO, muy usado en Brasil y Portugal) para absorber el ritmo y las fórmulas fijas de
este registro — es mucho más eficaz que memorizar listas aisladas.
