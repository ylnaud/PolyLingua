## La nominalización: el sello del portugués formal

Convertir verbos en sustantivos abstractos es la técnica más característica del estilo
formal:

| Verbo (registro neutro) | Sustantivo (registro formal) |
| --- | --- |
| decidir | a decisão |
| analisar | a análise |
| aumentar | o aumento |
| implementar | a implementação |

```
Neutro:    O governo decidiu aumentar os impostos.
Formal:    A decisão do governo de aumentar os impostos gerou debates.
```

## Conectores formales vs. cotidianos

| Cotidiano | Formal |
| --- | --- |
| mas | contudo / no entanto |
| porque | uma vez que / visto que |
| mesmo assim | não obstante |
| muito | consideravelmente |

## Vocabulario elevado

| Cotidiano | Formal |
| --- | --- |
| mostrar | demonstrar / evidenciar |
| ajudar | contribuir para |
| dizer | afirmar / sustentar |

## Cuándo usarlo (y cuándo evitarlo)

El estilo formal es perfecto para ensayos, informes, discursos y textos periodísticos
serios. Usarlo en una conversación casual con amigos sonaría tan extraño como hablar en
tono de discurso oficial en un bar — el verdadero dominio del C2 está en saber **cuándo**
activar este registro, no solo en saber usarlo.
